# 빠른 시작

Juxi Technology 제품에 오신 것을 환영합니다! 이 튜토리얼은 제품 사용을 빠르게 시작하도록 도와드립니다.

## 준비 사항

시작 전에 다음을 준비하세요:

- 제품 하드웨어
- USB 케이블
- PC(Windows/macOS/Linux)

## 1단계: 하드웨어 연결

1. 제품을 USB 케이블로 PC에 연결
2. 드라이버 자동 설치 대기
3. 장치가 올바르게 인식되었는지 확인

## 2단계: 소프트웨어 설치

```bash
# 의존성 설치
npm install

# 앱 실행
npm start
```

## 3단계: 사용 시작

이제 제품을 사용할 수 있습니다! 자세한 기능은 다른 튜토리얼을 참고하세요.
