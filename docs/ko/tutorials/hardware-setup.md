# 하드웨어 연결

제품의 하드웨어 연결 방법을 자세히 설명합니다.

## 인터페이스

제품에는 다음 인터페이스가 있습니다:

- USB-C: 전원 및 데이터 전송
- GPIO: 범용 입출력
- HDMI: 영상 출력

## 연결 절차

1. **전원 연결**: USB-C 케이블로 전원 연결
2. **주변기기 연결**: 필요에 따라 연결
3. **전원 켜기**: 전원 버튼으로 시작

## 주의사항

- 전원 전압이 규격 범위인지 확인
- 전원이 켜진 상태에서 GPIO 장치를 꽂지 말 것
