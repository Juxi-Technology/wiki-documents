## 공식 저장소 예제

Juxi Technology는 AmazingHand용 오픈소스 제어 코드를 제공합니다: [GitHub](https://github.com/Juxi-Technology/AmazingHand)

### 기본 제어

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
