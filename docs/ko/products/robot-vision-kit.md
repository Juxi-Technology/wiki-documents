# SO-ARM101 로봇 비전 키트

> **[스토어에서 구매](https://www.juxitech.com/ko/products/so-arm101-wrist-camera-mount)**

## 제품 개요

**주요 특징**:

- 3가지 설치 위치: **손목 / 측면 / 탑뷰**
- 듀얼 카메라 선택: 60FPS 고정 초점(빠른 동작 캡처) / 30FPS 자동 초점 줌(유연한 비전 개발)
- SO-ARM101 완전 매칭, 추가 수정 불필요
- 미끄럼 방지 그립 패드 포함

## 제품 사양

| 항목 | 사양 |
|------|------|
| 호환 플랫폼 | SO-ARM101, LeKiwi, XLerobot, M3 장착 홀 호환 플랫폼 |
| 설치 위치 | 손목 / 측면 / 탑뷰 |
| 카메라 선택 | 60FPS 고정 초점 / 30FPS 자동 초점 줌 |
| 훈련 프레임워크 호환 | ACT, Smolvla, Pi0, Pi0.5, GR00T N1.5 |

## 빠른 시작

- **손목**: 파지 조작 시점(파지 작업 권장)
- **측면**: 전체 환경 시점
- **탑뷰**: 데스크톱 조작의 탑뷰 시점(데이터 수집에 적합)
