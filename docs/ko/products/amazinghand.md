# AmazingHand 오픈소스 로봇 손

> **[스토어에서 구매](https://www.juxitech.com/ko/products/amazinghand)**

## 개요

5지 다관절 바이오닉 로봇 손. TTL 직렬 버스 제어, 오픈 CAD로 커스텀 손가락 설계 지원.

## 사양

| カテゴリ | 仕様 |
|------|------|
| 유형 | 5지 다관절 로봇 손 |
| 제어 | TTL 직렬 버스 |
| 에코시스템 | Python SDK, ROS |
| 오픈소스 | CAD/소스 공개 |

## 빠른 시작

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
