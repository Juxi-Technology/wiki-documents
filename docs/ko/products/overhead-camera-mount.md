# SO-ARM101 오버헤드 카메라 마운트

> **[스토어에서 구매](https://www.juxitech.com/ko/products/overhead-camera-mount-for-so-arm100-so-arm101-realsense-compatible)**

## 제품 개요

**주요 특징**:

- 탑뷰 시점 설치
- RealSense / USB 카메라 호환
- SO-ARM100/101 매칭
- 간편한 설치

## 제품 사양

| 항목 | 사양 |
|------|------|
| 시점 | 탑뷰(top-down) |
| 호환 | RealSense / USB 카메라 |
| 플랫폼 | SO-ARM100/101 |

## 빠른 시작

1. 마운트를 SO-ARM 장착 지점에 고정
2. 카메라 장착(RealSense 또는 USB)
3. 호스트에 연결, `python -m lerobot.find_cameras`로 인식 확인
