# SO-ARM101 오버헤드 카메라 마운트

> **[스토어에서 구매](https://www.juxitech.com/ko/products/overhead-camera-mount-for-so-arm100-so-arm101-realsense-compatible)**

## 제품 개요

SO-ARM101 오버헤드 카메라 마운트는 정면 위 시점 설치를 지원하며 RealSense 깊이 카메라와 일반 USB 카메라와 호환됩니다. 로봇 팔 비전 데이터 수집에 사용합니다(정면 위 시점이 LeRobot 훈련 데이터에 유리).

**주요 특징**:

- 정면 위 시점 설치
- RealSense / USB 카메라 호환
- SO-ARM100/101 호환
- 간편한 설치

## 사양

| 카테고리 | 사양 |
|------|------|
| 시점 | 정면 위(top-down) |
| 호환 | RealSense / USB 카메라 |
| 플랫폼 | SO-ARM100/101 |

## 빠른 시작

1. 将支架固定到 SO-ARM 安装点
2. 安装相机(RealSense 或 USB)
3. 连接主控,`python -m lerobot.find_cameras` 确认识别
