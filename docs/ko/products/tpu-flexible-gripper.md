# SO-ARM101 TPU 플렉시블 그리퍼

## 제품 개요

**주요 특징**:

- XLerobot 로봇팔에 직접 장착, 추가 수정 불필요
- 소프트 TPU: 유연, 내마모, 미끄럼 방지, 깨지기 쉬운/불규칙한 물체 안전 파지
- SO-ARM101 암 장착 카메라 브래킷/키트 호환(비전 가이드 파지)
- 나사 직결 고정, 플러그 앤 플레이, 복잡한 배선 불필요
