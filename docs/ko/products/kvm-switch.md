# 4 in 1 KVM 스위치

> **[스토어에서 구매](https://www.juxitech.com/ko/products/4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**

## 제품 개요

**주요 특징**:

- HDMI 다중 장치 전환
- TTL 시리얼(UART) 디버깅
- 블루투스 무선 연결
- USB 도킹 스테이션

## 제품 사양

| 항목 | 사양 |
|------|------|
| 기능 | HDMI 전환 + TTL 시리얼 + 블루투스 + USB HUB |
| 인터페이스 | HDMI / TTL / USB |
| 적용 | PC(Windows/Linux), Jetson |

## 빠른 시작

1. 여러 장치를 KVM의 해당 인터페이스에 연결
2. 버튼/소프트웨어로 표시와 입력 장치 전환
3. TTL 시리얼은 라즈베리파이/Jetson 디버깅에 사용
