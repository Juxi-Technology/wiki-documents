# Connexion matérielle

Guide détaillé de connexion matérielle du produit.

## Interfaces

- USB-C : alimentation et données
- GPIO : entrées/sorties générales
- HDMI : sortie vidéo

## Étapes de connexion

1. **Alimentation** : brancher le câble USB-C
2. **Périphériques** : connecter selon besoin
3. **Mise sous tension** : appuyer sur le bouton

## Précautions

- Vérifier la tension d'alimentation
- Ne pas brancher/débrancher de périphériques GPIO sous tension
