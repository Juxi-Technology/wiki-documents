# Configuration logicielle

Ce chapitre présente la configuration logicielle des produits.

## Prérequis système

- Node.js 18+
- Python 3.10+
- Git

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/Juxi-Technology/your-repo.git
# Entrer dans le répertoire
cd your-repo
# Installer les dépendances
npm install
```

## Fichier de configuration

Modifier `config.json` pour changer la configuration du site :

```json
{
  "port": 3000,
  "language": "zh-CN"
}
```
