# Module vidéo WiFi ESP32-S3

> **[Acheter en boutique](https://www.juxitech.com/fr/products/esp32-s3-wifi-video-module)**

## Présentation du produit

**Caractéristiques principales** :

- Caméra HD 2 MP (1600×1200@30FPS)
- Transmission vidéo WiFi en temps réel en **double mode AP + STA**
- Vision IA : segmentation par seuil de couleur + CNN léger (couleur/visage/QR code)
- Mise à niveau du firmware Type-C en une touche
- Interfaces de communication I2C / UART standard PH2.0

## Spécifications du produit

| Catégorie | Spécification |
|------|------|
| Contrôleur principal | ESP32-S3 (officiel Espressif, double cœur) |
| Caméra | CMOS 2 MP (1600×1200@30FPS) |
| Angle de vue | diagonal 68°, horizontal 49,5° |
| Sans fil | WiFi (double mode BT) AP/STA + antenne à gain élevé |
| Interfaces | Type-C / I2C / UART (PH2.0) |
| Touche fonction | Touche reset + touche programmable |
| Capacité de reconnaissance | Couleur, visage, QR code |

## Démarrage rapide

1. Rechercher et se connecter au hotspot du module depuis un téléphone/PC
2. Ouvrir l'adresse indiquée dans le navigateur pour voir la vidéo en direct
