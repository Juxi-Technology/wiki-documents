## 產品概述

4K 高清 HDMI 採集卡支持 HDMI / Micro HDMI / DP 三種主板接口轉換,通過 USB/Type-C 直連筆記本、PC、手機/平板顯示屏,適用於直播、錄屏、教學演示。

**核心特性**:

- 4K 高清採集
- HDMI / Micro HDMI / DP 接口兼容
- USB / Type-C 即插即用
- OBS / PotPlayer 主流軟件支持

## 快速開始

1. 按主板接口選擇接線方式(HDMI / Micro HDMI / DP 轉接)
2. 連接採集器 USB 到顯示端
3. OBS / PotPlayer 中選擇採集設備即可
