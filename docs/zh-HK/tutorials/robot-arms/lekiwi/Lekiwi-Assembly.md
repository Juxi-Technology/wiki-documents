# 五、安裝攝像頭

*注意：我們設計的支架是專爲我們選擇的相機設計的。對於不同的相機模塊，可能需要進行修改。*

## （選項 1）安裝前視攝像頭

使用 3個 m3\*12機螺釘 和 三顆m3螺母 安裝前視攝像頭支架到底板上



使用 4個 m2\*5\*5墊片螺絲固定攝像頭模組



## （選項 2）安裝臂載攝像頭



使用 4個 m2\*5\*5墊片螺絲固定攝像頭模組
