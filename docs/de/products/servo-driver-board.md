# JUXI-Bus-Servo-Treiberplatine

> **[Im Shop kaufen](https://www.juxitech.com/de/products/bus-servo-driver-board)**

## Produktübersicht

**Hauptmerkmale**:

- Bis zu **253** Serienbus-Servos an einem Bus
- **7–12,6 V** Breitspannungseingang, integrierte Stromversorgung (DC-5521-Buchse)
- Echtzeit-Feedback: Position, Geschwindigkeit, Drehmoment, Betriebsmodus
- **Type-C Plug-and-Play**, kompatibel mit Raspberry Pi/Jetson/RDK/PC
- Präzise Bohrungen, direkte Montage an SO-ARM100/101 in 2 Minuten
- TVS-Schutzschaltung (Überspannungs-/Überstromschutz)

## Produktspezifikationen

| Kategorie | Spezifikation |
|------|------|
| Eingangsspannung | DC 7 V – 12,6 V |
| Schnittstellen | USB Type-C / UART |
| Servo-Unterstützung | bis zu 253 Serienbus-Servos |
| Datenfeedback | Position, Geschwindigkeit, Drehmoment, Betriebsmodus |
| Platinengröße | 42,00 × 33,00 mm |
| Bohrungsabstand | 37,00 × 28,00 mm (passend zu SO-ARM) |
| Kompatible Servos | die meisten gängigen Serienbus-Servos |
| Kompatible Hosts | Raspberry Pi, NVIDIA Jetson (Nano/Orin/Xavier), RDK, PC (Win/macOS/Linux), Orange Pi |
