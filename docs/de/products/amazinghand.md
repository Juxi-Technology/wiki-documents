# AmazingHand Robotikhand

> **[Im Shop kaufen](https://www.juxitech.com/de/products/amazinghand)**

## Überblick

Bionische 5-Finger-Mehrgelenk-Robotikhand. TTL-Serial-Bussteuerung, offenes CAD für individuelle Fingerdesigns.

## Spezifikationen

| カテゴリ | 仕様 |
|------|------|
| Typ | 5-Finger-Mehrgelenk-Hand |
| Steuerung | TTL-Serial-Bus |
| Ökosystem | Python SDK, ROS |
| Open Source | CAD/Quellcode offen |

## Schnellstart

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
