# Feetech-Bus-Servo (SCS0009 / STS3215)

> **[Im Shop kaufen](https://www.juxitech.com/de/products/feetech-scs0009-serial-bus-servo)**

## Produktübersicht

**Hauptmerkmale**:

- Serienbus-Kommunikation, mehrere Servos an einem Bus
- Magnetencoder- (STS) / Potentiometer-Version (SCSCL)
- Echtzeit-Feedback für Position/Geschwindigkeit/Drehmoment
- Vollständige Dokumentation zur Speichertabelle
- FD-Host-Debugging (Windows)
