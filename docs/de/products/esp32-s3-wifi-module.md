# ESP32-S3-WiFi-Videomodul

> **[Im Shop kaufen](https://www.juxitech.com/de/products/esp32-s3-wifi-video-module)**

## Produktübersicht

**Hauptmerkmale**:

- 2-MP-HD-Kamera (1600×1200@30FPS)
- **AP + STA-Dualmodus** WiFi-Echtzeit-Videoübertragung
- KI-Vision: Farbschwellen-Segmentierung + leichtes CNN (Farbe/Gesicht/QR-Code)
- Type-C-Firmware-Upgrade per Knopfdruck
- Standard-PH2.0-I2C-/UART-Schnittstellen

## Produktspezifikationen

| Kategorie | Spezifikation |
|------|------|
| Hauptcontroller | ESP32-S3 (Espressif offiziell, Dual-Core) |

## Schnellstart

1. Hotspot des Moduls mit Handy/PC suchen und verbinden
2. Im Browser die angegebene Adresse öffnen und das Live-Video prüfen
