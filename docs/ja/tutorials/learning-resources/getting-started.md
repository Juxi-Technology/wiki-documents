# クイックスタート

JUXI 製品へようこそ！本チュートリアルは製品をすぐに使い始めるためのガイドです。

## 準備

始める前に、以下のものを準備してください：

- 製品ハードウェア
- USB データケーブル
- パソコン（Windows/macOS/Linux）

## ステップ1：ハードウェアの接続

1. 製品を USB データケーブルでパソコンに接続
2. デバイスドライバの自動インストールを待つ
3. デバイスが正しく認識されていることを確認

## ステップ2：ソフトウェアのインストール

```bash
# 依存関係のインストール
npm install
# アプリの起動
npm start
```

## ステップ3：使い始める

これで製品を使い始められます！詳しい機能は他のチュートリアルをご覧ください。
