# ソフトウェア設定

本章では製品のソフトウェア設定方法を紹介します。

## システム要件

- Node.js 18+
- Python 3.10+
- Git

## インストール手順

```bash
# リポジトリをクローン
git clone https://github.com/Juxi-Technology/your-repo.git
# ディレクトリに移動
cd your-repo
# 依存関係のインストール
npm install
```

## 設定ファイル

`config.json` を編集してサイト設定を変更します：

```json
{
  "port": 3000,
  "language": "zh-CN"
}
```
