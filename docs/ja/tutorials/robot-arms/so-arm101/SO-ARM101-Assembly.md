# Lerobot ロボットアーム組立ガイド

**Pro版:主動腕(リーダー)は 5V6A 電源アダプタ、從動腕(フォロワー)は 12V5A 電源アダプタを使用**

サーボID設定・角度キャリブレーション・組立は事前に実施してください。[公式組立ガイド](https://huggingface.co/docs/lerobot/so101) を参照。

## ステップ1: サーボID設定、サーボホーン取付(5番を除く)

**注意**: サーボ関節IDとギア比は **SO-ARM101** と厳密に対応させること。

バス上の各モーターには一意のIDが必要です(新品はデフォルト `1`)。また通信速度(ボーレート)は 100000 に設定します。

### Windows

[飛特サーボ上位機.zip] を使用してサーボID(1〜6)を設定し、中位をキャリブレーションします。

### Linux/Ubuntu

```
lerobot-setup-motors \\
    --robot.type=so101_follower \\
    --robot.port=/dev/ttyACM0
```

プロンプトの指示に従い、gripper サーボから順に接続して ID(6→1)を設定します:

```
'gripper' motor id set to 6
```

各サーボについて、**必ず 1 台だけ**を接続した状態で操作してください。全ステップ完了後、ID 1 のサーボから 3 ピンケーブルを順に接続します。

主動腕(リーダー)にも同様の手順を実行:

```
lerobot-setup-motors \\
    --teleop.type=so101_leader \\
    --teleop.port=/dev/ttyACM0
```

## ステップ2: 組立

從動腕の組立は主動腕とほぼ同じです(12歩目以降、エンドエフェクタの取付が異なります)。

サーボドライバボード: 銅スタンド 4 本 → M2.5*8 ネジ 4 本で固定します。
