# クイックスタート

Juxi Technology 製品へようこそ!このチュートリアルは製品のクイックスタートを支援します。

## 準備

始める前に以下をご用意ください:

- 製品ハードウェア
- USB ケーブル
- PC(Windows/macOS/Linux)

## ステップ 1: ハードウェア接続

1. 製品を USB ケーブルで PC に接続
2. ドライバの自動インストールを待つ
3. デバイスが正しく認識されたことを確認

## ステップ 2: ソフトウェアインストール

```bash
# 依存関係のインストール
npm install

# アプリ起動
npm start
```

## ステップ 3: 使用開始

これで製品を使い始められます!詳細は他のチュートリアルを参照してください。
