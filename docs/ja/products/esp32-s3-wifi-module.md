# ESP32-S3 WiFi 映像モジュール

> **[ストアで購入](https://www.juxitech.com/ja/products/esp32-s3-wifi-video-module)**

## 製品概要

**主な特長**：

- 200万画素高解像度カメラ（1600×1200@30FPS）
- **AP + STA デュアルモード** WiFi リアルタイム映像伝送
- AI ビジョン：色閾値分割 + 軽量 CNN（色/顔/QRコード認識）
- Type-C ワンタッチファームウェアアップグレード
- 標準 PH2.0 I2C / UART 通信インターフェース

## 製品仕様

| カテゴリ | 仕様 |
|------|------|
| 主制御チップ | ESP32-S3（Espressif 公式、デュアルコア） |
| カメラ | 200万画素 CMOS（1600×1200@30FPS） |
| 視野角 | 対角 68°、水平 49.5° |
| 無線 | WiFi（BT デュアルモード）AP/STA + 高利得アンテナ |
| インターフェース | Type-C / I2C / UART（PH2.0） |
| 機能キー | リセットキー + プログラム可能カスタムキー |
| 認識能力 | 色、顔、QRコード |

## クイックスタート

1. スマホ/PC でモジュールのホットスポットを検索して接続
2. ブラウザで指定アドレスを開きリアルタイム映像を確認
