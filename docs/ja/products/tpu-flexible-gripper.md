# SO-ARM101 TPU フレキシブルグリッパー

> **[ストアで購入](https://www.juxitech.com/ja/products/so-arm101-tpu-flexible-gripper)**

## 製品概要

この SO-ARM101 TPU フレキシブルグリッパーは XLerobot ロボットアーム専用設計で、SO-ARM101 アーム搭載カメラマウント/キットの取り付けに対応。柔らかい **TPU 素材**により、不規則で壊れやすい物体を損傷なく把持できます。オプションのカメラ構成(ズーム 30FPS / 固定焦点 60FPS)と組み合わせて、ロボット把持開発やビジョンガイド応用に対応します。

**主な特長**:

- XLerobot ロボットアームに直接取付、追加改造不要
- ソフト TPU:柔軟、耐摩耗、滑り止め、壊れやすい/不規則な物体を安全に把持
- SO-ARM101 アーム搭載カメラマウント/キット互換(ビジョンガイド把持)
- ネジ直結固定、プラグアンドプレイ、複雑な配線不要

### ビジョン把持開発

アーム搭載カメラと LeRobot フレームワークを併用:

```bash
# 录制视觉抓取数据
lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \
  --robot.cameras='{ front: {type: opencv, index_or_path: 0} }' \
  --dataset.repo_id=juxi/gripper_test \
  --dataset.num_episodes=50
```
## よくある質問

**Q: なぜ不規則/壊れやすい物体も把持できるの?**
TPU フレキシブル素材が物体の形状に適応し、均等に力を加えるため、把持物へのダメージを効果的に防ぎます。

**Q: カメラの選び方は?**
- ズーム 30FPS:焦点距離が柔軟、変距ビジョンに適
- 固定焦点 60FPS:高フレームレート、高速モーションキャプチャに適

**Q: 対応プラットフォームは?**
SO-ARM101 / XLerobot ロボットアームシリーズ。ACT、Smolvla、Pi0 などの LeRobot トレーニングフレームワークと互換。
