# AmazingHand 开源灵巧手

> **[在商店购买](https://www.juxitech.com/zh-hans/products/amazinghand)**

## 产品概述

AmazingHand 是钜犀科技开源的仿生灵巧手,5 指多关节设计,支持 TTL 串行总线控制。开源 CAD 文件可自由修改手指设计,广泛用于灵巧操作、抓取策略、人机交互研究。

**核心特性**:

- 5 指多关节,类人手比例
- TTL 串行总线控制,与主流主控兼容
- 开源 CAD/源码,支持定制改装
- 与 SO-ARM101 组合构建完整操作平台

## 快速开始

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
