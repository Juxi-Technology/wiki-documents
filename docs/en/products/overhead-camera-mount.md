## Overview

The SO-ARM101 overhead camera mount provides a top-down view, compatible with RealSense depth cameras and standard USB cameras. Ideal for robot vision data collection (top-down view benefits LeRobot training data).

**Key features**:

- Top-down mounting
- RealSense / USB camera compatible
- SO-ARM100/101 matched
- Easy installation

## Specifications

| Category | Spec |
|----------|------|
| View | Top-down |

| Platform | SO-ARM100/101 |

## Quick Start

1. Mount bracket to SO-ARM mounting points
2. Install camera (RealSense or USB)
3. Connect host, confirm with `python -m lerobot.find_cameras`
