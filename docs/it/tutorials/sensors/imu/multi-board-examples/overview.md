# Casi di comunicazione multi-host

## Note

1. Installare il driver CH341 (come amministratore)

https://www.wch.cn/downloads/CH341SER_EXE.html

Se nel gestore dispositivi del PC compare un dispositivo sconosciuto usb single serial o usb serial, disinstallarlo prima (tasto destro) e poi installare il driver!
