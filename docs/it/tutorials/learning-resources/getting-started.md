# Guida rapida

Benvenuto da JUXI! Questo tutorial ti aiuta a iniziare rapidamente con i nostri prodotti.

## Preparazione

Prima di iniziare, prepara:

- L'hardware del prodotto
- Un cavo dati USB
- Un computer (Windows/macOS/Linux)

## Passo 1: Collegare l'hardware

1. Collegare il prodotto al computer tramite il cavo USB
2. Attendere l'installazione automatica del driver
3. Verificare che il dispositivo sia riconosciuto correttamente

## Passo 2: Installare il software

```bash
# Installare le dipendenze
npm install
# Avviare l'app
npm start
```

## Passo 3: Iniziare a usare

Ora puoi usare il prodotto! Consulta gli altri tutorial per maggiori dettagli.
