# Modulo video WiFi ESP32-S3

> **[Acquista nel negozio](https://www.juxitech.com/it/products/esp32-s3-wifi-video-module)**

## Panoramica del prodotto

**Caratteristiche principali**:

- Fotocamera HD 2 MP (1600×1200@30FPS)
- Trasmissione video WiFi in tempo reale in **doppia modalità AP + STA**
- Visione IA: segmentazione a soglia di colore + CNN leggera (colore/volto/QR code)
- Aggiornamento firmware Type-C con un tocco
- Interfacce di comunicazione I2C / UART standard PH2.0

## Specifiche del prodotto

| Categoria | Specifica |
|------|------|
| Controller principale | ESP32-S3 (ufficiale Espressif, dual-core) |
| Fotocamera | CMOS 2 MP (1600×1200@30FPS) |
| Angolo di campo | diagonale 68°, orizzontale 49,5° |
| Wireless | WiFi (doppia modalità BT) AP/STA + antenna ad alto guadagno |
| Interfacce | Type-C / I2C / UART (PH2.0) |
| Tasto funzione | Tasto reset + tasto personalizzabile programmabile |
| Capacità di riconoscimento | Colore, volto, QR code |

## Guida rapida

1. Cercare e connettersi all'hotspot del modulo da telefono/PC
2. Aprire l'indirizzo indicato nel browser per vedere il video in diretta
