# Kit visione robotica SO-ARM101

> **[Acquista nel negozio](https://www.juxitech.com/it/products/so-arm101-wrist-camera-mount)**

## Panoramica del prodotto

**Caratteristiche principali**:

- Tre posizioni di montaggio: **polso / laterale / dall'alto**
- Scelta di due fotocamere: fuoco fisso 60FPS (cattura di movimenti rapidi) / zoom autofocus 30FPS (sviluppo visione flessibile)
- Perfetta compatibilità con SO-ARM101, nessuna modifica
- Pad di presa antiscivolo inclusi

## Specifiche del prodotto

| Categoria | Specifica |
|------|------|
| Piattaforme compatibili | SO-ARM101, LeKiwi, XLerobot, M3 (fori di montaggio) |
| Posizione di montaggio | Polso / laterale / dall'alto |
| Scelta fotocamera | Fuoco fisso 60FPS / zoom autofocus 30FPS |
| Framework di training | ACT, Smolvla, Pi0, Pi0.5, GR00T N1.5 |

## Guida rapida

- **Polso**: vista di presa (consigliato per compiti di presa)
- **Laterale**: vista globale dell'ambiente
- **Dall'alto**: vista dall'alto della scrivania (adatta alla raccolta dati)
