# 硬件设置

本章节详细介绍产品的硬件连接方法。

## 接口说明

产品包含以下接口：

- USB-C：电源和数据传输
- GPIO：通用输入输出接口
- HDMI：视频输出

## 连接步骤

1. **连接电源**：使用 USB-C 数据线连接电源
2. **连接外设**：根据需要连接其他外设
3. **开机启动**：按下电源按钮启动设备

## 注意事项

- 确保电源电压符合要求
- 避免在通电状态下插拔 GPIO 设备
