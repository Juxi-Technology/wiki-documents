## 硬件连接

### 步骤 1：安装舵机与云台支架

1. 将1号舵机（用于左右转动）安装在云台底部支架的指定位置，固定螺丝确保稳固
2. 将2号舵机（用于上下俯仰）安装在云台的上部支架，同样固定好
3. 按说明安装好摄像机固定结构

### 步骤 2：舵机与驱动板连接

1. 将两个舵机的数据线连接到驱动板的舵机接口
2. 注意舵机线的连接顺序，颜色一般为红（电源）、黑（地线）、白/黄（信号）
3. 确保舵机连接对应ID：舵机ID 1 为左右，舵机ID 2 为上下

### 步骤 3：电源与串口连接

1. 将舵机电源连接到驱动板的电源接口
2. 使用串口数据线连接驱动板与计算机的USB接口
3. 连接摄像头到计算机

## 驱动与依赖安装

### 安装串口驱动

#### Windows

1. 访问 CH343 芯片厂商官网，下载对应 Windows 版本的驱动安装程序
CH343驱动安装（以管理员身份安装）
https://www.wch.cn/downloads/CH343SER_EXE.html

>
> 若在设备管理器被识别成未知设备usb single serial 或usb serial，请先右键卸载，再安装驱动！

1. 运行安装程序，按提示完成驱动安装
2. 连接舵机驱动板到计算机，设备管理器中应能看到串口设备

#### Linux

大多数 Linux 发行版已内置 CH343 串口驱动，无需额外安装。如遇问题，可尝试：
1. 检查内核是否已加载驱动 `lsmod | grep ch343`
2. 如未加载，尝试重新插拔设备或重启

### 安装 Python依赖

在项目根目录下运行：

```python
pip install -r requirements.txt
```

项目主要依赖项包括：
- opencv-python：图像采集与处理
- numpy：数值计算库
- pyserial：串口通信库

## 验证硬件连接

在启动正式程序之前，我们可以使用工具进行硬件连接验证。

### 查找可用摄像头

运行以下命令列出可用摄像头：

```python
python examples/list_cameras.py
```

程序将检测并列出所有可用摄像头，记录下你需要使用的摄像头索引。

### 查找可用串口

运行以下命令列出可用串口：

```python
python examples/list_ports.py
```

记录下你所使用的串口设备名称。

### 硬件诊断

如需要对整体硬件进行全面检测，可以运行诊断工具：

```python
python examples/diagnostic.py --camera 0 --port COM3
```

诊断程序将依次测试摄像头、串口和云台。

## 安全提示

在使用过程中，请注意以下安全事项：
1. 舵机电源需在规定范围内（4V-7.4V），防止损坏舵机
2. 避免舵机长时间工作在极限位置，以延长使用寿命
3. 断电前建议先将云台回中，减轻下次启动负载
