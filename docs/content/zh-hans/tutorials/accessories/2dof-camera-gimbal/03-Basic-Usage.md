# 基础使用

> **[ 淘宝店铺 ](https://juxitechnology.taobao.com)**

本章节详细介绍云台的基本控制方法与使用流程，帮助用户熟悉基础操作。

---

## 控制方式概述

云台系统支持两种主要控制方式：
1. 键盘控制：通过键盘按键手动控制云台运动
2. 自动追踪：系统自动识别并追踪目标

---

## 键盘控制

### 键盘快捷键说明

以下是主程序中可使用的键盘快捷键：

|按键|功能说明|
|---|---|
|方向键 ←|云台向左转动|
|方向键 →|云台向右转动|
|方向键 ↑|云台向上俯仰|
|方向键 ↓|云台向下俯仰|
|C|连接或断开云台|
|R|云台回中（回到初始位置）|
|1|切换到人脸追踪模式|
|2|切换到颜色追踪模式|
|T|锁定/开始追踪目标|
|S|停止追踪|
|X|颜色模式：追踪红色物体|
|Y|颜色模式：追踪绿色物体|
|Z|颜色模式：追踪蓝色物体|
|Q|退出程序|


### 独立的键盘控制示例

你也可以使用单独的键盘控制程序进行练习：

```python
python examples/keyboard_control.py --port COM3
```

此程序仅提供基础的云台控制功能，适合初学者上手。

## 基础操作流程

### 启动与连接

1. 使用以下命令启动主程序：

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3
```

1. 程序启动后，按 `C` 连接云台
2. 观察舵机是否正常响应，如有异常请参考故障排除章节

### 手动控制练习

1. 按下方向键，观察云台运动是否与预期一致
2. 练习用方向键将云台移动到不同位置
3. 按 `R` 让云台回中
4. 熟悉云台的最小和最大位置限制
建议进行以下练习：
- 练习1：移动云台到最左、最右、最上、最下四个极限位置，熟悉位置范围
- 练习2：从任意位置回中，观察回中是否流畅
- 练习3：尝试精细调节，熟悉舵机的运动精度

## 基础示例程序

项目提供了几个递进的示例程序供用户学习：

### 仅显示摄像头

```python
python examples/01_camera_only.py --camera 0
```

此程序仅打开摄像头，显示实时画面，不涉及云台控制。适合验证摄像头功能是否正常。

### 仅控制云台

```python
python examples/02_gimbal_only.py --port COM3
```

此程序仅提供云台控制功能，不涉及摄像头。适合验证舵机与驱动板连接是否正常。

### 摄像头与云台结合

```python
python examples/03_simple_gimbal_camera.py --camera 0 --port COM3
```

此程序结合了摄像头显示与云台控制，可以观察画面与云台联动效果。

## 使用注意事项

在使用过程中，请注意以下几点：
1. 连接云台后，确认舵机已插上电源
2. 手动控制时，注意不要长时间停在极限位置
3. 操作时避免暴力碰撞云台支架
4. 如发现舵机异常抖动或异响，请立即断电检查
5. 长时间不使用时，建议断开电源连接
