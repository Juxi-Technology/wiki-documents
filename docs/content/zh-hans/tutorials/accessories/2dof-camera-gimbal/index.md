# 2 自由度相机云台

> **[ 淘宝店铺 ](https://juxitechnology.taobao.com)**

二自由度摄像头云台 —— 支持键盘手动控制，以及颜色、人脸、QR 码自动追踪。
硬件：SCS009 舵机 ×2（左右转动 + 上下俯仰）+ CH343 串行总线驱动板（默认波特率 1Mbps）。
