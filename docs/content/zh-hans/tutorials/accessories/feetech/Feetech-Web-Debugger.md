# 飞特总线舵机网页版调试（SCS0009 / STS3215 / HD1910）

> **桌面版工具：** [SCS0009 舵机调试工具使用教程](./SCS0009-Debug-Tool.md) ｜ [STS3215 & SCS0009 调试教程](./Feetech-STS3215&SCS0009-Tutorial.md)

飞特总线舵机调试工具的网页版：浏览器通过 **Web Serial** 直接打开 USB 串口与舵机通信，可完成串口连接、舵机扫描、型号识别、参数读写、位置控制与实时跟随、波特率修改、恢复出厂，以及 xdat 参数备份与恢复。

纯静态页面，**无需安装任何软件或 Python 环境**，打开网址即可使用。目前适配 **SCS0009**、**STS3215**、**HD1910** 三种型号。

## 一、打开网页

在线地址：

[https://juxi-technology.github.io/FT-ServoController-web/](https://juxi-technology.github.io/FT-ServoController-web/)

同一站点内还有完整的网页版使用教程（支持中英文切换）：

[https://juxi-technology.github.io/FT-ServoController-web/guide.html](https://juxi-technology.github.io/FT-ServoController-web/guide.html)

环境要求：

- **Chrome 或 Edge 89+**（Firefox、Safari 不支持 Web Serial）
- 页面须通过 **https 或 localhost** 打开
- 需安装 USB 转 TTL 驱动（CH340、CH343、CP2102 等）


## 二、连接串口

1. 在「🔌 串口连接」区选择**波特率**，默认 1000000（1M）。
1. 点击「**连接串口**」，在浏览器弹出的系统对话框中选择舵机对应的 USB 串口。
1. 连接成功后，右上角状态变为「🟢 已连接」。


可选波特率：1000000 / 500000 / 250000 / 128000 / 115200 / 76800 / 57600 / 38400。

## 三、扫描舵机与型号识别

1. 连接串口后，点击「🔍 **扫描舵机**」。页面扫描 ID 1–254，**发现即显示**，无需等待全部扫完。
1. 扫描过程中按钮会变成红色的「⏹ **停止扫描**」，再点一次即可中断，已经找到的舵机会保留。
1. 点击舵机芯片（或上方下拉框）选择目标舵机。


型号由舵机**地址 3 / 4 的两个字节**（舵机主版本号、次版本号）自动判断：

| 型号 | 识别字节（主 / 次） | 位置范围 | 字节序 |
|---|---|---|---|
| SCS0009 | 5 / 4 | 0–1023 | 大端 |
| STS3215 | 9 / 3 | 0–4095 | 小端 |
| HD1910 | 10 / 31 | 0–4095 | 小端 |

识别结果显示在舵机芯片上，例如 **ID1 (SCS0009 · SCS)**；参数表和位置范围会随选中舵机自动切换。识别表里没有的型号显示「未知型号」，日志中会打印实际读到的两个字节，便于反馈补充。

## 四、参数表

参数表按**地址、寄存器、值、存储区域、读写**五列展示选中舵机的全部寄存器，存储区域分为 EPROM、SRAM、DEFAULT 三类并按区域着色。

> **只有「读写」列标记为可写的那一行才能被选中并写入**；只读寄存器和 DEFAULT 区点不动，也不会进入写入行，避免误写只读区。

## 五、读取与写入参数

**读取参数**：点击舵机芯片选中目标舵机后，页面会**自动读取该舵机的全部参数**并填入参数表，同时把位置控制的滑杆对到它的当前实际位置。也可随时点击「📖 读取参数」手动刷新。

**写入参数**：

1. 在参数表中**选中一行**（只有可写行能选中）。
1. 底部「写入地址 0x」和「长度」会自动填好。
1. 在「值」输入框填入新值，点击「✏️ **写入**」。
1. 写入 EEPROM 时，页面会自动**解锁 → 写入 → 加锁**；结果以浮层提示成功或失败原因。


> 改 ID、波特率、角度限制这类参数前，先「保存当前舵机」备份一份 xdat，改错了好恢复。

## 六、位置控制

1. 选择舵机后，在「🎯 位置控制」区拖动**目标位置**滑杆，或直接在数值框输入。范围随型号变化：**SCS0009 为 0–1023**，**STS3215 / HD1910 为 0–4095**，滑杆与数值框双向联动。
1. 设置**速度**（寄存器原始值，不同系列单位含义不同）。
1. 点击「▶ **移动**」执行；页面会轮询 MOVING 标志，动作结束时提示关闭力矩。


**实时跟随**：勾选「实时跟随」后，拖动滑杆舵机会实时跟随。勾选时会先二次确认并自动打开该舵机的力矩；发送做了节流，不会把总线灌满。切换舵机、重新扫描或断开连接时会自动关闭，并提醒关闭力矩。

力矩控制：

| 按钮 | 作用 |
|---|---|
| ⚡ 力矩开 | 打开当前舵机力矩 |
| ⏹ 力矩关 | 关闭当前舵机力矩 |
| ⏹ 全部力矩关 | 一键释放总线上所有舵机 |

> **如果转动过程中突然断连，请重新连接后立即关闭力矩。**

## 七、读取状态

点击「📊 读取状态」，下方状态栏显示当前位置、速度、负载、电压、温度、电流和运行标志。

## 八、修改波特率

1. 在「🔧 波特率 / 恢复出厂」区选择**新波特率**。
1. 点击「🔧 **修改波特率**」。
1. 页面写入后，会按新速率**重新打开串口并回读验证**；若失败会**自动回滚**到原波特率，避免舵机失联。


## 九、恢复出厂

点击「🔄 **恢复出厂**」，需**二次确认**后执行。不同系列的恢复指令不同，页面会按识别到的型号自动选择：

| 型号 | 恢复指令 | 执行后 |
|---|---|---|
| SCS0009 | 0x0A 恢复出厂 | ID 回到 1，波特率回到 1M |
| STS3215 / HD1910 | 0x06 参数恢复 | ID 保持不变，其余参数回默认值 |

> 恢复出厂**不可撤销**，执行前建议先保存 xdat。

## 十、xdat 参数备份与恢复

「📁 xdat 参数（仅保存 EEPROM）」区提供三个操作：

| 按钮 | 作用 |
|---|---|
| 💾 保存当前舵机 | 读取该舵机全部参数并下载为 .xdat 文件 |
| 📂 打开 xdat | 载入本地 .xdat 文件并预览内容 |
| 📤 恢复参数到舵机 | 将已载入的 xdat 参数写回当前舵机 EEPROM |

保存的文件名带**型号和 ID**，例如 **SCS0009_ID1.xdat**、**HD1910_ID6.xdat**，避免不同型号的同一 ID 互相覆盖。

文件格式为「2 字节文件头 + 49 字节数据区」，寄存器地址 A 存放在偏移 A+2；多字节数值按型号字节序存放（SCS 大端、STS / HD1910 小端）。

> 为避免参数写乱，页面会校验文件与当前舵机是否同属一个字节序家族，**不一致时禁止写回**。恢复时只写可写的 EEPROM 参数，跳过型号与只读区；数据区只覆盖地址 0–48。恢复前请确认选中的舵机 ID 正确。

## 十一、日志

页面底部「📜 日志」实时记录每一步操作与返回结果，可点击「清空」清除。

界面支持**中英文切换**——右上角「EN / English」按钮即时切换界面和日志语言，历史日志也会同步刷新，无需重连。

## 十二、安全须知

- ⚠️ 同一时刻只能有一个程序占用串口。使用本页面时请关闭桌面版上位机、串口助手等其他程序。
- ⚠️ 运动过程中拔线，舵机可能仍在执行动作——重新连接后**先关力矩**。
- ⚠️ 接线、插拔一律断电进行。
- ⚠️ 离开页面前，可点击「⏹ 全部力矩关」一键释放所有舵机。


## 十三、常见问题

**Q1：页面提示不支持 Web Serial 或无法连接。**
使用 Chrome / Edge 89+，并通过 https 或 localhost 访问。Firefox、Safari 未实现 Web Serial。

**Q2：连接失败，提示无法打开串口。**
确认串口没有被其他程序占用（桌面版上位机、串口助手、Arduino IDE 等），并确认 USB 转 TTL 驱动已安装。

**Q3：扫描不到舵机。**
确认接线正确、舵机已供电、波特率与舵机一致。若舵机波特率被改过，请先试其他档位；总线上有 ID 冲突时两只舵机会同时应答，先单独接一只排查。

**Q4：参数表里的某些行点不动。**
这是设计如此：只有「读写」列标记为可写的行才能选中写入，只读寄存器和 DEFAULT 区不可写。

**Q5：修改波特率失败怎么办。**
页面会自动回滚到原波特率并提示失败原因，可检查接线后重试。

**Q6：舵机显示「未知型号」怎么办。**
说明该舵机地址 3 / 4 的两个字节不在识别表内。目前仅适配 SCS0009、STS3215、HD1910；可查看日志中的「主版本 / 次版本」数值反馈给我们补充。

**Q7：页面更新后行为没有变化。**
浏览器会缓存脚本，请用硬刷新重新加载（Windows：Ctrl+Shift+R；macOS：Cmd+Shift+R）。
