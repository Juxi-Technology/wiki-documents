# 网页端使用教程

本教程介绍如何使用浏览器版上位机连接、监测心率血氧模块。网页版基于 Web Serial 直接访问串口，无需安装 Python 或 `.exe`，Windows、macOS、Linux 均可使用。

**在线地址：**[https://juxi-technology.github.io/JUXI_HeartRate_SPO2/](https://juxi-technology.github.io/JUXI_HeartRate_SPO2/)

> 网页版与桌面上位机走同一套 Modbus RTU 协议（从机地址 `0x20`、9600 波特率），读数完全一致。

## 一、环境要求

- 桌面版 **Chrome、Edge 或 Opera**（需支持 Web Serial）
- Safari、Firefox 和手机浏览器未实现 Web Serial，无法连接串口
- USB 转 TTL 驱动（CH340、CP2102、FT232 等）
- 页面需要联网加载
- 浏览器一次只授权给页面一个串口设备

## 二、硬件连接

| 心率血氧模块 | USB 转 TTL |
|---|---|
| **VCC** | **5V**（不要接 3.3V） |
| **GND** | **GND** |
| **TX** | **RX**（交叉连接） |
| **RX** | **TX**（交叉连接） |

⚠️ TX 与 RX 必须交叉连接。接好后再把 USB 转 TTL 插入电脑。

## 三、连接设备

1. 用桌面版 Chrome / Edge / Opera 打开上面的在线地址。
1. 波特率保持 **9600**，与模块保持一致。
1. 点击「**连接串口**」，在浏览器自带的弹窗中选择模块对应的 USB 串口设备。
1. 状态显示「**已连接，待采集**」即连接成功，按钮旁会显示所选设备。

> 串口参数固定为 8 数据位、1 停止位、无校验、无流控，由页面自动设置，无需手动配置。

## 四、启动采集与监测

1. 点击「**启动采集**」——模块 LED 点亮，状态变为「采集已启动，LED已亮」。
1. 将手指放在传感器上，完全覆盖光学区域，轻放即可，不要用力按压。
1. 点击「**开始监测**」——状态变为「正在监测...」，实时数据开始刷新。

## 五、界面说明

### 实时数据

| 指标 | 单位 | 说明 |
|---|---|---|
| 血氧 (SPO2) | % | 血氧饱和度 |
| 心率 | 次/分 | 脉率 |
| 温度 | °C | 模块板载温度，非体温 |

**滤波**：默认开启。对读数做 5 点中位数平滑，并剔除超出合理范围的异常值（心率 35–220、血氧 70–100%、温度 0–60 °C）。剔除的数量会显示在数据区下方，例如「已剔除 N 个异常值」。取消勾选可查看未经处理的原始读数。

**状态提示**：未连接 / 等待选择设备… / 已连接，待采集 / 采集已启动，LED已亮 / 采集已关闭，LED已灭 / 正在监测… / 监测已停止 / 设备已断开 / 当前浏览器不支持 Web Serial。

### 语言切换

右上角的 **EN / 中文** 按钮用于切换界面语言。波特率和滤波开关的选择会被浏览器记住，下次打开时保持上次的设置。

### 使用文档页签

顶部「**使用文档**」页签内置本产品的 11 种语言教程，可在页面内直接切换语言阅读。

## 六、停止与断开

建议按以下顺序操作：

1. 点击「停止监测」
1. 点击「关闭采集」——LED 熄灭
1. 点击「断开连接」

## 七、数据解读

| 数据 | 正常范围 | 说明 |
|---|---|---|
| 血氧 SpO2 | 95% – 100% | 低于 90% 建议就医 |
| 心率 | 60 – 100 次/分 | 成人静息范围 |
| 温度 | 25 – 35 °C | 板载传感器温度，非体温 |

刚连接或手指未放好时显示 `-1` 属于正常现象。

## 八、与桌面上位机的区别

| 对比项 | 网页版 | 桌面上位机 |
|---|---|---|
| 安装 | 无需安装 | 需运行 `.exe` 或 Python 脚本 |
| 运行环境 | 浏览器 | Windows |
| 通信方式 | Web Serial | 系统串口 |
| 离线使用 | 不支持，页面需联网 | 支持 |
| 协议与读数 | 相同 | 相同 |

## 九、常见问题

**Q1：提示「当前浏览器不支持 Web Serial」。**
换用桌面版 Chrome、Edge 或 Opera。Safari、Firefox 和手机浏览器均未实现 Web Serial。

**Q2：点击「连接串口」后，弹窗里没有设备。**
检查 USB 转 TTL 驱动是否安装、数据线是否支持数据传输；可换一个 USB 口或重新插拔后再试。

**Q3：连接失败。**
确认串口没有被其他程序占用（串口助手、Arduino IDE 等），并确认设备已上电。

**Q4：点击「启动采集」后 LED 不亮。**
确认 VCC 接的是 5V 而不是 3.3V，并检查 TX/RX 是否交叉连接。

**Q5：数据一直显示 -1。**
确认已经点击「启动采集」，手指完全覆盖传感器光学区域，并保持稳定数秒。

**Q6：设备被拔出。**
页面会显示「设备已断开」，重新插好后再次点击「连接串口」。

## 十、注意事项

1. 先接传感器，再插 USB。
1. 传感器必须使用 5V 供电，3.3V 可能无法正常工作。
1. 测量时手指完全覆盖光学区域，不要用力按压。
1. 避免强光直射传感器。
1. 浏览器一次只授权一个串口设备，多个设备需要分别连接。
