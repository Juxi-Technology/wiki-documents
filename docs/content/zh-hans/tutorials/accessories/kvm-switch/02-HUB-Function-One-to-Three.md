# 02 · HUB 功能（一分三）

> [← 返回教程总览](/zh-hans/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜适用产品：钜犀科技 KVM&HUB&TTL

## 怎么用

**一根 Type-C 进，三个 USB-A 出**——只接一台电脑时，本产品就是普通 USB HUB：

1. 用 Type-C 线把电脑接到 **PC1**（或 PC2）口；
2. 键盘、鼠标、U 盘等插到任意 **USB-A** 口即可使用。

接两台电脑时，3 个 USB-A 作为一个整体在两台电脑间切换（见 [01 篇](/zh-hans/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)）。

（配图：教程原图 02 - 一分三 HUB）

## 支持什么设备

| 可以接 | 建议直连电脑 |
|---|---|
| 键盘、鼠标（含无线接收器） | 移动硬盘、固态存储 |
| U 盘 | 视频采集卡等高带宽设备 |
| 打印机、加密狗 | 电竞级高回报率外设（请谨慎） |
| 串口模块、传感器（接 TTL 口更佳，见 04 篇） | |

- **免驱**：Windows / macOS / Linux / 国产系统即插即用；
- 规格为 **USB 2.0**，请按上表选择设备。
