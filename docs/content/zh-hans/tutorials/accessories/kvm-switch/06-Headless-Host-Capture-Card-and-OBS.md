# 06 · 无显示器主机（采集卡 + OBS）

> [← 返回教程总览](/zh-hans/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜适用产品：钜犀科技 KVM&HUB&TTL

给"没有显示器的开发板 / 主板"接一套键鼠，**不需要给它配显示器**——画面走采集卡进电脑，键鼠走 KVM 切换。

## 工作方式

```
开发板（无显示器）──视频──→ 采集卡 ──USB──→ 你的电脑（OBS 窗口看画面）
开发板（无显示器）──键鼠──→ ←── KVM 切换 ──→ 你的电脑（同一套键鼠）
```

## 步骤

**① 接画面**（把主机的视频输出接到 **4K HDMI 采集卡**，采集卡 USB 端接你的电脑）：

| 主机输出接口 | 接线 |
|---|---|
| HDMI | HDMI 线 → 采集卡 |
| Micro HDMI（树莓派等） | Micro 转 HDMI 转接头 → HDMI 线 → 采集卡 |
| DP | DP 转 HDMI 转接头 → HDMI 线 → 采集卡 |

**② 接键鼠**：键鼠（或无线接收器）插在本产品 USB-A 口，按按键把键鼠**切到开发板**；

**③ 看画面 + 操作**：电脑上用 **OBS** 或 **PotPlayer** 添加"视频采集设备"，即可一边看开发板画面、一边敲键盘操作。

（配图：教程原图 06 - 开发板+采集卡实景、07 - 采集卡接线、08 - OBS 操作指南、09 - PotPlayer 操作指南）

## 提示

- 采集卡建议**直连电脑**（不经过 KVM 的 USB 口），保证画面稳定；
- 切走键鼠后，开发板上的操作会立即停止响应键鼠 —— 按一下按键即可切回。
