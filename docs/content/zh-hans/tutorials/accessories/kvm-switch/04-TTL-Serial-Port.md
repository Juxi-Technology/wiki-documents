# 04 · TTL 串口（无线串口）

> [← 返回教程总览](/zh-hans/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜适用产品：钜犀科技 KVM&HUB&TTL

## 它是什么

6 针 TTL 口是**串口透传口**：把开发板、传感器等设备接上来，它的串口数据会"同时"从两个地方输出（双向）：

```
                ┌─→ 电脑串口（USB，系统识别的 "USB-BLE-SERIAL CH9143"）
外接设备 → 6 针口 ┤
                └─→ 蓝牙无线（手机 BleUart App，见 03 篇）
```

**实测参考**：接入一枚 IMU 传感器后，电脑串口与蓝牙同时稳定收到约 1650 字节/秒的数据。

## 针脚定义与接线

从左到右：`GND` `RXD` `TXD` `TNOW` `3V3` `5V`

| 针脚 | 说明 | 接法 |
|---|---|---|
| GND | 地 | 与外部设备 GND 相连（**必须接**） |
| RXD | 本机接收 | 接外部设备的 **TXD**（交叉） |
| TXD | 本机发送 | 接外部设备的 **RXD**（交叉） |
| TNOW | 发送方向指示 | **悬空不接** |
| 3V3 | 3.3V 电源输出 | 可给低功耗外设供电（与 5V 二选一） |
| 5V | 5V 电源输出 | 可给低功耗外设供电（与 3V3 二选一） |

**要点**：收发必须**交叉**；电平 **3.3V**；电源针是**输出**，切勿回灌；只接低功耗模块。

## 电脑端使用

1. 本产品用 Type-C 连接电脑（PC1/PC2 任意口）；
2. 系统自动识别串口 **`USB-BLE-SERIAL CH9143`**（Windows 10/11 免驱）；
3. 用串口工具打开，参数：**115200，8N1**；
4. 即实时收到外接设备的数据（也可向设备发送数据）。

## 对接开发板（树莓派 / Jetson）

电平 3.3V，可直接对接（接线交叉、GND 相连）：

| 本产品 | 树莓派 | Jetson（Orin 系列 40 针） |
|---|---|---|
| RXD | Pin8（GPIO14 / TXD） | Pin8（UART1_TXD） |
| TXD | Pin10（GPIO15 / RXD） | Pin10（UART1_RXD） |
| GND | 任意 GND（如 Pin9） | 任意 GND（如 Pin9） |

> 树莓派需在 `raspi-config` 打开串口；Jetson 需先启用 40 针 UART。
> 典型场景：开发板串口接 KVM → 电脑上敲命令看日志，手机蓝牙同时也能看（无线调试）。

（配图：教程原图 10 - Jetson 针脚图、11 - 树莓派针脚图）

## 排查：串口没有数据？

依次检查：
1. 外部设备 TX/RX 是否**交叉**、GND 是否接好；
2. 外部设备波特率是否为 **115200**；
3. 外部设备是否已供电（可用本机 5V/3V3 针供电）；
4. 电脑串口是否被其他软件占用；设备切到另一台电脑时串口会短暂消失（正常）。
