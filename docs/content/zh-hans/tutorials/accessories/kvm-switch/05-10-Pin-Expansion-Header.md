# 05 · 十针扩展口

> [← 返回教程总览](/zh-hans/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜适用产品：钜犀科技 KVM&HUB&TTL

设备右下角的 **10 针排座**为**预留扩展接口**，丝印如下：

| 排针 | 丝印 |
|---|---|
| 上排 | `RI#` `DSR#` `FCE` `DTR#` `RST#` |
| 下排 | `CTS#` `DCD#` `GND` `GND` `GND` |

## 说明

- 该口用于**外接控制器、自定义线缆等二次开发场景**（串口控制信号相关）；
- 普通使用（切换键鼠、HUB、无线串口）**不需要连接此口**；
- 如需该接口的电气定义与使用方式，请联系我们获取（以实物与最新说明书为准）；
- 自行接线前请用万用表确认电平，避免对设备造成损伤。
