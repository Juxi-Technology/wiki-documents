# PC通讯

## 设备连接

滑动开关移动到STC8串口模式

![图 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## 打开串口调试助手

- 打开Uart Assistant，选择对应的串口号，以及波特率为115200，

![图 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- 参考压缩包中的命令词播报词协议列表V1_中文文件

![图 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- 当我们说出“小车前进”的时候，串口调试助手会打印出对应的协议

![图 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- 根据命令词播报词协议列表V1_中文文件输入对应指令，语音模块播报对应协议的文字

![图 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

可以听到语音模块正常播报。
