# 软件配置

本章节介绍产品的软件配置方法。

## 系统要求

- Node.js 18+
- Python 3.10+
- Git

## 安装步骤

```bash
# 克隆仓库
git clone https://github.com/Juxi-Technology/your-repo.git

# 进入目录
cd your-repo

# 安装依赖
npm install
```

## 配置文件

编辑 `config.json` 文件，根据你的需求进行配置：

```json
{
  "port": 3000,
  "language": "zh-CN"
}
```
