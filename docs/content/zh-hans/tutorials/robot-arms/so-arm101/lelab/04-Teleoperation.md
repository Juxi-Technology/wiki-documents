# 4 · 遥操作

> **上一篇**：[03 接线与校准](03-Calibration.md)
> **下一篇**：[05 录制数据集](05-Record-Dataset.md)

你用手拖主臂，从臂照着做。采演示数据靠它，也是确认校准做没做对最快的办法。

## 怎么跑

1. 打开 **Teleoperation** 页。
2. 确认串口和校准配置——LeLab 会记住校准时的选择。
3. 开始遥操作。
4. 拖主臂。

页面会实时显示关节位置。结束后点停止。

**停止才是让从臂停下来的动作。** 关标签页或杀进程，从臂会停在当时的位置。

## 看哪几样

| 检查 | 为什么 |
|---|---|
| 从臂跟得顺，不滞后、不抖 | 跟得糙就是没法用的训练数据 |
| 从臂的活动范围和主臂对得上 | 走不到头或撞限位，说明某个关节没校准好——回[第 3 篇](03-Calibration.md) |
| 两条臂方向一致 | 从臂反向跟随，说明关节校准方向反了 |
| 极限位置不撞东西 | 把要用到的整个行程走一遍 |

动作不对但没坏——偏了、某个关节反了、行程不够——**回去重新校准，不要将就**。校准歪了的臂会教策略做错事。

## 摄像头

配了摄像头的话，遥操作页会显示预览。

- 腕部摄像头：看得到夹爪和它马上要抓的东西吗？
- 固定摄像头：看得到整个工作台吗？
- 画面有没有歪的、反的？有的话**录之前**去[校准页](03-Calibration.md)改 rotation。

遥操作时录下来的帧，是策略唯一能看到的东西。
