# AmazingHand灵巧手产品资料

## 产品简介

AmazingHand 是一款**高精度、轻量化、手势追踪的灵巧手**，专为具身智能研究、机器人教育和人机交互应用设计。该产品采用8个高精度SCS0009 TTL串口舵机控制，支持右手、左手以及双手机器人操作，可实现复杂的手势动作和实时追踪功能。

### 一、硬件设计：高精度轻量化，易调试可扩展

- **舵机配置**：单个灵巧手采用**8个SCS0009 TTL串口舵机**，2个舵机协同控制同一根手指，提供精准的运动控制和稳定的抓取能力。

- **轻量化结构**：灵巧手总重仅0.416kg，结构紧凑，易于安装在各类机器人平台上。

- **便捷连接**：通过Type-C接口通信，配合舵机驱动板和MEGA328P开发板，即插即用，简化硬件连接流程。

- **模块化设计**：支持右手、左手单独配置，也可双手机器人协同工作，灵活适应不同应用场景。

### 二、软件生态：集成手势追踪，AI开发易上手

- **实时手势追踪**：基于MediaPipe的实时手部追踪技术，通过网络摄像头捕捉手势，实现灵巧手的模仿学习和跟随控制。

- **分布式数据流**：采用**DORA分布式数据流引擎**，实现硬件与算法的低延迟交互，支持手势数据到舵机控制的全链路打通。

- **仿真与硬件统一**：提供虚拟仿真环境，支持在仿真中验证控制算法，再无缝迁移到真实硬件。

- **开源生态**：控制代码、训练脚本及教程开源，支持二次开发和功能扩展。

### 三、核心应用场景：从教学到研究，全场景覆盖

1. **机器人教育入门**：提供从灵巧手组装、舵机调试、基础控制到手势追踪的全流程教程，配套演示程序和案例代码，零基础用户可快速上手。

2. **具身智能研究**：专注**手势模仿学习、人机交互**研究，支持通过摄像头捕捉人类手部动作训练灵巧手；典型应用：手势控制、物体抓取、人机协作等任务。

3. **人机交互原型**：低成本验证人机交互方案，适配**手势控制、遥操作、VR/AR交互**等场景，快速落地原型验证。

### 四、产品优势

- **高性价比**：采用成熟的串口舵机方案，成本可控，适合个人、实验室及教育机构批量部署。

- **手势追踪**：内置手势追踪功能，无需额外复杂设备，普通摄像头即可实现灵巧手的实时跟随控制。

- **开发友好**：提供完整的调试教程、演示程序和开发接口，从硬件调试到软件控制，快速上手。

- **双手协同**：支持单手机器人独立操作，也支持双手机器人协同工作，灵活适应不同实验和应用需求。
