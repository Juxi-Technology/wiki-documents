# 04-串口舵机版本-使用说明

SCS0009 官方总线舵机版 — 使用说明

> **如您购买的是 PWM 舵机版(ESP32-S3 + 8 路 PWM),请忽略本目录**,
使用 `..\01_gui_control` 或 `..\02_hand_tracking` 即可。

本目录说明的是 AmazingHand **官方原版 SCS0009 总线舵机**的支持情况。

## 当前状态

本delivery_package的 `..\02_hand_tracking\Demo` 同时支持两种舵机后端,可通过配置无缝切换:

|版本|舵机类型|波特率|配置文件|
|---|---|---|---|
|**PWM**(本包主要交付)|ESP32-S3 直驱 PWM|115200|`{l,r}_hand_pwm.toml`|
|**SCS0009**(官方原版)|官方总线舵机|1,000,000|`{l,r}_hand.toml`|

- **PWM 版**:菜单选 `3 - PWM 舵机(ESP32 直驱)`,用本包教程。

- **SCS0009 版**:菜单选 `2 - 真实硬件(SCS0009 总线舵机)`。

## SCS0009 版使用方法

1. 硬件:官方总线舵机 + 串口适配器(波特率 1M)。

2. 部署:`Demo\Windows_Scripts_CN\3-部署代码.bat`(或 Linux 对应脚本)。

3. 运行:4-运行代码.bat → 选 `2 - 真实硬件(SCS0009 总线舵机)` → 选手型。

4. 详细说明见 `..\02_hand_tracking\Demo\双版本舵机并存说明.md`
以及 `Demo\Windows_Scripts_CN\Windows使用教程.md`(官方教程)。

## 注意事项

- SCS0009 需要官方舵机 id 配置(已内置在 `{l,r}_hand.toml`),PWM 版不涉及。

- 两种舵机**同一时刻只接一套**,切换硬件 + 菜单选项即可。

- 本包以 PWM 版为主要交付物;SCS0009 官方教程以官方 Demo 为准。
