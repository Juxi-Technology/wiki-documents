# 产品资料

## 产品简介

LeKiwi 是由 SIGRobotics-UIUC（伊利诺伊大学香槟分校机器人兴趣小组）主导开发。提供低成本、高灵活性的开源机器人平台，推动教育、科研及工业自动化领域的机器人技术普及，硬件设计（3D 打印文件）、软件栈（兼容 LeRobot 框架）及教程全部开源，支持用户自定义扩展。

LeKiwi 分为移动平台和主从臂，主从臂采用 3D 打印件作为结构，6 个 12V 飞特舵机作为驱动关节，主臂位于固定平台，使用一个舵机驱动板，通过 USB-C 连接电脑，从臂固定在采用 3 个 12V 飞特舵机做驱动的移动平台，使用一个舵机驱动板，通过 USB-C 连接 树莓派 进行控制。

LeKiwi 深度集成 LeRobot（Hugging Face 开源机器人 ML 框架），支持模仿学习、数据收集与策略训练。基于 PyTorch 实现，包含预训练模型、数据集及仿真环境，兼容 Stanford ALOHA 等知名开源数据集。使用 DORA 框架（分布式数据流引擎），实现硬件 - 算法低延迟通信（Python 性能比 ROS2 快 17 倍），支持热重载功能，实时调整代码无需重启。

LeKiwi 非常适合教育 / 入门研究：机器人学入门教学，提供从组装、编程到 AI 策略部署的全流程教程；科研验证：支持模仿学习研究（如通过 VR 录制人类操作视频训练机器人），案例：花粉机器人 Ready2 通过 50 段 15 秒视频训练 2 小时，即学会叠衣、插钥匙等任务；工业原型开发：低成本验证自动化方案（如物料搬运、精密装配）。
