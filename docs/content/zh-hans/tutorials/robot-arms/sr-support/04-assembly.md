# 04 散件组装：打印、装配与接线

> **成品用户可跳过本页**：出厂已完成打印、装配、接线与走线检查（见
> [index 出厂状态](./index.md)）。仅在自组装或更换零件时按本页操作。

## 4.1 打印与检查

1. 打印底面板、肩舵机固定件、肘舵机固定件、顶部撑杆（各 1 件）；
2. 用卡尺核对底座外形约 88 × 82 mm、总高 68 mm；
3. 检查舵机安装槽与 25T 舵盘配合，无干涉后再上螺丝；
4. 打印件逐件称重并记录（对照 `hardware/v1/meshes/print_mass_model.json`）。

## 4.2 舵机准备（固件零点与舵盘安装）

1. **先接线、烧固件**：按 4.4 接线表接好两路舵机、IMU、舵机电源与共地（机械件先不装；
   主固件需要 IMU 才能启动），按 [03 页 3.1](./03-build-flash.md) 烧录主固件；
2. **上电到固件零点**：串口 115200 打开（串口工具/串口助手见
   [03 页 3.3](./03-build-flash.md)）并上电；启动完成后固件把两舵机驱动到 q=0
   （中位脉宽 1681 / 1456 µs），串口出现 `servo start q: 0.00 0.00 rad` 和
   `ready; send g to run`（或 `autorun on: ...`）即已到位；
3. **断电**：拔掉舵机电源（USB 可保留），确认两只舵机都不再受力；
4. **装舵盘**：把肩舵盘装到舵机上，使大臂竖直；肘舵盘使小臂与大臂成一条线；拧紧后
   手动检查行程无卡滞；
5. 方向约定（与仿真一致）：`shoulder +q` 使大臂向 **−Y**，`elbow +q` 使小臂向 **+X**；
   固件默认 `SERVO_SHOULDER_SIGN=-1`、`SERVO_ELBOW_SIGN=-1`。

> 固件中位 1681 / 1456 µs 已经包含了出厂标定时的舵盘换齿偏移，**不需要再自己数齿**：
> 在固件零点（q=0）装盘、大臂竖直即可。也可以在串口发送框输入 `e` 并回车，让两舵机回到
> 1520 µs 电气中位再装（等价的可选做法，见 [03 页](./03-build-flash.md) 命令表）；两种方式最终都由
> [05 页](./05-zero-tool.md) 的 `z` 精定零。

> 齿位只是**粗对中**。精确零点必须在整机组装完成、主固件烧录（[03 页](./03-build-flash.md)）
> 之后，用 [05 零点校准](./05-zero-tool.md) 把目测竖直姿态定义为 q=0（`z` 不依赖 IMU，
> 任意姿态可用），再把打印脉宽写回 `config.h` 并重烧。即使装配时舵盘没有装正，也能这样
> 定零；只有某侧行程不够（舵机被 500/2500 µs 限幅）时才需要拆盘重新错齿。
> 齿位决定两侧行程分配；固件手动限位（`Q_SHOULDER_MIN/MAX`）必须与实际行程一致，不要
> 随意放宽。定零后务必按 05 页把序列路点同步平移，否则扶正动作的物理姿态会漂移。

## 4.3 底座与手臂装配

1. 底面板与肩舵机固定件用 M3 螺丝固定，组成底座（总高约 68 mm）；
2. 肩舵机装入肩舵机固定件，舵盘朝上；
3. 肘舵机固定件安装到肩舵盘上并锁紧（作为上臂）；肘舵机装入肘舵机固定件；
4. 顶部撑杆（小臂）连接到肘舵盘；
5. 装配后手动把手臂摆到竖直（`q≈0`），确认与舵机中位一致。

## 4.4 接线

| 器件 | ESP32-S3 引脚 | 转接板 | 说明 |
|---|---|---|---|
| 转接板 3V3 | 3V3 | S1 信号脚 | 另一头接 IMU VCC（3.3 V） |
| 肩舵机信号 | GPIO4 | S4 | 50 Hz PWM |
| 肘舵机信号 | GPIO5 | S5 | 50 Hz PWM |
| IMU SDA | GPIO6 | S6 信号脚 | 另一头接 IMU SDA；I²C 0x23，100 kHz |
| IMU SCL | GPIO7 | S7 信号脚 | 另一头接 IMU SCL；I²C 0x23，100 kHz |
| IMU GND | GND | —（直连） | 共地 |
| LED（可选） | GPIO2 | — | 状态灯 |
| 5 V 电源输入 | 5V / GND | — | 一分二线：一路供 ESP32，一路接转接板 V+/GND 供舵机 |
| 舵机电源 | — | V+/GND 端子 | 5 V / ≥5 A；**更高电压只能接这里，不能接 ESP32 5V** |
| S2 / S3 | — | 空 | 不接 |

注意事项：

- 转接板为无源直连：S1/S6/S7 借用信号脚传 3V3 / SDA / SCL，S4/S5 传舵机信号；
  确认每个口的 V+/GND/信号顺序一致，插反会烧舵机或板子；
- I²C 线尽量短，不要与舵机线长距离并行；模块上拉一般为 3.3 V；
- **5 V 供电**时可直接接 ESP32 的 5V/GND，经一分二线同时给 ESP32 与舵机；
  更高电压（6 V / 7.4 V）只能接转接板 V+/GND，ESP32 必须单独用 USB 供电；
- **电池（5 V）给 ESP32 供电时，可以同时插 Type-C**：DevKitC-1 官方原理图中，USB VBUS
  经肖特基二极管接到 5V 网络，不会反灌，USB 只作数据（及辅助供电）；若用的是省掉该
  二极管的克隆板、或无法确认，烧录时断开 5 V→ESP32 分支、让 ESP32 只由 USB 供电（方式 2）；
- **调试/烧录时的供电（两种都正常，任选）**：
  1. 5 V 电源经一分二同时供 ESP32 与舵机，USB 只接数据；
  2. 更直观：断开 5 V→ESP32 的分支，ESP32 只由 USB 供电，5 V 电源只供舵机。
  烧录、串口监视、`c` 标定用方式 2 最省心；整机独立运行时用方式 1；
- 第一次上电先不接舵机，用万用表确认 V+ 电压与极性；再接一个舵机测试，最后接两个；
- 接线顺序：共地与信号 → 接通 5 V 电源（ESP32 与舵机同时上电）→ 需要串口时再插 USB；
  断电相反。

## 4.5 IMU 安装方向

IMU 固定在底座上（螺丝定位，方向不可调），固件因此启用 `IMU_YAW90`，把 IMU 坐标系下
的 up 向量换算到机体坐标：

```c
up_body = (up_imu.y, -up_imu.x, up_imu.z)
```

**机械方向自检**（装好舵机后、上电前就能看）：以 IMU 模块丝印/引脚定义标注的坐标轴为准，

- 肩舵机的**输出轴**（装舵盘的那根轴，也叫舵盘轴/齿轮轴）朝向 IMU 的 **−Y**；
- 肘舵机的**输出轴**朝向 IMU 的 **+X**。

从下往上看，两个舵机的顺序是 **肩舵机（下）→ 肘舵机（上）**，装舵盘和接线时不要弄反。

这两个方向分别就是机体的肩轴与肘轴。如果和实物对不上，说明 IMU 或舵机座装反了，
先改正再上电。

上电后再按 [06 调试页](./06-debug-and-calibrate.md) 复核：直立时 `up≈(0, 0, 1)`；
四种躺姿的 up 向量见 6.5 节表格。
