# 08 WiFi 与仿真镜像

本步为可选功能，不影响自扶正本身。

## 8.1 热点与状态页

热点：SSID `SR-Support`，密码 `srsupport`，地址 `192.168.4.1`（`w` 开关，上电默认开）。
`w` 通过串口发送：在串口监视器/串口助手的发送框输入 `w` 并回车即可切换；串口工具/
串口助手（含 Windows UartAssist 下载）见 [03 页 3.3](./03-build-flash.md)。

设备连上热点后打开 `http://192.168.4.1`（多数手机会自动弹出配网门户）。页面每 300 ms
刷新：运行状态、up 向量与直立度条、两关节指令角、扶正姿态/阶段、Home WiFi 状态、
Twin 流开关。浏览器有系统代理时，把该地址加入代理例外。

## 8.2 配网（让 ESP32 加入家里的 WiFi）

状态页 Home WiFi 卡片：`Scan` → 选网络 → 输密码 → `Connect`。成功后 AP+STA 双模：

- 热点保留（现场调试不受影响）；
- 家里局域网可直接访问（页面 `Robot IP` 显示地址）；
- 凭据写入 NVS，重启自动重连。

仅支持 2.4 GHz 网络；扶正动作执行期间会拒绝扫描/配网。

## 8.3 MuJoCo 无线实时镜像

状态页按 `Twin ON`（等价串口 `d`），然后：

```bash
python tools/live_twin.py --tcp <Robot IP>:3333
```

（在 `SR-Support` 目录下、先按 [02 页](./02-environment.md) 创建并激活 `.venv`；工具环境
也在那里安装。）

- 窗口中的模型按实机姿态实时显示，身体自动贴地；
- 手臂接触地面时会被"挡住"在接触角（模拟实机堵转），不会穿地；
- 有线串口只在烧录和导出日志时需要；
- 离线回放历史日志：`--replay <日志文件>`。

## 8.4 WiFi 遥测落盘

```bash
python tools/tcp_log.py
```

把热点的遥测流保存为 `logs/wifi_<时间>.txt`，可事后离线回放分析。
