# 文件远程传输

## 1、MobaXterm

MobaXterm是一款功能强大的远程工具，整合SHH、VNC、FTP等远程工具。

## 2、MobaXterm安装

官网网址：[https://mobaxterm.mobatek.net/](https://mobaxterm.mobatek.net/)

选择免费版本下载：

![图 2](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/2.png)

选择安装版本下载：

![图 3](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/3.png)

## 3、MobaXterm使用

在桌面找到`MobaXterm`图标打开：

![图 10](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/10.png)

## 4、MobaXterm：SSH远程

选择`Session` → `SSH` ：填写远程设备IP和用户名

例如：

Jetson主板默认信息：

用户名：juxi

密码：juxi

注意：MobaXterm使用SSH远程就会在侧边栏自动使用SFTP远程登录
