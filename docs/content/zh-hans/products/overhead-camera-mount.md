# SO-ARM101 顶置相机支架

> **[淘宝购买](https://item.taobao.com/item.htm?id=987942774005)**

## 产品概述

SO-ARM101 顶置相机支架提供俯视视角安装,兼容 RealSense 深度相机与普通 USB 摄像头。用于机械臂视觉数据采集(俯视视角利于 LeRobot 训练数据)。

**核心特性**:

- 俯视视角安装
- 兼容 RealSense / USB 摄像头
- 与 SO-ARM100/101 匹配
- 安装简便

## 产品规格

| 类别 | 规格 |
|------|------|
| 视角 | 俯视(top-down) |
| 兼容 | RealSense / USB 摄像头 |
| 平台 | SO-ARM100/101 |

## 快速开始

1. 将支架固定到 SO-ARM 安装点
2. 安装相机(RealSense 或 USB)
3. 连接主控,`python -m lerobot.find_cameras` 确认识别
