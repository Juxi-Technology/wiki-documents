# 4K HDMI 采集卡

> **[淘宝店铺](https://juxitechnology.taobao.com)**

## 产品概述

4K 高清 HDMI 采集卡支持 HDMI / Micro HDMI / DP 三种主板接口转换,通过 USB/Type-C 直连笔记本、PC、手机/平板显示屏,适用于直播、录屏、教学演示。

**核心特性**:

- 4K 高清采集
- HDMI / Micro HDMI / DP 接口兼容
- USB / Type-C 即插即用
- OBS / PotPlayer 主流软件支持

## 产品规格

| 类别 | 规格 |
|------|------|
| 输入 | HDMI / Micro HDMI / DP(转接) |
| 输出 | USB / Type-C |
| 采集 | 4K 高清 |
| 软件 | OBS / PotPlayer |

## 快速开始

1. 按主板接口选择接线方式(HDMI / Micro HDMI / DP 转接)
2. 连接采集器 USB 到显示端
3. OBS / PotPlayer 中选择采集设备即可
