## 产品概述

ESP32-WiFi 图传模块是一款紧凑、高性价比的 AI 视觉解决方案,采用双板模块化架构(核心处理板 + 通信扩展板)。核心板搭载 **ESP32-S3** 高性能处理器与 200 万像素高清摄像头,支持 WiFi 视频流传输、人脸识别、颜色识别等 AI 视觉功能,预装固件开箱即用。

**核心特性**:

- 200 万像素高清摄像头(1600×1200@30FPS)
- **AP + STA 双模式** WiFi 实时图传
- AI 视觉:颜色阈值分割 + 轻量 CNN(颜色/人脸/二维码识别)
- Type-C 一键固件升级
- 标准 PH2.0 I2C / UART 通信接口

## 快速开始

### 1. 开机连接

预装固件开箱即用,通电后模块自建 WiFi 热点:

- 手机/电脑搜索并连接模块热点
- 浏览器访问指定地址查看实时视频

### 2. 两种工作模式

| 模式 | 说明 |
|------|------|
| **AP 模式** | 模块自建 WiFi 热点,终端直连模块 |
| **STA 模式** | 模块连接现有 WiFi 路由器,与终端同网传输 |

### 3. 连接主控

**UART 通信**(树莓派/Jetson Orin):

```
ESP32 模块 RX → 主控 TX
ESP32 模块 TX → 主控 RX
```

**I2C 通信**:标准 PH2.0 I2C 接口,可输出人脸检测/颜色识别的**坐标数据**。

### 4. 二次开发

Type-C 连接电脑,一键固件升级;通过 UART/I2C 指令切换识别目标(颜色/人脸/二维码)。

## 常见问题

**Q: 如何观看实时视频?**

模块预装固件会自建 AP 热点,手机/电脑连接后通过指定网页或 App 查看。

**Q: 支持哪些识别?**

内置颜色阈值分割 + 轻量 CNN,支持颜色、人脸、二维码识别,可通过通信指令切换。

**Q: 能返回识别坐标吗?**

可以。通过 I2C/UART 通信接口输出人脸/颜色检测的坐标数据,用于二次开发。

**Q: 固件怎么更新?**

Type-C 连接电脑,支持一键固件升级。
