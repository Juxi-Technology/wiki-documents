# Lekiwi 具身智能移动机器人

> **[淘宝店铺](https://juxitechnology.taobao.com)lekiwi-embodied-intelligence-mobile-robotic-car)**

## 产品概述

Lekiwi 是钜犀科技低成本具身智能移动机器人,采用舵机控制方式,结构简单直观,适合课堂教学、入门学习与创客项目。支持 12V 电源(可选配 5521 DC 插头电源)。

**核心特性**:

- 简单结构,成本低,适合批量教学部署
- 舵机控制方式直观,上手快
- 与 SO-ARM101 共用 LeRobot 生态
