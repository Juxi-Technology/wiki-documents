# SO-ARM101和AmazingHand开源灵巧机械臂

## 产品概述

SO-ARM101 & AmazingHand 是一个完整的开源具身智能平台，它将 SO-ARM101 六轴机械臂与 AmazingHand 8 自由度四指灵巧手相结合。原有的平行夹持器被四指手取代，通过一个主臂舵机驱动，通过一个简单、可靠、工厂组装的机构实现同步的四指抓取和伸展。该平台基于 Hugging Face LeRobot 生态系统构建，支持主从遥操作、双视角数据采集以及 ACT、SmolVLA、Pi0、Pi0.5 和 GR00T N1.5 的端到端模仿学习——这是从夹持器过渡到灵巧手的最简单起点。

**SO-ARM101** 是在 SO-ARM100 基础上深度优化的开源六轴机械臂。改进后的走线方式和电机/齿轮搭配消除了关节电缆断裂问题，不再限制关节的运动范围，同时支持实时主从跟随和与 Hugging Face LeRobot 工具包的无缝兼容。

**AmazingHand** 是一个开源、低成本、完全 3D 可打印的 8 自由度机器人手开发套件。其舵机完全内置于手部主体内部，采用无电缆内部设计，每个手指由两个关节驱动，兼具灵巧性和自然的手指间协同能力。

## 主要优势

### 八自由度四指灵巧手

AmazingHand 提供四根手指（拇指、食指、中指和无名指），每根手指有两个关节，总共 8 个自由度。平行连杆机构使手指协同工作，实现更自然的抓取，所有舵机都内置在手部主体内，没有外部电缆，结构紧凑整洁。

### 单舵机连动驱动所有四指

主臂上的 6 号舵机 (STS3215) 通过范围映射驱动手部内的所有八个 SCS0009 总线舵机，因此一个简单的动作即可实现同步的四指抓取（握拳）或伸展（张开手掌）。机械结构简单，控制可靠，无需复杂的手部编程。

### ACT、SmolVLA、Pi0、Pi0.5 和 GR00T N1.5 的端到端模仿学习

运行主从遥操作以记录演示数据，然后一次性训练模仿学习策略。少量数据集足以让从臂自主完成预设抓取任务，整个闭环无需从头编写代码即可实现。

### 双视角数据采集

顶部支架摄像头从上方覆盖整个工作空间，以确定目标物体的空间位置和方向，同时桌面支架侧视摄像头实时传输工作空间上下文。两者协同作用，确保操作精确，快速响应场景变化，并防止漂移或停滞。

### 工厂组装，开箱即用

每台设备均经过组装、接线和校准——连接电源和 USB 后，平台即可进行遥操作和数据采集。摄像头选项包括 86° 自动对焦 30FPS 模块和 100° 广角定焦 60FPS 模块，无需 USB 驱动，即插即用。

### 无缝集成 Hugging Face LeRobot

直接复用 LeRobot 的预训练模型、数据集和算法库，与全球开发者社区共享代码和经验，无需自行重建工具链即可进入具身智能领域。

## 硬件概览

### 可选版本（根据您的末端执行器需求选择）：

| 版本 | 末端执行器 | 手部控制 | 适用对象 |
|---|---|---|---|
| 专业版 | TPU 柔性夹持器 | 独立舵机控制 | 需要标准 SO-ARM101 双指夹持器的用户 |
| 灵巧手版本 | AmazingHand 四指灵巧手 | 主臂 6 号舵机通过范围映射同步驱动 8 个总线舵机 | 探索灵巧抓取和端到端模仿学习的用户 |

**抓取方式：**专业版采用两指捏合，而灵巧手版本采用四指抓取和伸展。当前版本不支持独立单指控制，该功能已列入开发路线图。

### 兼容设备：

Raspberry Pi / D-Robotics RDK / NVIDIA Jetson 系列控制器，以及通过 USB 串口连接的 Windows 和 Linux 主机。与 LeRobot SO-ARM101 和 AmazingHand 开源项目完全兼容，并支持市场上大多数串口总线舵机。

### 三步简易设置：

- 使用随附的电缆将舵机驱动板连接到您的 Raspberry Pi、RDK 或 Jetson 控制器，然后为主臂供电 (DC5521 5V6A) 和从臂供电 (DC5521 12V5A)。
- 通电并通过 USB 串口连接。机械臂和灵巧手出厂时已组装、接线和校准——无需进行机械组装或舵机 ID 设置。
- 按照提供的 LeRobot 教程进行从臂遥操作、采集双视角数据集并训练您的模仿学习策略。
