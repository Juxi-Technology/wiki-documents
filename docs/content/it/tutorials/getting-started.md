# Guida rapida

Benvenuto da Juxi Technology! Questo tutorial ti aiuta a iniziare con i nostri prodotti.

## Preparazione

Prepara:

- Hardware del prodotto
- Cavo USB
- PC (Windows/macOS/Linux)

## Passo 1: Collegare l'hardware

1. Collegare il prodotto al PC via USB
2. Attendere l'installazione automatica dei driver
3. Verificare che il dispositivo sia riconosciuto

## Passo 2: Installare il software

```bash
# Installare le dipendenze
npm install

# Avviare l'applicazione
npm start
```

## Passo 3: Iniziare

Ora puoi usare il prodotto! Consulta gli altri tutorial per maggiori dettagli.
