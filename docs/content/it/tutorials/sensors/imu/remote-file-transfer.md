# Trasferimento remoto di file

## 1. MobaXterm

MobaXterm è un potente strumento remoto che integra strumenti remoti come SHH, VNC, FTP, ecc.

## 2. Installazione di MobaXterm

Sito web ufficiale: [https://mobaxterm.mobatek.net/](https://mobaxterm.mobatek.net/)

![Immagine 1](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/1.png)

### 2.1. Download di MobaXterm

Selezionare la versione gratuita per il download:

![Immagine 2](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/2.png)

Selezionare la versione di installazione per il download:

![Immagine 3](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/3.png)

### 2.2. Installazione di MobaXterm

Decomprimere il pacchetto scaricato dal sito web ufficiale e aprire il file `MobaXterm_installer_24.4.msi` per procedere all'installazione:

![Immagine 4](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/4.png)

Accettare il contratto:

![Immagine 5](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/5.png)

Selezionare la posizione di installazione del software: si consiglia la posizione predefinita

![Immagine 6](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/6.png)

Installazione effettiva:

![Immagine 7](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/7.png)

![Immagine 8](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/8.png)

## 3. Uso di MobaXterm

Individuare sul desktop l'icona `MobaXterm` e aprirla:

![Immagine 10](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/10.png)

## 4. MobaXterm: SSH remoto

Selezionare `Session` → `SSH`: inserire l'IP e il nome utente del dispositivo remoto

Ad esempio:

Informazioni predefinite della scheda Jetson:

Nome utente: juxi

Password: juxi

Nota: usando SSH remoto con MobaXterm, nella barra laterale verrà effettuato automaticamente l'accesso remoto tramite SFTP
