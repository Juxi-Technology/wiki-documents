# Collegamento hardware

Questo capitolo descrive in dettaglio il collegamento hardware dei prodotti.

## Interfacce

Il prodotto offre le seguenti interfacce:

- USB-C: alimentazione e trasferimento dati
- GPIO: ingressi/uscite di uso generale
- HDMI: uscita video

## Passi di collegamento

1. **Collegare l'alimentazione**: usare un cavo USB-C per l'alimentazione
2. **Collegare le periferiche**: collegare le altre periferiche secondo necessità
3. **Avviare**: premere il pulsante di accensione per avviare il dispositivo

## Note

- Verificare che la tensione di alimentazione rispetti i requisiti
- Evitare di collegare/scollegare dispositivi GPIO a dispositivo acceso
