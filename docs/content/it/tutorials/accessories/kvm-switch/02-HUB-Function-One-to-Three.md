# 02 · Funzione HUB (uno a tre)

> [← Torna alla panoramica](/it/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Prodotto applicabile: JUXI Technology KVM&HUB&TTL

## Come si usa

**Un ingresso Type-C, tre uscite USB-A** — con un solo computer collegato, questo prodotto è un normale HUB USB:

1. Collega il computer alla porta **PC1** (o PC2) con un cavo Type-C;
2. Collega tastiera, mouse, chiavetta USB, ecc. a una qualsiasi porta **USB-A**.

Con due computer collegati, le 3 porte USB-A commutano in blocco tra i due (vedi [01](/it/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

(Illustrazione: risorsa del tutorial 02 – HUB uno a tre)

## Dispositivi supportati

| Compatibili | Meglio collegare direttamente al computer |
|---|---|
| Tastiere, mouse (inclusi i ricevitori wireless) | Dischi rigidi portatili, SSD |
| Chiavette USB | Schede di acquisizione video e altri dispositivi ad alta larghezza di banda |
| Stampanti, dongle USB | Periferiche gaming ad alto polling rate (con cautela) |
| Moduli seriali, sensori (meglio la porta TTL — vedi 04) | |

- **Senza driver**: plug-and-play su Windows / macOS / Linux / sistemi operativi nazionali cinesi;
- La specifica è **USB 2.0** — scegli i dispositivi secondo la tabella sopra.
