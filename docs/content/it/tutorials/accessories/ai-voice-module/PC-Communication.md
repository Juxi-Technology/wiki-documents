# Comunicazione con PC

## Connessione del dispositivo

Portare l'interruttore a slitta in modalità porta seriale STC8

![Immagine 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## Apertura dell'assistente di debug della porta seriale

- Aprire Uart Assistant, selezionare il numero di porta seriale corrispondente e impostare il baud rate su 115200,

![Immagine 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- Consultare nell'archivio compresso il file 命令词播报词协议列表V1_中文

![Immagine 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- Quando diciamo “小车前进”, l'assistente di debug della porta seriale stampa il protocollo corrispondente

![Immagine 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- Inserire il comando corrispondente in base al file 命令词播报词协议列表V1_中文; il modulo vocale riproduce il testo corrispondente al protocollo

![Immagine 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

È possibile sentire il modulo vocale riprodurre correttamente.
