## Cablaggio

In base all'interfaccia della scheda madre, esistono tre metodi di cablaggio

**Porta HDMI**——&gt;Cavo HDMI——&gt;Porta HDMI della scheda di acquisizione——&gt; USB/Type-C ——&gt;laptop, PC, all-in-one, smartphone/tablet, ecc.

**Porta Micro HDMI**——&gt;Adattatore Micro HDMI——&gt;Cavo HDMI——&gt;Porta HDMI della scheda di acquisizione——&gt; USB/Type-C ——&gt;laptop, PC, all-in-one, smartphone/tablet, ecc.

**Porta DP**——&gt;Adattatore DP-HDMI——&gt;Cavo HDMI——&gt;Porta HDMI della scheda di acquisizione——&gt; USB/Type-C ——&gt;laptop, PC, all-in-one, smartphone/tablet, ecc.
