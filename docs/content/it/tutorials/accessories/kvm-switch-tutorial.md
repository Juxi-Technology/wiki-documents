# Uso dello switch KVM

Lo switch KVM offre funzione HUB, seriale TTL e modulo Bluetooth.

## Funzioni dei moduli

### 1. HUB

1× USB (Type-C) → 3× USB.

### 2. Seriale TTL

Pin (da sinistra): GND RXD TXD TNOW 3V3 5V

### 3. Bluetooth

Comandi AT o modalità slave (telefono: protocollo 4.2).

## Doppia commutazione

### 1. Dispositivo A + Dispositivo B (entrambi con display)

Pulsante e telecomando IR.

### 2. Scheda madre (senza display) + host (con display)

Commutazione con pulsante.
