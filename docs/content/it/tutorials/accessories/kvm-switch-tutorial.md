# Switch KVM

> **[Acquista nel negozio](https://www.juxitech.com/it/products/4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**


Lo switch KVM offre funzione HUB, seriale TTL e modulo Bluetooth.

![Immagine – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/1.png)

## Funzioni dei moduli

### 1. HUB

1× USB (Type-C) → 3× USB.

![1. Funzione HUB – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/2.png)

### 2. Seriale TTL

Pin (da sinistra): GND RXD TXD TNOW 3V3 5V

![2. Porta seriale TTL – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/3.png)

### 3. Bluetooth

Comandi AT o modalità slave (telefono: protocollo 4.2).

![3. Modulo Bluetooth – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/4.png)

## Doppia commutazione

### 1. Dispositivo A + Dispositivo B (entrambi con display)

Pulsante e telecomando IR.

![1. Dispositivo A + Dispositivo B entrambi con display – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/5.png)

### 2. Scheda madre (senza display) + host (con display)

Commutazione con pulsante.

È sufficiente aggiungere un dispositivo di acquisizione HDMI 4K collegato all'host e usare sull'host software come OBS e PotPlayer per acquisire lo schermo.

![2. Scheda madre senza display + Host con display – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/6.png)

**Cablaggio del dispositivo di acquisizione HDMI 4K**

In base all'interfaccia della scheda madre, ci sono le seguenti tre modalità di cablaggio

**Interfaccia HDMI** ——\> Cavo HDMI ——\> Interfaccia HDMI del dispositivo di acquisizione ——\> USB/Type-C ——\> Display come laptop, computer, all-in-one, smartphone/tablet, ecc.

**Interfaccia Micro HDMI** ——\> Adattatore Micro-HDMI → HDMI ——\> Cavo HDMI ——\> Interfaccia HDMI del dispositivo di acquisizione ——\> USB/Type-C ——\> Display come laptop, computer, all-in-one, smartphone/tablet, ecc.

**Interfaccia DP** ——\> Adattatore DP → HDMI ——\> Cavo HDMI ——\> Interfaccia HDMI del dispositivo di acquisizione ——\> USB/Type-C ——\> Display come laptop, computer, all-in-one, smartphone/tablet, ecc.
