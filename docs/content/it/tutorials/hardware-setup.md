# Collegamento hardware

Guida dettagliata al collegamento hardware del prodotto.

## Interfacce

- USB-C: alimentazione e dati
- GPIO: ingressi/uscite generali
- HDMI: uscita video

## Passaggi

1. **Alimentazione**: collegare il cavo USB-C
2. **Periferiche**: collegare secondo necessità
3. **Accensione**: premere il pulsante di accensione

## Precauzioni

- Verificare la tensione di alimentazione
- Non collegare/scollegare dispositivi GPIO sotto tensione
