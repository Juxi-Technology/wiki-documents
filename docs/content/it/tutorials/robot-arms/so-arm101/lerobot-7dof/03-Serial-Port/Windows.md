# Computer Windows

Apri il `Gestione dispositivi`, collega prima il `braccio passivo`, poi il `braccio attivo`, e controlla il numero di porta COM corrispondente

![image\.png](/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## Annotare il numero di porta

Braccio passivo:

COM6

Braccio attivo:

COM7
