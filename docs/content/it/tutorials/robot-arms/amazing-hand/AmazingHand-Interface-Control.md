## Esempio del repository ufficiale

Juxi Technology fornisce codice di controllo open source per AmazingHand: [GitHub](https://github.com/Juxi-Technology/AmazingHand)

### Controllo base

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
