## Come contribuire

### 1. Scrivere tutorial

Condividi la tua esperienza con SO-ARM101 scrivendo tutorial per aiutare gli altri.

**Per iniziare:**
- Scegli un argomento (scenari applicativi, approfondimenti tecnici, ecc.)
- Segui la struttura dei tutorial esistenti
- Invia una Pull Request

### 2. Tradurre la documentazione

Aiutaci a tradurre i documenti in più lingue, così più utenti potranno beneficiarne.

**Lingue attuali:** cinese semplificato / inglese / cinese tradizionale

### 3. Inviare casi d'uso

Condividi i tuoi casi d'uso e mostra i risultati dei tuoi progetti. Vedi la [pagina delle storie di successo](/it/cases/).

### 4. Segnalare problemi

Hai trovato un bug o hai un suggerimento? Invia un Issue per aiutarci a migliorare.

### 5. Contributi di codice

Contribuisci con codice ai progetti open source correlati, incluso LeRobot.
