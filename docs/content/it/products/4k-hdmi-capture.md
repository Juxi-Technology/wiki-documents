# Scheda di acquisizione HDMI 4K

> **[Acquista nel negozio](https://www.juxitech.com/it/products/4k-hd-hdmi-capture-card)**

## Panoramica

La scheda di acquisizione HDMI 4K supporta HDMI / Micro HDMI / DP e si collega via USB/Type-C direttamente a notebook, PC o display di smartphone/tablet. Ideale per streaming, registrazione e dimostrazioni didattiche.

**Caratteristiche principali**:

- Acquisizione 4K
- Compatibile HDMI / Micro HDMI / DP
- USB / Type-C plug-and-play
- Supporto OBS / PotPlayer

## Specifiche

| Categoria | Specifica |
|------|------|
| Ingresso | HDMI / Micro HDMI / DP (adattatore) |
| Uscita | USB / Type-C |
| Acquisizione | 4K |
| Software | OBS / PotPlayer |

## Avvio rapido

1. Scegliere il cablaggio in base all'interfaccia della scheda (HDMI / Micro HDMI / DP)
2. Collegare l'USB del capture al dispositivo di visualizzazione
3. Selezionare il dispositivo di acquisizione in OBS / PotPlayer
