# Storie di successo degli utenti

Qui raccogliamo casi reali di utenti dei prodotti Juxi Technology — educazione, ricerca e applicazioni commerciali.

---

## Educazione · Laboratorio di robotica

> "Il SO-ARM101 è esattamente ciò di cui la comunità robotica open source aveva bisogno — conveniente, liberamente modificabile e compatibile ROS 2 fin dall'inizio. Lo usiamo in università per insegnare algoritmi di bracci robotici agli studenti."

**—— Ricercatore di robotica, HKUST (Hong Kong)**

**Prodotto**: Braccio robotico SO-ARM101
**Uso**: Insegnamento di algoritmi di bracci robotici
**Valore**: Open source + compatibilità ROS 2 + modifica libera

## Commerciale · Deployment Edge AI

> "La piattaforma Edge AI Jetson di JuxiTech ci permette di distribuire modelli di computer vision in produzione con TensorRT, a costi molto inferiori rispetto ad altre soluzioni. L'SDK open source ci ha risparmiato settimane di integrazione."

**—— Sviluppatore Edge AI, contributore della community**

**Prodotto**: Piattaforma di calcolo Edge NVIDIA Jetson
**Uso**: Deployment di modelli di visione in produzione
**Valore**: Ottimizzazione TensorRT + SDK open source + vantaggio di costo
