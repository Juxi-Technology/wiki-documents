# Chi siamo

## Profilo aziendale

**Juxi Technology**, con sede a **Qianhai Shenzhen**, segue **"With Hong Kong · For the Mainland · To the World"**.

Sviluppiamo **intelligenza artificiale fisica, robotica incarnata e AI di periferia**, offrendo **soluzioni open source** agli sviluppatori di tutto il mondo.

## Impegno open source

**Ogni prodotto JuxiTech è open source.**

- 📐 Schemi hardware completi
- 🔧 Codice sorgente firmware
- 🖥️ File CAD
- 📦 Codice SDK

Gratuitamente su [Feishu Wiki](https://juxitech.feishu.cn) e [GitHub](https://github.com/Juxi-Technology).
