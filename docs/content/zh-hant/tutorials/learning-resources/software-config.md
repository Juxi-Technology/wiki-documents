# 軟件配置

本章節介紹產品軟體配置方法。

## 系統要求

- Node.js 18+
- Python 3.10+
- Git

## 安裝步驟

```bash
# 複製儲存庫
git clone https://github.com/Juxi-Technology/your-repo.git

# 進入目錄
cd your-repo

# 安裝依賴
npm install
```

## 配置檔案

編輯`config.json`以根據您的需要進行配置：

```json
{
  "port": 3000,
  "language": "zh-CN"
}
```
