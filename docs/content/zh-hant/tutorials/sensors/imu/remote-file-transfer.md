## 3、MobaXterm使用

![圖 10](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/10.png)

## 4、MobaXterm：SSH遠程

選擇`Session` → `SSH` ：填寫遠程裝置IP和使用者名

例如：

Jetson主板預設資訊：

使用者名：juxi

密碼：juxi

注意：MobaXterm使用SSH遠程就會在側邊欄自動使用SFTP遠程登錄
