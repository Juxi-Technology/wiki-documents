# IMU模塊介紹

> **[ 淘寶店鋪 ](https://juxitechnology.taobao.com)**


高精度 IMU 姿態傳感器內置**72MHz 高性能 32 位處理器**，可實時姿態解算與動態補償，數據更新頻率高達 100Hz，兼具響應迅捷、輸出穩定的優勢。支持 IIC 與串口雙通信模式，兼容單片機、Linux 主控，並可無縫集成 ROS 系統，廣泛適用於機器人運動控制、無人機航姿穩定、智能導航定位等高性能應用場景。
