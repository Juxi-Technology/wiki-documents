# GPS模組資料

​		GPS模組是基於ATGM336H-5N的高性能BDS/GNSS 定位導航模組。模組支援多種衞星導航系統，包括中國的北斗二號和北斗三號全部衞星，美國的GPS，俄羅斯的GLONASS，日本的QZSS，可以同時接收以上衞星導航系統的衞星信號，並且實現聯合定位、導航與授時，模組具有高靈敏度、低功耗、低成本等優勢，適用於車載導航、手持定位、可穿戴裝置。

**一、模組特點：**

- 支援北斗二號和北斗三號1~63 號全部衞星

- 支援BDS/GPS/QZSS 衞星導航系統的單系統定位，以及任意組合的多系統聯合定位。

- 支援A-GNSS

- 冷啓動捕獲靈敏度：-148dBm

- 跟蹤靈敏度：-162dBm

- 定位精度：2.5 米（CEP50）

- 首次定位時間：32 秒

- 低功耗：連續執行25mA@3.3V

- 內置天線檢測及天線短路保護功能
