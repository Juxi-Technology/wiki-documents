# 網頁端使用教程

本教程介紹如何使用瀏覽器版上位機連接、監測心率血氧模組。網頁版基於 Web Serial 直接存取串口，無需安裝 Python 或 `.exe`，Windows、macOS、Linux 均可使用。

**線上網址：**[https://juxi-technology.github.io/JUXI_HeartRate_SPO2/](https://juxi-technology.github.io/JUXI_HeartRate_SPO2/)

> 網頁版與桌面版上位機使用同一套 Modbus RTU 協議（從機位址 `0x20`、9600 波特率），讀數完全一致。

## 一、環境要求

- 桌面版 **Chrome、Edge 或 Opera**（需支援 Web Serial）
- Safari、Firefox 和手機瀏覽器未實作 Web Serial，無法連接串口
- USB 轉 TTL 驅動（CH340、CP2102、FT232 等）
- 頁面需要聯網載入
- 瀏覽器一次只授權頁面一個串口裝置

## 二、硬體連接

| 心率血氧模組 | USB 轉 TTL |
|---|---|
| **VCC** | **5V**（不要接 3.3V） |
| **GND** | **GND** |
| **TX** | **RX**（交叉連接） |
| **RX** | **TX**（交叉連接） |

⚠️ TX 與 RX 必須交叉連接。接好後再將 USB 轉 TTL 插入電腦。

## 三、連接裝置

1. 使用桌面版 Chrome / Edge / Opera 開啟上方線上網址。
1. 波特率保持 **9600**，與模組一致。
1. 點擊「**連接串口**」，在瀏覽器自帶的彈窗中選擇模組對應的 USB 串口裝置。
1. 狀態顯示「**已連接，待採集**」即連接成功，按鈕旁會顯示所選裝置。

> 串口參數固定為 8 數據位、1 停止位、無校驗、無流控，由頁面自動設定，無需手動配置。

## 四、啟動採集與監測

1. 點擊「**啟動採集**」——模組 LED 點亮，狀態變為「採集已啟動，LED已亮」。
1. 將手指放在傳感器上，完全覆蓋光學區域，輕放即可，不要用力按壓。
1. 點擊「**開始監測**」——狀態變為「正在監測...」，實時數據開始刷新。

## 五、介面說明

### 實時數據

| 指標 | 單位 | 說明 |
|---|---|---|
| 血氧 (SPO2) | % | 血氧飽和度 |
| 心率 | 次/分 | 脈率 |
| 溫度 | °C | 模組板載溫度，非體溫 |

**濾波**：預設開啟。對讀數做 5 點中位數平滑，並剔除超出合理範圍的異常值（心率 35–220、血氧 70–100%、溫度 0–60 °C）。剔除的數量會顯示在數據區下方，例如「已剔除 N 個異常值」。取消勾選可查看未經處理的原始讀數。

**狀態提示**：未連接 / 等待選擇裝置… / 已連接，待採集 / 採集已啟動，LED已亮 / 採集已關閉，LED已滅 / 正在監測… / 監測已停止 / 裝置已斷開 / 當前瀏覽器不支援 Web Serial。

### 語言切換

右上角的 **EN / 中文** 按鈕用於切換介面語言。波特率和濾波開關的選擇會被瀏覽器記住，下次開啟時保持上次的設定。

### 使用文件頁籤

頂部「**使用文件**」頁籤內置本產品的 11 種語言教程，可在頁面內直接切換語言閱讀。

## 六、停止與斷開

建議按以下順序操作：

1. 點擊「停止監測」
1. 點擊「關閉採集」——LED 熄滅
1. 點擊「斷開連接」

## 七、數據解讀

| 數據 | 正常範圍 | 說明 |
|---|---|---|
| 血氧 SpO2 | 95% – 100% | 低於 90% 建議就醫 |
| 心率 | 60 – 100 次/分 | 成人靜息範圍 |
| 溫度 | 25 – 35 °C | 板載傳感器溫度，非體溫 |

剛連接或手指未放好時顯示 `-1` 屬於正常現象。

## 八、與桌面上位機的區別

| 對比項 | 網頁版 | 桌面上位機 |
|---|---|---|
| 安裝 | 無需安裝 | 需執行 `.exe` 或 Python 腳本 |
| 執行環境 | 瀏覽器 | Windows |
| 通訊方式 | Web Serial | 系統串口 |
| 離線使用 | 不支援，頁面需聯網 | 支援 |
| 協議與讀數 | 相同 | 相同 |

## 九、常見問題

**Q1：提示「當前瀏覽器不支援 Web Serial」。**
換用桌面版 Chrome、Edge 或 Opera。Safari、Firefox 和手機瀏覽器均未實作 Web Serial。

**Q2：點擊「連接串口」後，彈窗中沒有裝置。**
檢查 USB 轉 TTL 驅動是否安裝、數據線是否支援數據傳輸；可換一個 USB 埠或重新插拔後再試。

**Q3：連接失敗。**
確認串口沒有被其他程式佔用（串口助手、Arduino IDE 等），並確認裝置已上電。

**Q4：點擊「啟動採集」後 LED 不亮。**
確認 VCC 接的是 5V 而不是 3.3V，並檢查 TX/RX 是否交叉連接。

**Q5：數據一直顯示 -1。**
確認已經點擊「啟動採集」，手指完全覆蓋傳感器光學區域，並保持穩定數秒。

**Q6：裝置被拔出。**
頁面會顯示「裝置已斷開」，重新插好後再次點擊「連接串口」。

## 十、注意事項

1. 先接傳感器，再插 USB。
1. 傳感器必須使用 5V 供電，3.3V 可能無法正常工作。
1. 測量時手指完全覆蓋光學區域，不要用力按壓。
1. 避免強光直射傳感器。
1. 瀏覽器一次只授權一個串口裝置，多個裝置需要分別連接。
