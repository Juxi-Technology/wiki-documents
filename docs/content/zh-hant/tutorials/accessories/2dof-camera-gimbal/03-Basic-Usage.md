# 基礎使用

> **[ 淘寶店鋪 ](https://juxitechnology.taobao.com)**

本章節詳細介紹雲台的基本控制方法與使用流程，幫助使用者熟悉基礎操作。

---

## 控制方式概述

雲台系統支援兩種主要控制方式：
1. 鍵盤控制：透過鍵盤按鍵手動控制雲台運動
2. 自動追蹤：系統自動辨識並追蹤目標

---

## 鍵盤控制

### 鍵盤快捷鍵說明

以下是主程式中可使用的鍵盤快捷鍵：

|按鍵|功能說明|
|---|---|
|方向鍵 ←|雲台向左轉動|
|方向鍵 →|雲台向右轉動|
|方向鍵 ↑|雲台向上俯仰|
|方向鍵 ↓|雲台向下俯仰|
|C|連接或斷開雲台|
|R|雲台回中（回到初始位置）|
|1|切換到人臉追蹤模式|
|2|切換到顏色追蹤模式|
|T|鎖定/開始追蹤目標|
|S|停止追蹤|
|X|顏色模式：追蹤紅色物體|
|Y|顏色模式：追蹤綠色物體|
|Z|顏色模式：追蹤藍色物體|
|Q|退出程式|


### 獨立的鍵盤控制範例

你也可以使用單獨的鍵盤控制程式進行練習：

```python
python examples/keyboard_control.py --port COM3
```

此程式僅提供基礎的雲台控制功能，適合初學者上手。

## 基礎操作流程

### 啟動與連接

1. 使用以下命令啟動主程式：

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3
```

1. 程式啟動後，按 `C` 連接雲台
2. 觀察舵機是否正常回應，如有異常請參考疑難排解章節

### 手動控制練習

1. 按下方向鍵，觀察雲台運動是否與預期一致
2. 練習用方向鍵將雲台移動到不同位置
3. 按 `R` 讓雲台回中
4. 熟悉雲台的最小和最大位置限制
建議進行以下練習：
- 練習1：移動雲台到最左、最右、最上、最下四個極限位置，熟悉位置範圍
- 練習2：從任意位置回中，觀察回中是否流暢
- 練習3：嘗試精細調節，熟悉舵機的運動精度

## 基礎範例程式

本專案提供了幾個遞進的範例程式供使用者學習：

### 僅顯示攝影機

```python
python examples/01_camera_only.py --camera 0
```

此程式僅開啟攝影機，顯示即時畫面，不涉及雲台控制。適合驗證攝影機功能是否正常。

### 僅控制雲台

```python
python examples/02_gimbal_only.py --port COM3
```

此程式僅提供雲台控制功能，不涉及攝影機。適合驗證舵機與驅動板連接是否正常。

### 攝影機與雲台結合

```python
python examples/03_simple_gimbal_camera.py --camera 0 --port COM3
```

此程式結合了攝影機顯示與雲台控制，可以觀察畫面與雲台聯動效果。

## 使用注意事項

在使用過程中，請注意以下幾點：
1. 連接雲台後，確認舵機已插上電源
2. 手動控制時，注意不要長時間停在極限位置
3. 操作時避免暴力碰撞雲台支架
4. 如發現舵機異常抖動或異音，請立即斷電檢查
5. 長時間不使用時，建議斷開電源連接
