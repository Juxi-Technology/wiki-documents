## 硬體連接

### 步驟 1：安裝舵機與雲台支架

1. 將1號舵機（用於左右轉動）安裝在雲台底部支架的指定位置，固定螺絲確保穩固
2. 將2號舵機（用於上下俯仰）安裝在雲台的上部支架，同樣固定好
3. 按說明安裝好攝影機固定結構

### 步驟 2：舵機與驅動板連接

1. 將兩個舵機的數據線連接到驅動板的舵機接口
2. 注意舵機線的連接順序，顏色一般為紅（電源）、黑（地線）、白/黃（訊號）
3. 確保舵機連接對應ID：舵機ID 1 為左右，舵機ID 2 為上下

### 步驟 3：電源與串口連接

1. 將舵機電源連接到驅動板的電源接口
2. 使用串口數據線連接驅動板與電腦的USB接口
3. 連接攝影機到電腦

## 驅動與相依性安裝

### 安裝串口驅動

#### Windows

1. 訪問 CH343 晶片廠商官網，下載對應 Windows 版本的驅動安裝程式
CH343驅動安裝（以管理員身分安裝）
https://www.wch.cn/downloads/CH343SER_EXE.html

>
> 若在裝置管理員被辨識成未知裝置usb single serial 或usb serial，請先按右鍵解除安裝，再安裝驅動！

1. 執行安裝程式，按提示完成驅動安裝
2. 連接舵機驅動板到電腦，裝置管理員中應能看到串口裝置

#### Linux

大多數 Linux 發行版已內建 CH343 串口驅動，無需額外安裝。如遇問題，可嘗試：
1. 檢查核心是否已載入驅動 `lsmod | grep ch343`
2. 如未載入，嘗試重新插拔裝置或重啟

### 安裝 Python相依性

在專案根目錄下執行：

```python
pip install -r requirements.txt
```

本專案主要相依性包括：
- opencv-python：影像擷取與處理
- numpy：數值計算庫
- pyserial：串口通訊庫

## 驗證硬體連接

在啟動正式程式之前，我們可以使用工具進行硬體連接驗證。

### 尋找可用攝影機

執行以下命令列出可用攝影機：

```python
python examples/list_cameras.py
```

程式將偵測並列出所有可用攝影機，記錄下你需要使用的攝影機索引。

### 尋找可用串口

執行以下命令列出可用串口：

```python
python examples/list_ports.py
```

記錄下你所使用的串口裝置名稱。

### 硬體診斷

如需對整體硬體進行全面檢測，可以執行診斷工具：

```python
python examples/diagnostic.py --camera 0 --port COM3
```

診斷程式將依序測試攝影機、串口和雲台。

## 安全提示

在使用過程中，請注意以下安全事項：
1. 舵機電源需在規定範圍內（4V-7.4V），防止損壞舵機
2. 避免舵機長時間工作在極限位置，以延長使用壽命
3. 斷電前建議先將雲台回中，減輕下次啟動負載
