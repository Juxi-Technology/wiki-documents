# 2 自由度相機雲台

> **[ 淘寶店鋪 ](https://juxitechnology.taobao.com)**

二自由度攝影機雲台 —— 支援鍵盤手動控制，以及顏色、人臉、QR 碼自動追蹤。
硬體：SCS009 舵機 ×2（左右轉動 + 上下俯仰）+ CH343 串行總線驅動板（預設鮑率 1Mbps）。
