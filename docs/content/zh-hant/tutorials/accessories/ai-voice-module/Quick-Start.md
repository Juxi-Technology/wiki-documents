# 快速上手

出廠已燒錄語音辨識功能韌體，使用者無需燒錄即可快速體驗，如需增加其他辨識詞條，如果需要重燒其他韌體，自訂詞條，可前往《3.自訂協定詞條製作》教學下查看如何自訂詞條。

## 1.使用前準備

1. type-c資料線一根  

2. 語音互動模組

## 3.語音辨識及播報實現

給語音互動模組使用type-c供上電之後，透過“你好，小犀”喚醒詞可以將模組喚醒，成功喚醒模組會回覆“我在”，表示當前時間是可以辨識語音狀態，如果15秒內沒有辨識到命令詞條，模組會進入休眠模式同時播報“我去休息了”。如果想重新喚醒模組可以重新說出喚醒詞。

出廠韌體自帶了命令詞和播報詞，可以在提供的資料附件裡查看到協定列表，下圖截取了部分命令詞播報詞協定列表的內容，可以透過功能類型來查看對應的命令詞代表什麼功能，需要播報的播報詞是被動的播報詞，需要透過電腦串列埠或者其他單晶片或者主控裝置給語音互動模組發送對應的指令才能觸發，具體可以下圖。

有兩種播報模式，一種是主動式的，一種是被動播報

主動播報：當我們根據表格說出命令詞之後，模組會主動播報對應的語句，喚醒之後我們說出“小車前進”，模組辨識到之後會主動播報“好的，正在前進” 

被動播報：需要透過協定表裡指令透過串列埠發送給語音模組，模組才會播報對應的語句，也可以根據IIC協定透過給被動播報的暫存器，寫入對應的播報資料。具體內容可以看《多主控通訊》
