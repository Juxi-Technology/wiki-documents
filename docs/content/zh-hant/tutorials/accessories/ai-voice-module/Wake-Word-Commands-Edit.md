# 修改喚醒詞和命令詞

## 1.注意事項

請在安靜的場景下進行修改喚醒詞，嘈雜的環境會影響語音互動模組的辨識準確率。

說詞條時，聲音要洪亮且語速不宜過快，建議與模組之間保持在 5 米以內。

## 3.修改喚醒詞

對語音互動模組說出 “你好，小犀” 將語音互動模組喚醒，當模組回覆 “我在”時，表明當前處於可辨識狀態  再對語音互動模組說出 “學習喚醒詞”詞條，語音互動模組回應 “說出喚醒詞”，即可進入到喚醒詞學習功能狀態  接著對語音互動模組說出想要設置的喚醒詞，喚醒詞盡量簡短，這裡以設置 “你好，小犀”為例  當語音互動模組辨識成功後，將會播報“學習成功”，表明喚醒詞修改成功，這時候我們就可以使用“你好小犀”詞條就能喚醒模組了。

注意事項：出廠韌體中的喚醒詞 “你好，小犀” 是基礎喚醒詞，無法透過語音進行修改或刪除。使用者使用語音修改的喚醒詞只能同時存在一個，與基礎喚醒詞時共同存在的

用法舉例如下：

對語音互動模組說出 "你好，小犀"將語音互動模組喚醒，當模組回覆 “我在”時，表明當前處於可辨識狀態  再對語音互動模組說出 “學習停車指令”詞條，語音互動模組回應 “請說指令”，即可進入到命令詞學習功能狀態  接著對語音互動模組說出想要設置的命令詞，命令詞應該盡量簡短，這裡以設置 “前方停車”位置  當語音互動模組辨識成功之後，會播報 “學習成功”，表明命令詞修改成功，這時候我們可以使用“前方停車” 詞條就能達到與 “停車”命令詞一樣的效果了  如果需要刪除掉 ”前方停車“ 詞條，只需要說出 ”刪除停車指令“ ，當回覆 ”刪除成功”時，即可完成詞條刪除（這裡只會刪除“前方停車”，不會刪除 ”停車“）。

注意：出廠韌體中命令詞時基礎命令詞，無法透過語音進行修改或者刪除，使用者使用語音修改的命令詞只能同時存在一個，並且與基本命令詞共存。
