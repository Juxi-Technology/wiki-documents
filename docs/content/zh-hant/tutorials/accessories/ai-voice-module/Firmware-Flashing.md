# 模組韌體燒錄

## 模組韌體燒錄方法

## 1.語音晶片燒錄步驟

## 1.1設備連接

![圖 1](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/1.png)

## 1.2.開啟燒錄軟體

開啟附件中的語音晶片韌體燒錄工具資料夾點擊”PACK_UPDATE_TOOL.exe“

![圖 2](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/2.png)

選擇CI1302晶片，然後點擊“韌體升級”

![圖 3](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/3.png)

進入韌體升級介面，按下"F1"可查看幫助

點擊選擇 剛剛製作固 件 ， 找 到 附件中出廠韌體 的 “ CI1302中文单麦_V00681_UART1_115200_2M”韌體。

![圖 4](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/4.png)

選擇韌體，找到對應的串列埠號，並點擊方框打勾

![圖 5](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/5.png)

將滑動開關撥到Download的位置，Download表示為語音晶片燒錄韌體（也就是靠右的一邊）

![圖 6](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/6.png)

撥到對應的位置之後，按下語音互動模組上的 RST 鍵，即可進入到燒錄中，等待燒錄成功，點擊“退出”即可。

![圖 7](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/7.png)
