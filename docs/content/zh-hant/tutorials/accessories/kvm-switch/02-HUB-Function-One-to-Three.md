# 02 · HUB 功能（一分三）

> [← 返回教程總覽](/zh-hant/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜適用產品：鉅犀科技 KVM&HUB&TTL

## 怎麼用

**一根 Type-C 進，三個 USB-A 出**——只接一台電腦時，本產品就是普通 USB HUB：

1. 用 Type-C 線把電腦接到 **PC1**（或 PC2）口；
2. 鍵盤、滑鼠、U 盤等插到任意 **USB-A** 口即可使用。

接兩台電腦時，3 個 USB-A 作為一個整體在兩台電腦間切換（見 [01 篇](/zh-hant/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)）。

（配圖：教程原圖 02 - 一分三 HUB）

## 支援什麼裝置

| 可以接 | 建議直連電腦 |
|---|---|
| 鍵盤、滑鼠（含無線接收器） | 行動硬碟、固態儲存 |
| U 盤 | 視訊擷取卡等高頻寬裝置 |
| 印表機、加密狗 | 電競級高回報率外設（請謹慎） |
| 序列埠模組、感測器（接 TTL 口更佳，見 04 篇） | |

- **免驅**：Windows / macOS / Linux / 國產系統即插即用；
- 規格為 **USB 2.0**，請按上表選擇裝置。
