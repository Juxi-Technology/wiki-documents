# 04 · TTL 序列埠（無線序列埠）

> [← 返回教程總覽](/zh-hant/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜適用產品：鉅犀科技 KVM&HUB&TTL

## 它是什麼

6 針 TTL 口是**序列埠透傳口**：把開發板、感測器等裝置接上來，它的序列埠資料會「同時」從兩個地方輸出（雙向）：

```
                ┌─→ 電腦序列埠（USB，系統識別的 "USB-BLE-SERIAL CH9143"）
外接裝置 → 6 針口 ┤
                └─→ 藍牙無線（手機 BleUart App，見 03 篇）
```

**實測參考**：接入一枚 IMU 感測器後，電腦序列埠與藍牙同時穩定收到約 1650 位元組/秒的資料。

## 針腳定義與接線

從左到右：`GND` `RXD` `TXD` `TNOW` `3V3` `5V`

| 針腳 | 說明 | 接法 |
|---|---|---|
| GND | 地 | 與外部裝置 GND 相連（**必須接**） |
| RXD | 本機接收 | 接外部裝置的 **TXD**（交叉） |
| TXD | 本機發送 | 接外部裝置的 **RXD**（交叉） |
| TNOW | 發送方向指示 | **懸空不接** |
| 3V3 | 3.3V 電源輸出 | 可給低功耗外設供電（與 5V 二選一） |
| 5V | 5V 電源輸出 | 可給低功耗外設供電（與 3V3 二選一） |

**要點**：收發必須**交叉**；電平 **3.3V**；電源針是**輸出**，切勿回灌；只接低功耗模組。

## 電腦端使用

1. 本產品用 Type-C 連接電腦（PC1/PC2 任意口）；
2. 系統自動識別序列埠 **`USB-BLE-SERIAL CH9143`**（Windows 10/11 免驅）；
3. 用序列埠工具開啟，參數：**115200，8N1**；
4. 即時收到外接裝置的資料（也可向裝置發送資料）。

## 對接開發板（樹莓派 / Jetson）

電平 3.3V，可直接對接（接線交叉、GND 相連）：

| 本產品 | 樹莓派 | Jetson（Orin 系列 40 針） |
|---|---|---|
| RXD | Pin8（GPIO14 / TXD） | Pin8（UART1_TXD） |
| TXD | Pin10（GPIO15 / RXD） | Pin10（UART1_RXD） |
| GND | 任意 GND（如 Pin9） | 任意 GND（如 Pin9） |

> 樹莓派需在 `raspi-config` 開啟序列埠；Jetson 需先啟用 40 針 UART。
> 典型場景：開發板序列埠接 KVM → 電腦上敲命令看日誌，手機藍牙同時也能看（無線除錯）。

（配圖：教程原圖 10 - Jetson 針腳圖、11 - 樹莓派針腳圖）

## 排查：序列埠沒有資料？

依次檢查：
1. 外部裝置 TX/RX 是否**交叉**、GND 是否接好；
2. 外部裝置鮑率是否為 **115200**；
3. 外部裝置是否已供電（可用本機 5V/3V3 針供電）；
4. 電腦序列埠是否被其他軟體佔用；裝置切到另一台電腦時序列埠會短暫消失（正常）。
