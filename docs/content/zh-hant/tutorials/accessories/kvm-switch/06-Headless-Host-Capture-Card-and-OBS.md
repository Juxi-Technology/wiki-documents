# 06 · 無顯示器主機（擷取卡 + OBS）

> [← 返回教程總覽](/zh-hant/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜適用產品：鉅犀科技 KVM&HUB&TTL

給「沒有顯示器的開發板 / 主機板」接一套鍵鼠，**不需要給它配顯示器**——畫面走擷取卡進電腦，鍵鼠走 KVM 切換。

## 工作方式

```
開發板（無顯示器）──視訊──→ 擷取卡 ──USB──→ 你的電腦（OBS 視窗看畫面）
開發板（無顯示器）──鍵鼠──→ ←── KVM 切換 ──→ 你的電腦（同一套鍵鼠）
```

## 步驟

**① 接畫面**（把主機的視訊輸出接到 **4K HDMI 擷取卡**，擷取卡 USB 端接你的電腦）：

| 主機輸出介面 | 接線 |
|---|---|
| HDMI | HDMI 線 → 擷取卡 |
| Micro HDMI（樹莓派等） | Micro 轉 HDMI 轉接頭 → HDMI 線 → 擷取卡 |
| DP | DP 轉 HDMI 轉接頭 → HDMI 線 → 擷取卡 |

**② 接鍵鼠**：鍵鼠（或無線接收器）插在本產品 USB-A 口，按按鍵把鍵鼠**切到開發板**；

**③ 看畫面 + 操作**：電腦上用 **OBS** 或 **PotPlayer** 新增「視訊擷取裝置」，即可一邊看開發板畫面、一邊敲鍵盤操作。

（配圖：教程原圖 06 - 開發板+擷取卡實景、07 - 擷取卡接線、08 - OBS 操作指南、09 - PotPlayer 操作指南）

## 提示

- 擷取卡建議**直連電腦**（不經過 KVM 的 USB 口），保證畫面穩定；
- 切走鍵鼠後，開發板上的操作會立即停止回應鍵鼠 —— 按一下按鍵即可切回。
