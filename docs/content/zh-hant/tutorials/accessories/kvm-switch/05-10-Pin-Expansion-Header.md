# 05 · 十針擴充埠

> [← 返回教程總覽](/zh-hant/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜適用產品：鉅犀科技 KVM&HUB&TTL

裝置右下角的 **10 針排座**為**預留擴充介面**，絲印如下：

| 排針 | 絲印 |
|---|---|
| 上排 | `RI#` `DSR#` `FCE` `DTR#` `RST#` |
| 下排 | `CTS#` `DCD#` `GND` `GND` `GND` |

## 說明

- 該口用於**外接控制器、自訂線纜等二次開發場景**（序列埠控制訊號相關）；
- 普通使用（切換鍵鼠、HUB、無線序列埠）**不需要連接此口**；
- 如需此介面的電氣定義與使用方式，請聯繫我們取得（以實物與最新說明書為準）；
- 自行接線前請用萬用電錶確認電平，避免對裝置造成損傷。
