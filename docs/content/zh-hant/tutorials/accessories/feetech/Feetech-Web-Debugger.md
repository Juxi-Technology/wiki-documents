# 飛特總線舵機網頁版調試（SCS0009 / STS3215 / HD1910）

> **桌面版工具：** [SCS0009 舵機調試工具使用教程](./SCS0009-Debug-Tool.md) ｜ [STS3215 & SCS0009 調試教程](./Feetech-STS3215&SCS0009-Tutorial.md)

飛特總線舵機調試工具的網頁版：瀏覽器透過 **Web Serial** 直接打開 USB 串口與舵機通信，可完成串口連接、舵機掃描、型號識別、參數讀寫、位置控制與實時跟隨、波特率修改、恢復出廠，以及 xdat 參數備份與恢復。

純靜態頁面，**無需安裝任何軟體或 Python 環境**，打開網址即可使用。目前適配 **SCS0009**、**STS3215**、**HD1910** 三種型號。

## 一、打開網頁

線上網址：

[https://juxi-technology.github.io/FT-ServoController-web/](https://juxi-technology.github.io/FT-ServoController-web/)

同一站點內還有完整的網頁版使用教程（支持中英文切換）：

[https://juxi-technology.github.io/FT-ServoController-web/guide.html](https://juxi-technology.github.io/FT-ServoController-web/guide.html)

環境要求：

- **Chrome 或 Edge 89+**（Firefox、Safari 不支持 Web Serial）
- 頁面須透過 **https 或 localhost** 打開
- 需安裝 USB 轉 TTL 驅動（CH340、CH343、CP2102 等）


## 二、連接串口

1. 在“🔌 串口連接”區選擇**波特率**，默認 1000000（1M）。
1. 點擊“**連接串口**”，在瀏覽器彈出的系統對話框中選擇舵機對應的 USB 串口。
1. 連接成功後，右上角狀態變為“🟢 已連接”。


可選波特率：1000000 / 500000 / 250000 / 128000 / 115200 / 76800 / 57600 / 38400。

## 三、掃描舵機與型號識別

1. 連接串口後，點擊“🔍 **掃描舵機**”。頁面掃描 ID 1–254，**發現即顯示**，無需等待全部掃完。
1. 掃描過程中按鈕會變成紅色的“⏹ **停止掃描**”，再點一次即可中斷，已經找到的舵機會保留。
1. 點擊舵機芯片（或上方下拉框）選擇目標舵機。


型號由舵機**地址 3 / 4 的兩個字節**（舵機主版本號、次版本號）自動判斷：

| 型號 | 識別字節（主 / 次） | 位置範圍 | 字節序 |
|---|---|---|---|
| SCS0009 | 5 / 4 | 0–1023 | 大端 |
| STS3215 | 9 / 3 | 0–4095 | 小端 |
| HD1910 | 10 / 31 | 0–4095 | 小端 |

識別結果顯示在舵機芯片上，例如 **ID1 (SCS0009 · SCS)**；參數表和位置範圍會隨選中舵機自動切換。識別表裡沒有的型號顯示“未知型號”，日誌中會輸出實際讀到的兩個字節，便於反饋補充。

## 四、參數表

參數表按**地址、寄存器、值、存儲區域、讀寫**五列展示選中舵機的全部寄存器，存儲區域分為 EPROM、SRAM、DEFAULT 三類並按區域著色。

> **只有“讀寫”列標記為可寫的那一行才能被選中並寫入**；只讀寄存器和 DEFAULT 區點不動，也不會進入寫入行，避免誤寫只讀區。

## 五、讀取與寫入參數

**讀取參數**：點擊舵機芯片選中目標舵機後，頁面會**自動讀取該舵機的全部參數**並填入參數表，同時把位置控制的滑桿對到它的當前實際位置。也可隨時點擊“📖 讀取參數”手動刷新。

**寫入參數**：

1. 在參數表中**選中一行**（只有可寫行能選中）。
1. 底部“寫入地址 0x”和“長度”會自動填好。
1. 在“值”輸入框填入新值，點擊“✏️ **寫入**”。
1. 寫入 EEPROM 時，頁面會自動**解鎖 → 寫入 → 加鎖**；結果以浮層提示成功或失敗原因。


> 改 ID、波特率、角度限制這類參數前，先“保存當前舵機”備份一份 xdat，改錯了好恢復。

## 六、位置控制

1. 選擇舵機後，在“🎯 位置控制”區拖動**目標位置**滑桿，或直接在數值框輸入。範圍隨型號變化：**SCS0009 為 0–1023**，**STS3215 / HD1910 為 0–4095**，滑桿與數值框雙向聯動。
1. 設置**速度**（寄存器原始值，不同系列單位含義不同）。
1. 點擊“▶ **移動**”執行；頁面會輪詢 MOVING 標誌，動作結束時提示關閉力矩。


**實時跟隨**：勾選“實時跟隨”後，拖動滑桿舵機會實時跟隨。勾選時會先二次確認並自動打開該舵機的力矩；發送做了節流，不會把總線灌滿。切換舵機、重新掃描或斷開連接時會自動關閉，並提醒關閉力矩。

力矩控制：

| 按鈕 | 作用 |
|---|---|
| ⚡ 力矩開 | 打開當前舵機力矩 |
| ⏹ 力矩關 | 關閉當前舵機力矩 |
| ⏹ 全部力矩關 | 一鍵釋放總線上所有舵機 |

> **如果轉動過程中突然斷連，請重新連接後立即關閉力矩。**

## 七、讀取狀態

點擊“📊 讀取狀態”，下方狀態欄顯示當前位置、速度、負載、電壓、溫度、電流和運行標誌。

## 八、修改波特率

1. 在“🔧 波特率 / 恢復出廠”區選擇**新波特率**。
1. 點擊“🔧 **修改波特率**”。
1. 頁面寫入後，會按新速率**重新打開串口並回讀驗證**；若失敗會**自動回滾**到原波特率，避免舵機失聯。


## 九、恢復出廠

點擊“🔄 **恢復出廠**”，需**二次確認**後執行。不同系列的恢復指令不同，頁面會按識別到的型號自動選擇：

| 型號 | 恢復指令 | 執行後 |
|---|---|---|
| SCS0009 | 0x0A 恢復出廠 | ID 回到 1，波特率回到 1M |
| STS3215 / HD1910 | 0x06 參數恢復 | ID 保持不變，其餘參數回默認值 |

> 恢復出廠**不可撤銷**，執行前建議先保存 xdat。

## 十、xdat 參數備份與恢復

“📁 xdat 參數（僅保存 EEPROM）”區提供三個操作：

| 按鈕 | 作用 |
|---|---|
| 💾 保存當前舵機 | 讀取該舵機全部參數並下載為 .xdat 文件 |
| 📂 打開 xdat | 加載本地 .xdat 文件並預覽內容 |
| 📤 恢復參數到舵機 | 將已加載的 xdat 參數寫回當前舵機 EEPROM |

保存的文件名帶**型號和 ID**，例如 **SCS0009_ID1.xdat**、**HD1910_ID6.xdat**，避免不同型號的同一 ID 互相覆蓋。

文件格式為“2 字節文件頭 + 49 字節數據區”，寄存器地址 A 存放在偏移 A+2；多字節數值按型號字節序存放（SCS 大端、STS / HD1910 小端）。

> 為避免參數寫亂，頁面會校驗文件與當前舵機是否同屬一個字節序家族，**不一致時禁止寫回**。恢復時只寫可寫的 EEPROM 參數，跳過型號與只讀區；數據區只覆蓋地址 0–48。恢復前請確認選中的舵機 ID 正確。

## 十一、日誌

頁面底部“📜 日誌”實時記錄每一步操作與返回結果，可點擊“清空”清除。

界面支持**中英文切換**——右上角“EN / English”按鈕即時切換界面和日誌語言，歷史日誌也會同步刷新，無需重連。

## 十二、安全須知

- ⚠️ 同一時刻只能有一個程序佔用串口。使用本頁面時請關閉桌面版上位機、串口助手等其他程序。
- ⚠️ 運動過程中拔線，舵機可能仍在執行動作——重新連接後**先關力矩**。
- ⚠️ 接線、插拔一律斷電進行。
- ⚠️ 離開頁面前，可點擊“⏹ 全部力矩關”一鍵釋放所有舵機。


## 十三、常見問題

**Q1：頁面提示不支持 Web Serial 或無法連接。**
使用 Chrome / Edge 89+，並透過 https 或 localhost 訪問。Firefox、Safari 未實現 Web Serial。

**Q2：連接失敗，提示無法打開串口。**
確認串口沒有被其他程序佔用（桌面版上位機、串口助手、Arduino IDE 等），並確認 USB 轉 TTL 驅動已安裝。

**Q3：掃描不到舵機。**
確認接線正確、舵機已供電、波特率與舵機一致。若舵機波特率被改過，請先試其他檔位；總線上有 ID 衝突時兩隻舵機會同時應答，先單獨接一隻排查。

**Q4：參數表裡的某些行點不動。**
這是設計如此：只有“讀寫”列標記為可寫的行才能選中寫入，只讀寄存器和 DEFAULT 區不可寫。

**Q5：修改波特率失敗怎麼辦。**
頁面會自動回滾到原波特率並提示失敗原因，可檢查接線後重試。

**Q6：舵機顯示“未知型號”怎麼辦。**
說明該舵機地址 3 / 4 的兩個字節不在識別表內。目前僅適配 SCS0009、STS3215、HD1910；可查看日誌中的“主版本 / 次版本”數值反饋給我們補充。

**Q7：頁面更新後行為沒有變化。**
瀏覽器會緩存腳本，請用強制重新整理（硬刷新）重新載入（Windows：Ctrl+Shift+R；macOS：Cmd+Shift+R）。
