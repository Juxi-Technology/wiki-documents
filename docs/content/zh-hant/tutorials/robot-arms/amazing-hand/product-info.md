# AmazingHand靈巧手產品資料

## 產品簡介

AmazingHand 是一款**高精度、輕量化、手勢追蹤的靈巧手**，專為具身智能研究、機器人教育和人機交互應用設計。該產品採用8個高精度SCS0009 TTL串口舵機控制，支援右手、左手以及雙手機器人操作，可實現複雜的手勢動作和實時追蹤功能。

### 一、硬件設計：高精度輕量化，易除錯可擴展

- **舵機配置**：單個靈巧手採用**8個SCS0009 TTL串口舵機**，2個舵機協同控制同一根手指，提供精準的運動控制和穩定的抓取能力。

- **輕量化結構**：靈巧手總重僅0.416kg，結構緊湊，易於安裝在各類機器人平台上。

- **便捷連接**：通過Type-C接口通信，配合舵機驅動板和MEGA328P開發板，即插即用，簡化硬件連接流程。

- **模組化設計**：支援右手、左手單獨配置，也可雙手機器人協同工作，靈活適應不同應用場景。

### 二、軟件生態：集成手勢追蹤，AI開發易上手

- **實時手勢追蹤**：基於MediaPipe的實時手部追蹤技術，通過網絡攝像頭捕捉手勢，實現靈巧手的模仿學習和跟隨控制。

- **分佈式數據流**：採用**DORA分佈式數據流引擎**，實現硬件與算法的低延遲交互，支援手勢數據到舵機控制的全鏈路打通。

- **仿真與硬件統一**：提供虛擬仿真環境，支援在仿真中驗證控制算法，再無縫遷移到真實硬件。

- **開源生態**：控制代碼、訓練腳本及教程開源，支援二次開發和功能擴展。

### 三、核心應用場景：從教學到研究，全場景覆蓋

1. **機器人教育入門**：提供從靈巧手組裝、舵機除錯、基礎控制到手勢追蹤的全流程教程，配套演示程式和案例代碼，零基礎使用者可快速上手。

2. **具身智能研究**：專注**手勢模仿學習、人機交互**研究，支援通過攝像頭捕捉人類手部動作訓練靈巧手；典型應用：手勢控制、物體抓取、人機協作等任務。

3. **人機交互原型**：低成本驗證人機交互方案，適配**手勢控制、遙操作、VR/AR交互**等場景，快速落地原型驗證。

### 四、產品優勢

- **高性價比**：採用成熟的串口舵機方案，成本可控，適合個人、實驗室及教育機構批量部署。

- **手勢追蹤**：內置手勢追蹤功能，無需額外複雜裝置，普通攝像頭即可實現靈巧手的實時跟隨控制。

- **開發友好**：提供完整的除錯教程、演示程式和開發接口，從硬件除錯到軟件控制，快速上手。

- **雙手協同**：支援單手機器人獨立操作，也支援雙手機器人協同工作，靈活適應不同實驗和應用需求。
