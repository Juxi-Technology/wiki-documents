## 官方倉庫示例

鉅犀科技為 AmazingHand 4 指靈巧手提供開源控制代碼：[GitHub](https://github.com/Juxi-Technology/AmazingHand)

### 基礎控制

倉庫包含完整的 Python 控制示例，支持 TTL 通信協議。克隆倉庫後運行：

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```

### TTL 通信協議

靈巧手通過 TTL 串行總線與主控通信，協議詳情請參閱倉庫 README 和源碼。
