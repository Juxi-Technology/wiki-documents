# 產品資料

> **[ 淘寶店鋪 ](https://juxitechnology.taobao.com)**

## 產品簡介

LeKiwi 是由 SIGRobotics-UIUC（伊利諾伊大學香檳分校機器人興趣小組）主導開發。提供低成本、高靈活性的開源機器人平台，推動教育、科研及工業自動化領域的機器人技術普及，硬體設計（3D 列印檔案）、軟體堆疊（相容 LeRobot 框架）及教學全部開源，支援使用者自訂擴充。

LeKiwi 分為移動平台和主從臂，主從臂採用 3D 列印件作為結構，6 個 12V 飛特伺服馬達作為驅動關節，主臂位於固定平台，使用一個伺服馬達驅動板，透過 USB-C 連接電腦，從臂固定在採用 3 個 12V 飛特伺服馬達做驅動的移動平台，使用一個伺服馬達驅動板，透過 USB-C 連接 樹莓派 進行控制。

LeKiwi 深度整合 LeRobot（Hugging Face 開源機器人 ML 框架），支援模仿學習、資料收集與策略訓練。基於 PyTorch 實現，包含預訓練模型、資料集及模擬環境，相容 Stanford ALOHA 等知名開源資料集。使用 DORA 框架（分散式資料流引擎），實現硬體 - 演算法低延遲通訊（Python 效能比 ROS2 快 17 倍），支援熱重載功能，即時調整程式碼無需重新啟動。

LeKiwi 非常適合教育 / 入門研究：機器人學入門教學，提供從組裝、程式設計到 AI 策略部署的全流程教學；科研驗證：支援模仿學習研究（如透過 VR 錄製人類操作影片訓練機器人），案例：花粉機器人 Ready2 透過 50 段 15 秒影片訓練 2 小時，即學會疊衣、插鑰匙等任務；工業原型開發：低成本驗證自動化方案（如物料搬運、精密裝配）。
