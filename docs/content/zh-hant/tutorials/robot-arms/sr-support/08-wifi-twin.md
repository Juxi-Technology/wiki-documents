# 08 WiFi 與模擬鏡像

本步為可選功能，不影響自扶正本身。

## 8.1 熱點與狀態頁

熱點：SSID `SR-Support`，密碼 `srsupport`，地址 `192.168.4.1`（`w` 開關，上電預設開）。
`w` 透過串列埠傳送：在串列埠監視器/串列埠助手的傳送框輸入 `w` 並按 Enter 即可切換；串列埠工具/
串列埠助手（含 Windows UartAssist 下載）見 [03 頁 3.3](./03-build-flash.md)。

裝置連上熱點後開啟 `http://192.168.4.1`（多數手機會自動彈出配網門戶）。頁面每 300 ms
重新整理：執行狀態、up 向量與直立度條、兩關節指令角、扶正姿態/階段、Home WiFi 狀態、
Twin 流開關。瀏覽器有系統代理時，把該地址加入代理例外。

## 8.2 配網（讓 ESP32 加入家裡的 WiFi）

狀態頁 Home WiFi 卡片：`Scan` → 選網路 → 輸密碼 → `Connect`。成功後 AP+STA 雙模：

- 熱點保留（現場除錯不受影響）；
- 家裡區域網可直接訪問（頁面 `Robot IP` 顯示地址）；
- 憑據寫入 NVS，重啟自動重連。

僅支援 2.4 GHz 網路；扶正動作執行期間會拒絕掃描/配網。

## 8.3 MuJoCo 無線即時鏡像

狀態頁按 `Twin ON`（等價串列埠 `d`），然後：

```bash
python tools/live_twin.py --tcp <Robot IP>:3333
```

（在 `SR-Support` 目錄下、先按 [02 頁](./02-environment.md) 建立並啟用 `.venv`；工具環境
也在那裡安裝。）

- 視窗中的模型按實機姿態即時顯示，身體自動貼地；
- 手臂接觸地面時會被"擋住"在接觸角（模擬實機堵轉），不會穿地；
- 有線串列埠只在燒錄和匯出日誌時需要；
- 離線回放歷史日誌：`--replay <日誌檔案>`。

## 8.4 WiFi 遙測落盤

```bash
python tools/tcp_log.py
```

把熱點的遙測流儲存為 `logs/wifi_<時間>.txt`，可事後離線回放分析。
