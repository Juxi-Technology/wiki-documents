# 01 基礎知識

## 1.1 工作原理

SR-Support 是 2-DOF（肩 + 肘）主動自扶正裝置：

- **機構**：一隻兩關節手臂安裝在方形底座上，肩關節繞機體長軸擺動、肘關節摺疊小臂；
- **感知**：6 軸 IMU 提供姿態四元數，韌體用機體 up 向量把倒姿分為四類
  （`pitch_pos/neg`、`roll_pos/neg`，見 [06 除錯頁](./06-debug-and-calibrate.md) 6.5）；
- **執行**：參考序列執行器——每個倒姿對應一組路點（20 拍/路點、每拍限速 0.08 rad），
  手臂撐地/按壓把身體撬回直立；`roll_neg` 另帶肘部"楔形泵"與鞭甩下砸兜底；
- **兜底**：14 秒超時/姿態重規劃/跌倒門自動重試；`roll_neg` 分階段自適應保持，
  中途站起立即收臂；
- **驗證**：四方向直接起身約 1–6 秒；同一模型可用於 MuJoCo 模擬與實機即時鏡像
  （[09 頁](./09-mujoco.md)）。

## 1.2 整機概覽

| 專案 | 參數 |
|---|---|
| 底座 | 約 88 × 82 mm，總高 68 mm（底面板 + 肩舵機固定件，3D 列印） |
| 手臂 | 肩軸距底 56 mm，肘軸再高 40.1 mm；小臂杆約 17 cm（12 mm 管） |
| 整機質量 | 約 133 g（模型質量表：foot 92.1 / arm1 20.7 / arm2 20.1 g，含兩舵機） |
| 肩關節 | PTK7452MG；手動限位 `[-1.85, +1.82]` rad（模擬關節範圍 `[-1.07, +2.07]`） |
| 肘關節 | PTK7452MG；手動限位 `[-0.90, +0.70]` rad（機械約 ±1.55 rad） |
| 主控 | ESP32-S3-DevKitC-1（Arduino framework / PlatformIO） |
| 姿態 | Juxi ICM42670P 6 軸 IMU（I²C 地址 0x23，100 kHz） |
| 舵機驅動 | ESP32 LEDC，50 Hz，14 bit，脈寬 500–2500 µs |
