# 04 散件組裝：列印、裝配與接線

> **成品使用者可跳過本頁**：出廠已完成列印、裝配、接線與走線檢查（見
> [index 出廠狀態](./index.md)）。僅在自組裝或更換零件時按本頁操作。

## 4.1 列印與檢查

1. 列印底面板、肩舵機固定件、肘舵機固定件、頂部撐杆（各 1 件）；
2. 用卡尺核對底座外形約 88 × 82 mm、總高 68 mm；
3. 檢查舵機安裝槽與 25T 舵盤配合，無干涉後再上螺絲；
4. 列印件逐件稱重並記錄（對照 `hardware/v1/meshes/print_mass_model.json`）。

## 4.2 舵機準備（韌體零點與舵盤安裝）

1. **先接線、燒韌體**：按 4.4 接線表接好兩路舵機、IMU、舵機電源與共地（機械件先不裝；
   主韌體需要 IMU 才能啟動），按 [03 頁 3.1](./03-build-flash.md) 燒錄主韌體；
2. **上電到韌體零點**：串列埠 115200 開啟（串列埠工具/串列埠助手見
   [03 頁 3.3](./03-build-flash.md)）並上電；啟動完成後韌體把兩舵機驅動到 q=0
   （中位脈寬 1681 / 1456 µs），串列埠出現 `servo start q: 0.00 0.00 rad` 和
   `ready; send g to run`（或 `autorun on: ...`）即已到位；
3. **斷電**：拔掉舵機電源（USB 可保留），確認兩隻舵機都不再受力；
4. **裝舵盤**：把肩舵盤裝到舵機上，使大臂豎直；肘舵盤使小臂與大臂成一條線；擰緊後
   手動檢查行程無卡滯；
5. 方向約定（與模擬一致）：`shoulder +q` 使大臂向 **−Y**，`elbow +q` 使小臂向 **+X**；
   韌體預設 `SERVO_SHOULDER_SIGN=-1`、`SERVO_ELBOW_SIGN=-1`。

> 韌體中位 1681 / 1456 µs 已經包含了出廠標定時的舵盤換齒偏移，**不需要再自己數齒**：
> 在韌體零點（q=0）裝盤、大臂豎直即可。也可以在串列埠傳送框輸入 `e` 並按 Enter，讓兩舵機回到
> 1520 µs 電氣中位再裝（等價的可選做法，見 [03 頁](./03-build-flash.md) 命令表）；兩種方式最終都由
> [05 頁](./05-zero-tool.md) 的 `z` 精定零。

> 齒位只是**粗對中**。精確零點必須在整機組裝完成、主韌體燒錄（[03 頁](./03-build-flash.md)）
> 之後，用 [05 零點校準](./05-zero-tool.md) 把目測豎直姿態定義為 q=0（`z` 不依賴 IMU，
> 任意姿態可用），再把列印脈寬寫回 `config.h` 並重燒。即使裝配時舵盤沒有裝正，也能這樣
> 定零；只有某側行程不夠（舵機被 500/2500 µs 限幅）時才需要拆盤重新錯齒。
> 齒位決定兩側行程分配；韌體手動限位（`Q_SHOULDER_MIN/MAX`）必須與實際行程一致，不要
> 隨意放寬。定零後務必按 05 頁把序列路點同步平移，否則扶正動作的物理姿態會漂移。

## 4.3 底座與手臂裝配

1. 底面板與肩舵機固定件用 M3 螺絲固定，組成底座（總高約 68 mm）；
2. 肩舵機裝入肩舵機固定件，舵盤朝上；
3. 肘舵機固定件安裝到肩舵盤上並鎖緊（作為上臂）；肘舵機裝入肘舵機固定件；
4. 頂部撐杆（小臂）連線到肘舵盤；
5. 裝配後手動把手臂擺到豎直（`q≈0`），確認與舵機中位一致。

## 4.4 接線

| 器件 | ESP32-S3 引腳 | 轉接板 | 說明 |
|---|---|---|---|
| 轉接板 3V3 | 3V3 | S1 訊號腳 | 另一頭接 IMU VCC（3.3 V） |
| 肩舵機訊號 | GPIO4 | S4 | 50 Hz PWM |
| 肘舵機訊號 | GPIO5 | S5 | 50 Hz PWM |
| IMU SDA | GPIO6 | S6 訊號腳 | 另一頭接 IMU SDA；I²C 0x23，100 kHz |
| IMU SCL | GPIO7 | S7 訊號腳 | 另一頭接 IMU SCL；I²C 0x23，100 kHz |
| IMU GND | GND | —（直連） | 共地 |
| LED（可選） | GPIO2 | — | 狀態燈 |
| 5 V 電源輸入 | 5V / GND | — | 一分二線：一路供 ESP32，一路接轉接板 V+/GND 供舵機 |
| 舵機電源 | — | V+/GND 端子 | 5 V / ≥5 A；**更高電壓只能接這裡，不能接 ESP32 5V** |
| S2 / S3 | — | 空 | 不接 |

注意事項：

- 轉接板為無源直連：S1/S6/S7 借用訊號腳傳 3V3 / SDA / SCL，S4/S5 傳舵機訊號；
  確認每個口的 V+/GND/訊號順序一致，插反會燒舵機或板子；
- I²C 線儘量短，不要與舵機線長距離並行；模組上拉一般為 3.3 V；
- **5 V 供電**時可直接接 ESP32 的 5V/GND，經一分二線同時給 ESP32 與舵機；
  更高電壓（6 V / 7.4 V）只能接轉接板 V+/GND，ESP32 必須單獨用 USB 供電；
- **電池（5 V）給 ESP32 供電時，可以同時插 Type-C**：DevKitC-1 官方原理圖中，USB VBUS
  經肖特基二極體接到 5V 網路，不會反灌，USB 只作資料（及輔助供電）；若用的是省掉該
  二極體的克隆板、或無法確認，燒錄時斷開 5 V→ESP32 分支、讓 ESP32 只由 USB 供電（方式 2）；
- **除錯/燒錄時的供電（兩種都正常，任選）**：
  1. 5 V 電源經一分二同時供 ESP32 與舵機，USB 只接資料；
  2. 更直觀：斷開 5 V→ESP32 的分支，ESP32 只由 USB 供電，5 V 電源只供舵機。
  燒錄、串列埠監視、`c` 標定用方式 2 最省心；整機獨立執行時用方式 1；
- 第一次上電先不接舵機，用萬用表確認 V+ 電壓與極性；再接一個舵機測試，最後接兩個；
- 接線順序：共地與訊號 → 接通 5 V 電源（ESP32 與舵機同時上電）→ 需要串列埠時再插 USB；
  斷電相反。

## 4.5 IMU 安裝方向

IMU 固定在底座上（螺絲定位，方向不可調），韌體因此啟用 `IMU_YAW90`，把 IMU 座標系下
的 up 向量換算到機體座標：

```c
up_body = (up_imu.y, -up_imu.x, up_imu.z)
```

**機械方向自檢**（裝好舵機後、上電前就能看）：以 IMU 模組絲印/引腳定義標註的座標軸為準，

- 肩舵機的**輸出軸**（裝舵盤的那根軸，也叫舵盤軸/齒輪軸）朝向 IMU 的 **−Y**；
- 肘舵機的**輸出軸**朝向 IMU 的 **+X**。

從下往上看，兩個舵機的順序是 **肩舵機（下）→ 肘舵機（上）**，裝舵盤和接線時不要弄反。

這兩個方向分別就是機體的肩軸與肘軸。如果和實物對不上，說明 IMU 或舵機座裝反了，
先改正再上電。

上電後再按 [06 除錯頁](./06-debug-and-calibrate.md) 複核：直立時 `up≈(0, 0, 1)`；
四種躺姿的 up 向量見 6.5 節表格。
