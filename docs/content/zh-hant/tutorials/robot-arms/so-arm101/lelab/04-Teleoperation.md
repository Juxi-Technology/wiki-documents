# 4 · 遙操作

> **上一篇**：[03 連接與校準](03-Calibration.md)
> **下一篇**：[05 錄製資料集](05-Record-Dataset.md)

你用手移動主臂；從臂複製動作。這就是錄製示範的方式，也是確認校準最快的方法。

## 執行方式

1. 開啟 **Teleoperation** 分頁。
2. 確認埠與校準設定檔——LeLab 會記住校準時的那些設定。
3. 開始遙操作。
4. 移動主臂。

執行期間，分頁會即時串流關節位置。完成後按停止。

**停止才是讓從臂停下的動作。** 關閉分頁或終止程序，手臂會停在原處。

## 要檢查什麼

| 檢查項目 | 原因 |
|---|---|
| 從臂平順跟隨，沒有延遲或抖動 | 粗糙的跟隨會變成不能用的訓練資料 |
| 從臂的範圍與主臂相符 | 中途停下或撞到極限，表示某個關節校準錯誤——回到[第 3 篇](03-Calibration.md) |
| 兩條手臂往同一個方向移動 | 從臂反向，表示某個關節的校準方向錯了 |
| 極限位置不會碰撞 | 走過你打算使用的完整範圍 |

若動作不對但沒壞——有偏移、某個關節反向、範圍不足——請重新校準，不要用補償硬撐。校準錯誤的手臂會產生讓策略學錯的資料集。

## 攝影機

若有設定攝影機，遙操作畫面會顯示它們的預覽。

- 腕部攝影機：看得見夾爪以及它即將抓取的東西嗎？
- 固定攝影機：看得見整個工作區嗎？
- 畫面是不是歪的或上下顛倒？錄製前先在[校準分頁](03-Calibration.md)修正 **rotation**。

遙操作期間錄下的畫格，是策略唯一會看到的東西。
