# 3 · 連接與校準

> **上一篇**：[02 安裝與啟動](02-Install.md)
> **下一篇**：[04 遙操作](04-Teleoperation.md)

校準會記錄每個關節的零點與行程範圍。每條手臂做一次；拆解過或校準檔遺失後必須重做。

## 開始之前

- 兩條手臂都已組裝完成，舵機已設定 ID。
- 兩條手臂都已通電。
- 每條手臂各一條 USB 線，接到**兩個獨立的 USB 埠**——共用集線器有時會不穩定地列舉。

### Linux：序列埠權限

```bash
sudo usermod -aG dialout $USER
```

接著**登出再登入**。少了這步，LeLab 找得到手臂，但每次讀取都會因權限錯誤而失敗。Windows 與 macOS 不需要任何設定。

## 哪條手臂是哪條

| 手臂 | LeRobot 名稱 | LeLab 的稱呼 |
|---|---|---|
| 你用手移動的那條 | `so101_leader` | **teleop** |
| 跟隨的那條 | `so101_follower` | **robot** |

先校準主臂。把兩者搞混，是剛校準好的手臂行為異常的常見原因。

## 流程

開啟 **Calibration** 分頁，一次處理一條手臂：

1. **選擇裝置**——主臂（teleop）或從臂（robot）。
2. **選擇序列埠。** LeLab 會列出它看到的 USB 序列裝置。要分辨它們，拔掉一條手臂，看哪個項目消失。這個選擇會被記住。
3. **選擇校準設定檔**——現有的或新增的。設定檔保存已儲存的零點位置；這條手臂若曾校準過，就沿用它的設定檔。
4. **依照引導步驟操作。** LeLab 會依序帶過每個關節；把關節移到它要求的位置並確認。不需要鍵盤輸入。
5. **另一條手臂重複一次**——用它自己的設定檔與埠。

> 每個設定檔屬於一條實體手臂。把兩條手臂對調，就表示要重新校準。

## 攝影機

攝影機在同一個分頁設定。每台攝影機的名稱（`front`、`wrist`……）就是策略看到的鍵，因此請用你在訓練日誌中認得出來的名稱。

攝影機可以在校準前或校準後安裝；校準不依賴它們。保持綁定穩定——在錄製與推論之間對調哪台實體攝影機叫 `wrist`，會讓訓練好的策略表現得毫無道理。

### 旋轉

攝影機若上下顛倒或側裝，設定它的 **Rotation**：0°、90°、180° 或 270°，順時針。上下顛倒的腕部攝影機是 180°。

旋轉以攝影機為單位儲存，並套用到設定預覽、遙操作預覽、錄製的畫格與推論。沒有設定旋轉的設定檔一律視為 0°。

- **90° 與 270° 會交換輸出尺寸。** 640 × 480 的擷取會變成 480 × 640。
- **Checkpoint 的影像尺寸無法透露方向。** 0° 與 180° 產生相同的尺寸，但影像相反。推論前，設成錄製時所用的旋轉——見[第 6 篇](06-Train-and-Inference.md)。

## 儲存了什麼

| 檔案 | 內容 |
|---|---|
| `~/.cache/huggingface/lerobot/calibration/teleoperators/so101_leader/*.json` | 主臂設定檔 |
| `~/.cache/huggingface/lerobot/calibration/robots/so101_follower/*.json` | 從臂設定檔 |
| `~/.cache/huggingface/lerobot/ports/leader_port.txt` | 主臂序列埠 |
| `~/.cache/huggingface/lerobot/ports/follower_port.txt` | 從臂序列埠 |

這些位於 `~/.cache/` 底下，因此清理快取的工具可能會刪掉它們。若已校準的手臂又要求重新校準，請檢查這裡——見[疑難排解](07-Troubleshooting.md)。
