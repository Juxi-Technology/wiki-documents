# So-ARM 系列 STS3215 舵機校準-網頁端

> **桌面版工具：** [SoARM 系列舵機校準工具使用教程](./SO-ARM101-Servo-Calibration-Tool.md)

So-ARM101 舵機標定工具的**網頁版**：整個界面運行在瀏覽器裡，透過 Web Serial 直接連接串口，**不需要安裝 Python**。

線上網址：

[https://juxi-technology.github.io/SO-ARM101-ServoController/](https://juxi-technology.github.io/SO-ARM101-ServoController/)

> ⚠️ 本工具僅支持 **Feetech（STS3215 系列）舵機**。

## 一、使用前準備

- **瀏覽器**：Chrome 或 Edge 89+（Firefox / Safari 不支持 Web Serial）
- 在 **HTTPS 或 localhost** 下打開；GitHub Pages 已滿足
- **USB 轉串口適配器** + Feetech STS3215 舵機，默認 **1 M 波特率**（`1000000`）


## 二、連接機械臂

1. 頂欄左側選擇“**連接波特率**”，默認 `1000000`。**如果舵機被改過波特率，請先選對再連接**。
1. 點“主動臂”或“從動臂”的“**連接串口**”，在瀏覽器彈窗裡選擇對應的 COM 口。
1. 連接成功後會自動掃描舵機（ID 1–6）。


> 兩臂可以分別連接、獨立操作。若掃描不到舵機，先檢查連接波特率是否與舵機一致，再確認串口沒有被其他程序佔用。

## 三、演示模式（無硬體）

勾選頂欄的“**演示模式（無硬體）**”再連接，會使用一套模擬的 6 舵機數據，可以瀏覽整個界面。

> 演示模式下的數據是模擬的，**不會操作真實硬體**。

## 四、三個功能頁

### 🦾 舵機標定

實時顯示各舵機的位置、電壓、溫度、力矩狀態；提供單個舵機的“中位校準”“中位測試”“失能電機”“清限位”操作，以及整臂校準入口。

### 🎚️ 單舵機控制

每個舵機一行：**ID / Pos / 滑桿 / L（目標）**。

- **Pos 與滑桿雙向綁定**：拖動滑桿時 Pos 跟隨，鬆開發送命令；在 Pos 裡輸入數值則立即發送。


### 🔬 FT 調試器

串口連接、掃描舵機、讀取全部寄存器、單個寄存器讀寫、位置控制、修改波特率、恢復出廠、xdat 參數備份與恢復。

## 五、完整校準流程（推薦）

1. 在“舵機標定”頁點“**主動臂中位校準**”打開嚮導。
1. 點“**開始中位值記錄**”（按鈕變橙）→ 把機械臂擺到標準中位 → 點“**完成中位值記錄**”。
1. 點“**記錄運動範圍**”（按鈕變綠）→ 把每個關節從頭轉到尾（**夾爪也要轉**）→ 再點一次停止。
1. 6 個關節完成後會**自動保存校準文件**；對從動臂重複一次。
1. 兩臂都校準好後，點頂欄“**🎮 遙控**”即可用主動臂帶動從動臂。


## 六、校準文件放在哪裡

瀏覽器只能把文件下載到“下載”目錄。保存後嚮導會顯示目標路徑，**請手動移動過去**：

| 部位 | 目標路徑 |
|---|---|
| 主動臂 | `~/.cache/huggingface/lerobot/calibration/teleoperators/so_leader/my_leader_arm.json` |
| 從動臂 | `~/.cache/huggingface/lerobot/calibration/robots/so_follower/my_follower_arm.json` |

Windows 上 `~` 就是 `%USERPROFILE%`，完整路徑形如 `%USERPROFILE%.cache\huggingface\lerobot\calibration...`。

## 七、遙控

兩臂都校準並連接後，點頂欄“**🎮 遙控**”，用主動臂的角度驅動從動臂。再次點擊“⏹ 停止遙控”結束。

> 遙控前請確認兩臂周圍安全——**力矩開啟後舵機無法用手掰動**。遙控需要兩個已連接的串口。

## 八、FT 調試器詳解

### 讀取與寫入寄存器

- 點“**讀取全部參數**”讀取所選舵機的全部寄存器，結果填入參數表。
- **點擊參數表中的一行會填入上方的地址與長度，再輸入“值”並點“寫入**”。
- 灰色行（DEFAULT 區）**不可讀寫**，避免誤寫只讀區域。


### 位置控制

選擇舵機後，透過滑桿或數值設定目標位置，點“移動”執行。若力矩未開啟，會先詢問是否開啟。

### 修改波特率

選擇新波特率後點“應用”，寫入後會斷開並嘗試用新波特率重連；失敗會在日誌中給出原因。

### 恢復出廠設置

把 ID 改回 1、波特率改回 1M，**且不可撤銷**，執行前需二次確認。

### xdat 參數備份與恢復

| 按鈕 | 作用 |
|---|---|
| 💾 保存當前舵機為 xdat | 讀取全部參數並下載 `.xdat` 文件 |
| 📂 打開 xdat | 加載本地 `.xdat` 文件 |
| 📤 恢復參數到舵機 | 把 xdat 參數寫回當前舵機 EEPROM |

> 恢復會覆蓋 ID、波特率和限位等設置，執行前請確認選中的舵機正確。EEPROM 有寫入壽命，不要頻繁寫。

## 九、注意事項

1. **頁面需要保持在前台**：瀏覽器會節流背景標籤頁，遙控和實時刷新會變慢甚至停住。
1. **兩臂的同一關節行程要掃得一致**，否則遙控時動作幅度會對不上。
1. **夾爪不是連續旋轉關節，也要掃行程**，否則範圍會落成默認的 0–4095。
1. FT 調試器裡**灰色行（DEFAULT 區）不可讀寫**；EEPROM 有寫入壽命，不要頻繁寫。
1. **遙控前確認兩臂周圍安全**，力矩開啟後舵機無法用手掰動。
1. 同一時刻只能有一個程序佔用串口——使用本頁面時請關閉桌面版或其他上位機。


## 十、常見問題

**Q1：連不上 / 掃描不到舵機。**
先檢查連接波特率是否與舵機一致，再確認串口沒被其他程序佔用。

**Q2：Pos 不刷新。**
確認舵機在線；重新點“連接串口”或刷新頁面。

**Q3：寫入失敗。**
查看日誌裡的具體原因；確認地址和長度來自參數表中的行。

**Q4：提示當前瀏覽器不支持 Web Serial。**
使用 Chrome / Edge 89+，並透過 HTTPS 或 localhost 打開。

**Q5：校準文件保存後 LeRobot 找不到。**
瀏覽器只會下載到“下載”目錄，需手動移動到第六節列出的路徑。
