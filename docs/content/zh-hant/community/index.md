## 如何貢獻

### 1. 撰寫教程

分享你使用 SO-ARM101 的經驗,撰寫教程幫助他人。

**如何開始：**
- 選擇一個主題(應用場景、技術解析等)
- 參照現有教程結構編寫
- 提交 Pull Request

### 2. 翻譯文檔

幫助我們將文檔翻譯成更多語言,讓更多用戶受益。

**現有語言：** 簡體中文 / 英文 / 繁體中文

### 3. 提交案例

分享你的使用案例,展示你的項目成果。參考[成功案例頁](/zh-hant/cases/)。

### 4. 報告問題

發現 Bug 或有改進建議？提交 Issue 幫助我們改進。

### 5. 代碼貢獻

對相關開源項目的代碼貢獻,包括 LeRobot 等。
