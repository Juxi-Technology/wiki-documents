# 4 合 1 KVM 切換器

> **[淘寶店鋪](https://juxitechnology.taobao.com)4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**

## 產品概述

4 合 1 KVM 切換器集 HDMI 切換、TTL 串口、藍牙與 USB 擴展於一體,專為機器人開發調試設計。多台設備(機械臂主控/顯示器/外設)一鍵切換。

**核心特性**:

- HDMI 多設備切換
- TTL 串口(UART)調試
- 藍牙無線連接
- USB 擴展塢

## 產品規格

| 類別 | 規格 |
|------|------|
| 功能 | HDMI 切換 + TTL 串口 + 藍牙 + USB HUB |
| 接口 | HDMI / TTL / USB |
| 適用 | PC(Windows/Linux)、Jetson |

## 快速開始

1. 將多台設備接入 KVM 對應接口
2. 按鍵/軟件切換顯示與輸入設備
3. TTL 串口用於調試樹莓派/Jetson
