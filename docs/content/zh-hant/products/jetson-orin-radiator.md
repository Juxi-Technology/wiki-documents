# Jetson Orin 散熱器

## 產品概述

Jetson Orin散熱器是一款高效能全金屬散熱解決方案，專為NVIDIA Jetson Orin NX SUPER和Jetson Orin Nano SUPER開發者套件而設計。它將PWM調速散熱風扇整合到全金屬鋁散熱片中，並透過附帶的導熱膏與載板緊密結合，提供出色的熱管理，確保您的Orin能夠穩定地發揮全部效能。憑藉緊湊的尺寸、精確對齊的安裝孔以及完整的安裝套件，它是機器人、邊緣AI和高負載嵌入式開發的理想散熱伴侶。

## 主要優勢

### 相容 Jetson Orin NX / Nano SUPER

支援 Jetson Orin NX SUPER 和 Jetson Orin Nano SUPER，具有精確對齊的安裝孔，確保牢固、緊密的貼合。請注意，它與 Jetson Nano B01 不相容，因為其孔距和尺寸不匹配。

### 內建PWM調速風扇

整合的PWM調速風扇可根據載板負載自動調節轉速，在平衡散熱效率與靜音體驗的同時，降低噪音，提供更安靜的執行環境。

### 卓越的散熱效能

全金屬黑色散熱片內建散熱風扇，並透過導熱膏與載板緊密接觸，實現卓越的導熱性。螺釘固定安裝方式使拆卸和重新組裝快速簡單。

### 優質靜音滾珠軸承風扇

採用優質靜音滾珠軸承風扇，使用壽命長，提供長達50,000小時的品質保證。普通液壓風扇僅能持續約5,000小時，散熱片高溫會蒸發風扇潤滑劑，縮短壽命併產生噪音。滾珠軸承風扇使用壽命長達50,000小時，不受高溫影響，即使在長時間高負荷執行下也能保持穩定和安靜。

### 包含導熱膏

隨附一支導熱膏，幫助您均勻塗抹在散熱片上。其卓越的導熱效能可迅速將熱量從模組傳導至散熱器，加速散熱。

### 安全整潔的安裝

散熱器透過隨附的十字彈片和4個限高螺釘固定在載板上，確保安裝穩定整潔，底部乾淨。彈片與板子緊密貼合，走線整齊，風扇朝上，冷卻核心晶片區域。

### 即插即用4針電源介面

Jetson Orin NX SUPER 和 Jetson Orin Nano SUPER 開發者套件配備內建4針風扇介面，支援PWM調速散熱風扇，實現即插即用安裝。
