# SO-ARM101 頂置相機支架

> **[淘寶店鋪](https://juxitechnology.taobao.com)**

## 產品概述

SO-ARM101 頂置相機支架提供俯視視角安裝,兼容 RealSense 深度相機與普通 USB 攝像頭。用於機械臂視覺數據採集(俯視視角利於 LeRobot 訓練數據)。

**核心特性**:

- 俯視視角安裝
- 兼容 RealSense / USB 攝像頭
- 與 SO-ARM100/101 匹配
- 安裝簡便

## 產品規格

| 類別 | 規格 |
|------|------|
| 視角 | 俯視(top-down) |
| 兼容 | RealSense / USB 攝像頭 |
| 平台 | SO-ARM100/101 |

## 快速開始

1. 將支架固定到 SO-ARM 安裝點
2. 安裝相機(RealSense 或 USB)
3. 連接主控,`python -m lerobot.find_cameras` 確認識別
