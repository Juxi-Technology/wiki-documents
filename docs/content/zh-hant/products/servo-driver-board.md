# JUXI 總線舵機驅動板

> **[淘寶購買](https://item.taobao.com/item.htm?id=910782102628)**

## 產品概述

JUXI 總線舵機適配器是一款一體化串行總線舵機控制解決方案,專為 LeRobot SO-ARM100/101 機械臂和多舵機機器人項目設計。它將舵機供電和控制電路集成在一塊緊湊的電路板上,消除複雜佈線、獨立供電電路和底層控制開發的麻煩。

**核心特性**:

- 單總線控制多達 **253 個**串行總線舵機
- **7~12.6V** 寬電壓輸入,集成供電(DC 5521 接口)
- 實時數據反饋:位置、速度、扭矩、操作模式
- **Type-C 即插即用**,兼容樹莓派/Jetson/RDK/PC
- 精確校準安裝孔,2 分鐘內直接安裝到 SO-ARM100/101
- TVS 保護電路(過壓過流保護)

## 快速開始

### SO-ARM 機械臂 3 步安裝

1. 將驅動板與 SO-ARM 3D 打印底座預留安裝孔對齊
2. 使用附帶的 M2.5 螺絲固定
3. 連接舵機總線電纜,接入電源和 Type-C USB 到控制器

### 電源選擇

| 適配器 | 適用範圍 |
|--------|---------|
| **5V 6A** | 標準總線舵機項目、SO-ARM 機械臂(標準舵機 7V) |
| **12V 5A** | 大扭矩舵機項目、多舵機機器人(大扭矩舵機 12V) |

## 常見問題

**Q: 支持哪些舵機?**
市面上幾乎所有的串行總線舵機(Feetech SCS/STS 系列等)。

**Q: 需要單獨裝驅動嗎?**
不需要。Type-C 連接主控後即插即用。

**Q: 為什麼有 TVS 保護?**
防止電壓尖峰損壞驅動板和舵機,確保複雜環境下穩定運行。

**Q: 怎麼選電源適配器?**
標準舵機用 5V 6A,大扭矩舵機用 12V 5A。
