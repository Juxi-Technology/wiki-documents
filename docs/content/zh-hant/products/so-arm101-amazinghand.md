# SO-ARM101 與 AmazingHand 開源靈巧手機械臂

## 產品概述

SO-ARM101 & AmazingHand 是一個完整的開源具身智慧平台，它將 SO-ARM101 六軸機械臂與 AmazingHand 8 自由度四指靈巧手相結合。原有的平行夾持器被四指手取代，透過一個主臂舵機驅動，透過一個簡單、可靠、工廠組裝的機構實現同步的四指抓取和伸展。該平台基於 Hugging Face LeRobot 生態系統構建，支援主從遙操作、雙視角資料採集以及 ACT、SmolVLA、Pi0、Pi0.5 和 GR00T N1.5 的端到端模仿學習——這是從夾持器過渡到靈巧手的最簡單起點。

**SO-ARM101** 是在 SO-ARM100 基礎上深度最佳化的開源六軸機械臂。改進後的走線方式和馬達/齒輪搭配消除了關節電纜斷裂問題，不再限制關節的運動範圍，同時支援即時主從跟隨和與 Hugging Face LeRobot 工具包的無縫相容。

**AmazingHand** 是一個開源、低成本、完全 3D 可列印的 8 自由度機器人手開發套件。其舵機完全內建於手部主體內部，採用無電纜內部設計，每個手指由兩個關節驅動，兼具靈巧性和自然的手指間協同能力。

## 主要優勢

### 八自由度四指靈巧手

AmazingHand 提供四根手指（拇指、食指、中指和無名指），每根手指有兩個關節，總共 8 個自由度。平行連桿機構使手指協同工作，實現更自然的抓取，所有舵機都內建在手部主體內，沒有外部電纜，結構緊湊整潔。

### 單舵機連動驅動所有四指

主臂上的 6 號舵機 (STS3215) 透過範圍對映驅動手部內的所有八個 SCS0009 總線舵機，因此一個簡單的動作即可實現同步的四指抓取（握拳）或伸展（張開手掌）。機械結構簡單，控制可靠，無需複雜的手部程式設計。

### ACT、SmolVLA、Pi0、Pi0.5 和 GR00T N1.5 的端到端模仿學習

執行主從遙操作以記錄演示資料，然後一次性訓練模仿學習策略。少量資料集足以讓從臂自主完成預設抓取任務，整個閉環無需從頭編寫程式碼即可實現。

### 雙視角資料採集

頂部支架攝影機從上方覆蓋整個工作空間，以確定目標物體的空間位置和方向，同時桌面支架側視攝影機即時傳輸工作空間上下文。兩者協同作用，確保操作精確，快速響應場景變化，並防止漂移或停滯。

### 工廠組裝，開箱即用

每臺裝置均經過組裝、接線和校準——連線電源和 USB 後，平台即可進行遙操作和資料採集。攝影機選項包括 86° 自動對焦 30FPS 模組和 100° 廣角定焦 60FPS 模組，無需 USB 驅動，即插即用。

### 無縫整合 Hugging Face LeRobot

直接複用 LeRobot 的預訓練模型、資料集和演算法庫，與全球開發者社群共享程式碼和經驗，無需自行重建工具鏈即可進入具身智慧領域。

## 硬體概覽

### 可選版本（根據您的末端執行器需求選擇）：

| 版本 | 末端執行器 | 手部控制 | 適用物件 |
|---|---|---|---|
| 專業版 | TPU 柔性夾持器 | 獨立舵機控制 | 需要標準 SO-ARM101 雙指夾持器的使用者 |
| 靈巧手版本 | AmazingHand 四指靈巧手 | 主臂 6 號舵機透過範圍對映同步驅動 8 個總線舵機 | 探索靈巧抓取和端到端模仿學習的使用者 |

**抓取方式：**專業版採用兩指捏合，而靈巧手版本採用四指抓取和伸展。當前版本不支援獨立單指控制，該功能已列入開發路線圖。

### 相容裝置：

Raspberry Pi / D-Robotics RDK / NVIDIA Jetson 系列控制器，以及透過 USB 串列埠連線的 Windows 和 Linux 主機。與 LeRobot SO-ARM101 和 AmazingHand 開源專案完全相容，並支援市場上大多數串列埠總線舵機。

### 三步簡易設定：

- 使用隨附的電纜將舵機驅動板連線到您的 Raspberry Pi、RDK 或 Jetson 控制器，然後為主臂供電 (DC5521 5V6A) 和從臂供電 (DC5521 12V5A)。
- 通電並透過 USB 串列埠連線。機械臂和靈巧手出廠時已組裝、接線和校準——無需進行機械組裝或舵機 ID 設定。
- 按照提供的 LeRobot 教學進行從臂遙操作、採集雙視角資料集並訓練您的模仿學習策略。
