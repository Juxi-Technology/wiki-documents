# 하드웨어 연결

본 장에서는 제품의 하드웨어 연결 방법을 자세히 설명합니다.

## 인터페이스 설명

제품에는 다음 인터페이스가 있습니다:

- USB-C: 전원 및 데이터 전송
- GPIO: 범용 입출력 인터페이스
- HDMI: 영상 출력

## 연결 절차

1. **전원 연결**: USB-C 케이블로 전원 연결
2. **주변기기 연결**: 필요에 따라 다른 주변기기 연결
3. **부팅**: 전원 버튼을 눌러 장치 시작

## 주의사항

- 전원 전압이 요구사항을 충족하는지 확인
- 전원이 켜진 상태에서 GPIO 장치를 꽂거나 빼지 마세요
