# 빠른 시작

JUXI 제품에 오신 것을 환영합니다! 본 튜토리얼은 제품을 빠르게 사용하기 위한 가이드입니다.

## 준비 사항

시작하기 전에 다음을 준비하세요:

- 제품 하드웨어
- USB 데이터 케이블
- 컴퓨터(Windows/macOS/Linux)

## 1단계: 하드웨어 연결

1. 제품을 USB 데이터 케이블로 컴퓨터에 연결
2. 장치 드라이버 자동 설치 대기
3. 장치가 올바르게 인식되었는지 확인

## 2단계: 소프트웨어 설치

```bash
# 의존성 설치
npm install
# 앱 실행
npm start
```

## 3단계: 사용 시작

이제 제품을 사용할 수 있습니다! 더 자세한 기능은 다른 튜토리얼을 참고하세요.
