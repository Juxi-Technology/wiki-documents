# IMU 모듈 소개

고정밀 IMU 자세 센서는 **72MHz 32비트 프로세서**를 내장하고 실시간 자세 연산 및 동적 보상, 최대 **100Hz** 데이터 업데이트를 지원합니다. IIC 및 직렬 이중 통신 모드, MCU·Linux 호스트·ROS 시스템에 대응합니다.

## 버전 소개

| 성능 비교 | 6축 | 9축 | 10축 |
|---------|-----|-----|------|
| 고성능 32비트 프로세서 | √ | √ | √ |
| 3축 자이로 | √ | √ | √ |
| 3축 가속도계 | √ | √ | √ |
| 3축 자력계 | - | √ | √ |
| 기압계 | - | - | √ |
| AHRS 항자세 데이터 융합 | - | √ | √ |
| 용도 | 비용 민감 | 안정성+정밀도 | 3D 위치 인식 |

## 핀 기능

| 핀 | 기능 |
|----|------|
| SDA / SCL | I2C 데이터/클록 |
| GND | 접지 |
| 3V3 / 5V | 전원 |
| RX / TX | 직렬 수신/송신 |

## 제품 파라미터

| 항목 | 사양 |
|------|------|
| 직렬 보레이트 | 115200bps |
| 출력 주파수 | 기본 25Hz, 10~100Hz |
| IIC 클록 | 100KHz |
| 출력 내용 | 3축 가속/각속도/자이로/오일러/자력계/기압/고도/온도/쿼터니언 |
| 동작 온도 | -40°C~+85°C |
| 지원 기기 | PC, Raspberry Pi, Jetson, RDK, STM32, Arduino 등 |
| 동작 전압 | 5V / 3.3V, 11mA |
| 크기·무게 | 27.4×22.6×12mm, 3.8g |
| ROS | ROS1/ROS2 |
