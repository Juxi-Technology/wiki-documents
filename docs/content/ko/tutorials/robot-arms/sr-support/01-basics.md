# 01 기초

## 1.1 동작 원리

SR-Support는 2자유도(숄더 + 엘보) 능동형 자기 기립 장치입니다:

- **기구**: 사각 베이스에 장착된 두 관절 암; 숄더는 몸체의 장축을 중심으로 회전하고
  엘보는 전완을 접습니다;
- **센싱**: 6축 IMU가 자세 쿼터니언을 제공하며, 펌웨어는 몸체 좌표계의 상향 벡터로부터
  각 넘어짐을 네 가지 자세(`pitch_pos/neg`, `roll_pos/neg`, [06 페이지](./06-debug-and-calibrate.md) 6.5 참조)
  중 하나로 분류합니다;
- **구동**: 레퍼런스 시퀀스 실행기 - 각 자세에는 웨이포인트 스케줄(웨이포인트당 20틱,
  틱당 0.08 rad 슬루)이 있어 암을 지면에 짚거나 지레질하여 몸체를 다시 세웁니다;
  `roll_neg`는 추가로 엘보 웨지 펌프와 휩-슬램 폴백을 사용합니다;
- **폴백**: 14초 타임아웃, 자세 재계획 및 폴 게이트 후 자동 재시도;
  `roll_neg`는 단계별 적응형 홀드를 사용하며 일어서는 즉시 수축으로 빠져나갑니다;
- **검증됨**: 네 방향 모두 약 1-6초 만에 직접 일어섭니다; 동일한 모델이
  MuJoCo 시뮬레이션과 라이브 하드웨어 트윈([08 페이지](./08-wifi-twin.md))을 구동합니다.

## 1.2 개요

| 항목 | 사양 |
|---|---|
| 베이스 | 약 88 × 82 mm, 높이 68 mm(하단 플레이트 + 숄더 서보 마운트, 3D 프린팅) |
| 암 | 숄더 축은 베이스 위 56 mm, 엘보는 숄더 위 40.1 mm; 전완 스트럿 약 17 cm(12 mm 튜브) |
| 질량 | 약 133 g(모델 질량 표: 발 92.1 / 암1 20.7 / 암2 20.1 g, 서보 2개 포함) |
| 숄더 | PTK7452MG; 수동 제한 `[-1.85, +1.82]` rad(시뮬레이션 관절 범위 `[-1.07, +2.07]`) |
| 엘보 | PTK7452MG; 수동 제한 `[-0.90, +0.70]` rad(기계적 약 ±1.55 rad) |
| 컨트롤러 | ESP32-S3-DevKitC-1(Arduino 프레임워크 / PlatformIO) |
| 자세 센서 | Juxi ICM42670P 6축 IMU(I²C 주소 0x23, 100 kHz) |
| 서보 구동 | ESP32 LEDC, 50 Hz, 14비트, 500–2500 µs 펄스 폭 |
