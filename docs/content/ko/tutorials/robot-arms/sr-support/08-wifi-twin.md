# 08 WiFi와 시뮬레이션 트윈

이 단계는 선택 사항이며 자기 기립 자체에는 필요하지 않습니다.

## 8.1 핫스팟과 상태 페이지

핫스팟: SSID `SR-Support`, 비밀번호 `srsupport`, 주소 `192.168.4.1`(`w`로 토글; 부팅 시
기본적으로 켜짐). `w`는 시리얼로 전송합니다: 시리얼 모니터/어시스턴트의 송신 상자에
`w`를 입력하고 Enter를 누르세요; 시리얼 도구 / Windows용 UartAssist 다운로드는
[03 페이지 3.3절](./03-build-flash.md)에 있습니다.

핫스팟에 접속하고 `http://192.168.4.1`을 여세요(휴대폰은 보통 포털이 자동으로 뜹니다).
페이지는 300 ms마다 갱신됩니다: 상태, 상향 벡터와 수직도 바, 관절 명령, 기립
자세/단계, Home WiFi 상태, 트윈 스트림 스위치. 브라우저가 프록시를 사용한다면 이
주소에 대한 예외를 추가하세요.

## 8.2 프로비저닝 (가정용 WiFi 접속)

상태 페이지에서 Home WiFi 카드를 사용하세요: `Scan` → 네트워크 선택 → 비밀번호 입력 →
`Connect`. 성공하면 ESP32는 AP+STA로 동작합니다:

- 핫스팟은 계속 유지됩니다(벤치 작업에 영향 없음);
- 가정용 LAN에서 로봇에 접근할 수 있습니다(페이지에 `Robot IP`가 표시됨);
- 자격 증명은 NVS에 저장되며 부팅 시 자동으로 다시 접속합니다.

2.4 GHz 전용입니다; 기립이 실행 중일 때는 스캔/접속이 거부됩니다.

## 8.3 무선 MuJoCo 라이브 트윈

상태 페이지에서 `Twin ON`을 누르고(시리얼 `d`와 동일), 다음을 실행하세요:

```bash
python tools/live_twin.py --tcp <Robot IP>:3333
```

(`SR-Support` 폴더에서; [02 페이지](./02-environment.md)처럼 먼저 `.venv`를 만들고
활성화하세요 - 도구 환경도 그곳에서 설정합니다.)

- 창이 실제 자세를 실시간으로 반영하며 몸체를 바닥 위에 유지합니다;
- 암은 스톨된 서보처럼 바닥 접촉 각도에 고정됩니다(바닥 관통 없음);
- USB 케이블은 플래싱과 로그 덤프에만 필요합니다;
- `--replay <file>`로 기록된 로그를 오프라인 재생할 수 있습니다.

## 8.4 WiFi 텔레메트리 로깅

```bash
python tools/tcp_log.py
```

핫스팟 텔레메트리 스트림을 `logs/wifi_<time>.txt`에 저장하여 오프라인 재생과 분석에
사용합니다.

## 8.5 시뮬레이션 및 학습 레퍼런스

저장소에는 재생과 재학습을 위한 MuJoCo 모델과 학습 코드(`training/b_line/`)가 포함되어
있습니다; 모델 파일은 [10 페이지](./10-reference.md)에 설명되어 있습니다.
