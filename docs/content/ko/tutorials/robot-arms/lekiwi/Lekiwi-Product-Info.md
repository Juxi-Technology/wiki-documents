# 제품 정보

> **[스토어에서 구매](https://www.juxitech.com/ko/products/lekiwi-embodied-intelligence-mobile-robotic-car)**

## 제품 개요

LeKiwi는 SIGRobotics-UIUC(일리노이 대학교 어배너-섐페인 캠퍼스의 로보틱스 연구회)의 주도로 개발되었습니다. 교육, 연구, 산업 자동화 분야에서 로봇 기술의 확산을 촉진하는 저비용의 매우 유연한 오픈소스 로봇 플랫폼을 제공합니다. 하드웨어 설계(3D 프린팅 파일), 소프트웨어 스택(LeRobot 프레임워크와 호환), 튜토리얼이 모두 오픈소스이며 사용자 정의 확장을 지원합니다.

LeKiwi는 모바일 플랫폼과 리더-팔로워 암으로 구성됩니다. 리더-팔로워 암은 3D 프린팅 부품을 구조로 사용하고 6개의 12V Feetech 서보를 구동 관절로 사용합니다. 리더 암은 고정된 플랫폼에 놓여 있고 서보 드라이버 보드 하나를 사용하며 USB-C로 컴퓨터에 연결됩니다. 팔로워 암은 모바일 플랫폼에 장착되며, 이 플랫폼은 3개의 12V Feetech 서보로 구동됩니다. 팔로워 암은 서보 드라이버 보드 하나를 사용하고 Raspberry Pi에 연결된 USB-C를 통해 제어됩니다.

LeKiwi는 LeRobot(Hugging Face의 오픈소스 로봇 머신러닝 프레임워크)을 긴밀하게 통합하여 모방 학습, 데이터 수집, 정책 학습을 지원합니다. PyTorch로 구현되었으며 사전 학습된 모델, 데이터셋, 시뮬레이션 환경을 포함하고 Stanford ALOHA와 같은 잘 알려진 오픈소스 데이터셋과 호환됩니다. DORA 프레임워크(분산 데이터플로 엔진)를 사용하여 저지연 하드웨어-알고리즘 통신을 구현하고(Python 성능이 ROS2보다 17배 빠름) 핫 리로딩을 지원하므로 재시작 없이 실시간으로 코드를 조정할 수 있습니다.

LeKiwi는 교육 및 입문 수준의 연구에 매우 적합합니다: 로보틱스 입문 교육은 조립과 프로그래밍부터 AI 정책 배포까지 모든 것을 다루는 엔드투엔드 튜토리얼을 제공합니다. 연구 검증은 모방 학습 연구(예: VR로 기록한 사람의 조작 영상을 이용한 로봇 학습)를 지원하며, 꽃가루 로봇 Ready2가 15초짜리 영상 50개로 단 2시간 학습한 후 옷 개기나 열쇠 삽입 같은 작업을 익힌 사례가 있습니다. 산업 프로토타이핑은 자동화 솔루션(예: 자재 운반 및 정밀 조립)의 저비용 검증입니다.
