# 04-시리얼 서보 버전-사용 설명

SCS0009 공식 버스 서보 버전 — 사용 설명

> **구매하신 제품이 PWM 서보 버전(ESP32-S3 + 8채널 PWM)이라면 본 디렉터리는 무시하세요**,
`..\01_gui_control` 또는 `..\02_hand_tracking`을 사용하면 됩니다.

이 디렉터리는 AmazingHand **공식 원본 SCS0009 버스 서보**의 지원 현황을 설명합니다.

## 현재 상태

본 delivery_package의 `..\02_hand_tracking\Demo\`는 두 가지 서보 백엔드를 동시에 지원하며, 설정을 통해 원활하게 전환할 수 있습니다:

|버전|서보 유형|보드레이트|설정 파일|
|---|---|---|---|
|**PWM**(본 패키지의 주요 납품물)|ESP32-S3 직접 구동 PWM|115200|`{l,r}_hand_pwm.toml`|
|**SCS0009**(공식 원본)|공식 버스 서보|1,000,000|`{l,r}_hand.toml`|

- **PWM 버전**: 메뉴에서 `3 - PWM 舵机(ESP32 直驱)`를 선택하고 본 패키지 튜토리얼을 사용합니다.

- **SCS0009 버전**: 메뉴에서 `2 - 真实硬件(SCS0009 总线舵机)`를 선택합니다.

## SCS0009 버전 사용 방법

1. 하드웨어: 공식 버스 서보 + 시리얼 어댑터(보드레이트 1M).

2. 배포: `Demo\Windows_Scripts_CN\3-部署代码.bat`(또는 Linux 대응 스크립트).

3. 실행: 4-运行代码.bat → `2 - 真实硬件(SCS0009 总线舵机)` 선택 → 손 유형 선택.

4. 자세한 설명은 `..\02_hand_tracking\Demo\双版本舵机并存说明.md`
및 `Demo\Windows_Scripts_CN\Windows使用教程.md`(공식 튜토리얼)를 참조하세요.

## 주의 사항

- SCS0009는 공식 서보 id 설정이 필요합니다( `{l,r}_hand.toml`에 이미 내장), PWM 버전은 해당 없음.

- 두 서보는 **동시에 한 세트만 연결**하며, 하드웨어 + 메뉴 옵션을 전환하면 됩니다.

- 본 패키지는 PWM 버전을 주요 납품물로 하며; SCS0009 공식 튜토리얼은 공식 Demo를 기준으로 합니다.
