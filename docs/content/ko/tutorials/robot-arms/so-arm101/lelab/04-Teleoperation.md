# 4 · 텔레오퍼레이션

> **이전:** [03 연결 및 캘리브레이션](03-Calibration.md)
> **다음:** [05 데이터셋 녹화](05-Record-Dataset.md)

리더 팔을 손으로 움직이면 팔로워가 그 움직임을 따라합니다. 이렇게 시연을 녹화하며, 캘리브레이션을 확인하는 가장 빠른 방법이기도 합니다.

## 실행하기

1. **Teleoperation** 탭을 엽니다.
2. 포트와 캘리브레이션 프로필을 확인합니다 — LeLab은 캘리브레이션 시점의 선택을 기억합니다.
3. 텔레오퍼레이션을 시작합니다.
4. 리더 팔을 움직입니다.

탭은 실행 중에 관절 위치를 스트리밍합니다. 끝나면 중지를 누르십시오.

**팔로워를 정지시키는 것은 중지입니다.** 탭을 닫거나 프로세스를 종료하면 팔은 그 자리에 남습니다.

## 확인할 항목

| 확인 | 이유 |
|---|---|
| 팔로워가 지연이나 떨림 없이 부드럽게 따라오는가 | 거친 추적은 쓸 수 없는 학습 데이터가 됩니다 |
| 팔로워의 범위가 리더와 일치하는가 | 중간에 멈추거나 한계에 부딪히면 관절이 잘못 캘리브레이션된 것입니다 — [3장](03-Calibration.md)으로 돌아가십시오 |
| 두 팔이 같은 방향으로 움직이는가 | 팔로워가 반대로 움직이면 관절이 잘못된 방향으로 캘리브레이션된 것입니다 |
| 양 끝에서 충돌하지 않는가 | 사용할 전체 범위를 통과해 보십시오 |

동작이 잘못되었지만 고장은 아니라면 — 오프셋, 특정 관절 반전, 범위 부족 — 보상하지 말고 다시 캘리브레이션하십시오. 잘못 캘리브레이션된 팔은 정책이 잘못된 동작을 하도록 학습시키는 데이터셋을 만듭니다.

## 카메라

카메라를 구성했다면 텔레오퍼레이션 뷰에 미리보기가 표시됩니다.

- 손목 카메라: 그리퍼와 그것이 곧 잡을 물체가 보이는가?
- 고정 카메라: 작업 공간 전체가 보이는가?
- 두 이미지 중 하나가 옆으로 기울거나 거꾸로 되어 있는가? 그렇다면 녹화 전에 [캘리브레이션 탭](03-Calibration.md)에서 **rotation**을 수정하십시오.

텔레오퍼레이션 중 녹화된 프레임은 정책이 보는 유일한 것입니다.
