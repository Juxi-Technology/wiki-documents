# 3 · 연결 및 캘리브레이션

> **이전:** [02 설치 및 실행](02-Install.md)
> **다음:** [04 텔레오퍼레이션](04-Teleoperation.md)

캘리브레이션은 각 관절의 영점과 이동 범위를 기록합니다. 팔마다 한 번씩 하십시오. 분해한 뒤나 캘리브레이션 파일을 잃어버린 뒤에는 다시 하십시오.

## 시작하기 전에

- 두 팔 모두 조립 완료, 서보에 ID 부여 완료.
- 두 팔 모두 전원 공급 완료.
- 팔마다 USB 케이블 하나씩, **분리된 USB 포트 두 개**에 연결 — 공유 허브는 열거가 불안정할 때가 있습니다.

### Linux: 시리얼 권한

```bash
sudo usermod -aG dialout $USER
```

그런 다음 **로그아웃했다가 다시 로그인**하십시오. 그렇게 하지 않으면 LeLab은 팔을 찾지만 모든 읽기가 권한 오류로 실패합니다. Windows와 macOS에서는 아무것도 필요하지 않습니다.

## 어느 팔이 어느 팔인가

| 팔 | LeRobot 이름 | LeLab에서 부르는 이름 |
|---|---|---|
| 손으로 움직이는 팔 | `so101_leader` | **teleop** |
| 따라오는 팔 | `so101_follower` | **robot** |

리더를 먼저 캘리브레이션하십시오. 둘을 혼동하는 것이 방금 캘리브레이션한 팔이 이상하게 동작하는 흔한 이유입니다.

## 흐름

**Calibration** 탭을 열고 한 번에 팔 하나씩 진행하십시오:

1. **장치를 선택**합니다 — 리더(teleop) 또는 팔로워(robot).
2. **시리얼 포트를 선택합니다.** LeLab은 인식한 USB 시리얼 장치를 나열합니다. 구별하려면 팔 하나를 뽑고 어느 항목이 사라지는지 확인하십시오. 선택은 기억됩니다.
3. **캘리브레이션 프로필을 선택**합니다 — 기존 프로필 또는 새 프로필. 프로필은 저장된 영점 위치를 담습니다. 이 팔을 이전에 캘리브레이션했다면 그 프로필을 재사용하십시오.
4. **가이드 단계를 따릅니다.** LeLab이 각 관절을 차례로 안내합니다. 요청하는 위치로 관절을 움직이고 확인하십시오. 키보드 입력은 없습니다.
5. **다른 팔에 대해 반복**합니다 — 자체 프로필과 포트를 사용합니다.

> 각 프로필은 하나의 물리적 팔에 속합니다. 두 팔을 서로 바꾸면 다시 캘리브레이션해야 합니다.

## 카메라

카메라는 같은 탭에서 구성합니다. 각 카메라의 이름(`front`, `wrist`, …)이 정책이 보는 키이므로, 학습 로그에서 알아볼 수 있는 이름을 사용하십시오.

카메라는 캘리브레이션 전후 어느 때든 장착할 수 있으며, 캘리브레이션은 카메라에 의존하지 않습니다. 바인딩은 안정적으로 유지하십시오 — 녹화와 추론 사이에 `wrist`라는 물리적 카메라를 다른 것으로 바꾸면 학습된 정책이 터무니없이 동작합니다.

### 회전

카메라를 거꾸로 또는 옆으로 장착했다면 **Rotation**을 설정하십시오: 0°, 90°, 180°, 270°(시계 방향). 거꾸로 장착한 손목 카메라는 180°입니다.

회전은 카메라별로 저장되며 설정 미리보기, 텔레오퍼레이션 미리보기, 녹화된 프레임, 추론에 적용됩니다. 회전 설정이 없는 프로필은 0°로 처리됩니다.

- **90°와 270°는 출력 크기를 바꿉니다.** 640 × 480 캡처가 480 × 640이 됩니다.
- **체크포인트 이미지 크기로는 방향을 알 수 없습니다.** 0°와 180°는 크기가 같지만 이미지는 반대입니다. 추론 전에 녹화할 때 사용한 회전을 설정하십시오 — [6장](06-Train-and-Inference.md)을 참조하십시오.

## 저장되는 항목

| 파일 | 내용 |
|---|---|
| `~/.cache/huggingface/lerobot/calibration/teleoperators/so101_leader/*.json` | 리더 프로필 |
| `~/.cache/huggingface/lerobot/calibration/robots/so101_follower/*.json` | 팔로워 프로필 |
| `~/.cache/huggingface/lerobot/ports/leader_port.txt` | 리더 시리얼 포트 |
| `~/.cache/huggingface/lerobot/ports/follower_port.txt` | 팔로워 시리얼 포트 |

이 파일들은 `~/.cache/` 아래에 있으므로 캐시 정리 도구가 삭제할 수 있습니다. 캘리브레이션한 팔이 다시 캘리브레이션을 요구하면 여기를 확인하십시오 — [문제 해결](07-Troubleshooting.md)을 참조하십시오.
