# 5 · 데이터셋 녹화

> **이전:** [04 텔레오퍼레이션](04-Teleoperation.md)
> **다음:** [06 학습과 추론](06-Train-and-Inference.md)

데이터셋은 **에피소드**의 모음이며, 각 에피소드는 작업을 처음부터 끝까지 한 번 시연한 것입니다. 녹화는 텔레오퍼레이션에 녹화 컨트롤을 더한 것입니다.

## 설정

**Recording** 탭을 열고 다음을 입력하십시오:

| 항목 | 입력할 내용 |
|---|---|
| **데이터셋 이름**(`repo_id`) | `your-name/task-name`, 예: `juxi/pick-up-the-cube`. 업로드할 계획이라면 `name/` 부분이 Hugging Face 사용자 이름이어야 합니다 |
| **작업 설명** | 한 문장, 예: `pick up the cube and drop it in the box`. 이것이 정책이 조건으로 받는 텍스트입니다 |
| **Episodes** | 시연 수 — 아래 참조 |
| **카메라** | 포함할 구성된 카메라와 그 해상도 및 프레임 레이트 |

### 에피소드는 몇 개나

단순한 집기-놓기에는 **30~50**개. 매우 반복적인 작업은 더 적게, 변화가 많은 작업은 더 많이 필요합니다.

**일관성이 개수보다 중요합니다**: 모든 에피소드에서 동일한 시작 위치, 카메라 프레이밍, 작업 설명을 사용하십시오. 거의 동일한 시연 50개가 다양한 시연 100개보다 낫습니다. 정책이 견고해지길 원하는 부분에만 변화를 주십시오 — 모든 에피소드가 같은 위치에서 큐브로 시작하면 정책은 그 위치를 학습합니다.

## 녹화 중

| 키 | 동작 |
|---|---|
| `SPACE` 또는 `→` | 현재 에피소드를 종료하고 다음을 시작 |
| `DEL` 또는 `←` | 방금 녹화한 에피소드를 버리고 다시 녹화 |

탭에 에피소드 카운터와 세션 카운터가 표시됩니다.

작업이 완료되면 에피소드를 종료하십시오 — 팔이 시작 위치로 돌아온 뒤가 아니라. 복귀는 다음 에피소드의 몫입니다.

팔을 잘못 다루거나 물체를 건드려 어긋나게 했거나 작업을 완료하지 못했을 때 에피소드를 다시 녹화하십시오. 정책은 실수를 포함해 데이터셋의 모든 것에서 학습합니다.

## 중지

에피소드가 충분히 모이면 세션을 중지하십시오. **녹화는 중지할 때 확정됩니다** — 바로 그때 데이터셋 인덱스가 기록됩니다. 에피소드 도중 종료된 세션은 불완전하게 읽히는 데이터셋을 남길 수 있습니다.

## 데이터가 저장되는 위치

기본적으로 `~/.cache/huggingface/lerobot/` 아래에, 선택한 `repo_id`를 키로 저장됩니다. **Upload** 탭에서 푸시하기 전까지는 아무것도 업로드되지 않습니다.

## 녹화 확인

**Datasets** 탭을 열고 데이터셋을 선택하십시오. 에피소드를 프레임 단위로, 카메라 하나씩, 관절 움직임 추적 그래프와 함께 넘겨 볼 수 있습니다.

학습 전에 이렇게 하십시오. 팔을 잡고 있을 때는 보이지 않는 것들을 잡아냅니다:

- 카메라가 잘못 회전됨 — 프레임이 옆으로 기울어져 있음
- 시작 부분에 죽은 시간이 늘어선 에피소드
- 중간에 손목 카메라가 프레임 밖으로 벗어남

다시 녹화하는 데는 몇 분이 들지만, 학습 후에 발견하면 학습 한 번이 듭니다.
