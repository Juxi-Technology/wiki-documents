# 06 · 모니터 없는 호스트(캡처 카드 + OBS)

> [← 개요로 돌아가기](/ko/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | 적용 제품: JUXI Technology(鉅犀科技) KVM&HUB&TTL

"모니터가 없는 개발 보드 / 메인보드"에 키보드·마우스를 연결하고 싶을 때 — **모니터를 따로 마련할 필요가 없습니다**. 영상은 캡처 카드를 통해 PC로 들어가고, 키보드·마우스는 KVM으로 전환합니다.

## 동작 방식

```
개발 보드(모니터 없음) ──영상──→ 캡처 카드 ──USB──→ 사용 중인 PC(OBS 창에서 화면 확인)
개발 보드(모니터 없음) ──키보드/마우스──→ ←── KVM 전환 ──→ 사용 중인 PC(같은 키보드/마우스)
```

## 절차

**① 영상 연결**(호스트의 영상 출력을 **4K HDMI 캡처 카드**에 연결, 캡처 카드의 USB 쪽을 사용 중인 PC에 연결):

| 호스트 출력 | 배선 |
|---|---|
| HDMI | HDMI 케이블 → 캡처 카드 |
| Micro HDMI(라즈베리 파이 등) | Micro-HDMI 젠더 → HDMI 케이블 → 캡처 카드 |
| DP | DP-HDMI 젠더 → HDMI 케이블 → 캡처 카드 |

**② 키보드·마우스 연결**: 키보드·마우스(또는 무선 리시버)를 본 제품의 USB-A 포트에 연결하고, 버튼을 눌러 **개발 보드 쪽으로 전환**;

**③ 화면 보기 + 조작**: PC에서 **OBS** 또는 **PotPlayer**에 "비디오 캡처 장치"를 추가하면 개발 보드 화면을 보면서 키보드로 조작할 수 있습니다.

(이미지: 튜토리얼 원본 06 - 개발 보드+캡처 카드 실사, 07 - 캡처 카드 배선, 08 - OBS 가이드, 09 - PotPlayer 가이드)

## 팁

- 캡처 카드는 **PC에 직접 연결**하는 것을 권장합니다(KVM의 USB 포트를 거치지 않음). 화면이 안정적입니다;
- 키보드·마우스를 전환한 후에는 개발 보드가 키보드·마우스에 반응하지 않습니다 — 버튼을 한 번 누르면 되돌아옵니다.
