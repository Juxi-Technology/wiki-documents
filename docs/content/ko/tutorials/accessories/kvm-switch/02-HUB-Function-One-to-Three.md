# 02 · HUB 기능(1대3)

> [← 개요로 돌아가기](/ko/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | 적용 제품: JUXI Technology(鉅犀科技) KVM&HUB&TTL

## 사용 방법

**Type-C 하나 입력, USB-A 세 개 출력** — PC 한 대만 연결하면 본 제품은 일반 USB HUB가 됩니다:

1. Type-C 케이블로 PC를 **PC1**(또는 PC2) 포트에 연결;
2. 키보드, 마우스, USB 메모리 등을 아무 **USB-A** 포트에 연결하면 바로 사용 가능.

두 대의 PC를 연결하면 3개의 USB-A 포트가 하나의 그룹으로 두 PC 사이를 전환합니다([01](/ko/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers) 참조).

(이미지: 튜토리얼 원본 02 - 1대3 HUB)

## 연결 가능한 기기

| 연결 가능 | PC 직접 연결 권장 |
|---|---|
| 키보드, 마우스(무선 리시버 포함) | 휴대용 하드디스크, SSD |
| USB 메모리 | 비디오 캡처 카드 등 고대역폭 기기 |
| 프린터, 동글 | 게이밍 고보고율(폴링레이트) 주변기기(주의) |
| 시리얼 모듈, 센서(TTL 포트 권장, 04 참조) | |

- **드라이버 불필요**: Windows / macOS / Linux / 중국 국산 OS에서 플러그 앤 플레이;
- 규격은 **USB 2.0**이므로 위 표에 따라 기기를 선택하세요.
