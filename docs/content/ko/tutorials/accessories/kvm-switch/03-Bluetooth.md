# 03 · 블루투스 기능

> [← 개요로 돌아가기](/ko/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | 적용 제품: JUXI Technology(鉅犀科技) KVM&HUB&TTL

## 블루투스의 역할

본체에는 블루투스 모듈이 내장되어 있습니다(**6핀 TTL 포트와 같은 시리얼 채널의 "무선 측"**). 개발 보드/센서를 TTL 포트에 연결하면 해당 데이터가 PC 시리얼 포트로 출력될 뿐 아니라 **블루투스로도 동시에 출력**됩니다. 휴대폰으로 연결하면 무선으로 데이터를 주고받을 수 있습니다.

> 배선은 [04 - TTL 시리얼 포트(무선 시리얼)](/ko/tutorials/accessories/kvm-switch/04-TTL-Serial-Port)를 참조하세요. 블루투스 연결과 데이터 송수신은 **PC 전환의 영향을 받지 않습니다**(어느 PC로 전환해도 연결 유지).

## 동작 원리(먼저 이것부터)

⚠️ **블루투스는 "리모컨"이 아닙니다** — **무선 시리얼 케이블**입니다. "6핀 포트에 연결된 외부 기기"와 "휴대폰/PC" 사이의 시리얼 데이터를 전달합니다. **외부 기기가 연결되어 있지 않으면 블루투스로 연결해도 아무 내용이 표시되지 않습니다. 이는 정상입니다.**

```
【외부 기기】            【본 제품】                【나】
 개발 보드/센서 ──6핀──> 시리얼 패스스루 ──┬─ 유선 → PC 시리얼(USB-BLE-SERIAL CH9143)
(데이터 생성/수신)                        └─ 무선 → 휴대폰/PC 블루투스(BleUart App)
```

**예시 1: IMU 자세 데이터 무선 확인**

1. IMU 모듈의 TX/RX/GND/5V를 6핀에 연결(교차 배선·전원 공급, 04 참조) → IMU가 데이터 출력 시작;
2. 전환 버튼을 약 3초간 길게 눌러 블루투스 모드 진입(인디케이터 점등);
3. 휴대폰 BleUart App에서 `CH9143BLE2U`에 연결;
4. 휴대폰에 연속 데이터 프레임이 즉시 표시됩니다(실측 약 80프레임/초의 자세 데이터);
5. 동시에 PC 측 시리얼 도구에서 `USB-BLE-SERIAL CH9143`을 열어도 완전히 동일한 데이터를 볼 수 있습니다.

**예시 2: 라즈베리 파이 / Jetson 무선 디버깅**

1. 라즈베리 파이 Pin8(TXD)/Pin10(RXD)/GND를 6핀에 교차 연결;
2. 라즈베리 파이 부팅 시 부팅 로그가 시리얼로 출력;
3. 휴대폰 BleUart로 연결하면 **부팅 로그를 무선으로 확인** 가능;
4. App에서 입력해 전송하면 데이터가 6핀 TXD를 통해 라즈베리 파이로 출력됩니다 — 휴대폰이 곧 **무선 시리얼 콘솔**(로그인·명령 전송 가능)이 됩니다.

## 휴대폰 연결 순서(4단계)

1. **전환 버튼을 약 3초간 길게 눌러** 인디케이터가 켜질 때까지 기다림 — 블루투스 모드 진입(광고 이름: `CH9143BLE2U`);
2. 휴대폰에 WCH 공식 앱 **"BleUart"** 설치(앱 스토어 검색, 무료);
3. 앱 실행 → "블루투스 연결" 탭 → 목록에서 **CH9143BLE2U** 선택;
4. 연결 성공(**비밀번호 불필요**) — 바로 데이터 송수신 가능.

(이미지: 튜토리얼 원본 04 - 길게 눌러 블루투스 모드 진입)

## ⚠️ 중요 안내

- **휴대폰 시스템 설정의 블루투스 "페어링"을 사용하지 마세요**: PIN 코드를 요구하며 어떤 숫자를 입력해도 성공하지 않습니다 — BLE 기기는 항상 **BleUart App**으로 직접 연결하세요;
- 블루투스 모듈은 **동시에 한 대의 호스트 기기만 연결 가능**합니다(휴대폰 연결 중에는 PC에서 블루투스 연결 불가, 반대도 마찬가지). PC 측 **시리얼 포트**(USB)는 이 제한을 받지 않아 동시 사용이 가능합니다.

## 문제 해결

| 문제 | 해결 방법 |
|---|---|
| CH9143BLE2U가 검색되지 않음 | 버튼을 다시 길게 눌러 인디케이터 점등 확인. 10m 이내인지 확인 |
| PIN 코드 요구 / 연결 불가 | 시스템 페어링을 중단하고 BleUart App 사용 |
| App에서 연결 불가 | 다른 기기(PC 등)가 이미 연결 중일 수 있음 — 다른 연결을 끊고 재시도 |
| 연결됐지만 데이터 없음 | 블루투스는 6핀 포트의 시리얼 데이터를 전송합니다 — 먼저 외부 기기가 TTL 포트에 연결되어 있는지 확인(04 참조) |
