## 제품 한 줄 소개

**2입력 3출력 USB 키보드/마우스 전환기**: 키보드·마우스 한 세트(및 주변기기)를 두 대의 PC 사이에서 버튼 하나로 전환. 3포트 USB HUB 내장. 또한 **무선 시리얼 기능** — 개발 보드/센서의 시리얼 포트를 6핀 헤더에 연결하면 데이터가 "PC 시리얼 포트 + 휴대폰 블루투스"로 동시에 전달됩니다.

## 인터페이스 한눈에 보기

| 위치 | 명칭 | 설명 |
|---|---|---|
| 좌측 / 우측 | PC1 / PC2 포트(Type-C) | 두 대의 PC를 각각 연결 |
| 하단 | USB-A × 3 | 키보드/마우스, USB 메모리, 프린터 등 — 전환 시 함께 이동 |
| 상단 | 전원 포트(Type-C) | 보조 전원(호스트 전원이 부족할 때 사용) |
| 중앙 | 전환 버튼 | 짧게 누르면 전환, 길게 누르면 블루투스 모드 |
| 좌상단 | 적외선 수신부 | 적외선 리모컨으로 전환 |
| 우하단 | TTL 시리얼 포트(6핀) | 무선 시리얼 기능(04 참조) |
| 우하단 | 10핀 헤더 | 확장 인터페이스(05 참조) |
| 우상단 | 블루투스 모듈(내장) | 무선 시리얼 기능(03 참조) |

**인디케이터**: PC1/PC2(현재 채널) | 전원 | UART 시리얼(송수신 시 점멸) | 블루투스(길게 누른 후 점등)

## 빠른 시작(5분)

1. PC A → Type-C 케이블 → **PC1** 포트, PC B → **PC2** 포트(한 대만 연결해도 됨. 이때는 일반 USB HUB로 동작);
2. 키보드/마우스(또는 무선 리시버)를 아무 **USB-A** 포트에 연결;
3. 전환 버튼을 눌러 **PC1/PC2 인디케이터**로 현재 연결된 PC를 확인;
4. 호스트 전원이 부족하면 **전원 포트**에도 Type-C 전원을 연결.

(이미지: 튜토리얼 원본 01 - 기능 배치)

## 두 가지 중요 안내

- 본 제품은 **영상을 전환하지 않습니다**: 각 PC는 자체 모니터에 연결합니다. 모니터가 없는 호스트는 캡처 카드 방식을 사용하세요(06 참조);
- 본 제품은 **USB 2.0**입니다: 키보드/마우스, 프린터, USB 메모리, 동글에는 충분합니다. 고속 저장장치는 PC에 직접 연결하는 것을 권장합니다.
