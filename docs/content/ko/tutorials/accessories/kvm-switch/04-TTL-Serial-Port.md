# 04 · TTL 시리얼 포트(무선 시리얼)

> [← 개요로 돌아가기](/ko/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | 적용 제품: JUXI Technology(鉅犀科技) KVM&HUB&TTL

## 무엇인가

6핀 TTL 포트는 **시리얼 패스스루 포트**입니다. 개발 보드, 센서 등을 연결하면 해당 시리얼 데이터가 "동시에" 두 곳으로 출력됩니다(양방향):

```
                ┌─→ PC 시리얼 포트(USB, 시스템 인식명 "USB-BLE-SERIAL CH9143")
외부 기기 → 6핀 ┤
                └─→ 블루투스 무선(휴대폰 BleUart App, 03 참조)
```

**실측 참고**: IMU 센서를 연결한 결과 PC 시리얼과 블루투스에서 동시에 약 1650바이트/초의 데이터를 안정적으로 수신했습니다.

## 핀 정의와 배선

왼쪽부터: `GND` `RXD` `TXD` `TNOW` `3V3` `5V`

| 핀 | 설명 | 배선 |
|---|---|---|
| GND | 접지 | 외부 기기의 GND와 연결(**필수**) |
| RXD | 본체 수신 | 외부 기기의 **TXD**에 연결(교차) |
| TXD | 본체 송신 | 외부 기기의 **RXD**에 연결(교차) |
| TNOW | 송신 방향 표시 | **연결하지 않음(공중)** |
| 3V3 | 3.3V 전원 출력 | 저전력 주변기기에 전원 공급 가능(5V와 택일) |
| 5V | 5V 전원 출력 | 저전력 주변기기에 전원 공급 가능(3V3와 택일) |

**요점**: 송수신은 반드시 **교차** 연결. 전압 레벨은 **3.3V**. 전원 핀은 **출력**입니다 — 역으로 전원을 넣지 마세요. 저전력 모듈만 연결하세요.

(이미지: 튜토리얼 원본 12 - TTL 배선 예시)

## PC 측 사용

1. 본 제품을 Type-C로 PC에 연결(PC1/PC2 아무 포트나 가능);
2. 시스템이 시리얼 포트 **`USB-BLE-SERIAL CH9143`**을 자동 인식(Windows 10/11 드라이버 불필요);
3. 시리얼 도구로 열기. 파라미터: **115200, 8N1**;
4. 외부 기기의 데이터를 실시간으로 수신(기기로 데이터 전송도 가능).

## 개발 보드 연결(라즈베리 파이 / Jetson)

전압 레벨 3.3V이므로 직접 연결 가능(교차 배선, GND 연결):

| 본 제품 | 라즈베리 파이 | Jetson(Orin 시리즈 40핀) |
|---|---|---|
| RXD | Pin8(GPIO14 / TXD) | Pin8(UART1_TXD) |
| TXD | Pin10(GPIO15 / RXD) | Pin10(UART1_RXD) |
| GND | 아무 GND(예: Pin9) | 아무 GND(예: Pin9) |

> 라즈베리 파이는 `raspi-config`에서 시리얼을 활성화해야 합니다. Jetson은 40핀 UART를 먼저 활성화해야 합니다.
> 대표적인 사용 예: 개발 보드 시리얼을 KVM에 연결 → PC에서 명령을 입력하며 로그 확인, 휴대폰 블루투스로도 동시 확인(무선 디버깅).

(이미지: 튜토리얼 원본 10 - Jetson 핀 배치, 11 - 라즈베리 파이 핀 배치)

## 문제 해결: 시리얼 데이터가 없나요?

순서대로 확인하세요:
1. 외부 기기의 TX/RX가 **교차** 연결인지, GND가 연결됐는지;
2. 외부 기기의 보드레이트가 **115200**인지;
3. 외부 기기에 전원이 공급되는지(본 제품의 5V/3V3 핀으로 공급 가능);
4. PC 시리얼 포트가 다른 프로그램에 점유되어 있지 않은지. 기기를 다른 PC로 전환하면 포트가 잠시 사라집니다(정상).
