# 05 · 10핀 확장 헤더

> [← 개요로 돌아가기](/ko/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | 적용 제품: JUXI Technology(鉅犀科技) KVM&HUB&TTL

본체 우하단의 **10핀 헤더**는 **예약된 확장 인터페이스**입니다. 실크 인쇄는 다음과 같습니다:

| 열 | 실크 인쇄 |
|---|---|
| 상단 열 | `RI#` `DSR#` `FCE` `DTR#` `RST#` |
| 하단 열 | `CTS#` `DCD#` `GND` `GND` `GND` |

## 설명

- 이 포트는 **외부 컨트롤러 연결, 사용자 정의 케이블 등 2차 개발** 용도입니다(시리얼 제어 신호 관련);
- 일반 사용(키보드/마우스 전환, HUB, 무선 시리얼)에서는 **이 포트에 연결할 필요가 없습니다**;
- 이 인터페이스의 전기적 정의와 사용 방법이 필요하면 저희에게 문의하세요(실물과 최신 설명서 기준);
- 직접 배선하기 전에 멀티미터로 전압 레벨을 확인하여 기기 손상을 방지하세요.
