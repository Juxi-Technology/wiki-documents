# 07 · FAQ 및 주의사항

> [← 개요로 돌아가기](/ko/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | 적용 제품: JUXI Technology(鉅犀科技) KVM&HUB&TTL
> 모듈별 개별 질문은 해당 문서를 참조하세요(블루투스 → 03, TTL 시리얼 → 04).

## 자주 묻는 질문

**Q1: 모니터 화면을 전환할 수 있나요?**
아니요. 본 제품은 키보드/마우스와 USB 기기를 전환합니다. 두 대의 PC는 각자 모니터에 연결하고, 모니터가 없는 호스트는 캡처 카드 방식을 사용합니다([06](/ko/tutorials/accessories/kvm-switch/06-Headless-Host-Capture-Card-and-OBS) 참조).

**Q2: 드라이버를 설치해야 하나요?**
아니요, 드라이버가 필요 없습니다(Windows / macOS / Linux / 중국 국산 OS).

**Q3: 휴대용 하드디스크를 연결할 수 있나요?**
본 제품은 USB 2.0입니다. 고속 저장장치와 캡처 카드는 PC에 직접 연결하는 것을 권장합니다. USB 메모리, 키보드/마우스, 프린터, 동글 등은 문제없습니다.

**Q4: 휴대폰 블루투스가 연결되지 않거나 PIN 코드를 요구합니다?**
시스템 블루투스 "페어링"을 사용하지 말고 **BleUart** App을 설치해 앱 안에서 연결하세요([03](/ko/tutorials/accessories/kvm-switch/03-Bluetooth) 참조).

**Q5: 휴대폰과 PC가 동시에 블루투스 연결할 수 있나요?**
아니요 — 동시에 하나의 호스트 기기만 연결할 수 있습니다. PC 측 **시리얼 포트**(USB)는 영향을 받지 않아 동시에 사용할 수 있습니다.

**Q6: 전환할 때 USB 기기가 잠깐 끊기나요?**
정상입니다: 기기가 전환에 따라 PC 사이를 "이동"하며 다른 PC가 다시 인식합니다(일부 기기는 몇 초 소요).

**Q7: HUB로만 사용할 수 있나요?**
가능합니다. PC 한 대만 연결하면 3포트 USB HUB가 됩니다([02](/ko/tutorials/accessories/kvm-switch/02-HUB-Function-One-to-Three) 참조).

**Q8: 게이밍 마우스를 지원하나요?**
키보드/마우스는 표준 USB 2.0 HID로 동작하며 사무·디버깅 환경에서는 차이를 느낄 수 없습니다. 게이밍용 고보고율 기기는 주의하세요.

## 주의사항

- TTL 포트 전압 레벨은 **3.3V**입니다. 5V 신호 레벨을 인가하지 마세요. `3V3/5V`는 **출력** 핀입니다 — 전원을 역으로 넣지 마세요;
- USB 2.0 대역폭은 제한적입니다. [02](/ko/tutorials/accessories/kvm-switch/02-HUB-Function-One-to-Three)의 권장 사항에 따라 기기를 선택하세요;
- 임의로 분해하거나 납땜하지 마세요. 정전기에 민감하므로 만지기 전에 방전하세요;
- 제품 기능과 인터페이스는 실물 기준입니다. 본 튜토리얼이 갱신되면 최신 버전을 기준으로 합니다.
