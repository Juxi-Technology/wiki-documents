# 2자유도 짐벌

> **[스토어에서 구매](https://www.juxitech.com/ko/products/2-dof-servo-pan-tilt-unit)**

2자유도 카메라 짐벌 — 키보드 수동 제어와 색상, 얼굴, QR 코드 자동 추적을 지원합니다.
하드웨어: SCS009 서보 ×2(좌우 회전 + 상하 틸트) + CH343 시리얼 버스 드라이버 보드(기본 보드레이트 1Mbps).
