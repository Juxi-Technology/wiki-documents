# 기본 사용법

> **[스토어에서 구매](https://www.juxitech.com/ko/products/2-dof-servo-pan-tilt-unit)**

이 섹션에서는 짐벌의 기본 제어 방법과 사용 절차를 자세히 소개하여 사용자가 기본 조작에 익숙해지도록 돕습니다.

---

## 제어 방식 개요

짐벌 시스템은 두 가지 주요 제어 방식을 지원합니다:
1. 키보드 제어: 키보드 키를 통해 짐벌 운동을 수동으로 제어합니다
2. 자동 추적: 시스템이 대상을 자동으로 인식하고 추적합니다

---

## 키보드 제어

### 키보드 단축키 설명

다음은 메인 프로그램에서 사용할 수 있는 키보드 단축키입니다:

|키|기능 설명|
|---|---|
|방향키 ←|짐벌 왼쪽 회전|
|방향키 →|짐벌 오른쪽 회전|
|방향키 ↑|짐벌 위로 틸트|
|방향키 ↓|짐벌 아래로 틸트|
|C|짐벌 연결 또는 연결 해제|
|R|짐벌 중앙 복귀(초기 위치로 복귀)|
|1|얼굴 추적 모드로 전환|
|2|색상 추적 모드로 전환|
|T|대상 잠금/추적 시작|
|S|추적 중지|
|X|색상 모드: 빨간색 물체 추적|
|Y|색상 모드: 초록색 물체 추적|
|Z|색상 모드: 파란색 물체 추적|
|Q|프로그램 종료|


### 독립적인 키보드 제어 예제

별도의 키보드 제어 프로그램으로 연습할 수도 있습니다:

```python
python examples/keyboard_control.py --port COM3
```

이 프로그램은 기본적인 짐벌 제어 기능만 제공하므로 초보자가 시작하기에 적합합니다.

---

## 기본 조작 절차

### 시작 및 연결

1. 다음 명령으로 메인 프로그램을 시작합니다:

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3
```

1. 프로그램이 시작되면 `C`를 눌러 짐벌을 연결합니다
2. 서보가 정상적으로 응답하는지 관찰하고, 이상이 있으면 문제 해결 섹션을 참고하세요

### 수동 제어 연습

1. 방향키를 눌러 짐벌 운동이 예상과 일치하는지 관찰합니다
2. 방향키로 짐벌을 다양한 위치로 이동하는 연습을 합니다
3. `R`을 눌러 짐벌을 중앙으로 복귀시킵니다
4. 짐벌의 최소 및 최대 위치 제한을 익힙니다
다음 연습을 권장합니다:
- 연습 1: 짐벌을 최좌측, 최우측, 최상단, 최하단 네 개의 한계 위치로 이동하여 위치 범위에 익숙해집니다
- 연습 2: 임의 위치에서 중앙으로 복귀시키고 복귀가 원활한지 관찰합니다
- 연습 3: 미세 조정을 시도하여 서보의 운동 정밀도에 익숙해집니다

## 기본 예제 프로그램

프로젝트는 사용자가 학습할 수 있도록 단계별 예제 프로그램을 제공합니다:

### 카메라만 표시

```python
python examples/01_camera_only.py --camera 0
```

이 프로그램은 카메라만 열어 실시간 화면을 표시하며 짐벌 제어는 다루지 않습니다. 카메라 기능이 정상인지 검증하기에 적합합니다.

### 짐벌만 제어

```python
python examples/02_gimbal_only.py --port COM3
```

이 프로그램은 짐벌 제어 기능만 제공하며 카메라는 다루지 않습니다. 서보와 드라이버 보드 연결이 정상인지 검증하기에 적합합니다.

### 카메라와 짐벌 결합

```python
python examples/03_simple_gimbal_camera.py --camera 0 --port COM3
```

이 프로그램은 카메라 화면 표시와 짐벌 제어를 결합하여 화면과 짐벌의 연동 효과를 관찰할 수 있습니다.

## 사용 시 주의사항

사용 중에는 다음 사항에 주의하세요:
1. 짐벌을 연결한 후 서보 전원이 연결되어 있는지 확인합니다
2. 수동 제어 시 한계 위치에 장시간 머무르지 않도록 주의합니다
3. 조작 시 짐벌 브래킷에 강한 충격을 가하지 않도록 합니다
4. 서보에서 이상한 떨림이나 소음이 발생하면 즉시 전원을 차단하고 점검합니다
5. 장시간 사용하지 않을 때는 전원 연결을 분리하는 것을 권장합니다
