|파라미터|1번 서보(좌우 회전)|2번 서보(상하 틸트)|

## 하드웨어 연결

### 단계 1: 서보와 짐벌 브래킷 설치

1. 1번 서보(좌우 회전용)를 짐벌 하부 브래킷의 지정된 위치에 설치하고, 나사로 단단히 고정합니다
2. 2번 서보(상하 틸트용)를 짐벌 상부 브래킷에 설치하고 마찬가지로 잘 고정합니다
3. 설명에 따라 카메라 고정 구조물을 설치합니다

### 단계 2: 서보와 드라이버 보드 연결

1. 두 서보의 데이터 케이블을 드라이버 보드의 서보 포트에 연결합니다
2. 서보 케이블의 연결 순서에 주의하세요. 색상은 일반적으로 빨간색(전원), 검은색(접지), 흰색/노란색(신호)입니다
3. 서보가 올바른 ID에 연결되었는지 확인합니다: 서보 ID 1은 좌우, 서보 ID 2는 상하입니다

### 단계 3: 전원 및 시리얼 포트 연결

1. 서보 전원을 드라이버 보드의 전원 포트에 연결합니다
2. 시리얼 데이터 케이블로 드라이버 보드와 컴퓨터의 USB 포트를 연결합니다
3. 카메라를 컴퓨터에 연결합니다

## 드라이버 및 의존성 설치

### 시리얼 드라이버 설치

#### Windows

1. CH343 칩 제조사 공식 웹사이트를 방문하여 Windows 버전에 해당하는 드라이버 설치 프로그램을 다운로드합니다
CH343 드라이버 설치(관리자 권한으로 설치)
https://www.wch.cn/downloads/CH343SER_EXE.html

>
> 장치 관리자에서 usb single serial 또는 usb serial이라는 알 수 없는 장치로 인식되는 경우, 먼저 마우스 오른쪽 버튼으로 클릭하여 제거한 후 드라이버를 설치하세요!

1. 설치 프로그램을 실행하고 안내에 따라 드라이버 설치를 완료합니다
2. 서보 드라이버 보드를 컴퓨터에 연결하면 장치 관리자에서 시리얼 장치가 확인되어야 합니다

#### Linux

대부분의 Linux 배포판에는 CH343 시리얼 드라이버가 내장되어 있어 별도로 설치할 필요가 없습니다. 문제가 발생하면 다음을 시도해 보세요:
1. 커널에 드라이버가 로드되었는지 확인 `lsmod | grep ch343`
2. 로드되지 않은 경우 장치를 다시 연결하거나 재부팅합니다

### Python 의존성 설치

프로젝트 루트 디렉터리에서 실행합니다:

```python
pip install -r requirements.txt
```

프로젝트의 주요 의존성은 다음과 같습니다:
- opencv-python: 이미지 캡처 및 처리
- numpy: 수치 계산 라이브러리
- pyserial: 시리얼 통신 라이브러리

## 하드웨어 연결 검증

정식 프로그램을 시작하기 전에 도구를 사용하여 하드웨어 연결을 검증할 수 있습니다.

### 사용 가능한 카메라 찾기

다음 명령을 실행하여 사용 가능한 카메라를 나열합니다:

```python
python examples/list_cameras.py
```

프로그램이 사용 가능한 모든 카메라를 감지하여 나열합니다. 사용할 카메라 인덱스를 기록해 두세요.

### 사용 가능한 시리얼 포트 찾기

다음 명령을 실행하여 사용 가능한 시리얼 포트를 나열합니다:

```python
python examples/list_ports.py
```

사용할 시리얼 포트 장치 이름을 기록해 두세요.

### 하드웨어 진단

전체 하드웨어를 종합적으로 점검하려면 진단 도구를 실행할 수 있습니다:

```python
python examples/diagnostic.py --camera 0 --port COM3
```

진단 프로그램은 카메라, 시리얼 포트, 짐벌을 순서대로 테스트합니다.

## 안전 수칙

사용 중에는 다음 안전 사항에 주의하세요:
1. 서보 전원은 규정 범위(4V-7.4V) 내에서 사용하여 서보 손상을 방지합니다
2. 수명 연장을 위해 서보가 한계 위치에서 장시간 동작하지 않도록 합니다
3. 전원을 끄기 전에 먼저 짐벌을 중앙으로 복귀시키면 다음 시작 시 부하를 줄일 수 있습니다
