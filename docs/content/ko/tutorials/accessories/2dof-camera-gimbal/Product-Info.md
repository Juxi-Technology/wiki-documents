# 제품 정보

> **[스토어에서 구매](https://www.juxitech.com/ko/products/2-dof-servo-pan-tilt-unit)**

2자유도 카메라 짐벌 제어 프로젝트로, 색상, 얼굴, QR 코드 자동 추적을 지원합니다.

---

## 📋 기능 특성

- 🎮 키보드로 짐벌 수동 제어
- 🎯 색상 물체 자동 추적
- 👤 얼굴 자동 추적
- 📱 QR 코드 자동 추적
- 🔒 대상 잠금 메커니즘
- 🚀 빠른 시작(DSHOW 백엔드 사용)

---

## 🛠 하드웨어 구성

- **서보 모델**: SCS009
- **서보 할당**:
  - 1번 서보: 좌우 회전 제어
  - 2번 서보: 상하 틸트 제어
- **통신 방식**: 시리얼 버스 드라이버 보드
- **드라이버 보드 칩**: CH343
- **보드레이트**: 기본 1Mbps

### 서보 파라미터


|파라미터|1번 서보(좌우)|2번 서보(상하)|
|---|---|---|
|범위|220-802|220-511|
|중앙 위치|511|511|
|설명|220=왼쪽, 802=오른쪽|220=위, 511=중앙 위치|

## 🚀 빠른 시작

### 의존성 설치

```python
pip install -r requirements.txt
```

### 사용 가능한 장치 찾기

**사용 가능한 카메라 찾기**

```python
python examples/list_cameras.py
```

**사용 가능한 시리얼 포트 찾기**

```python
python examples/list_ports.py
```

### 데모 실행

명령줄 파라미터로 구성합니다:

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3 --color red
```

**파라미터 설명**
- `--camera` 또는 `-c`: 카메라 인덱스(기본 0)
- `--port` 또는 `-p`: 시리얼 포트 장치(기본 COM3)
- `--color` 또는 `-C`: 기본 색상(기본 red)

## 🎮 사용 설명

### 단축키


|키|기능|
|---|---|
|1|얼굴 추적 모드로 전환|
|2|색상 추적 모드로 전환|
|C|짐벌 연결|
|R|짐벌 중앙 복귀|
|T|대상 잠금/추적 시작|
|S|추적 중지|
|X|색상 모드: 빨간색|
|Y|색상 모드: 초록색|
|Z|색상 모드: 파란색|
|Q|프로그램 종료|


### 자동 추적 사용 절차

1. `C`를 눌러 짐벌을 연결합니다
2. `1` 또는 `2`를 눌러 모드를 선택합니다
3. 대상 물체를 화면 중앙으로 이동합니다
4. `T`를 눌러 대상을 잠급니다
5. 대상을 움직이면 짐벌이 자동으로 따라갑니다

## 🔧 기술 설명

### 추적 제어 파라미터

`src/trackers/tracking_controller.py`에서 조정할 수 있습니다:

|파라미터|기본값|설명|
|---|---|---|
|kp_pan|0.08|좌우 추적의 비례 게인|
|kp_tilt|0.12|상하 추적의 비례 게인|
|dead_zone|30|데드존(픽셀), 이 범위 내에서는 이동하지 않음|
|min_move_interval|0.15|최소 이동 간격(초)|


### 대상 잠금 메커니즘

잠금 후 시스템은 다음 조건에 따라 대상을 선택합니다:
- 잠금 지점에서 가장 가까운 대상(가중치 70%)
- 크기가 잠금 시와 가장 유사한 대상(가중치 30%)
