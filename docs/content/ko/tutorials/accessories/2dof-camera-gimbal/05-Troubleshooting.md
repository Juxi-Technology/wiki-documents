# 문제 해결

> **[스토어에서 구매](https://www.juxitech.com/ko/products/2-dof-servo-pan-tilt-unit)**

이 섹션에서는 자주 발생하는 문제와 해결 방법을 정리하여 사용자가 사용 중 겪는 각종 문제를 빠르게 점검하고 해결할 수 있도록 돕습니다.

---

## 하드웨어 관련 문제

### 서보가 응답하지 않음

**가능한 원인:**
1. 서보 전원이 연결되지 않음
2. 서보와 드라이버 보드의 연결 불량
3. 시리얼 포트 연결 실패
4. 서보가 활성화되지 않음
**해결 방법:**
1. 서보 전원이 올바르게 연결되어 전원이 들어오는지 확인합니다
2. 서보와 드라이버 보드의 연결 케이블이 단단히 연결되었는지 확인합니다
3. `examples/diagnostic.py`를 실행하여 진단 정보를 확인합니다
4. `C`를 눌러 짐벌을 연결했고 서보가 활성화되었는지 확인합니다

### 서보 운동 방향이 반대

**가능한 원인:**
- 서보 설치 방향 또는 프로그램 제어 파라미터 조정 필요
**해결 방법:**
`src/trackers/tracking_controller.py`의 `calculate_move` 메서드에서 해당 파라미터의 부호를 반대로 수정합니다:

# 좌우가 반대인 경우

```python
delta_pan = -int(self.kp_pan * err_x)
```

# 상하가 반대인 경우

```python
delta_tilt = -int(self.kp_tilt * err_y)
```

### 서보 떨림

**가능한 원인:**
- 추적 파라미터가 너무 민감함
- 데드존 범위가 너무 작음
- 서보 부하가 과다하거나 전원 공급 부족
**해결 방법:**
1. `dead_zone` 파라미터를 증가시킵니다
2. `min_move_interval`을 증가시킵니다
3. `kp_pan`과 `kp_tilt`를 감소시킵니다
4. 전원 전압이 정상인지 확인합니다

### 시리얼 포트 연결 실패

**가능한 원인:**
- 드라이버가 설치되지 않음
- 시리얼 포트 번호가 올바르지 않음
- 시리얼 포트가 다른 프로그램에 의해 점유됨
- 연결 케이블 고장
**해결 방법:**
1. Windows에서 장치 관리자를 확인하여 드라이버가 정상적으로 설치되었는지 확인합니다
2. `examples/list_ports.py`를 실행하여 올바른 시리얼 포트를 찾습니다
3. 시리얼 포트를 점유할 수 있는 다른 프로그램을 종료합니다
4. USB 포트나 데이터 케이블을 교체해 봅니다

## 소프트웨어 관련 문제

### 카메라를 열 수 없음

**가능한 원인:**
- 카메라 인덱스가 올바르지 않음
- 카메라가 다른 프로그램에 의해 점유됨
- 카메라 하드웨어 연결 문제
- 카메라 드라이버 문제
**해결 방법:**
1. `examples/list_cameras.py`를 실행하여 사용 가능한 카메라 인덱스를 확인합니다
2. 카메라를 사용할 수 있는 다른 프로그램을 종료합니다
3. 카메라 연결이 정상인지 확인합니다
4. USB 포트를 교체해 봅니다

### OpenCV 오류 발생

**가능한 원인:**
- OpenCV 버전 문제
- 의존성 라이브러리 설치 불완전
- 카메라 하드웨어 이상
**해결 방법:**
1. 의존성 라이브러리를 다시 설치해 봅니다:

```python
pip install --upgrade opencv-python numpy
```

1. Python 버전이 요구 사항(>=3.8)을 충족하는지 확인합니다
2. 오류 스택 정보를 확인하여 문제 코드를 파악합니다

### 의존성 설치 실패

**가능한 원인:**
- pip 버전이 너무 오래됨
- 네트워크 연결 문제
- 권한 문제
**해결 방법:**
1. 먼저 pip를 업그레이드합니다:

```python
pip install --upgrade pip
```

1. 중국 내 미러 소스를 사용하여 속도를 높입니다:

```python
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

1. 네트워크 연결이 정상인지 확인합니다

### 프로그램 시작이 느림

**가능한 원인:**
- Windows에서 DSHOW를 사용하지 않음
- 카메라 하드웨어 초기화에 시간이 필요함
**해결 방법:**
1. 코드에서 `cv2.CAP_DSHOW`를 카메라 백엔드로 사용하는지 확인합니다
2. 다른 프로그램이 카메라를 점유하고 있는지 확인합니다
3. 몇 초 기다립니다. 카메라 초기화에는 보통 시간이 걸립니다

## 추적 관련 문제

### 대상 인식이 부정확함

**색상 추적 시:**
- 대상 색상과 배경의 대비가 뚜렷한지 확인합니다
- 색상 파라미터를 조정합니다(`src/detectors/color_detector.py`에서)
- 조명이 충분하고 균일하도록 합니다
**얼굴 추적 시:**
- 조명이 충분해야 하며 역광을 피합니다
- 얼굴이 카메라를 정면으로 향해야 합니다
- 적절한 거리를 유지합니다

### 추적 시 짐벌이 움직이지 않음

**가능한 원인:**
1. 짐벌이 연결되지 않음
2. 대상이 잠기지 않음
3. 대상이 데드존 안에 있음
4. 프로그램 오류
**해결 방법:**
1. `C`를 눌러 짐벌을 연결했는지 확인합니다
2. `T`를 눌러 대상을 잠갔는지 확인합니다
3. 콘솔 출력을 확인하여 오류 메시지를 찾습니다
4. 대상이 `dead_zone` 범위 안에 있는지 확인합니다

### 추적 방향이 반대

**해결 방법:**
"서보 운동 방향이 반대"의 해결 방법을 참고하세요.

### 추적 떨림

**해결 방법:**
"서보 떨림"의 해결 방법을 참고하세요.

### 대상 잠금 실패

**가능한 원인:**
1. 잠금 시 대상이 화면 중앙에 없음
2. 대상이 너무 작거나 색상이 뚜렷하지 않음
3. 대상이 검출되지 않음
**해결 방법:**
1. 잠금 시 대상이 화면 중앙에 있도록 합니다
2. 대상 크기가 적절하여 올바르게 검출되는지 확인합니다
3. 콘솔 출력을 확인하여 대상이 검출되었는지 확인합니다
4. 대상 위치를 다시 조정한 후 잠급니다

## 진단 도구 사용

### 진단 프로그램 사용

시스템은 전체 시스템의 하드웨어를 테스트할 수 있는 종합 진단 도구를 제공합니다:

```python
python examples/diagnostic.py --camera 0 --port COM3
```

진단 프로그램은 다음을 순서대로 테스트합니다:
1. 카메라가 정상적으로 동작하는지
2. 시리얼 포트가 정상적으로 연결되는지
3. 서보가 정상적으로 응답하는지
진단이 완료되면 테스트 결과가 표시되어 문제 위치를 파악하는 데 도움이 됩니다.

### 디버그 출력 확인

프로그램 실행 시 콘솔에 다음과 같은 디버그 정보가 출력됩니다:
- 검출된 대상 정보
- 대상 좌표
- 오차 값
- 짐벌 이동 명령
- 모든 오류 정보
이러한 출력을 주의 깊게 관찰하면 문제를 빠르게 파악하는 데 도움이 됩니다.

## 복구 방법

### 짐벌을 안전한 위치로 복구

- `R`을 눌러 짐벌을 중앙으로 복귀시킵니다
- 또는 `gimbal.return_to_center()`를 호출합니다

### 모든 설정 재설정

- `S`를 눌러 추적을 중지합니다
- `R`을 눌러 중앙으로 복귀시킵니다
- 대상을 다시 잠급니다

### 재보정

추적 효과가 심각하게 좋지 않으면 다음을 수행할 수 있습니다:
1. 추적 파라미터 조정
2. 대상 다시 잠금
3. 필요 시 프로그램 재시작
4. 하드웨어 연결 확인
