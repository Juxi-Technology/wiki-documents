# 빠른 시작 가이드

> **[스토어에서 구매](https://www.juxitech.com/ko/products/2-dof-servo-pan-tilt-unit)**

> 하드웨어가 이미 조립된 상태에서 기능을 빠르게 체험하고 싶은 사용자를 위한 문서입니다

---

## 단계 0: 사용 가능한 장치 찾기

시작하기 전에 올바른 카메라와 시리얼 포트를 찾아야 합니다.

### 사용 가능한 카메라 찾기

```python
python examples/list_cameras.py
```

프로그램이 사용 가능한 모든 카메라와 인덱스를 나열합니다. 사용할 인덱스를 기억해 두세요(일반적으로 0).

### 사용 가능한 시리얼 포트 찾기

```python
python examples/list_ports.py
```

프로그램이 사용 가능한 모든 시리얼 포트를 나열합니다. Windows에서는 COM3, COM4 등이고, Linux에서는 /dev/ttyUSB0 등입니다.

## 단계 1: 의존성 설치

```python
pip install -r requirements.txt
```

---

## 단계 2: 단계별 튜토리얼을 순서대로 실행(선택 사항이지만 권장)

시스템을 더 잘 이해하기 위해 다음 프로그램들을 순서대로 실행하는 것을 권장합니다:
1. **01_camera_only.py** - 카메라 화면만 표시하고 짐벌은 연결하지 않음

```python
python examples/01_camera_only.py --camera 0
```

기능: 카메라가 정상적으로 동작하는지 검증
1. **02_gimbal_only.py** - 짐벌만 제어하고 카메라는 연결하지 않음

```python
python examples/02_gimbal_only.py --port COM3
```

기능: 서보와 드라이버 보드 연결이 정상인지 검증
1. **03_simple_gimbal_camera.py** - 카메라와 짐벌 결합

```python
python examples/03_simple_gimbal_camera.py --camera 0 --port COM3
```

기능: 짐벌을 수동 제어하면서 카메라 화면을 확인
1. **04_color_track_simple.py** - 간단한 색상 추적(잠금 없음)

```python
python examples/04_color_track_simple.py --camera 0 --port COM3 --color red
```

기능: 가장 기본적인 자동 추적 데모

## 단계 3: 전체 프로그램 실행

기본 기능에 익숙해지면 전체 자동 추적 프로그램을 실행합니다:

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3 --color red
```

## 전체 프로그램 단축키


|키|기능|
|---|---|
|1|얼굴 추적 모드로 전환|
|2|색상 추적 모드로 전환|
|C|짐벌 연결|
|R|짐벌 중앙 복귀|
|T|대상 잠금/추적 시작|
|S|추적 중지|
|X|색상 모드: 빨간색|
|Y|색상 모드: 초록색|
|Z|색상 모드: 파란색|
|Q|프로그램 종료|


---

## 빠른 체험 절차

### 색상 추적 체험

1. `C`를 눌러 짐벌을 연결합니다
2. `2`를 눌러 색상 추적 모드로 들어갑니다
3. 빨간색 물체(또는 다른 색상)를 화면 중앙으로 이동합니다
4. `T`를 눌러 대상을 잠급니다
5. 물체를 움직이며 짐벌이 따라오는지 관찰합니다

### 얼굴 추적 체험

1. `C`를 눌러 짐벌을 연결합니다
2. `1`을 눌러 얼굴 추적 모드로 들어갑니다
3. 얼굴을 화면 중앙에 놓습니다
4. `T`를 눌러 대상을 잠급니다
5. 얼굴을 움직이며 짐벌이 따라오는지 관찰합니다

## 자주 묻는 질문 빠른 답변

질문: 프로그램에서 시리얼 포트 번호를 찾을 수 없다고 표시됩니까?
답변: `list_ports.py`를 실행하여 사용 가능한 시리얼 포트를 확인한 다음, `--port` 파라미터로 지정합니다.
질문: 카메라가 열리지 않습니까?
답변: `list_cameras.py`를 실행하여 사용 가능한 카메라를 확인하고, `--camera` 파라미터로 인덱스를 지정합니다.
질문: 짐벌이 움직이지 않습니까?
답변: `C`를 눌러 짐벌을 연결했는지, 서보 전원이 연결되어 있는지 확인합니다.
질문: 추적 방향이 반대입니까?
답변: 문제 해결 섹션을 참고하세요.
