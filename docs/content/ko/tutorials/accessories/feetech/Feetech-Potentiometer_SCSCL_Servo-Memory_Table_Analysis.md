# 1 서보 통신 프로토콜

서보는 FT-SCS 자체 프로토콜을 사용합니다. 기본 보율은 1M 또는 500k으로 TTL 단일 버스 통신, 데이터 비트 8, 패리티 없음, 스톱 비트 1. 보율은 38400~1Mbps(500k)로 설정 가능, 기본 통신 주소(국번)는 1.

# 3 특수 바이트 설명

## 3.1 서보 위상

- 비트 수/비트 가중치: 설명

- BIT0（1）: 구동 방향 위상；(0)정방향、(1)역방향

- BIT1（2）: ----

- BIT2（4）: ----

- BIT3（8）: 속도 모드；(0)속도 0은 정지、(1)속도 0은 최고 속도

- BIT4（16）: ----

- BIT5（32）: PWM 위상、(0)동상、(1)역상

- BIT6（64）: 전압 모드、(0)1.5K 저압 샘플링、(1)1K 고압 샘플링

- BIT7（128）: ----

여러 비트를 동시에 설정하면 서보 위상값은 각 비트 값의 합입니다.

## 3.2 서보 상태

서보 상태: 0은 정상, 1은 이상

- 비트 수/비트 가중치: 설명

- BIT0（1）: 전압 상태

- BIT1（2）: ----

- BIT2（4）: 온도 상태

- BIT3（8）: ----

- BIT4（16）: ----

- BIT5（32）: 부하 상태

- BIT6（64）: ----

- BIT7（128）: ----

여러 상태가 동시에 있으면 서보 상태값은 각 비트 값의 합입니다. 예: 전압 과전압/부족전압과 서보 과열 시 서보 상태값은 4+1=5;

## 3.3 언로드 조건

언로드 조건: 0은 꺼짐, 1은 켜짐

- 비트 수/비트 가중치: 설명

- BIT0（1）: 전압 보호

- BIT1（2）: ----

- BIT2（4）: 과열 보호

- BIT3（8）: ----

- BIT4（16）: ----

- BIT5（32）: 부하 과부하

- BIT6（64）: ----

- BIT7（128）: ----

여러 비트를 동시에 설정하면 서보 언로드 조건값은 각 비트 값의 합입니다. 예: 전압 보호와 과열 보호가 동시에 켜진 경우 언로드 조건값은 4+1=5;
