## 3 특수 바이트 설명

### 3.1 서보 위상

- 비트 수/비트 가중치: 설명

- BIT0（1）: 구동 방향 위상；(0)정방향、(1)역방향

- BIT1（2）: 구동 브리지 모드；(0)브러시리스、(1)브러시, 재시작 후 적용

- BIT2（4）: 속도 단위；(0)0.732RPM、(1)0.0146RPM

- BIT3（8）: 속도 모드；(0)속도 0은 정지、(1)속도 0은 최고 속도

- BIT4（16）: 각도 피드백 모드；(0)단일 회전 각도 피드백、(1)전체 각도 피드백

- BIT5（32）: 구동 브리지 구성/전압 샘플링、(0)독립 H브리지/1K 고압 샘플링、(1)통합 H브리지/1.5K 저압 샘플링/전류 피드백 없음

- BIT6（64）: PWM 주파수、(0)24kHz、(1)16kHz

- BIT7（128）: 위치 피드백 방향 위상、(0)정방향、(1)역방향

여러 비트를 동시에 설정하면 서보 위상값은 각 비트 값의 합입니다. 예: 원래 위상값이 0이고 서보가 역방향으로 동작하면 위상값은 128+1=129;
