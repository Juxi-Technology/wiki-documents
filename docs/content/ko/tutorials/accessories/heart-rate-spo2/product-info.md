# 제품 자료

## 1. 제품 개요

Gravity: MAX30102 심박·혈중 산소 센서 모듈은 Maxim의 고정밀 MAX30102 전용 심박·혈중 산소 검출 칩을 탑재하고, 자체 개발한 심박·혈중 산소 알고리즘을 통합한 마이크로컨트롤러를 내장하여 호스트 장치에서 복잡한 연산 프로그램을 작성할 필요 없이 표준화된 심박수·혈중 산소 포화도 측정값을 직접 출력할 수 있습니다.

모듈은 PPG(광전용적맥파) 방식으로 원시 생체 데이터를 수집하며, 기판의 마이크로컨트롤러가 신호 필터링, 데이터 연산, 수치 보정의 전 과정을 자동으로 처리한 후 I2C, UART 두 가지 범용 통신 인터페이스를 통해 검출 결과를 외부로 전송합니다. 개발자의 하드웨어 적응 난이도와 호스트 MCU 리소스 점유를 크게 줄여 초보자도 빠르게 프로젝트 개발을 완료할 수 있습니다. 또한 모듈에는 전용 PC 호스트 콘솔 소프트웨어가 함께 제공되어 PC에서 직접 데이터를 읽고 심박·혈중 산소 검출 데이터를 실시간으로 시각화하여 확인할 수 있어 디버깅이 간편하고 효율적입니다.

## 2. 검출 원리

본 모듈은 **광전용적맥파 검출법(PPG)**으로 비침습 생리 지표 검출을 구현합니다. 인체의 동맥 혈관은 심장 박동에 따라 규칙적인 이완과 수축을 반복하며 혈관 내 혈액 용적이 주기적으로 변동합니다. 혈액 용적의 변화는 손끝 조직의 광투과율에 직접 영향을 미칩니다. 본 모듈은 특정 파장의 광원을 방출하고 반사광 신호를 수집하여 광투과율의 동적 변화를 포착하고, 내장 알고리즘과 결합하여 실시간 맥박 심박수와 혈중 산소 포화도 값을 정확하게 산출합니다.

## 3. 사용 시 주의사항

1. **가압 강도가 데이터 정밀도에 영향**: 손끝으로 센서를 누르는 힘이 균일하지 않거나 압력이 계속 변하면 광로 신호가 방해를 받아 심박·혈중 산소 측정값에 편차가 생깁니다. 사용 시 손가락을 안정적으로 유지하고 가압 강도를 일정하게 유지하는 것이 좋습니다.
1. **착용 안내**: 본 모듈의 검출 부위는 손끝으로 한정됩니다. 검출 프로브에는 앞뒤 구분이 없어 착용에 특별한 절차가 없습니다.
1. **비의료기기 고지**: 본 제품은 소비자용 전자 검출 모듈이며 전문 의료기기가 아닙니다. 검출 데이터는 일상 건강 참고용으로만 사용해야 하며 임상 진단, 질병 모니터링 및 의료 보조 치료에 사용할 수 없습니다.

- 손가락 끝을 센서에 밀착시키고 함께 제공되는 밴드로 고정하면 됩니다

## 4. 기술 사양

- 공급 전압: 3.3-5V
- 동작 전류: <15mA
- 통신 방식: I2C/UART
- I2C 주소: 0x57
- 시리얼 보레이트: 9600
- 동작 온도 범위: -40℃~85℃
- 제품 크기: 25.5*32mm

**핀 정의(실크 인쇄):**

| 번호 | 실크 인쇄 | 기능 설명 |
|---|---|---|
| 1 | D/T | I2C 데이터선/TX |
| 2 | C/T | I2C 클록선/RX |
| 3 | GND | 전원 음극 |
| 4 | VCC | 전원 양극 |
