# 모듈 펌웨어 플래싱

## 모듈 펌웨어 플래싱 방법

## 1.음성 칩 플래싱 단계

## 1.1장치 연결

![그림 1](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/1.png)

## 1.2.플래싱 소프트웨어 열기

첨부 파일의 "음성 칩 펌웨어 플래싱 도구" 폴더를 열고 ”PACK_UPDATE_TOOL.exe“ 를 클릭합니다

![그림 2](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/2.png)

CI1302 칩을 선택한 후 “펌웨어 업그레이드” 를 클릭합니다

![그림 3](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/3.png)

펌웨어 업그레이드 화면에 들어가면 "F1" 을 눌러 도움말을 볼 수 있습니다

방금 제작한 펌웨어를 선택하여 클릭하고, 첨부 파일의 출하 시 펌웨어인 “ CI1302中文单麦_V00681_UART1_115200_2M” 펌웨어를 찾습니다.

![그림 4](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/4.png)

펌웨어를 선택하고 해당하는 시리얼 포트 번호를 찾은 뒤 사각형 상자를 클릭하여 체크합니다

![그림 5](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/5.png)

슬라이드 스위치를 Download 위치로 옮깁니다. Download 는 음성 칩 펌웨어 플래싱을 나타냅니다 (즉, 오른쪽에 있는 쪽)

![그림 6](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/6.png)

해당 위치로 옮긴 후 음성 인터랙션 모듈의 RST 키를 누르면 플래싱이 진행되며, 플래싱이 성공할 때까지 기다린 후 “종료” 를 클릭하면 됩니다.

![그림 7](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/7.png)
