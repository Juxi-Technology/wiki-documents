# 웨이크 워드 및 명령어 수정

## 1.주의 사항

조용한 환경에서 웨이크 워드를 수정하십시오. 시끄러운 환경은 음성 인터랙션 모듈의 인식 정확도에 영향을 미칩니다.

항목을 말할 때는 목소리가 우렁차야 하고 말하는 속도가 너무 빠르지 않아야 하며, 모듈과의 거리는 5 미터 이내를 유지하는 것이 좋습니다.

## 3.웨이크 워드 수정

음성 인터랙션 모듈에 “你好，小犀” 라고 말하여 음성 인터랙션 모듈을 웨이크합니다. 모듈이 “我在” 라고 응답하면 현재 인식 가능한 상태임을 나타냅니다.   이어서 음성 인터랙션 모듈에 “学习唤醒词” 항목을 말하면, 음성 인터랙션 모듈이 “说出唤醒词” 라고 응답하며 웨이크 워드 학습 기능 상태로 들어갑니다.   그다음 음성 인터랙션 모듈에 설정하고자 하는 웨이크 워드를 말합니다. 웨이크 워드는 가능한 한 짧게 하는 것이 좋으며, 여기서는 “你好，小犀” 를 설정하는 것을 예로 듭니다.   음성 인터랙션 모듈이 성공적으로 인식하면 “学习成功” 을 재생하여 웨이크 워드 수정이 성공했음을 나타내며, 이때 “你好小犀” 항목으로 모듈을 웨이크할 수 있습니다.

주의 사항: 출하 시 펌웨어의 웨이크 워드 “你好，小犀” 는 기본 웨이크 워드로, 음성으로 수정하거나 삭제할 수 없습니다. 사용자가 음성으로 수정한 웨이크 워드는 동시에 하나만 존재할 수 있으며, 기본 웨이크 워드와 함께 공존합니다.

음성 인터랙션 모듈에 "你好，小犀" 라고 말하여 음성 인터랙션 모듈을 웨이크합니다. 모듈이 “我在” 라고 응답하면 현재 인식 가능한 상태임을 나타냅니다.   이어서 음성 인터랙션 모듈에 “学习停车指令” 항목을 말하면, 음성 인터랙션 모듈이 “请说指令” 이라고 응답하며 명령어 학습 기능 상태로 들어갑니다.   그다음 음성 인터랙션 모듈에 설정하고자 하는 명령어를 말합니다. 명령어는 가능한 한 짧게 하는 것이 좋으며, 여기서는 “前方停车” 을 설정하는 것을 예로 듭니다.   음성 인터랙션 모듈이 성공적으로 인식하면 “学习成功” 을 재생하여 명령어 수정이 성공했음을 나타내며, 이때 “前方停车” 항목을 사용하면 “停车” 명령어와 동일한 효과를 얻을 수 있습니다.   “前方停车” 항목을 삭제해야 하는 경우에는 ”删除停车指令“ 이라고 말하기만 하면 되며, ”删除成功” 이라고 응답하면 항목 삭제가 완료됩니다 (여기서는 “前方停车” 만 삭제되고 ”停车“ 는 삭제되지 않습니다).

주의: 출하 시 펌웨어의 명령어는 기본 명령어로, 음성으로 수정하거나 삭제할 수 없습니다. 사용자가 음성으로 수정한 명령어는 동시에 하나만 존재할 수 있으며, 기본 명령어와 공존합니다.
