# PC 통신

## 장치 연결

슬라이드 스위치를 STC8 시리얼 포트 모드로 이동합니다

![그림 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## 시리얼 디버깅 어시스턴트 열기

- Uart Assistant 를 열고 해당하는 포트 번호와 보드레이트 115200 을 선택합니다,

![그림 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- 압축 파일 안의 命令词播报词协议列表V1_中文 파일을 참조하십시오

![그림 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- 우리가 “小车前进” 이라고 말하면 시리얼 디버깅 어시스턴트가 해당 프로토콜을 출력합니다

![그림 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- 命令词播报词协议列表V1_中文 파일에 따라 해당 명령을 입력하면 음성 모듈이 해당 프로토콜의 문자를 재생합니다

![그림 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

음성 모듈이 정상적으로 재생되는 것을 들을 수 있습니다.
