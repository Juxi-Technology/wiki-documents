# 빠른 시작

출하 시 음성 인식 기능 펌웨어가 이미 플래싱되어 있으므로 사용자는 플래싱 없이 바로 체험할 수 있습니다. 다른 인식 항목을 추가해야 하거나 다른 펌웨어를 다시 플래싱해야 하는 경우, 사용자 정의 항목은 "3. 사용자 정의 프로토콜 항목 제작" 튜토리얼에서 항목을 사용자 정의하는 방법을 확인할 수 있습니다.

## 1.사용 전 준비

1. type-c 데이터 케이블 1개  

2. 음성 인터랙션 모듈

## 3.음성 인식 및 재생 구현

음성 인터랙션 모듈에 type-c 로 전원을 공급한 후, “你好，小犀” 웨이크 워드로 모듈을 웨이크할 수 있으며, 모듈이 성공적으로 웨이크되면 “我在” 라고 응답하여 현재 음성을 인식할 수 있는 상태임을 나타냅니다. 15 초 이내에 명령 항목이 인식되지 않으면 모듈은 절전 모드로 들어가며 동시에 “我去休息了” 를 재생합니다. 모듈을 다시 웨이크하려면 웨이크 워드를 다시 말하면 됩니다.

출하 시 펌웨어에는 명령어와 재생 문구가 기본으로 포함되어 있으며, 제공된 자료 첨부 파일에서 프로토콜 목록을 확인할 수 있습니다. 아래 그림은 명령어 재생 문구 프로토콜 목록의 일부 내용을 캡처한 것으로, 기능 유형을 통해 해당 명령어가 어떤 기능을 나타내는지 확인할 수 있습니다. 재생해야 하는 재생 문구는 수동 재생 문구로, PC 시리얼 포트 또는 다른 마이크로컨트롤러나 호스트 컨트롤러 장치를 통해 음성 인터랙션 모듈에 해당 명령을 전송해야만 트리거될 수 있습니다. 구체적인 내용은 아래 그림을 참조하십시오.

재생 모드에는 능동 방식과 수동 재생 두 가지가 있습니다

능동 재생: 표에 따라 명령어를 말하면 모듈이 해당 문장을 능동적으로 재생합니다. 웨이크 후 “小车前进” 이라고 말하면 모듈이 인식한 뒤 “好的，正在前进” 을 능동적으로 재생합니다
