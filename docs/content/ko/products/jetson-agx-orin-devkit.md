# Jetson AGX Orin 개발자 키트(64GB)

> **[스토어에서 구매](https://www.juxitech.com)** <!-- TODO: 商品上架后替换为商品页 URL -->

## 제품 개요

NVIDIA® Jetson AGX Orin™ 개발자 키트는 Jetson Orin 패밀리의 플래그십 개발자 키트입니다 — 엣지에서 로보틱스, 컴퓨터 비전 및 생성형 AI 애플리케이션을 개발하기 위한 소형 AI 컴퓨터입니다. **Juxi Technology는 완전하고 검증된 문서와 함께 NVIDIA 공식 키트를 판매합니다.**

주요 특징:

- **최대 275 TOPS**의 AI 성능, 소비 전력은 15W~60W에서 설정 가능 *(NVIDIA)*
- **2048코어 NVIDIA Ampere 아키텍처 GPU, 64개 Tensor 코어 탑재** *(NVIDIA)*
- **사전 플래싱 출고** — eMMC에는 L4T BSP 이미지가 들어 있어 개봉 즉시 Ubuntu로 바로 부팅됩니다
- **다른 Jetson Orin 모듈 에뮬레이션** — 다시 플래싱하여 AGX Orin, Orin NX 또는 Orin Nano의 성능/전력 특성을 에뮬레이션할 수 있습니다 *(NVIDIA User Guide)*
- **현재 소프트웨어: JetPack 7.2.1** (Jetson Linux 39.2.1, Ubuntu 24.04, CUDA 13.2.1) — 업데이트 경로는 Jetson ISO이며 호스트 PC가 필요하지 않습니다

**사용 사례**: 온디바이스 LLM/에이전트 AI, 멀티 스트림 영상 분석, 로보틱스 인지, 엣지 생성형 AI.

## 제품 사양

| 카테고리 | 사양 |
|---|---|
| 모듈 | NVIDIA Jetson AGX Orin 64GB |
| AI 성능 | 최대 275 TOPS |
| GPU | 2048코어 NVIDIA Ampere 아키텍처 GPU, 64개 Tensor 코어 탑재 |
| 메모리 | 64GB |
| 스토리지 | eMMC(사전 플래싱) + M.2 M-Key(NVMe SSD 선택 사양) |
| 전원 | 15W–60W 설정 가능 |
| 디스플레이 | DisplayPort 1.4(유일한 디스플레이 출력, MST로 최대 2대의 디스플레이 지원) |
| 네트워킹 | 10GBASE-T 이더넷, Wi-Fi 모듈 포함 |
| I/O | USB-C 2개(1개는 플래싱용), USB-A 3.2 4개, 40핀 헤더, PCIe x16(x8), microSD, 카메라 커넥터 |
| OS | 사전 플래싱된 L4T BSP(최신 버전보다 오래된 것일 수 있음, Jetson ISO로 업데이트) |

*전체 모듈 사양: NVIDIA 공식 데이터 시트(NVIDIA 다운로드 페이지에서 링크)를 참조하십시오.*

## 시작하기

1. DisplayPort 모니터, USB 키보드와 마우스를 연결합니다
2. 동봉된 USB-C 전원 공급 장치를 연결합니다(DC 잭 위쪽 포트) — 키트의 전원이 자동으로 켜집니다
3. Ubuntu로 부팅하여 최초 설정을 완료합니다
4. Jetson ISO로 JetPack 7.2.1로 업데이트합니다(USB 스틱 사용, 호스트 PC 불필요)
