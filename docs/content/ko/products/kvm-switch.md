# 4-in-1 KVM 스위처

> **[스토어에서 구매](https://www.juxitech.com/ko/products/4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**

## 제품 개요

4-in-1 KVM 스위처는 HDMI 전환, TTL 직렬, 블루투스, USB 확장을 하나로 통합했습니다. 로봇 개발 디버깅 특화 설계로 여러 기기(로봇 팔 제어기/디스플레이/주변기기)를 원클릭으로 전환합니다.

**주요 특징**:

- HDMI 다중 기기 전환
- TTL 직렬(UART) 디버깅
- 블루투스 무선 연결
- USB 확장 허브

## 사양

| 카테고리 | 사양 |
|------|------|
| 기능 | HDMI 전환 + TTL 직렬 + 블루투스 + USB HUB |
| 인터페이스 | HDMI / TTL / USB |
| 대상 | PC(Windows/Linux), Jetson |

## 빠른 시작

1. 각 기기를 해당 포트에 연결
2. 버튼 또는 소프트웨어로 디스플레이/입력 전환
3. Pi/Jetson 디버깅용 TTL 시리얼
