# SO-ARM101 & AmazingHand 오픈소스 다지 핸드 로봇 암

## 제품 개요

SO-ARM101 & AmazingHand는 SO-ARM101 6축 로봇 암과 AmazingHand 8 자유도 사지 다지 핸드를 결합한 완전한 오픈소스 체화 AI 플랫폼입니다. 기본 병렬 그리퍼를 리더 암의 서보 하나로 구동되는 사지 핸드로 교체해, 단순하고 신뢰성 높은 공장 조립 방식의 기구로 네 손가락의 동기화된 파지와 펼침을 구현합니다. Hugging Face LeRobot 에코시스템을 기반으로 리더-팔로워 원격 조작, 듀얼 뷰 데이터 수집, ACT·SmolVLA·Pi0·Pi0.5·GR00T N1.5를 이용한 엔드투엔드 모방 학습을 지원합니다. 그리퍼에서 다지 핸드로 넘어가는 가장 쉬운 출발점입니다.

**SO-ARM101**은 SO-ARM100을 기반으로 대폭 최적화한 오픈소스 6축 로봇 암입니다. 새로워진 배선 경로와 모터/기어 조합으로 관절의 케이블 끊김 문제를 해결하고 관절의 가동 범위도 더 이상 제한하지 않으며, 실시간 리더-팔로워 추종과 Hugging Face LeRobot 툴킷과의 완전한 호환성을 지원합니다.

**AmazingHand**는 오픈소스이자 저비용이며 완전히 3D 프린팅 가능한 8 자유도 로봇 핸드 개발 키트입니다. 서보는 모두 핸드 본체 내부에 수납되고 내부 무배선 설계를 채택했으며, 각 손가락은 두 개의 관절로 구동되어 정교함과 손가락 간 자연스러운 협응을 함께 갖췄습니다.

## 주요 장점

### 8 자유도를 갖춘 사지 다지 핸드

AmazingHand는 네 개의 손가락(엄지, 검지, 중지, 약지), 손가락당 두 개의 관절 마디, 총 8 자유도를 제공합니다. 병렬 링크 기구로 손가락이 함께 움직여 더 자연스러운 파지를 구현하며, 모든 서보가 핸드 본체 안에 있어 외부 배선이 없는 콤팩트하고 깔끔한 구조입니다.

### 서보 하나의 링크로 네 손가락 모두 구동

리더 암의 6번 서보(STS3215)가 가동 범위 매핑을 통해 핸드 내부의 8개 SCS0009 버스 서보를 모두 구동하므로, 한 번의 동작으로 네 손가락의 동기화된 파지(주먹 쥐기) 또는 펼침(손바닥 펴기)이 이루어집니다. 단순한 기구, 신뢰할 수 있는 제어, 핸드 측의 복잡한 프로그래밍이 필요 없습니다.

### ACT, SmolVLA, Pi0, Pi0.5, GR00T N1.5를 이용한 엔드투엔드 모방 학습

리더-팔로워 원격 조작으로 시연 데이터를 기록한 뒤 모방 학습 정책을 한 번에 학습시킵니다. 작은 데이터셋만으로도 팔로워 암이 정해진 파지 작업을 자율적으로 완수할 수 있으며, 처음부터 코드를 작성하지 않고도 전체 루프를 완성할 수 있습니다.

### 듀얼 뷰 데이터 수집

상단 브래킷 카메라가 작업 영역 전체를 위에서 포착해 대상 물체의 공간 위치와 자세를 파악하고, 데스크 스탠드 측면 카메라가 작업 영역 상황을 실시간으로 전송합니다. 두 카메라가 함께 정밀한 조작을 유지하고 장면 변화에 빠르게 대응하며 이탈이나 정지를 방지합니다.

### 공장 조립 완료, 개봉 즉시 사용

각 제품은 조립·배선·캘리브레이션을 마친 상태로 발송되며, 전원과 USB만 연결하면 원격 조작과 데이터 수집을 시작할 수 있습니다. 카메라는 86° 오토포커스 30FPS 모듈과 100° 광각 고정 초점 60FPS 모듈 중에서 선택할 수 있고, 둘 다 USB 드라이버가 필요 없는 플러그 앤 플레이입니다.

### Hugging Face LeRobot과의 완벽한 통합

LeRobot의 사전 학습 모델, 데이터셋, 알고리즘 라이브러리를 그대로 재사용하고 전 세계 개발자 커뮤니티와 코드와 경험을 공유하며, 툴체인을 직접 다시 구축하지 않고도 체화 AI에 진입할 수 있습니다.

## 하드웨어 개요

### 사용 가능한 버전(엔드 이펙터 용도에 따라 선택):

| 버전 | 엔드 이펙터 | 핸드 제어 | 권장 사용자 |
|---|---|---|---|
| Pro 버전 | TPU 플렉시블 그리퍼 | 서보 개별 제어 | SO-ARM101 표준 2지 그리퍼가 필요한 사용자 |
| 다지 핸드 버전 | AmazingHand 사지 다지 핸드 | 리더 암 6번 서보를 가동 범위 매핑해 8개 버스 서보를 일괄 구동 | 정교한 파지와 엔드투엔드 모방 학습을 탐구하는 사용자 |

**파지 방식:**Pro 버전은 두 손가락 집기, 다지 핸드 버전은 네 손가락 파지와 펼침을 사용합니다. 손가락별 독립 제어는 현재 버전에서 지원되지 않으며 개발 로드맵에 포함되어 있습니다.

### 호환 기기:

Raspberry Pi / D-Robotics RDK / NVIDIA Jetson 시리즈 컨트롤러와 USB 시리얼 연결의 Windows 및 Linux PC. LeRobot SO-ARM101 및 AmazingHand 오픈소스 프로젝트와 완전히 호환되며 시중 대부분의 시리얼 버스 서보를 지원합니다.

### 간편한 3단계 설정:

- 제공된 케이블로 서보 드라이버 보드를 Raspberry Pi, RDK 또는 Jetson 컨트롤러에 연결한 뒤 리더 암(DC5521 5V6A)과 팔로워 암(DC5521 12V5A)에 전원을 넣습니다.
- 전원을 켜고 USB 시리얼로 연결합니다. 암과 핸드는 조립·배선·캘리브레이션 완료 상태로 도착하므로 기계 조립이나 서보 ID 설정이 필요하지 않습니다.
- 제공된 LeRobot 튜토리얼에 따라 팔로워 암을 원격 조작하고, 듀얼 뷰 데이터셋을 수집하며 모방 학습 정책을 학습시킵니다.
