# Lekiwi 임베디드 지능 모바일 로봇

> **[스토어에서 구매](https://www.juxitech.com/ko/products/lekiwi-embodied-intelligence-mobile-robotic-car)**

## 제품 개요

Lekiwi는 鉅犀科技의 저비용 임베디드 지능 모바일 로봇입니다. 서보 제어 방식을 채택해 구조가 단순하고 직관적이며, 교실 수업, 입문 학습, 메이커 프로젝트에 적합합니다. 12V 전원 지원(5521 DC 플러그 전원 옵션 선택 가능).

**주요 특징**:

- 단순한 구조와 낮은 비용으로 교육 현장 대량 배치에 최적
- 직관적인 서보 제어로 빠른 학습
- SO-ARM101과 LeRobot 생태계 공유

## 제품 사양

| 카테고리 | 사양 |
|------|------|
| 유형 | 모바일 로봇/교육용 로봇 팔 |
| 제어 | 서보 구동 |
| 전원 | 12V(DC 5521) |
| 플랫폼 | PC / 마이컴 |
