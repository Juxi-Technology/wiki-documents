## 소개

이 **심박수 & SpO2 센서 모듈**은 Maxim의 **MAX30102 심박수·혈중산소 칩**과 내장 알고리즘 마이크로컨트롤러를 통합하여, 심박수와 SpO2 값을 직접 출력할 수 있습니다. 추가적인 알고리즘 개발이 필요 없어 센서 통합의 복잡성을 크게 줄이고 호스트 MCU 리소스를 절약합니다.

「**PPG (광용적맥파법)**」를 이용한 광학 측정으로 온보드 마이크로컨트롤러가 센서의 원시 데이터를 처리하여 정확한 심박수와 SpO2 수치를 산출하고 I2C 또는 UART 인터페이스로 출력합니다. 모듈에는 PC에서 실시간 데이터 모니터링과 기록을 위한 호스트 소프트웨어가 포함되어 있어 웨어러블 기기, 가정용 건강 모니터링, 장기 생리 추적, 임베디드 헬스 프로젝트에 적합합니다 — 건강 중심 임베디드 개발을 위한 훌륭한 선택입니다.

- 정품 MAX30102 칩
- 알고리즘 마이크로컨트롤러 내장
- PPG 광학 감지
- I2C/UART 듀얼 인터페이스
- 호스트 소프트웨어 데이터 모니터링
- 멀티 플랫폼 호환

## 제품 장점

### 01 고정밀 감지, 안정적 & 신뢰성

정품의 **MAX30102 고정밀 심박수 및 SpO2 칩**과 전문적인 생리학적 파라미터 감지 알고리즘을 탑재하여 다양한 가정용 건강 모니터링 시나리오에 적합한 안정적이고 신뢰할 수 있는 측정값을 제공합니다.

### 02 알고리즘 마이크로컨트롤러 내장

온보드 마이크로컨트롤러가 센서의 원시 데이터를 처리하여 심박수와 SpO2 값을 계산한 후 I2C 또는 UART 인터페이스로 결과를 출력합니다. 복잡한 신호 처리나 알고리즘 개발이 필요 없어 개발 난이도와 출시 기간을 획기적으로 줄입니다.

### 03 PPG 광학 감지, 비침습 측정

「**광용적맥파법 (PPG)**」을 이용한 비침습 감지 — 채혈이나 침습적 시술이 필요 없습니다. 손끝을 센서 감지 영역에 대고 포함된 스트랩으로 고정하기만 하면 되며, 장기 연속 모니터링 애플리케이션에 이상적입니다.

### 04 손쉬운 디버깅을 위한 호스트 소프트웨어 동봉

전용 호스트 소프트웨어 제공 — USB-시리얼 어댑터로 모듈을 PC에 연결하면 실시간 감지 데이터를 확인할 수 있어 편리한 디버깅과 데이터 기록이 가능합니다.

### 05 듀얼 통신 인터페이스, 유연한 적용

I2C 및 UART 통신 인터페이스를 동시에 지원합니다. I2C 주소는 0x57로 고정되고 시리얼 보드레이트는 기본값 9600입니다. 프로젝트 요구 사항과 하드웨어 리소스에 가장 적합한 통신 방식을 선택하세요.
