# USB 드라이버 프리 사운드 카드

> **[스토어에서 구매](https://www.juxitech.com/ko/products/usb-2-0-driver-free-sound-card-onboard-mic-speaker-for-ai-voice-interaction)**

## 제품 개요

USB 드라이버 프리 사운드 카드는 온보드 마이크와 스피커를 갖춘 플러그 앤 플레이 오디오 장치입니다. 시스템이 자동으로 오디오 입출력 장치로 인식합니다. 로봇 음성 상호작용, AI 음성 어시스턴트 개발(KWS 모듈, LLM 보이스 어시스턴트와 함께 사용)에 적합합니다.

**주요 특징**:

- 플러그 앤 플레이, 드라이버 불필요
- 온보드 마이크 + 스피커
- Raspberry Pi, Jetson, PC 호환
- USB 오디오 키트와 함께 Jetson 개발에 사용

## 사양

| 카테고리 | 사양 |
|------|------|
| 인터페이스 | USB 2.0 |
| 오디오 | 입력(마이크) + 출력(스피커) |
| 플랫폼 | Raspberry Pi / Jetson / PC |
| 샘플 레이트 | 16KHz / 48KHz, 16비트 |

## 빠른 시작

```bash
# 插入 USB 即自动识别
# 验证设备
arecord -l    # 录音设备
aplay -l      # 播放设备
```
