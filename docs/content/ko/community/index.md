## 기여 방법

### 1. 튜토리얼 작성

SO-ARM101 사용 경험을 튜토리얼로 공유해 다른 사람들을 도와주세요.

**시작하기:**
- 주제를 선택하세요 (응용 시나리오, 기술 심화 등)
- 기존 튜토리얼 구조를 따르세요
- Pull Request를 제출하세요

### 2. 문서 번역

더 많은 사용자가 혜택을 받을 수 있도록 문서를 여러 언어로 번역하는 데 도움을 주세요.

**현재 언어:** 간체 중국어 / 영어 / 번체 중국어

### 3. 사례 제출

사용 사례를 공유하고 프로젝트 결과를 소개해 주세요. [성공 사례 페이지](/ko/cases/)를 참조하세요.

### 4. 이슈 신고

버그를 발견했거나 제안이 있으신가요? Issue를 제출해 개선을 도와주세요.

### 5. 코드 기여

LeRobot을 포함한 관련 오픈소스 프로젝트에 코드를 기여하세요.
