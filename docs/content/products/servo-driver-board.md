# JUXI Bus Servo Driver Board

> **[Buy in Store](https://www.juxitech.com/products/bus-servo-driver-board)**

## Overview

The JUXI bus servo adapter is an all-in-one serial bus servo control solution designed for LeRobot SO-ARM100/101 robot arms and multi-servo robotics projects. It integrates servo power and control circuits on one compact board, eliminating complex wiring and separate power circuits.

**Key features**:

- Single-bus control of up to **253** serial bus servos
- **7-12.6V** wide voltage input with integrated power (DC 5521)
- Real-time feedback: position, speed, torque, operation mode
- **Type-C plug-and-play**, compatible with Raspberry Pi / Jetson / RDK / PC
- Precision-machined mounting holes — installs onto SO-ARM100/101 in 2 minutes
- TVS protection (over-voltage / over-current)

## Quick Start

### 3-Step SO-ARM Installation

1. Align the driver board with the mounting holes on the SO-ARM 3D-printed base
2. Secure with the included M2.5 screws
3. Connect servo bus cable, power, and Type-C USB to the controller

### Power Adapter Selection

| Adapter | Use Case |
|---------|----------|
| **5V 6A** | Standard bus servo projects, SO-ARM arms (7V standard servos) |
| **12V 5A** | High-torque servo projects, multi-servo robots (12V) |

## FAQ

**Q: Which servos are supported?**

**A:** Almost all mainstream serial bus servos (Feetech SCS/STS series, etc.).

**Q: Do I need separate drivers?**

**A:** No. Type-C connects to the host with plug-and-play servo control and data feedback.

**Q: What is TVS protection for?**

**A:** Prevents voltage spikes from damaging the board and servos, ensuring stable operation in complex environments.

**Q: Which power adapter?**

**A:** 5V 6A for standard servos, 12V 5A for high-torque servos.
