# FEETECH SCS0009 Serial Bus Servo

## Product Overview

This FEETECH SCS0009 serial bus servo is a robotic actuator adapted for AmazingHand dexterous hands. It features full-dimensional real-time feedback, metal gear transmission, 10-bit encoder, and standard TTL serial bus communication, with multiple intelligent protection mechanisms built-in.

## Key Advantages

### Native Compatibility with Amazing Hand Dexterous Hands

Perfectly adapted to Amazing Hand dexterous hands, works out of the box after simple configuration, saves development time for robotic project integration.

### Ultra-Compact Size

Suitable for robotics applications that requires compact footprint, such as microrobot joints and dexterous hands.

### Full-Dimensional Real-Time Feedback

Provides real-time feedback of position, speed, voltage, current, temperature, and load.

### Metal Gearbox

Includes 1:416 gear reduction ratio metal gearbox.

### 10-bit encoder

Provides 1024-step resolution for precise closed-loop control.

### Standard TTL Serial Bus Communication

Communicates through serial connection that can be daisy-chained with a single 3-pin wire.

## Hardware Overview

### Core Features

- Transmission structure: metal gear
- Sensor: 10-bit encoder
- Communication: TTL serial bus
- Protection: Overvoltage, overcurrent, overheating, overload protection
- Feedback: Real-time position, speed, torque, temperature, voltage data output
- Compact size: Optimized for dexterous hand joint installation

### Compatible Platforms

- [Amazing Hand dexterous hands](https://github.com/pollen-robotics/AmazingHand/tree/main)
- Other serial bus servo compatible robotic platforms requiring small-size high-precision actuators
