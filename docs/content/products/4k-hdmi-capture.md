## Overview

4K HDMI capture card supports HDMI / Micro HDMI / DP board interfaces via adapters, connecting directly via USB/Type-C to laptops, PCs, and displays — for streaming, recording, and teaching demos.

**Key features**:

- 4K HD capture
- HDMI / Micro HDMI / DP compatible
- USB / Type-C plug-and-play
- OBS / PotPlayer support
