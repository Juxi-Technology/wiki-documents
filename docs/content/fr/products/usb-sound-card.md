> **[Acheter en boutique](https://www.juxitech.com/fr/products/usb-2-0-driver-free-sound-card-onboard-mic-speaker-for-ai-voice-interaction)**

## Présentation

La carte son USB sans pilote intègre micro et haut-parleur — le système la détecte automatiquement comme périphérique audio. Idéale pour l'interaction vocale robotique et les assistants vocaux IA (avec modules KWS et assistants vocaux LLM).

**Caractéristiques clés** :

- Plug-and-play, aucun pilote
- Micro + haut-parleur intégrés
- Compatible Raspberry Pi, Jetson, PC
- Kit audio USB pour le développement Jetson

## Spécifications

| Catégorie | Spécification |
|------|------|
| Interface | USB 2.0 |
| Audio | Entrée (micro) + Sortie (haut-parleur) |
| Plateformes | Raspberry Pi / Jetson / PC |
| Fréquence d'échantillonnage | 16KHz / 48KHz, 16 bits |
