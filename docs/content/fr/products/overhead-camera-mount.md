# Support caméra aérienne SO-ARM101

> **[Acheter en boutique](https://www.juxitech.com/fr/products/overhead-camera-mount-for-so-arm100-so-arm101-realsense-compatible)**

## Présentation

Le support caméra aérienne SO-ARM101 offre un montage en vue de dessus, compatible avec les caméras de profondeur RealSense et les caméras USB classiques. Utilisé pour la collecte de données vision du bras robotique (la vue de dessus est avantageuse pour les données d'entraînement LeRobot).

**Caractéristiques clés** :

- Montage en vue de dessus
- Compatible RealSense / USB
- Adapté aux SO-ARM100/101
- Installation simple

## Spécifications

| Catégorie | Spécification |
|------|------|
| Vue | Dessus (top-down) |
| Compatibilité | RealSense / caméra USB |
| Plateforme | SO-ARM100/101 |

## Démarrage rapide

1. 将支架固定到 SO-ARM 安装点
2. 安装相机(RealSense 或 USB)
3. 连接主控,`python -m lerobot.find_cameras` 确认识别
