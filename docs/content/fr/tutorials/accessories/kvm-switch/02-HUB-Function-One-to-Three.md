# 02 · Fonction HUB (un vers trois)

> [← Retour à la présentation](/fr/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Produit concerné : JUXI Technology KVM&HUB&TTL

## Utilisation

**Une entrée Type-C, trois sorties USB-A** — avec un seul ordinateur connecté, ce produit est un HUB USB classique :

1. Connectez l'ordinateur au port **PC1** (ou PC2) avec un câble Type-C ;
2. Branchez le clavier, la souris, la clé USB, etc. sur n'importe quel port **USB-A**.

Avec deux ordinateurs connectés, les 3 ports USB-A commutent en bloc entre les deux (voir [01](/fr/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

| Compatibles | À connecter directement à l'ordinateur |

| Imprimantes, dongles USB | Périphériques gaming à haut taux de rapport (avec prudence) |
