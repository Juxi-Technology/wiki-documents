# Communication PC

## Connexion de l'appareil

Déplacez l'interrupteur à glissière en mode port série STC8

![Image 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## Ouvrir l'assistant de débogage série

- Ouvrez Uart Assistant, sélectionnez le numéro de port série correspondant, avec un débit en bauds de 115200,

![Image 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- Consultez le fichier 命令词播报词协议列表V1_中文 dans l'archive compressée

![Image 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- Lorsque nous disons “小车前进”, l'assistant de débogage série affiche le protocole correspondant

![Image 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- Saisissez la commande correspondante selon le fichier 命令词播报词协议列表V1_中文, et le module vocal diffuse le texte correspondant au protocole

![Image 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

Vous pouvez entendre le module vocal diffuser normalement.
