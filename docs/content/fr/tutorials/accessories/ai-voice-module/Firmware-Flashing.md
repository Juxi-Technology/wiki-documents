# Flashage du micrologiciel du module

## Méthode de flashage du micrologiciel du module

## 1. Étapes de flashage de la puce vocale

## 1.1 Connexion de l'appareil

![Image 1](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/1.png)

## 1.2. Ouvrir le logiciel de flashage

Ouvrez le dossier « Outil de flashage du micrologiciel de la puce vocale » dans les pièces jointes et cliquez sur ”PACK_UPDATE_TOOL.exe“

![Image 2](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/2.png)

Sélectionnez la puce CI1302, puis cliquez sur “Mise à niveau du micrologiciel”

![Image 3](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/3.png)

Entrez dans l'interface de mise à niveau du micrologiciel ; appuyez sur "F1" pour consulter l'aide

Cliquez pour sélectionner le micrologiciel que vous venez de créer, et localisez le micrologiciel d'usine “CI1302中文单麦_V00681_UART1_115200_2M” dans les pièces jointes.

![Image 4](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/4.png)

Sélectionnez le micrologiciel, trouvez le numéro de port série correspondant et cliquez sur la case pour la cocher

![Image 5](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/5.png)

Placez l'interrupteur à glissière sur la position Download ; Download signifie le flashage du micrologiciel dans la puce vocale (c'est-à-dire le côté droit)

![Image 6](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/6.png)

Après avoir basculé sur la position correspondante, appuyez sur le bouton RST du module d'interaction vocale pour entrer en mode flashage ; attendez que le flashage réussisse, puis cliquez sur “Quitter”.

![Image 7](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/7.png)
