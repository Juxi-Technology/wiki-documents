# Démarrage rapide

Bienvenue chez JUXI ! Ce tutoriel vous aide à démarrer rapidement avec nos produits.

## Préparation

Avant de commencer, préparez :

- Le matériel du produit
- Un câble de données USB
- Un ordinateur (Windows/macOS/Linux)

## Étape 1 : Connecter le matériel

1. Connecter le produit à l'ordinateur via le câble USB
2. Attendre l'installation automatique du pilote
3. Vérifier que le périphérique est bien reconnu

## Étape 2 : Installer le logiciel

```bash
# Installer les dépendances
npm install
# Démarrer l'application
npm start
```

## Étape 3 : Commencer

Vous pouvez maintenant utiliser le produit ! Consultez les autres tutoriels pour plus de détails.
