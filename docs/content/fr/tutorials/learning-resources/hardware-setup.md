# Connexion matérielle

Ce chapitre détaille la connexion matérielle des produits.

## Interfaces

Le produit propose les interfaces suivantes :

- USB-C : alimentation et transfert de données
- GPIO : entrées/sorties universelles
- HDMI : sortie vidéo

## Étapes de connexion

1. **Brancher l'alimentation** : connecter via un câble USB-C
2. **Brancher les périphériques** : connecter les autres périphériques selon le besoin
3. **Démarrer** : appuyer sur le bouton d'alimentation pour lancer l'appareil

## Remarques

- Vérifier que la tension d'alimentation respecte les exigences
- Éviter de brancher/débrancher des périphériques GPIO sous tension
