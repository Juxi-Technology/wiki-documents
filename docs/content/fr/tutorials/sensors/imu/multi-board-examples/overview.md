# Cas de communication multi-hôtes

## Remarques

1. Installer le pilote CH341 (en tant qu'administrateur)

https://www.wch.cn/downloads/CH341SER_EXE.html

Si un périphérique inconnu usb single serial ou usb serial apparaît dans le gestionnaire de périphériques du PC, désinstallez-le d'abord (clic droit), puis installez le pilote !
