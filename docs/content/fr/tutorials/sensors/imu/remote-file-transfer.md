# Transfert de fichiers à distance

## 1. MobaXterm

MobaXterm est un outil distant puissant, qui intègre des outils distants tels que SHH, VNC, FTP.

## 2. Installation de MobaXterm

Site officiel : [https://mobaxterm.mobatek.net/](https://mobaxterm.mobatek.net/)

![Image 1](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/1.png)

### 2.1. Téléchargement de MobaXterm

Choisissez la version gratuite à télécharger :

![Image 2](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/2.png)

Choisissez la version d'installation à télécharger :

![Image 3](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/3.png)

### 2.2. Installation de MobaXterm

Décompressez l'archive téléchargée depuis le site officiel, ouvrez le fichier `MobaXterm_installer_24.4.msi` pour procéder à l'installation :

![Image 4](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/4.png)

Acceptez le contrat :

![Image 5](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/5.png)

Choisissez l'emplacement d'installation du logiciel : l'emplacement par défaut est recommandé

![Image 6](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/6.png)

Installation proprement dite :

![Image 7](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/7.png)

![Image 8](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/8.png)

Fin de l'installation :

![Image 9](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/9.png)

## 3. Utilisation de MobaXterm

Sur le bureau, trouvez l'icône `MobaXterm` et ouvrez-la :

![Image 10](../../../../../public/images/tutorials/sensors/imu/remote-file-transfer/10.png)

## 4. MobaXterm : SSH à distance

Sélectionnez `Session` → `SSH` : renseignez l'IP et le nom d'utilisateur de l'appareil distant

Par exemple :

Informations par défaut de la carte Jetson :

Nom d'utilisateur : juxi

Mot de passe : juxi

Remarque : lorsque MobaXterm utilise SSH à distance, il se connecte automatiquement en SFTP à distance dans la barre latérale
