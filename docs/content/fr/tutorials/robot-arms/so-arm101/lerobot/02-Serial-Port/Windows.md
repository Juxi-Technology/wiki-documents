# Étape 2 : Vérification du port série (Windows)

Ouvrez le `Gestionnaire de périphériques`, branchez d'abord le `bras esclave`, puis le `bras maître`, et consultez le numéro de port COM correspondant

![image.png](../../../../../../../public/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## Noter mes numéros de port

Bras esclave :

COM6

Bras maître :

COM7
