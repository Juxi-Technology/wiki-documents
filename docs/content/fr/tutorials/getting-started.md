# Démarrage rapide

Bienvenue chez Juxi Technology ! Ce tutoriel vous aide à démarrer rapidement avec nos produits.

## Préparation

Préparez :

- Le matériel du produit
- Câble USB
- PC (Windows/macOS/Linux)

## Étape 1 : Connecter le matériel

1. Connecter le produit au PC via USB
2. Attendre l'installation automatique des pilotes
3. Vérifier que l'appareil est reconnu

## Étape 2 : Installer le logiciel

```bash
# Installer les dépendances
npm install

# Lancer l'application
npm start
```

## Étape 3 : Commencer

Vous pouvez maintenant utiliser le produit ! Voir les autres tutoriels pour plus de détails.
