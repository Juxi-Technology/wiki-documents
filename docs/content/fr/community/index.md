## Comment contribuer

### 1. Rédiger des tutoriels

Partagez votre expérience avec SO-ARM101 en rédigeant des tutoriels pour aider les autres.

**Pour commencer :**
- Choisissez un sujet (cas d'usage, analyses techniques approfondies, etc.)
- Suivez la structure des tutoriels existants
- Soumettez une Pull Request

### 2. Traduire la documentation

Aidez-nous à traduire la documentation dans davantage de langues afin que plus d'utilisateurs en bénéficient.

**Langues actuelles :** Chinois simplifié / Anglais / Chinois traditionnel

### 3. Soumettre des cas d'usage

Partagez vos cas d'usage et présentez les résultats de vos projets. Voir la page [Témoignages d'utilisateurs](/fr/cases/).

### 4. Signaler des problèmes

Vous avez trouvé un bug ou une suggestion ? Soumettez une Issue pour nous aider à nous améliorer.

### 5. Contributions de code

Contribuez au code des projets open source liés, notamment LeRobot.
