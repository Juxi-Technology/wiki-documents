## Cómo contribuir

### 1. Escribir tutoriales

Comparte tu experiencia con SO-ARM101 escribiendo tutoriales para ayudar a otros.

**Para empezar:**
- Elige un tema (casos de uso, análisis técnicos en profundidad, etc.)
- Sigue la estructura de tutoriales existente
- Envía un Pull Request

### 2. Traducir la documentación

Ayúdanos a traducir la documentación a más idiomas para que más usuarios se beneficien.

**Idiomas actuales:** chino simplificado / inglés / chino tradicional

### 3. Enviar casos

Comparte tus casos de uso y muestra los resultados de tus proyectos. Consulta la [página de Casos de éxito](/es/cases/).

### 4. Reportar problemas

¿Encontraste un error o tienes una sugerencia? Envía un Issue para ayudarnos a mejorar.

### 5. Contribuciones de código

Contribuye con código a los proyectos open source relacionados, incluido LeRobot.
