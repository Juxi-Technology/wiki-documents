## Introducción

El **Módulo sensor de frecuencia cardíaca y SpO2** integra el chip **MAX30102 de frecuencia cardíaca y oxígeno en sangre** con un microcontrolador con algoritmo integrado, lo que permite la salida directa de los valores de frecuencia cardíaca y SpO2 sin necesidad de desarrollo adicional de algoritmos. Esto reduce significativamente la complejidad de integración del sensor y ahorra recursos del MCU host.

Mediante la **PPG (Fotopletismografía)** óptica, el microcontrolador integrado procesa los datos brutos del sensor para ofrecer lecturas precisas de frecuencia cardíaca y SpO2, transmitidas mediante la interfaz I2C o UART. El módulo incluye un software host de acompañamiento para el monitoreo y registro de datos en tiempo real desde el PC — ideal para wearables, monitoreo de salud en el hogar, seguimiento fisiológico a largo plazo y proyectos de salud embebidos: una excelente opción para el desarrollo embebido orientado a la salud.

## Ventajas del producto

### 01 Detección de alta precisión, estable y fiable

Equipado con un **chip MAX30102 de alta precisión para frecuencia cardíaca y SpO2** y algoritmos profesionales de detección de parámetros fisiológicos, el módulo ofrece lecturas estables y fiables adecuadas para diversos escenarios de monitoreo de salud de consumo.

### 02 Microcontrolador con algoritmo integrado

El microcontrolador integrado procesa los datos brutos del sensor para calcular los valores de frecuencia cardíaca y SpO2, y luego transmite los resultados mediante la interfaz I2C o UART. No se requiere procesamiento complejo de señales ni desarrollo de algoritmos, lo que reduce drásticamente la dificultad de desarrollo y el tiempo de comercialización.

### 03 Detección óptica PPG, medición no invasiva

Utiliza la **fotopletismografía (PPG)** para la detección no invasiva — sin necesidad de extracción de sangre ni procedimientos invasivos. Basta con colocar la yema del dedo sobre la zona de detección del sensor y asegurarla con la correa incluida, ideal para aplicaciones de monitoreo continuo a largo plazo.

### 04 Software host de acompañamiento para una depuración fácil

Se proporciona un software host dedicado: conecte el módulo a su PC mediante un adaptador USB-serie para ver los datos de detección en tiempo real, facilitando la depuración y el registro de datos.

### 05 Doble interfaz de comunicación, adaptación flexible

Admite simultáneamente las interfaces de comunicación I2C y UART. La dirección I2C está fijada en 0x57 y la velocidad en baudios predeterminada es 9600. Seleccione el método de comunicación que mejor se adapte a los requisitos de su proyecto y a sus recursos de hardware.
