# Tarjeta de captura HDMI 4K

> **[Comprar en la tienda](https://www.juxitech.com/es/products/4k-hd-hdmi-capture-card)**

## Descripción general

La tarjeta de captura HDMI 4K admite HDMI / Micro HDMI / DP y se conecta por USB/Type-C directamente a portátiles, PC o pantallas de teléfono/tableta. Ideal para streaming, grabación y demostraciones educativas.

**Características clave**:

- Captura 4K
- Compatible con HDMI / Micro HDMI / DP
- USB / Type-C plug-and-play
- Soporte OBS / PotPlayer

## Especificaciones

| Categoría | Especificación |
|------|------|
| Entrada | HDMI / Micro HDMI / DP (adaptador) |
| Salida | USB / Type-C |
| Captura | 4K |
| Software | OBS / PotPlayer |

## Inicio rápido

1. Elija el cableado según la interfaz de la placa (HDMI / Micro HDMI / DP)
2. Conecte el USB del capturador al dispositivo de visualización
3. Seleccione el dispositivo de captura en OBS / PotPlayer
