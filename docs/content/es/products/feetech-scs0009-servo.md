# Servomotor de bus serie FEETECH SCS0009

## Descripción general del producto

Este servomotor de bus serie FEETECH SCS0009 es un actuador robótico adaptado a las manos hábiles de AmazingHand. Ofrece retroalimentación en tiempo real en todas las dimensiones, transmisión con engranajes metálicos, codificador de 10 bits y comunicación por bus serie TTL estándar, con múltiples mecanismos de protección inteligente integrados.

## Ventajas clave

### Compatibilidad nativa con las manos hábiles de Amazing Hand

Perfectamente adaptado a las manos hábiles de Amazing Hand, listo para usar tras una configuración sencilla, ahorrando tiempo de desarrollo en la integración de proyectos robóticos.

### Tamaño ultracompacto

Adecuado para aplicaciones robóticas que requieren un tamaño reducido, como articulaciones de microrobots y manos hábiles.

### Retroalimentación en tiempo real completa

Proporciona retroalimentación en tiempo real de posición, velocidad, voltaje, corriente, temperatura y carga.

### Caja de engranajes metálica

Incluye una caja de engranajes metálica con relación de reducción 1:416.

### Codificador de 10 bits

Ofrece una resolución de 1024 pasos para un control de bucle cerrado preciso.

### Comunicación por bus serie TTL estándar

Se comunica mediante una conexión serie que se puede encadenar con un solo cable de 3 pines.

## Descripción general del hardware

### Funciones principales

- Estructura de transmisión: engranaje metálico
- Sensor: codificador de 10 bits
- Comunicación: bus serie TTL
- Protección: sobretensión, sobrecorriente, sobrecalentamiento y sobrecarga
- Retroalimentación: salida de datos en tiempo real de posición, velocidad, par, temperatura y voltaje
- Tamaño compacto: optimizado para la instalación en articulaciones de manos hábiles

### Plataformas compatibles

- [Las manos hábiles de Amazing Hand](https://github.com/pollen-robotics/AmazingHand/tree/main)
- Otras plataformas robóticas compatibles con servomotores de bus serie que requieren actuadores compactos de alta precisión
