# 02 · Función HUB (uno a tres)

> [← Volver a la descripción general](/es/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Producto aplicable: JUXI Technology KVM&HUB&TTL

## Cómo usarlo

**Una entrada Type-C, tres salidas USB-A** — con un solo ordenador conectado, este producto es un HUB USB normal:

1. Conecte el ordenador al puerto **PC1** (o PC2) con un cable Type-C;
2. Conecte el teclado, el ratón, la memoria USB, etc. a cualquier puerto **USB-A**.

Con dos ordenadores conectados, los 3 puertos USB-A cambian entre ambos como un bloque (ver [01](/es/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

(Ilustración: material del tutorial 02 – HUB uno a tres)

## Qué dispositivos admite

| Compatibles | Mejor conectar directamente al ordenador |
|---|---|
| Teclados, ratones (incl. receptores inalámbricos) | Discos duros portátiles, SSD |
| Memorias USB | Tarjetas capturadoras de vídeo y otros dispositivos de alto ancho de banda |
| Impresoras, dongles USB | Periféricos gaming de alta frecuencia de sondeo (con precaución) |
| Módulos serie, sensores (mejor el puerto TTL — ver 04) | |

- **Sin controladores**: plug-and-play en Windows / macOS / Linux / sistemas operativos nacionales chinos;
- La especificación es **USB 2.0** — elija los dispositivos según la tabla anterior.
