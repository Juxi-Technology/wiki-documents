# Conmutador KVM

> **[Comprar en la tienda](https://www.juxitech.com/es/products/4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**


El conmutador KVM ofrece función HUB, TTL serie y módulo Bluetooth.

![imagen – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/1.png)

## Funciones de los módulos

### 1. HUB

Un solo cable USB Type-C expande un puerto USB en tres puertos USB.

![1. Función HUB – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/2.png)

### 2. TTL serie

Pines (izquierda a derecha): GND RXD TXD TNOW 3V3 5V

![2. Puerto serie TTL – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/3.png)

### 3. Bluetooth

Conectar mediante comandos AT, o cambiar a modo esclavo; el teléfono debe conectarse mediante el protocolo 4.2.

![3. Módulo Bluetooth – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/4.png)

## Conmutación dual

### 1. Dispositivo A + Dispositivo B (ambos con pantalla)

Conmutación por botón y mando a distancia por infrarrojos

![1. Dispositivo A + Dispositivo B ambos con pantalla – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/5.png)

### 2. Placa base (sin pantalla) + host (con pantalla)

Solo se necesita añadir un dispositivo de captura de HDMI 4K conectado al host y, a continuación, **en el host, usar software como OBS y Potplayer para capturar la pantalla**

![2. Placa base sin pantalla + host con pantalla – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/6.png)

**Conexión del dispositivo de captura de HDMI 4K**

Según la interfaz de la placa base, existen las siguientes tres formas de conexión

**Interfaz HDMI** ——> cable HDMI ——> interfaz HDMI del capturador ——> USB/Type-C ——> pantallas como portátiles, ordenadores, all-in-one, móviles/tabletas, etc.

**Interfaz Micro HDMI** ——> adaptador Micro a HDMI ——> cable HDMI ——> interfaz HDMI del capturador ——> USB/Type-C ——> pantallas como portátiles, ordenadores, all-in-one, móviles/tabletas, etc.

**Interfaz DP** ——> adaptador DP a HDMI ——> cable HDMI ——> interfaz HDMI del capturador ——> USB/Type-C ——> pantallas como portátiles, ordenadores, all-in-one, móviles/tabletas, etc.
