# Comunicación con PC

## Conexión del dispositivo

Desplace el interruptor deslizante al modo de puerto serie STC8

![Imagen 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## Abrir el asistente de depuración de puerto serie

- Abra Uart Assistant, seleccione el número de puerto serie correspondiente y ajuste la velocidad en baudios a 115200,

![Imagen 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- Consulte el archivo de lista de protocolo de palabras de comando y frases de reproducción V1_中文 incluido en el paquete comprimido

![Imagen 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- Cuando decimos “小车前进”, el asistente de depuración de puerto serie imprime el protocolo correspondiente

![Imagen 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- Introduzca la instrucción correspondiente según el archivo de lista de protocolo de palabras de comando y frases de reproducción V1_中文, y el módulo de voz reproduce el texto correspondiente al protocolo

![Imagen 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

Puede escuchar que el módulo de voz reproduce con normalidad.
