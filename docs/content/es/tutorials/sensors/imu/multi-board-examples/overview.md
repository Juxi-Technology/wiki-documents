# Casos de comunicación multi-host

## Notas

1. Instalar el controlador CH341 (como administrador)

https://www.wch.cn/downloads/CH341SER_EXE.html

Si en el administrador de dispositivos del PC aparece un dispositivo desconocido usb single serial o usb serial, desinstálelo primero (clic derecho) y luego instale el controlador.
