# Inicio rápido

¡Bienvenido a Juxi Technology! Este tutorial te ayuda a empezar con nuestros productos.

## Preparación

Prepara:

- Hardware del producto
- Cable USB
- PC (Windows/macOS/Linux)

## Paso 1: Conectar el hardware

1. Conectar el producto al PC por USB
2. Esperar la instalación automática del driver
3. Confirmar que el dispositivo se reconoce

## Paso 2: Instalar el software

```bash
# Instalar dependencias
npm install

# Iniciar la aplicación
npm start
```

## Paso 3: Empezar

¡Ya puedes usar el producto! Consulta otros tutoriales para más detalles.
