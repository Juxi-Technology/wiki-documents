# Inicio rápido

¡Bienvenido a JUXI! Este tutorial le ayuda a empezar rápidamente con nuestros productos.

## Preparación

Antes de empezar, prepare:

- El hardware del producto
- Un cable USB de datos
- Un ordenador (Windows/macOS/Linux)

## Paso 1: Conectar el hardware

1. Conectar el producto al ordenador mediante el cable USB
2. Esperar la instalación automática del controlador
3. Comprobar que el dispositivo se reconoce correctamente

## Paso 2: Instalar el software

```bash
# Instalar dependencias
npm install
# Iniciar la aplicación
npm start
```

## Paso 3: Empezar a usar

¡Ya puede usar el producto! Consulte otros tutoriales para más detalles.
