## Cómo usar

1. **Elige la categoría temática**: elige la categoría correspondiente según tus intereses o necesidades
2. **Consulta la lista de tutoriales**: en cada categoría, consulta los tutoriales y documentos disponibles
3. **Sigue los pasos**: sigue los pasos de los tutoriales para aprender y usar el producto gradualmente
4. **Practica y explora**: durante el uso real, prueba distintas funciones y configuraciones para acumular experiencia
