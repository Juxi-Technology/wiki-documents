# Guía de selección de brazos robóticos

Juxi Technology ofrece varios brazos robóticos para diferentes usos.

## Comparativa

| Característica | SO-ARM101 | AmazingHand | Lekiwi |
|----------------|-----------|-------------|--------|
| **Tipo** | Teleoperación de doble brazo | Mano robótica | Brazo educativo low-cost |
| **DOF** | 6 DOF por brazo | 5 dedos, multiarticulado | 6 DOF |
| **Control** | LeRobot / API Python | Bus serie TTL | Servos |
| **Uso** | Aprendizaje IA, teleop | Prehensión, gestos | Educación, principiante |
| **Open source** | [LeRobot](https://github.com/Juxi-Technology/lerobot) | [AmazingHand](https://github.com/Juxi-Technology/AmazingHand) | Docs oficiales |

## Cómo elegir

- 🎓 Estudiantes/educación → **Lekiwi**(económico, simple)
- 🤖 Investigación en prehensión → **AmazingHand**(5 dedos, TTL)
- 🧠 Investigación IA → **SO-ARM101**(integración LeRobot, Jetson)
