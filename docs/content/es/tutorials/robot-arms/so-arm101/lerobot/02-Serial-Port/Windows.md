# Paso 2: Ver el puerto del dispositivo serie (Windows)

Abre el `Administrador de dispositivos`, primero conecta el `brazo seguidor` y luego el `brazo líder`, y consulta el número de puerto COM correspondiente

![image.png](../../../../../../../public/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## Registrar mis números de puerto

Brazo seguidor:

COM6

Brazo líder:

COM7
