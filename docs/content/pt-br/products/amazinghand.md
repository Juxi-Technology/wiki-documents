# Mão Dexterous de 4 Dedos Open Source AmazingHand

> **[Comprar na loja](https://www.juxitech.com/products/amazinghand)**

## Visão Geral

A AmazingHand é a mão dexterous de 4 dedos open source da Juxi Technology, com design multiarticulado e controle por barramento serial TTL. Os arquivos CAD abertos permitem o design personalizado dos dedos para pesquisas em manipulação dexterous, estratégias de preensão e HRI.

**Principais recursos**:

- 4 dedos multiarticulados, proporções humanas
- Controle por barramento serial TTL, compatível com controladores mainstream
- CAD/fonte aberto, personalizável
- Combina com o SO-ARM101 para plataformas completas de manipulação
- Rastreamento de mão em tempo real: rastreie gestos via webcam e controle a mão ao vivo
- Demonstrações por simulação: execute demos de rastreamento de mão sem hardware (ecossistema dora-rs)
- Controle individual do ângulo dos dedos; mão única (esquerda/direita) ou dupla
- Alimentação: placa driver de servo 5V3A, conexão USB ao host

## Início Rápido

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
