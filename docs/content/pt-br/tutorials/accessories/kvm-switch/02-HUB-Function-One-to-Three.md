# 02 · Função HUB (um para três)

> [← Voltar à visão geral](/pt-br/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Produto aplicável: JUXI Technology KVM&HUB&TTL

## Como usar

**Uma entrada Type-C, três saídas USB-A** — com apenas um computador conectado, este produto é um HUB USB comum:

1. Conecte o computador à porta **PC1** (ou PC2) com um cabo Type-C;
2. Conecte teclado, mouse, pen drive etc. a qualquer porta **USB-A**.

Com dois computadores conectados, as 3 portas USB-A alternam entre eles como um conjunto (ver [01](/pt-br/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

## Dispositivos suportados

| Compatíveis | Melhor conectar diretamente ao computador |
|---|---|
| Teclados, mouses (incluindo receptores sem fio) | HDs externos, SSDs |
| Pen drives | Placas de captura de vídeo e outros dispositivos de alta largura de banda |
| Impressoras, dongles USB | Periféricos gamer de alta taxa de sondagem (com cautela) |
| Módulos seriais, sensores (a porta TTL é melhor — ver 04) | |

- **Sem driver**: plug-and-play no Windows / macOS / Linux / sistemas operacionais nacionais chineses;
- A especificação é **USB 2.0** — escolha os dispositivos conforme a tabela acima.
