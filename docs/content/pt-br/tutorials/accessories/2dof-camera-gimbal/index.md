# Gimbal de Câmera 2-DOF

> **[Comprar na loja](https://www.juxitech.com/pt/products/2-dof-servo-pan-tilt-unit)**

Gimbal de câmera 2-DOF — suporta controle manual por teclado e rastreamento automático de cor, rosto e QR code.
Hardware: servos SCS009 ×2 (rotação horizontal + inclinação vertical) + placa de driver de barramento serial CH343 (taxa de transmissão padrão de 1 Mbps).
