# Configuração de Hardware

Este capítulo detalha o método de conexão do hardware do produto.

## Descrição das Interfaces

O produto inclui as seguintes interfaces:

- USB-C: Alimentação e transmissão de dados
- GPIO: Interface de entrada/saída de uso geral
- HDMI: Saída de vídeo

## Etapas de Conexão

1. **Conectar a Alimentação**: Use o cabo USB-C para conectar a alimentação
2. **Conectar Periféricos**: Conecte outros periféricos conforme necessário
3. **Ligar**: Pressione o botão de energia para iniciar o dispositivo

## Observações

- Certifique-se de que a tensão de alimentação atenda aos requisitos
- Evite conectar/desconectar dispositivos GPIO com o dispositivo ligado
