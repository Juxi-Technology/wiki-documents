# Guia Rápido

Bem-vindo aos produtos da Juxi Technology! Este tutorial ajudará você a começar rapidamente.

## Pré-requisitos

Antes de começar, certifique-se de ter o seguinte:

- Hardware do produto
- Cabo USB
- Computador (Windows/macOS/Linux)

## Etapa 1: Conectar o Hardware

1. Conecte o produto ao computador usando o cabo USB
2. Aguarde a instalação automática dos drivers do dispositivo
3. Confirme que o dispositivo foi reconhecido corretamente

## Etapa 2: Instalar o Software

```bash
# Install dependencies
npm install

# Start application
npm start
```

## Etapa 3: Começar a Usar

Agora você pode começar a usar o produto! Confira mais tutoriais para conhecer os recursos detalhados.
