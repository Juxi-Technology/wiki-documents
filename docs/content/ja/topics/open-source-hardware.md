# なぜ私たちはオープンソースで作るのか——オープンソース・ロボットハードウェアの事例

Juxi Technology(JuxiTech)では、出荷するすべての製品に完全なハードウェア回路図、ファームウェアのソースコード、CADファイルを同梱しています。それらはすべて本Wikiで無料で入手できます。「プロプライエタリな囲い込み」が業界の常識である中で、なぜすべてをオープンソースにするのでしょうか?

## クローズドハードウェアの本当のコスト

研究ラボが専有ロボットアームを購入するとき、単にハードウェアを買っているのではありません——クローズドなエコシステムに足を踏み入れているのです。独自コントローラ、専有通信プロトコル、ブラックボックスのファームウェアにより、システムの改造・修理・完全な理解が不可能になります。不具合が起こればメーカーに送り返すしかなく、メーカーが想定しなかったことをさせる必要があれば、行き詰まります。可能性の限界に挑む研究者にとって、クローズドハードウェアは天井です。

## 研究の加速装置としてのオープンソース

私たちはブラックボックスを開けた後に何が起きるかを見てきました。SO-ARM101は大学ラボによって特定の把持タスク向けに改造され、AmazingHandは義肢研究に応用され、私たちのJetsonエッジAIプラットフォームは想像もしなかった自律ロボットに組み込まれています。それぞれの改造はコミュニティへ還元され、単一企業では実現できない改善の好循環を生み出しています。

## 深センで製造し、世界で使われる

私たちの前海の立地は、世界のハードウェア製造の中心に私たちを置いています。深センのサプライチェーンを活用し、生産品質を保ちながらコストを抑えています。その結果:世界中のラボ・学校・メイカーが使えるオープンソースロボットハードウェア——資金豊富な機関だけのものではありません。

## 今後の展望

私たちはより多くの具身知能プラットフォーム、物理AIツール、エッジコンピューティングソリューションで製品ラインを拡大していきます。すべてオープン、すべてドキュメント化、すべてコミュニティのために。今後のリリース、技術深掘り、コミュニティショーケースについては、私たちのWikiとブログをフォローしてください。
