# SO-ARM101 7軸ロボットアーム

> **[ストアで購入](https://www.juxitech.com/products/so-arm101-open-source-7-dof-robotic-arm)**

## 製品概要

SO-ARM101 は、SO-ARM100 をベースに深く最適化されたオープンソースロボットアームです。ケーブル配線とモーター/ギアの組み合わせを見直すことで、関節部のケーブル断線問題を解消し、性能のアップグレードによりリアルタイムな leader-follower 追従を実現しています。**本製品は 7 自由度版です**：6 軸モデルに手首ロール（yaw）サーボを追加し、手首の姿勢自由度が大幅に向上して、より多くの到達点と多角度からの精密把持が可能になります。

Hugging Face の **LeRobot** ツールキットに対応し、PyTorch モデルや共有データセットに直接接続できるため、模倣学習や強化学習をすぐに実践できます。完全な組立チュートリアルと DIY キットが付属し、学生・研究者・メイカーが学習・研究・創作のためにインテリジェントロボティクスを活用できます。

**主なポイント**：7 自由度 + 90° 手首ロール · 30kg.cm の 12V 高トルクサーボ · オプションの TPU フレキシブルグリッパー · デュアルビューによるデータ収集 · NVIDIA Jetson / D-Robotics RDK でのオンボード推論 · 工場組立済みですぐに使用可能 · ACT / SmolVLA / Pi0 / Pi0.5 / GR00T N1.5 のモデル訓練に対応。

## 主な特長

### 90° 手首ロールを備えた 7 自由度

7 自由度版は、6 軸の設計に左右の手首ロール（yaw）サーボを追加しています。これにより、手首がはるかに多くの角度から対象にアプローチでき、作業空間内のより多くの点に到達できます。この追加された自由度が、多角度からのきめ細かな把持を可能にします。

### leader-follower 遠隔操作と模倣学習

本アームは Hugging Face の AI フレームワークを統合しています。leader アームを遠隔操作してデモ動作を記録し、1 回の訓練で模倣学習モデルを学習させ、最適化されたポリシーをデプロイできます。複雑なタスクにも取り組み、環境に適応しながら、自動化ループをエンドツーエンドで完結させます。

### デュアルビューによる全体カバレッジ

アーム搭載カメラが近距離から対象物の空間位置・角度・表面テクスチャを捉え、より高忠実度なデータ収集を実現します。一方、卓上スタンドのシーンカメラが作業空間の環境をリアルタイムに読み取ります。2 台のカメラが連携することで、操作の精度を維持し、変化にすばやく対応し、ドリフトや停止を防ぎます。

### 30kg.cm 高トルク 12V バスサーボ

フォロワーアームは 7 × Feetech STS3215-C018（12V, 30kg.cm, 1:345）に統一し、多軸負荷がかかる状況でも十分な把持トルクを確保しています。一方、リーダーアームは 7.4V のままとして、操作感とコストのバランスを取っています。12 ビット磁気エンコーダが全軸で 0.088° の精度を実現します。

### 各種モデルの訓練に対応

同一のハードウェア上で ACT、SmolVLA、Pi0、Pi0.5、GR00T N1.5 のポリシーを訓練・デプロイでき、LeRobot モデルハブから `lerobot/smolvla_base`、`lerobot/pi0_base`、`lerobot/pi05_base`、`lerobot/xvla-widowx` などの事前学習済みモデルをそのまま再利用できます。

### NVIDIA / D-Robotics RDK でのオンボード推論

Raspberry Pi、D-Robotics RDK、NVIDIA Jetson コントローラーのいずれかにケーブル 1 本で接続するだけで、アーム自体で推論を実行でき、モーター制御とエンコーダフィードバックもリアルタイムで行えます。

### 工場組立済みで開封後すぐに使用可能

すべてのユニットは組立・配線・キャリブレーション済みで出荷されます——電源と USB を接続するだけで、遠隔操作とデータ収集を開始できる状態になります。

### アップグレード可能なフレキシブルグリッパー

フレキシブルグリッパーは標準のリジッドグリッパーをアップグレードしたもので、柔軟な TPU 素材による 3D プリント品です。内部に補強リブを備えた中空設計を採用し、フィン型グリッパーの原理で動作します。把持する対象物の形状に沿って変形し、対象物に加わる接触力を低減するため、従来のリジッドグリッパーでは安全に扱えなかった柔らかいものや壊れやすいもの（果物、ガラス製品、卵、食品加工）に最適です。
