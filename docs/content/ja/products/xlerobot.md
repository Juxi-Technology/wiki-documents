# XLeRobot 双腕移動ロボット

## 製品概要

XLeRobot は双腕移動ロボットプラットフォームです:全方向ホイール(キャスター)のシャーシを移動ベースとし、カメラタワーで 2 台の SO-ARM101 フォロワーアームを搭載。2 台のサーボドライバ基板、Raspberry Pi/Jetson ホストコントローラ、PD モバイルバッテリーを組み合わせることで、移動操作が可能なオープンソースロボットを構成します。具身知能研究、家事操作、LeRobot エコシステム開発を対象としています。

**主な特長**:

- 双腕操作 + 全方向移動シャーシで、家庭内のさまざまな物品を移動しながら把持可能
- SO-ARM101 ロボットアームをベースに、Feetech STS3215-C018 バスサーボを採用
- カメラタワー + 手首カメラ、データ収集と模倣学習に対応
- 2 台のサーボドライバ基板が双腕とシャーシを独立に駆動、12V 給電
- 完全な LeRobot ソフトウェアエコシステム:環境構築、データ収集、訓練と推論
- 完成品組み立てとパーツキット組み立ての 2 形態を提供、パーツキットには完全な付属品リスト付き
- Lekiwi ベース互換(既存の Lekiwi があれば、そのシャーシをそのまま流用可能)

| カテゴリ | 仕様 |
|------|------|

| 電源 | PD モバイルバッテリー 12V バージョン(単口最大 100W、テスト済みで動作に十分) |
| ホストコントローラ | Raspberry Pi(別途用意)/ Jetson |

## クイックスタート

### 1. LeRobot 環境構築

お使いの OS に応じた環境構築チュートリアル(macOS / Ubuntu / Windows)に従い、LeRobot と依存関係をインストールします。

### 2. XLeRobot ファイルの移動

XLeRobot ファイルを対応するディレクトリに移動し、ソフトウェアの準備を完了します。

### 3. ロボットの組み立て

- **完成品組み立て**:付属品リストに従い、シャーシ、カメラタワーベース、双腕と配線をそのまま取り付けます
- **パーツキット組み立て**:まずサーボを設定([Bambot](https://bambot.org/feetech.js) でスキャンして ID を変更)し、次にカート、シャーシ、ロボットアームベース、配線の順に組み立て、最後にバッテリーを設置します

パーツキットの組み立てでは、電源ケーブルを最後に接続することを推奨します。他のケーブルを抜き差しするときは電源を切断したままにして、サーボドライバ基板を保護してください。

## よくある質問

**Q: 完成品とパーツキットの違いは何ですか?**

**A:** 完成品は付属品リストに従って組み立て済みのキットです。パーツキットはご自身で組み立てる必要があり、まず Bambot ツールでサーボ ID を設定します(ロボットアーム 1-6、シャーシ 7/8/9、カメラタワー 7/8)。

**Q: 他に自分で用意する必要がある部品はありますか?**

**A:** モバイルバッテリー、Raspberry Pi、および PD 5V5A Raspberry Pi 電源ケーブルはご自身で購入する必要があります(チュートリアルに記載済み)。

**Q: サーボ ID はどのように設定しますか?**

**A:** サーボとサーボドライバ基板をコンピューターに接続した後、[Bambot サーボ設定ページ](https://bambot.org/feetech.js)でスキャンしてサーボ ID の名前を変更します。公式 LeRobot コードリポジトリは現在、ロボットアーム以外のサーボ設定に対応していないため、代わりに Bambot を使用します。

**Q: 組み立て完了後、そのまま押して移動できますか?**

**A:** できません。完全に組み立てた後は、カートのように押して移動しないでください。サーボのギアが破損する可能性があります。手動で移動する必要がある場合は、ロボットを持ち上げてください(約 12kg)。
