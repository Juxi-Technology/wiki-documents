## 貢献の方法

### 1. チュートリアルを書く

SO-ARM101 の使用経験をチュートリアルとして共有し、他の人の役に立ちましょう。

**はじめ方:**
- トピックを選ぶ(活用シーン、技術の深掘り解説など)
- 既存のチュートリアル構成に従う
- Pull Request を送る

### 2. ドキュメントを翻訳する

ドキュメントをより多くの言語に翻訳し、より多くのユーザーに役立ててもらいましょう。

**現在対応している言語:** 簡体字中国語 / 英語 / 繁体字中国語

### 3. 事例を投稿する

あなたの活用事例を共有し、プロジェクトの成果を見せてください。[成功事例ページ](/ja/cases/)を参照。

### 4. 問題を報告する

バグを見つけましたか?改善の提案はありますか?Issue を送信して改善にご協力ください。

### 5. コードに貢献する

LeRobot など関連するオープンソースプロジェクトにコードを貢献します。
