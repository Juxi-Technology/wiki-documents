# 会社概要

## 会社紹介

**Juxi Technology** は**深圳前海**に拠点を置き、**"With Hong Kong · For the Mainland · To the World"** の理念のもと、**物理AI・具身ロボティクス・エッジAI** を開発し、グローバル開発者に**オープンソースソリューション**を提供します。

> **オープンソースロボティクスの未来を築く** — 私たちは、ロボティクスの未来はオープンエコシステムに属すると信じています。

## コアテクノロジー

| 領域 | 内容 |
|------|------|
| **マルチモーダル知覚** | 視覚、音声、IMU とマルチセンサー融合 |
| **エッジAI** | NVIDIA Jetson プラットフォーム、PyTorch/TensorRT 最適化 |
| **ロボティクス制御** | ロボットアーム、多指ハンド、サーボとモーション制御 |

## オープンソースコミットメント

**すべての JuxiTech 製品はオープンソースです。** 私たちが公開しているもの:

- 📐 完全なハードウェア回路図
- 🔧 ファームウェアソースコード
- 🖥️ CADファイル
- 📦 SDKコード

これらはすべて [Feishu Wiki](https://juxitech.feishu.cn) と [GitHub Organization](https://github.com/Juxi-Technology)、および [Hugging Face](https://huggingface.co/Juxi-Technology) で無料公開しています。開発者と研究者のコミュニティがこのプラットフォームに継続的に貢献し、改善を続けています。

## エコシステムサポート

すぐに使えるサポート:

- 🤖 **ROS 2**
- 🧠 **LeRobot**(HuggingFace)
- 🖥️ **NVIDIA Jetson**
- 🍓 **Raspberry Pi**

## 製品ラインナップ

- **ロボットアーム**: 研究・教育・産業オートメーション向けのオープンソース 6 軸アーム
- **多指ハンド**: 具身AI・ヒューマンロボットインタラクション研究向けの AmazingHand 4 指ハンド
- **エッジコンピューティング**: PyTorch と TensorRT 最適化を備えた NVIDIA Jetson 開発キット
- **センサー & IMU**: 自律システム向けの高精度慣性航法と姿勢センシング
