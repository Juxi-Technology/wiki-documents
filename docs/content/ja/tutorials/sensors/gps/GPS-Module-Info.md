# モジュール資料

​		GPSモジュールはATGM336H-5Nをベースとした高性能なBDS/GNSS測位ナビゲーションモジュールです。本モジュールは多様な衛星測位システムに対応しており、中国の北斗二号および北斗三号の全衛星、アメリカのGPS、ロシアのGLONASS、日本のQZSSを含みます。上記の衛星測位システムの衛星信号を同時に受信でき、統合測位・ナビゲーション・時刻供給を実現します。本モジュールは高感度、低消費電力、低コストなどの利点を持ち、カーナビゲーション、ハンディ測位、ウェアラブルデバイスに適しています。

**一、モジュールの特徴：**

- 北斗二号および北斗三号の1～63号の全衛星に対応

- BDS/GPS/QZSS衛星測位システムの単一システム測位、および任意の組み合わせによるマルチシステム統合測位に対応。

- A-GNSSに対応

- コールドスタート捕捉感度：-148dBm

- 追尾感度：-162dBm

- 測位精度：2.5メートル（CEP50）

- 初回測位時間：32秒

- 低消費電力：連続動作時25mA@3.3V

- 内蔵アンテナ検出およびアンテナ短絡保護機能
