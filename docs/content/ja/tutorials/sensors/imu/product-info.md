# 製品情報

> **[ストアで購入](https://www.juxitech.com/ja/products/imu-module-ahrs-attitude-and-heading-angle-sensor)**


高精度 IMU 姿勢センサーは **72MHz 高性能32ビットプロセッサ** を内蔵し、リアルタイム姿勢演算と動的補償に対応。データ更新周波数は最大 **100Hz** で、応答の速さと出力の安定性を兼ね備えています。IIC・シリアルの両通信モードに対応し、単体マイコン・Linux 主機に加え ROS システムともシームレスに統合でき、ロボットの運動制御、ドローンの姿勢安定化、インテリジェントナビゲーション・測位など、高性能なアプリケーションシーンに広く適用できます。
