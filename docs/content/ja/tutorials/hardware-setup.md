# ハードウェア接続

製品のハードウェア接続方法を詳しく説明します。

## インターフェース

製品には以下のインターフェースがあります:

- USB-C: 電源とデータ転送
- GPIO: 汎用入出力
- HDMI: 映像出力

## 接続手順

1. **電源接続**: USB-C ケーブルで電源を接続
2. **周辺機器接続**: 必要に応じて周辺機器を接続
3. **電源投入**: 電源ボタンを押して起動

## 注意事項

- 電源電圧が仕様範囲内であることを確認
- 通電中に GPIO デバイスの抜き差しをしない
