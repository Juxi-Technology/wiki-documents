# 4K HDMI キャプチャカード

## 配線方法

マザーボードのインターフェースに応じて、以下の3つの配線方法があります

**HDMIポート**——&gt;HDMIケーブル——&gt;キャプチャカードのHDMIポート——&gt; USB/Type-C ——&gt;ノートPC・デスクトップ・一体型PC・スマートフォン/タブレットなどのディスプレイ

**Micro HDMIポート**——&gt;Micro HDMI変換アダプタ——&gt;HDMIケーブル——&gt;キャプチャカードのHDMIポート——&gt; USB/Type-C ——&gt;ノートPC・デスクトップ・一体型PC・スマートフォン/タブレットなどのディスプレイ

**DPポート**——&gt;DP-HDMI変換アダプタ——&gt;HDMIケーブル——&gt;キャプチャカードのHDMIポート——&gt; USB/Type-C ——&gt;ノートPC・デスクトップ・一体型PC・スマートフォン/タブレットなどのディスプレイ
