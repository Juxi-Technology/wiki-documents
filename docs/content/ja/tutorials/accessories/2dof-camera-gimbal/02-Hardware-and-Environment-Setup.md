## ハードウェアの接続

### ステップ 1：サーボとジンバルブラケットの取り付け

1. 1 番サーボ（左右回転用）をジンバル下部ブラケットの所定位置に取り付け、ねじでしっかり固定します
2. 2 番サーボ（上下ピッチ用）をジンバル上部ブラケットに取り付け、同様に固定します
3. 説明に従ってカメラ固定構造を取り付けます

### ステップ 2：サーボとドライバボードの接続

1. 2 つのサーボのデータケーブルをドライバボードのサーボインターフェースに接続します
2. サーボケーブルの接続順序に注意してください。色は一般に赤（電源）、黒（グラウンド）、白/黄（信号）です
3. サーボが対応する ID に接続されていることを確認します：サーボ ID 1 が左右、サーボ ID 2 が上下です

### ステップ 3：電源とシリアルポートの接続

1. サーボ電源をドライバボードの電源インターフェースに接続します
2. シリアルケーブルを使用して、ドライバボードとコンピューターの USB インターフェースを接続します
3. カメラをコンピューターに接続します

## ドライバと依存関係のインストール

### シリアルドライバのインストール

#### Windows

1. CH343 チップメーカーの公式サイトにアクセスし、お使いの Windows バージョンに対応するドライバインストーラーをダウンロードします
CH343 ドライバのインストール（管理者権限でインストール）
https://www.wch.cn/downloads/CH343SER_EXE.html

>
> デバイスマネージャーで不明なデバイス（usb single serial または usb serial）として認識された場合は、まず右クリックしてアンインストールし、その後ドライバをインストールしてください！

1. インストーラーを実行し、画面の指示に従ってドライバのインストールを完了します
2. サーボドライバボードをコンピューターに接続すると、デバイスマネージャーにシリアルポートデバイスが表示されるはずです

#### Linux

ほとんどの Linux ディストリビューションには CH343 シリアルドライバが組み込まれており、追加インストールは不要です。問題が発生した場合は、以下を試してください：
1. カーネルにドライバがロードされているか確認します `lsmod | grep ch343`
2. ロードされていない場合は、デバイスを挿し直すか、再起動を試します

### Python 依存関係のインストール

プロジェクトのルートディレクトリで実行します：

```python
pip install -r requirements.txt
```

プロジェクトの主な依存関係は以下のとおりです：
- opencv-python：画像の取得と処理
- numpy：数値計算ライブラリ
- pyserial：シリアル通信ライブラリ

## ハードウェア接続の検証

本番プログラムを起動する前に、ツールを使用してハードウェア接続を検証できます。

### 利用可能なカメラの確認

以下のコマンドを実行して、利用可能なカメラを一覧表示します：

```python
python examples/list_cameras.py
```

プログラムが利用可能なすべてのカメラを検出して一覧表示します。使用するカメラのインデックスを控えてください。

### 利用可能なシリアルポートの確認

以下のコマンドを実行して、利用可能なシリアルポートを一覧表示します：

```python
python examples/list_ports.py
```

使用するシリアルポートデバイスの名前を控えてください。

### ハードウェア診断

ハードウェア全体を総合的にチェックする必要がある場合は、診断ツールを実行できます：

```python
python examples/diagnostic.py --camera 0 --port COM3
```

診断プログラムはカメラ、シリアルポート、ジンバルの順にテストします。

## 安全上の注意

使用中は、以下の安全事項に注意してください：
1. サーボ電源は規定範囲内（4V-7.4V）で使用し、サーボの破損を防いでください
2. 寿命を延ばすため、サーボを長時間にわたり限界位置で動作させるのは避けてください
3. 電源を切る前にジンバルを中央に戻すことをお勧めします。次回起動時の負荷を軽減できます
