# 2自由度ジンバル

> **[ストアで購入](https://www.juxitech.com/ja/products/2-dof-servo-pan-tilt-unit)**

2自由度カメラジンバル —— キーボードによる手動制御に加え、カラー・顔・QR コードの自動トラッキングに対応しています。
ハードウェア：SCS009 サーボ ×2（左右回転 + 上下ピッチ）+ CH343 シリアルバスドライバボード（デフォルトボーレート 1Mbps）。
