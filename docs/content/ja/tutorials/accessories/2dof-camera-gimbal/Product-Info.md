# 製品情報

> **[ストアで購入](https://www.juxitech.com/ja/products/2-dof-servo-pan-tilt-unit)**

2自由度カメラジンバル制御プロジェクト。カラートラッキング、顔トラッキング、QR コードトラッキングに対応しています。

---

## 📋 主な機能

- 🎮 キーボードによるジンバルの手動制御
- 🎯 カラー物体の自動トラッキング
- 👤 顔の自動トラッキング
- 📱 QR コードの自動トラッキング
- 🔒 ターゲットロック機構
- 🚀 高速起動（DSHOW バックエンドを使用）

---

## 🛠 ハードウェア構成

- **サーボ型番**：SCS009
- **サーボの割り当て**：
  - 1 番サーボ：左右回転の制御
  - 2 番サーボ：上下ピッチの制御
- **通信方式**：シリアルバス（ドライバボード経由）
- **ドライバボードのチップ**：CH343
- **ボーレート**：デフォルト 1Mbps

### サーボパラメータ


|パラメータ|1 番サーボ（左右）|2 番サーボ（上下）|
|---|---|---|
|範囲|220-802|220-511|
|中央位置|511|511|
|説明|220=左、802=右|220=上、511=中央|

### デモの実行

コマンドライン引数で設定します：

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3 --color red
```

**パラメータの説明**
- `--camera` または `-c`：カメラインデックス（デフォルト 0）
- `--port` または `-p`：シリアルポートデバイス（デフォルト COM3）
- `--color` または `-C`：デフォルトの色（デフォルト red）

## 🎮 使い方

### ショートカットキー


|キー|機能|
|---|---|
|1|顔トラッキングモードに切り替え|
|2|カラートラッキングモードに切り替え|
|C|ジンバルに接続|
|R|ジンバルを中央に戻す|
|T|ターゲットのロック/トラッキング開始|
|S|トラッキングを停止|
|X|カラーモード：赤|
|Y|カラーモード：緑|
|Z|カラーモード：青|
|Q|プログラムを終了|


### 自動トラッキングの使用手順

1. `C` を押してジンバルに接続します
2. モードを選択します（`1` または `2` を押す）
3. ターゲット物体を画面中央に移動します
4. `T` を押してターゲットをロックします
5. ターゲットを移動させると、ジンバルが自動的に追従します

## 🔧 技術説明

### トラッキング制御パラメータ

`src/trackers/tracking_controller.py` で調整できます：

|パラメータ|デフォルト値|説明|
|---|---|---|
|kp_pan|0.08|左右トラッキングの比例ゲイン|
|kp_tilt|0.12|上下トラッキングの比例ゲイン|
|dead_zone|30|デッドゾーン（ピクセル）。この範囲内では移動しません|
|min_move_interval|0.15|最小移動間隔（秒）|


### ターゲットロック機構

ロック後、システムは以下の条件に基づいてターゲットを選択します：
- ロックポイントから最も近い（重み 70%）
- サイズがロック時と最も類似している（重み 30%）
