## ステップ 0：利用可能なデバイスの確認

開始する前に、使用するカメラとシリアルポートを特定する必要があります。

### 利用可能なカメラの確認

```python
python examples/list_cameras.py
```

プログラムが利用可能なすべてのカメラとインデックスを一覧表示します。使用するインデックス（通常は 0）を控えてください。

### 利用可能なシリアルポートの確認

```python
python examples/list_ports.py
```

プログラムが利用可能なすべてのシリアルポートを一覧表示します。Windows では COM3、COM4 など、Linux では /dev/ttyUSB0 などです。

## ステップ 2：段階的なチュートリアルを順番に実行（任意ですが推奨）

システムをよりよく理解するために、以下のプログラムを順番に実行することをお勧めします：
1. **01_camera_only.py** - カメラ映像のみ表示、ジンバルには接続しない

```python
python examples/01_camera_only.py --camera 0
```

機能：カメラが正常に動作するかを検証します
1. **02_gimbal_only.py** - ジンバルのみ制御、カメラには接続しない

```python
python examples/02_gimbal_only.py --port COM3
```

機能：サーボとドライバボードの接続が正常かを検証します
1. **03_simple_gimbal_camera.py** - カメラとジンバルの組み合わせ

```python
python examples/03_simple_gimbal_camera.py --camera 0 --port COM3
```

機能：ジンバルを手動制御しながらカメラ映像を確認します
1. **04_color_track_simple.py** - シンプルなカラートラッキング（ロックなし）

```python
python examples/04_color_track_simple.py --camera 0 --port COM3 --color red
```

機能：最も基本的な自動トラッキングのデモ

## ステップ 3：完全版プログラムの実行

基本機能に慣れたら、完全版の自動トラッキングプログラムを実行します：


## 完全版プログラムのショートカットキー


|キー|機能|
|---|---|
|1|顔トラッキングモードに切り替え|
|2|カラートラッキングモードに切り替え|
|C|ジンバルに接続|
|R|ジンバルを中央に戻す|
|T|ターゲットのロック/トラッキング開始|
|S|トラッキングを停止|
|X|カラーモード：赤|
|Y|カラーモード：緑|
|Z|カラーモード：青|
|Q|プログラムを終了|

## 簡単な体験手順

### カラートラッキングを試す

1. `C` を押してジンバルに接続します
2. `2` を押してカラートラッキングモードに入ります
3. 赤い物体（または他の色の物体）を画面中央に移動します
4. `T` を押してターゲットをロックします
5. 物体を移動させ、ジンバルが追従する様子を観察します

### 顔トラッキングを試す

1. `C` を押してジンバルに接続します
2. `1` を押して顔トラッキングモードに入ります
3. 顔を画面中央に合わせます
4. `T` を押してターゲットをロックします
5. 顔を動かし、ジンバルが追従する様子を観察します

## よくある質問と簡単な回答

Q：プログラムがシリアルポート番号を見つけられないと表示される場合は？
A：`list_ports.py` を実行して利用可能なシリアルポートを確認し、`--port` パラメータで指定してください。
Q：カメラが開けない場合は？
A：`list_cameras.py` を実行して利用可能なカメラを確認し、`--camera` パラメータでインデックスを指定してください。
Q：ジンバルが動かない場合は？
A：`C` を押してジンバルに接続済みであること、およびサーボ電源が接続されていることを確認してください。
Q：トラッキングの方向が逆になった場合は？
A：トラブルシューティングの章を参照してください。
