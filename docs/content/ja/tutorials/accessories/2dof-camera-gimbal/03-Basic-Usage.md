# 基本的な使い方

> **[ストアで購入](https://www.juxitech.com/ja/products/2-dof-servo-pan-tilt-unit)**

本章では、ジンバルの基本的な制御方法と使用手順を詳しく説明し、ユーザーが基本操作に慣れることを目的としています。

---

## 制御方式の概要

ジンバルシステムは 2 つの主要な制御方式に対応しています：
1. キーボード制御：キーボードのキーでジンバルの動きを手動制御します
2. 自動トラッキング：システムがターゲットを自動的に認識してトラッキングします

---

## キーボード制御

### キーボードショートカットの説明

以下はメインプログラムで使用できるキーボードショートカットです：

|キー|機能説明|
|---|---|
|方向キー ←|ジンバルが左に回転|
|方向キー →|ジンバルが右に回転|
|方向キー ↑|ジンバルが上を向く（ピッチ）|
|方向キー ↓|ジンバルが下を向く（ピッチ）|
|C|ジンバルを接続または切断|
|R|ジンバルを中央に戻す（初期位置に復帰）|
|1|顔トラッキングモードに切り替え|
|2|カラートラッキングモードに切り替え|
|T|ターゲットのロック/トラッキング開始|
|S|トラッキングを停止|
|X|カラーモード：赤い物体をトラッキング|
|Y|カラーモード：緑の物体をトラッキング|
|Z|カラーモード：青い物体をトラッキング|
|Q|プログラムを終了|


### 独立したキーボード制御の例

単独のキーボード制御プログラムを使って練習することもできます：

```python
python examples/keyboard_control.py --port COM3
```

このプログラムは基本的なジンバル制御機能のみを提供しており、初心者の練習に適しています。

## 基本操作手順

### 起動と接続

1. 以下のコマンドでメインプログラムを起動します：

```python
python examples/auto_tracking_demo.py --camera 0 --port COM3
```

1. プログラム起動後、`C` を押してジンバルに接続します
2. サーボが正常に応答するか観察します。異常がある場合はトラブルシューティングの章を参照してください

### 手動制御の練習

1. 方向キーを押し、ジンバルの動きが期待どおりかを確認します
2. 方向キーでジンバルをいろいろな位置に移動する練習をします
3. `R` を押してジンバルを中央に戻します
4. ジンバルの最小位置と最大位置の制限に慣れましょう
以下の練習を行ってみましょう：
- 練習 1：ジンバルを最左・最右・最上・最下の 4 つの限界位置に移動し、位置範囲に慣れる
- 練習 2：任意の位置から中央に戻し、中央への戻りがスムーズかを観察する
- 練習 3：細かい調整を試し、サーボの動作精度に慣れる

## 基本的なサンプルプログラム

プロジェクトには、学習用に段階的に進められるサンプルプログラムがいくつか用意されています：

### カメラ映像のみ表示

```python
python examples/01_camera_only.py --camera 0
```

このプログラムはカメラを開いてリアルタイム映像を表示するだけで、ジンバル制御は行いません。カメラ機能が正常かを検証するのに適しています。

### ジンバルのみ制御

```python
python examples/02_gimbal_only.py --port COM3
```

このプログラムはジンバル制御機能のみを提供し、カメラは使用しません。サーボとドライバボードの接続が正常かを検証するのに適しています。

### カメラとジンバルの組み合わせ

```python
python examples/03_simple_gimbal_camera.py --camera 0 --port COM3
```

このプログラムはカメラ表示とジンバル制御を組み合わせたもので、映像とジンバルの連動効果を確認できます。

## 使用上の注意

使用中は、以下の点に注意してください：
1. ジンバルに接続した後、サーボの電源が接続されていることを確認してください
2. 手動制御時は、長時間にわたって限界位置に停留しないよう注意してください
3. 操作時はジンバルブラケットに強い衝撃を与えないでください
4. サーボに異常な振動や異音がある場合は、直ちに電源を切って確認してください
5. 長時間使用しない場合は、電源接続を外すことをお勧めします
