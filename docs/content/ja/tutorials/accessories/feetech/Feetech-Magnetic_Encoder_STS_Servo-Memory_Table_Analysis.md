## 3 特殊バイトの説明

### 3.1 サーボ位相

- ビット数/ビット重み: 説明

- BIT0（1）: 駆動方向位相；(0)正方向、(1)逆方向

- BIT1（2）: 駆動ブリッジモード；(0)ブラシレス、(1)ブラシ付き、再起動で有効

- BIT2（4）: 速度単位；(0)0.732RPM、(1)0.0146RPM

- BIT3（8）: 速度モード；(0)速度0は停止、(1)速度0は最高速度

- BIT4（16）: 角度フィードバックモード；(0)単回転角度をフィードバック、(1)全角度をフィードバック

- BIT5（32）: 駆動ブリッジ構成/電圧サンプリング、(0)独立Hブリッジ/1K高圧サンプリング、(1)一体型Hブリッジ/1.5K低圧サンプリング/電流フィードバックなし

- BIT6（64）: PWM周波数、(0)24kHz、(1)16kHz

- BIT7（128）: 位置フィードバック方向位相、(0)正方向、(1)逆方向

複数のビットを同時に設定した場合、サーボの位相値は各ビット値の合計になります。例: 元の位相値が0でサーボが逆方向に動作する場合、位相値は128+1=129;

### 3.2 サーボステータス

サーボステータス: 0は正常、1は異常

- ビット数/ビット重み: 説明

- BIT0（1）: 電圧ステータス

- BIT1（2）: 磁気エンコーダステータス

- BIT2（4）: 温度ステータス

- BIT3（8）: 電流ステータス

- BIT4（16）: ----

- BIT5（32）: 負荷ステータス

- BIT6（64）: ----

- BIT7（128）: ----

複数のステータスが同時にある場合、サーボのステータス値は各ビット値の合計になります。例: 電圧過電圧/不足電圧とサーボ過熱の場合、サーボステータス値は4+1=5;

- BIT2（4）: 過熱保護

- BIT3（8）: 過電流保護

- BIT4（16）: ----

- BIT5（32）: 負荷過負荷

- BIT6（64）: ----

- BIT7（128）: ----

複数のビットを同時に設定した場合、サーボのアンロード条件値は各ビット値の合計になります。例: 電圧保護と過熱保護が同時にオンの場合、アンロード条件値は4+1=5;
