# MAX30102 心拍・血中酸素センサーモジュール使用チュートリアル

本チュートリアルでは、Juxi Technology の MAX30102 心拍・血中酸素センサーモジュールの使用方法を説明します。本モジュールは Maxim 製 MAX30102 専用心拍・血中酸素検出チップを搭載し、独自開発の心拍・血中酸素アルゴリズムを内蔵しており、心拍数、血中酸素飽和度、基板温度を直接出力できるほか、I2C と UART の 2 種類の通信方式にも対応します。

## クイックスタート

1. まず[製品資料](./product-info.md)を読み、電源（3.3–5V）とピン定義を確認します。
2. データをすぐに見たいだけの場合：[Web 版使用チュートリアル](./web-console.md)を使い、Chrome / Edge で Web ページを開くだけです。
3. マイコンに接続する場合：[Arduino 使用チュートリアル](./arduino.md)を参照してください。
4. ラズベリーパイに接続する場合：[ラズベリーパイ使用チュートリアル](./raspberry-pi.md)を参照してください。
5. PC に接続する場合：[PC 側 · Python 実行](./pc/python.md)または [PC 側ホストコンソール](./pc/upper-computer.md)を参照してください。

> 本製品はコンシューマー向け電子検出モジュールであり、専門医療機器ではありません。検出データは日常の健康参考用です。
