# Web 版使用チュートリアル

本チュートリアルでは、ブラウザ版ホストコンソールを使用して心拍・血中酸素モジュールに接続し、モニタリングする方法を説明します。Web 版は Web Serial でシリアルポートに直接アクセスするため、Python や `.exe` のインストールが不要で、Windows、macOS、Linux のいずれでも使用できます。

**オンライン URL：**[https://juxi-technology.github.io/JUXI_HeartRate_SPO2/](https://juxi-technology.github.io/JUXI_HeartRate_SPO2/)

> Web 版とデスクトップ版ホストコンソールは同じ Modbus RTU プロトコル（スレーブアドレス `0x20`、9600 ボー）を使用しており、読み取り値は完全に一致します。

## 一、動作環境

- デスクトップ版 **Chrome、Edge、Opera**（Web Serial 対応が必要）
- Safari、Firefox、モバイルブラウザは Web Serial 非対応のため、シリアルポートに接続できません
- USB-TTL 変換ドライバ（CH340、CP2102、FT232 など）
- ページの読み込みにはインターネット接続が必要
- ブラウザがページに一度に許可できるシリアルデバイスは 1 台のみ

## 二、ハードウェア接続

| 心拍・血中酸素モジュール | USB-TTL 変換 |
|---|---|
| **VCC** | **5V**（3.3V には接続しないでください） |
| **GND** | **GND** |
| **TX** | **RX**（クロス接続） |
| **RX** | **TX**（クロス接続） |

⚠️ TX と RX は必ずクロス接続してください。接続後に USB-TTL 変換を PC に挿入します。

## 三、デバイスの接続

1. デスクトップ版 Chrome / Edge / Opera で上記のオンライン URL を開きます。
1. ボーレートはモジュールに合わせて **9600** のままにします。
1. 「**シリアルポートに接続**」をクリックし、ブラウザのダイアログでモジュールに対応する USB シリアルデバイスを選択します。
1. ステータスが「**接続済み、収集待ち**」になれば接続成功です。ボタンの横に選択したデバイスが表示されます。

> シリアルパラメータは 8 データビット、1 ストップビット、パリティなし、フロー制御なしに固定されており、ページが自動設定するため手動設定は不要です。

## 四、収集とモニタリングの開始

1. 「**収集開始**」をクリックします。モジュールの LED が点灯し、ステータスが「収集開始済み、LED 点灯」に変わります。
1. 指をセンサーの上に置き、光学領域を完全に覆います。軽く置くだけでよく、強く押さないでください。
1. 「**モニタリング開始**」をクリックします。ステータスが「モニタリング中...」に変わり、リアルタイムデータの更新が始まります。

## 五、画面の説明

### リアルタイムデータ

| 指標 | 単位 | 説明 |
|---|---|---|
| 血中酸素 (SPO2) | % | 血中酸素飽和度 |
| 心拍数 | 回/分 | 脈拍数 |
| 温度 | °C | モジュール基板上の温度（体温ではありません） |

**フィルタリング**：デフォルトで有効です。読み取り値に 5 点メディアン平滑化を適用し、妥当な範囲（心拍数 35–220、血中酸素 70–100%、温度 0–60 °C）を超える異常値を除外します。除外された数はデータ領域の下に「異常値を N 個除外しました」のように表示されます。チェックを外すと、未処理の生の読み取り値を確認できます。

**ステータス表示**：未接続 / デバイス選択待ち… / 接続済み、収集待ち / 収集開始済み、LED 点灯 / 収集停止済み、LED 消灯 / モニタリング中… / モニタリング停止済み / デバイス切断済み / 現在のブラウザは Web Serial 非対応です。

### 言語切り替え

右上の **EN / 中文** ボタンで画面の言語を切り替えます。ボーレートとフィルタリングスイッチの選択はブラウザに記憶され、次回開いたときに前回の設定が維持されます。

### 使用ドキュメントタブ

上部の「**使用ドキュメント**」タブには本製品の 11 言語のチュートリアルが組み込まれており、ページ内で直接言語を切り替えて閲覧できます。

## 六、停止と切断

以下の順序で操作することをおすすめします。

1. 「モニタリング停止」をクリック
1. 「収集停止」をクリック — LED が消灯
1. 「接続を切断」をクリック

## 七、データの見方

| データ | 正常範囲 | 説明 |
|---|---|---|
| 血中酸素 SpO2 | 95% – 100% | 90% 未満は受診を推奨 |
| 心拍数 | 60 – 100 回/分 | 成人の安静時範囲 |
| 温度 | 25 – 35 °C | 基板センサーの温度（体温ではありません） |

接続直後や指が正しく置かれていない場合に `-1` が表示されるのは正常な現象です。

## 八、デスクトップ版ホストコンソールとの違い

| 比較項目 | Web 版 | デスクトップ版ホストコンソール |
|---|---|---|
| インストール | 不要 | `.exe` または Python スクリプトの実行が必要 |
| 動作環境 | ブラウザ | Windows |
| 通信方式 | Web Serial | システムのシリアルポート |
| オフライン使用 | 不可（ページの読み込みにインターネット接続が必要） | 可能 |
| プロトコルと読み取り値 | 同じ | 同じ |

## 九、よくある質問

**Q1：「現在のブラウザは Web Serial 非対応です」と表示される。**
デスクトップ版 Chrome、Edge、Opera に切り替えてください。Safari、Firefox、モバイルブラウザは Web Serial 非対応です。

**Q2：「シリアルポートに接続」をクリックしても、ダイアログにデバイスが表示されない。**
USB-TTL 変換ドライバがインストールされているか、データケーブルがデータ通信に対応しているかを確認してください。別の USB ポートを試すか、挿し直してから再度お試しください。

**Q3：接続に失敗する。**
シリアルポートが他のプログラム（シリアルアシスタント、Arduino IDE など）に占有されていないこと、およびデバイスに電源が入っていることを確認してください。

**Q4：「収集開始」をクリックしても LED が点灯しない。**
VCC が 3.3V ではなく 5V に接続されていることを確認し、TX/RX がクロス接続されているか確認してください。

**Q5：データがずっと -1 と表示される。**
「収集開始」をクリック済みであること、指がセンサーの光学領域を完全に覆っていることを確認し、数秒間安定させてください。

**Q6：デバイスが抜かれた。**
ページに「デバイス切断済み」と表示されます。挿し直してから再度「シリアルポートに接続」をクリックしてください。

## 十、注意事項

1. 先にセンサーを接続し、その後 USB を挿入します。
1. センサーは必ず 5V で給電してください。3.3V では正常に動作しない可能性があります。
1. 測定時は指で光学領域を完全に覆い、強く押さないでください。
1. センサーに強い光が直接当たらないようにしてください。
1. ブラウザが一度に許可できるシリアルデバイスは 1 台のみです。複数のデバイスは個別に接続する必要があります。
