# クイックスタート

出荷時には音声認識機能のファームウェアがすでに書き込まれており、ユーザーは書き込むことなくすぐに体験できます。他の認識エントリーを追加したい場合、他のファームウェアを再書き込みする場合、エントリーをカスタマイズする場合は、《3.カスタムプロトコルエントリーの作成》チュートリアルでエントリーのカスタマイズ方法を確認できます。

## 3.音声認識と再生の実現

音声対話モジュールに type-c で電源を供給した後、“你好，小犀” というウェイクワードでモジュールをウェイクアップできます。ウェイクアップに成功するとモジュールは “我在” と返答し、現在音声を認識できる状態であることを示します。15 秒以内にコマンドエントリーが認識されない場合、モジュールはスリープモードに入り、同時に “我去休息了” を再生します。モジュールを再度ウェイクアップしたい場合は、もう一度ウェイクワードを話せばよいです。

出荷時ファームウェアにはコマンドワードと再生フレーズが付属しており、提供された資料の添付ファイルでプロトコルリストを確認できます。下図はコマンドワード・再生フレーズのプロトコルリストの一部を抜粋したものです。機能タイプから、対応するコマンドワードがどのような機能を表すかを確認できます。再生する必要がある再生フレーズはパッシブ再生フレーズであり、PC のシリアルポートや他のマイコンまたはホストコントローラデバイスから音声対話モジュールに対応するコマンドを送信しないとトリガーできません。詳しくは下図をご覧ください。

再生モードには 2 種類あり、1 つはアクティブ式、もう 1 つはパッシブ再生です

アクティブ再生：表に従ってコマンドワードを話すと、モジュールは対応するフレーズをアクティブに再生します。ウェイクアップ後に “小车前进” と話すと、モジュールは認識後 “好的，正在前进” をアクティブに再生します 

パッシブ再生：プロトコル表内のコマンドをシリアルポートを通じて音声モジュールに送信して初めて、モジュールが対応するフレーズを再生します。IIC プロトコルに従ってパッシブ再生のレジスタに書き込み、対応する再生データを書き込むこともできます。具体的な内容は《マルチホストコントローラ通信》をご覧ください
