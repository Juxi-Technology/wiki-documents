# 製品資料

## 1.音声対話モジュールの紹介

CI1302 は启英泰伦が開発した新世代の高性能ニューラルネットワークスマート音声チップで、启英泰伦が自社開発した脳ニューラルネットワークプロセッサ BNPU V3 と CPU コアを統合しており、システムの主周波数は最大 220MHz、内蔵 SRAM は最大 640KByte に達し、PMU 電源管理ユニットと RC 発振器を統合し、さらにデュアルチャネルの高性能・低消費電力 Audio Codec と、多系統の UART、IIC、IIS、PWM、GPIO、PDM などの周辺制御インターフェースを統合しています。チップはわずかな抵抗やコンデンサなどの周辺部品だけで各種スマート音声製品のハードウェアソリューションを実現でき、コストパフォーマンスが極めて高いです。

第 3 世代のハードウェア BNPU 技術を採用し、DNN\\TDNN\\RNN\\CNN などのニューラルネットワークおよび並列ベクトル演算に対応し、音声認識、声紋認識、コマンドワードの自己学習、音声検出、深層学習によるノイズ低減などの機能を実現できます。本チップソリューションは中国語、英語、日本語など多様な世界の言語にも対応しており、家電、照明、玩具、ウェアラブルデバイス、産業、自動車などの製品分野に幅広く応用でき、音声対話および制御と各種スマート音声ソリューションの応用を実現します。

CI1302 チップは脳ニューラルネットワークプロセッサコア(BNPU)を備え、オフラインでの NN 加速演算と音声信号処理のハードウェア高速化などに対応し、CPU 主周波数は最大 220MHz に達し、オフラインでの遠距離音声認識が可能で、2MB FLASH ストレージを内蔵し、300 個のコマンドワードに対応できます。

## 2.製品の特長

- 110+ 個以上の音声コマンドをプリセットし、中国語と英語のカスタムコマンドワードに対応しています。

ユーザーは弊社提供の Web ページでコマンドワードを変更し、新しいファームウェアファイルを生成して、PC ソフトウェアでファームウェアをモジュールに書き込むことで、モジュールが新しいコマンドを認識できるようになります。2M の内蔵ストレージを備え、最大約 120 個のコマンドワードを書き込むことができます。

- 高忠実度スピーカーと高性能マイクを内蔵しています。

先進的なアルゴリズムと回路によるノイズ低減技術を統合し、環境の背景ノイズを効果的に除去でき、5 メートルの範囲内で認識率 99% に達し、自然な対話とエコーキャンセルを実現します。クリアな音質出力を提供し、音声の細部を正確に再現します。

- オンボードのコプロセッサと IIC/シリアルポート/Type-C インターフェース。

STC8H チップを統合し、音声データを自動的にシリアルポートまたは IIC データ形式に変換し、外部ホストコントローラデバイスとの通信プロセスを簡素化します。各種接続ケーブルを無償で提供しており、ユーザーはこれを MCU 開発ボードや組込みホストコントローラデバイスに接続し、通信を実現して独自の DIY プロジェクトを作成できます。

- 各種開発ボードに基づく使用チュートリアルを提供

STM32、ESP32、MSPM0、Raspberry Pi、Jetson シリーズ開発ボード、RDK などの開発ボード情報を提供します。また、ROS1 および ROS2 システムの SDK ファイルも提供します。

## 3.動作原理

本モジュールはコマンドモードでウェイクアップします。ユーザーはまず設定済みのウェイクワードを発話して音声対話モジュールを起動する必要があり、起動後は音声認識を行うことができます。出荷時ファームウェアのデフォルトのウェイクキーワードは “你好，小犀” で、15 秒経過しても音声が認識されない場合、モジュールはスリープモードに入り、次に使用する際には改めてウェイクアップする必要があります。

CI1302 チップが対応する音声エントリーを認識すると、シリアルポートや IIC インターフェースを通じて送信し、再生をフィードバックします；IIC チップは受信した音声コマンドを保存し、IIC スレーブプロトコルを通じて送信します。

モジュールはウェイクワードの変更、コマンドワードの変更、カスタムエントリーに対応しています。操作方法はチュートリアル《[ウェイクワードとコマンドワードの変更](https://juxitech.feishu.cn/wiki/Po6bw8OtLiDNonklg7ZcBbGknyc)》、《[カスタムプロトコルエントリーの作成](https://juxitech.feishu.cn/wiki/CIHLwo8qNiVBtKkhuTtcZIeNnAb)》で学ぶことができます。

## 4.注意事項

1、5v 電圧で給電してください。5v を超えるとモジュールが破損します

2、使用環境は静かな場所にしてください。騒がしい環境は認識効果に影響します

3、エントリーを発話する際は、声をはっきりと大きくし、話す速度は速すぎないようにしてください。モジュールとの距離は 5 メートル以内に保つことを推奨します
