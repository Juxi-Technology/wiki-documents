# PC 通信

## デバイスの接続

スライドスイッチを STC8 シリアルモードに移動します

![図 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## シリアルデバッグアシスタントを開く

- Uart Assistant を開き、対応するシリアルポート番号とボーレート 115200 を選択します

![図 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- 圧縮ファイル内の命令词播报词协议列表V1_中文ファイルを参照します

![図 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- “小车前进” と発話すると、シリアルデバッグアシスタントに対応するプロトコルが出力されます

![図 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- 命令词播报词协议列表V1_中文ファイルに従って対応するコマンドを入力すると、音声モジュールが対応するプロトコルの文字を再生します

![図 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

音声モジュールが正常に再生されるのを聞くことができます。
