# 02 · HUB機能（1分3）

> [← 概要に戻る](/ja/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜対象製品：JUXI Technology（鉅犀科技）KVM&HUB&TTL

## 使い方

**Type-C 1本入力、USB-A 3ポート出力**——PCを1台だけ接続すれば、本製品は通常のUSB HUBとして動作します：

1. Type-CケーブルでPCを **PC1**（またはPC2）ポートに接続；
2. キーボード、マウス、USBメモリなどを任意の **USB-A** ポートに接続して使用。

2台のPCを接続した場合、3つのUSB-Aポートは一括して2台のPC間を切り替わります（[01](/ja/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers) 参照）。

（図：チュートリアル素材 02 - 1分3 HUB）

## 接続できる機器

| 接続可能 | PCへ直接接続を推奨 |
|---|---|
| キーボード、マウス（ワイヤレスレシーバー含む） | ポータブルHDD、SSD |
| USBメモリ | ビデオキャプチャーカードなど高帯域の機器 |
| プリンター、ドングル | ゲーミング向け高レポートレート機器（ご注意ください） |
| シリアルモジュール、センサー（TTLポート推奨、04参照） | |

- **ドライバー不要**：Windows / macOS / Linux / 中国国産OSでプラグアンドプレイ；
- 仕様は **USB 2.0** です。上表に従って機器を選択してください。
