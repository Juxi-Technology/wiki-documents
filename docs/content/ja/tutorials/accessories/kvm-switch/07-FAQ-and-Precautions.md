# 07 · よくある質問と注意事項

> [← 概要に戻る](/ja/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜対象製品：JUXI Technology（鉅犀科技）KVM&HUB&TTL
> 各モジュール固有の質問は該当ページをご覧ください（Bluetooth → 03、TTLシリアル → 04）。

## よくある質問

**Q1：ディスプレイの映像を切り替えられますか？**
いいえ。本製品が切り替えるのはキーボード・マウスとUSB機器です。2台のPCはそれぞれ自分のディスプレイに接続し、ディスプレイのないホストはキャプチャーカード方式を使用します（[06](/ja/tutorials/accessories/kvm-switch/06-Headless-Host-Capture-Card-and-OBS) 参照）。

**Q2：ドライバーのインストールは必要ですか？**
不要です。ドライバーなしで動作します（Windows / macOS / Linux / 中国国産OS）。

**Q3：ポータブルHDDを接続できますか？**
本製品はUSB 2.0です。高速ストレージやキャプチャーカードはPCへの直接接続を推奨します。USBメモリ、キーボード・マウス、プリンター、ドングルなどは問題ありません。

**Q4：スマホのBluetoothに接続できない / PINコードを求められる？**
システムのBluetooth「ペアリング」は使わず、**BleUart** Appをインストールしてアプリ内で接続してください（[03](/ja/tutorials/accessories/kvm-switch/03-Bluetooth) 参照）。

**Q5：スマホとPCが同時にBluetooth接続できますか？**
できません——同時に接続できるホスト機器は1台のみです。PC側の**シリアルポート**（USB）は影響を受けず、同時に使用できます。

**Q6：切替時にUSB機器が一瞬切断されますか？**
正常です：機器は切替に伴ってPC間を「移動」し、もう一方のPCが再認識します（機器によっては数秒かかります）。

**Q7：HUBとしてだけ使えますか？**
使えます。PCを1台だけ接続すれば3ポートUSB HUBになります（[02](/ja/tutorials/accessories/kvm-switch/02-HUB-Function-One-to-Three) 参照）。

**Q8：ゲーミングマウスに対応しますか？**
キーボード・マウスは標準USB 2.0 HIDで動作し、オフィスやデバッグ用途では体感差はありません。ゲーミング向け高レポートレート機器はご注意ください。

## 注意事項

- TTLポートの電圧レベルは **3.3V** です。5Vの信号レベルを入力しないでください。`3V3/5V` は**出力**ピンです——電源を逆流させないでください；
- USB 2.0の帯域には限りがあります。[02](/ja/tutorials/accessories/kvm-switch/02-HUB-Function-One-to-Three) の推奨に従って機器を選択してください；
- 分解・はんだ付けの改造はしないでください。静電気に敏感です——触れる前に除電してください；
- 製品の機能とインターフェースは実物を基準とします。本チュートリアルが更新された場合は、最新版を基準とします。
