# 04 · TTLシリアルポート（ワイヤレスシリアル）

> [← 概要に戻る](/ja/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜対象製品：JUXI Technology（鉅犀科技）KVM&HUB&TTL

## これは何か

6ピンTTLポートは**シリアルパススルーポート**です。開発ボードやセンサーなどを接続すると、そのシリアルデータが「同時に」2か所から出力されます（双方向）：

```
                ┌─→ PCシリアルポート（USB、システム認識名 "USB-BLE-SERIAL CH9143"）
外部機器 → 6ピン ┤
                └─→ Bluetoothワイヤレス（スマホ BleUart App、03参照）
```

**実測参考**：IMUセンサーを接続したところ、PCシリアルとBluetoothで同時に約1650バイト/秒のデータを安定して受信しました。

## ピン定義と配線

左から：`GND` `RXD` `TXD` `TNOW` `3V3` `5V`

| ピン | 説明 | 配線 |
|---|---|---|
| GND | グラウンド | 外部機器のGNDに接続（**必須**） |
| RXD | 本体の受信 | 外部機器の **TXD** に接続（クロス） |
| TXD | 本体の送信 | 外部機器の **RXD** に接続（クロス） |
| TNOW | 送信方向インジケーター | **未接続のまま** |
| 3V3 | 3.3V電源出力 | 低消費電力の周辺機器へ給電可（5Vとどちらか一方） |
| 5V | 5V電源出力 | 低消費電力の周辺機器へ給電可（3V3とどちらか一方） |

**要点**：送受信は必ず**クロス**接続。電圧レベルは **3.3V**。電源ピンは**出力**です——逆流させないでください。低消費電力モジュールのみ接続してください。

（図：チュートリアル素材 12 - TTL配線例）

## PC側での使用

1. 本製品をType-CでPCに接続（PC1/PC2どちらでも可）；
2. システムがシリアルポート **`USB-BLE-SERIAL CH9143`** を自動認識（Windows 10/11ではドライバー不要）；
3. シリアルツールで開く。パラメーター：**115200、8N1**；
4. 外部機器のデータがリアルタイムで受信できます（機器への送信も可能）。

## 開発ボードとの接続（Raspberry Pi / Jetson）

電圧レベル3.3Vのため、直接接続できます（クロス配線、GND接続）：

| 本製品 | Raspberry Pi | Jetson（Orinシリーズ 40ピン） |
|---|---|---|
| RXD | Pin8（GPIO14 / TXD） | Pin8（UART1_TXD） |
| TXD | Pin10（GPIO15 / RXD） | Pin10（UART1_RXD） |
| GND | 任意のGND（例：Pin9） | 任意のGND（例：Pin9） |

> Raspberry Piでは `raspi-config` でシリアルを有効化してください。Jetsonでは40ピンUARTを事前に有効化してください。
> 典型的な用途：開発ボードのシリアルをKVMに接続 → PCでコマンドを打ちログを確認、同時にスマホのBluetoothでも確認（ワイヤレスデバッグ）。

（図：チュートリアル素材 10 - Jetsonピン配置、11 - Raspberry Piピン配置）

## トラブルシューティング：シリアルデータがない？

順に確認してください：
1. 外部機器のTX/RXが**クロス**接続か、GNDは接続済みか；
2. 外部機器のボーレートが **115200** か；
3. 外部機器に給電されているか（本製品の5V/3V3ピンから給電可能）；
4. PCのシリアルポートが他のソフトに占有されていないか。機器を別のPCに切り替えるとポートは一時的に消えます（正常）。
