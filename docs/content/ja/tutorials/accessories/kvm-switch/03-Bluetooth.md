# 03 · Bluetooth機能

> [← 概要に戻る](/ja/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜対象製品：JUXI Technology（鉅犀科技）KVM&HUB&TTL

## Bluetoothの役割

本体にはBluetoothモジュールを内蔵しています（**6ピンTTLポートと同じシリアルチャンネルの「ワイヤレス側」**）。開発ボード/センサーをTTLポートに接続すると、そのデータはPCシリアルポートから出力されるだけでなく、**Bluetoothでも同時に出力**されます。スマホで接続すればワイヤレスでデータを送受信できます。

> 配線は [04 - TTLシリアルポート（ワイヤレスシリアル）](/ja/tutorials/accessories/kvm-switch/04-TTL-Serial-Port) を参照。Bluetooth接続とデータ送受信は**PC切替の影響を受けません**（どのPCに切り替えても接続は維持されます）。

## 動作の仕組み（まずはこちら）

⚠️ **Bluetoothは「リモコン」ではありません**——**ワイヤレスシリアルケーブル**です。「6ピンポートに接続した外部機器」と「スマホ/PC」の間のシリアルデータを伝送します。**外部機器が接続されていない場合、Bluetoothで接続しても何も表示されません。これは正常です。**

```
【外部機器】              【本製品】                  【あなた】
 開発ボード/センサー ──6ピン──> シリアルパススルー ──┬─ 有線 → PCシリアル（USB-BLE-SERIAL CH9143）
（データ生成/受信）                                 └─ 無線 → スマホ/PC Bluetooth（BleUart App）
```

**例1：IMU姿勢データをワイヤレスで確認**

1. IMUモジュールのTX/RX/GND/5Vを6ピンに接続（クロス接続・給電、04参照）→ IMUがデータ出力を開始；
2. 切替ボタンを約3秒長押ししてBluetoothモードへ（インジケーター点灯）；
3. スマホのBleUart Appで `CH9143BLE2U` に接続；
4. スマホに連続したデータフレームが即座に表示されます（実測で約80フレーム/秒の姿勢データ）；
5. 同時に、PC側のシリアルツールで `USB-BLE-SERIAL CH9143` を開いても、まったく同じデータが確認できます。

**例2：Raspberry Pi / Jetsonのワイヤレスデバッグ**

1. Raspberry PiのPin8(TXD)/Pin10(RXD)/GNDを6ピンにクロス接続；
2. Raspberry Piを起動すると、起動ログがシリアルから出力；
3. スマホのBleUartで接続すれば、**起動ログをワイヤレスで確認**できます；
4. Appで入力して送信すると、データは6ピンのTXDからRaspberry Piへ出力されます——スマホが**ワイヤレスシリアルコンソール**になります（ログイン・コマンド送信が可能）。

## スマホ接続手順（4ステップ）

1. **切替ボタンを約3秒長押し**し、インジケーターが点灯するまで待つ —— Bluetoothモードに入ります（アドバタイズ名：`CH9143BLE2U`）；
2. スマホにWCH公式アプリ **「BleUart」** をインストール（アプリストアで検索、無料）；
3. アプリを開く → 「Bluetooth接続」をタップ → リストから **CH9143BLE2U** を選択；
4. 接続成功（**パスワード不要**）——データの送受信が可能になります。

（図：チュートリアル素材 04 - 長押しでBluetoothモードへ）

## ⚠️ 重要なお知らせ

- **スマホのシステム設定にあるBluetooth「ペアリング」は使わないでください**：PINコードの入力を求められ、どの数字を入力しても成功しません——BLE機器は常に **BleUart App** で直接接続してください；
- Bluetoothモジュールは**同時に1台のホスト機器にしか接続できません**（スマホ接続中はPCからBluetooth接続できず、その逆も同様）。PC側の**シリアルポート**（USB）はこの制限を受けず、同時に使用できます。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| CH9143BLE2U が見つからない | もう一度ボタンを長押ししてインジケーターを点灯させる。10m以内にいることを確認 |
| PINコードを求められる / 接続できない | システムのペアリングを中止し、BleUart Appを使用 |
| Appで接続できない | 他の機器（PCなど）が接続中の可能性。他の接続を切断してから再試行 |
| 接続できたがデータがない | Bluetoothは6ピンポートのシリアルデータを伝送します。まず外部機器がTTLポートに接続されているか確認（04参照） |
