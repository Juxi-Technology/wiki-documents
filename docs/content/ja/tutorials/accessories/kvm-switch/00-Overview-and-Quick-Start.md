## 製品をひとことで

**2入力3出力のUSBキーボード・マウス切替器**：1組のキーボード・マウス（および周辺機器）を2台のPC間でボタン1つで切替。3ポートUSB HUB内蔵。さらに**ワイヤレスシリアル機能**——開発ボード/センサーのシリアルポートを6ピンヘッダーに接続すると、データが「PCシリアルポート + スマホBluetooth」へ同時にパススルーされます。

## インターフェース一覧

| 位置 | 名称 | 説明 |
|---|---|---|
| 左側 / 右側 | PC1 / PC2 ポート（Type-C） | 2台のPCをそれぞれ接続 |
| 底面 | USB-A × 3 | キーボード・マウス/USBメモリ/プリンターなど。切替に追従 |
| 上面 | 電源ポート（Type-C） | 補助電源（ホストの給電が不足する場合に使用） |
| 中央 | 切替ボタン | 短押しで切替、長押しでBluetoothモード |
| 左上 | 赤外線受光部 | 赤外線リモコンでの切替に対応 |
| 右下 | TTLシリアルポート（6ピン） | ワイヤレスシリアル機能（04参照） |
| 右下 | 10ピンヘッダー | 拡張インターフェース（05参照） |
| 右上 | Bluetoothモジュール（内蔵） | ワイヤレスシリアル機能（03参照） |

**インジケーター**：PC1/PC2（現在のチャンネル）｜電源｜UARTシリアル（送受信中に点滅）｜Bluetooth（長押し後に点灯）

## クイックスタート（5分）

1. PC A → Type-Cケーブル → **PC1** ポート、PC B → **PC2** ポート（1台のみでも可。その場合は単なるUSB HUBとして動作）；
2. キーボード/マウス（またはワイヤレスレシーバー）を任意の **USB-A** ポートに接続；
3. 切替ボタンを押し、**PC1/PC2インジケーター**で現在の接続先を確認；
4. ホストの給電が不足する場合は、**電源ポート**にもType-C給電を接続。

## 2つの重要なお知らせ

- 本製品は**映像の切替は行いません**：各PCはそれぞれ自分のディスプレイに接続します。ディスプレイのないホストはキャプチャーカード方式をご利用ください（06参照）；
- 本製品は **USB 2.0** です：キーボード・マウス/プリンター/USBメモリ/ドングルには十分です。高速ストレージなどはPCへの直接接続を推奨します。
