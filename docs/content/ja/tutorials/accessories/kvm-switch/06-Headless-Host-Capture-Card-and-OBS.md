# 06 · ディスプレイなしホスト（キャプチャーカード + OBS）

> [← 概要に戻る](/ja/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜対象製品：JUXI Technology（鉅犀科技）KVM&HUB&TTL

「ディスプレイのない開発ボード / マザーボード」にキーボード・マウスを接続したい——**ディスプレイを用意する必要はありません**。映像はキャプチャーカード経由でPCに入り、キーボード・マウスはKVMで切り替えます。

## 動作イメージ

```
開発ボード（ディスプレイなし）──映像──→ キャプチャーカード ──USB──→ お使いのPC（OBSウィンドウで表示）
開発ボード（ディスプレイなし）──キーボード・マウス──→ ←── KVM切替 ──→ お使いのPC（同じキーボード・マウス）
```

## 手順

**① 映像を接続**（ホストの映像出力を **4K HDMIキャプチャーカード** へ、カードのUSB側をお使いのPCへ）：

| ホストの出力 | 配線 |
|---|---|
| HDMI | HDMIケーブル → キャプチャーカード |
| Micro HDMI（Raspberry Piなど） | Micro-HDMI変換アダプター → HDMIケーブル → キャプチャーカード |
| DP | DP-HDMI変換アダプター → HDMIケーブル → キャプチャーカード |

**② キーボード・マウスを接続**：キーボード・マウス（またはワイヤレスレシーバー）を本製品のUSB-Aポートに接続し、ボタンを押して**開発ボード側へ切り替え**；

**③ 画面を見て操作**：PC上で **OBS** または **PotPlayer** に「映像キャプチャーデバイス」を追加すれば、開発ボードの画面を見ながらキーボードで操作できます。

（図：チュートリアル素材 06 - 開発ボード+キャプチャーカード実景、07 - キャプチャーカード配線、08 - OBS操作ガイド、09 - PotPlayer操作ガイド）

## ヒント

- キャプチャーカードは**PCへ直接接続**することを推奨します（KVMのUSBポートを経由しない）。映像が安定します；
- キーボード・マウスを切り替えた後、開発ボード側はキーボード・マウスに反応しなくなります——ボタンをもう一度押せば切戻せます。
