# 05 · 10ピン拡張ヘッダー

> [← 概要に戻る](/ja/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start)｜対象製品：JUXI Technology（鉅犀科技）KVM&HUB&TTL

本体右下の **10ピンヘッダー**は**拡張用に予約されたインターフェース**です。シルク印刷は以下のとおり：

| 列 | シルク印刷 |
|---|---|
| 上段 | `RI#` `DSR#` `FCE` `DTR#` `RST#` |
| 下段 | `CTS#` `DCD#` `GND` `GND` `GND` |

## 説明

- このポートは**外部コントローラーの接続やカスタムケーブルなどの二次開発**（シリアル制御信号関連）向けです；
- 通常の使用（キーボード・マウス切替、HUB、ワイヤレスシリアル）では**このポートに接続する必要はありません**；
- 本インターフェースの電気的定義と使用方法が必要な場合は、弊社までお問い合わせください（実物と最新の説明書が基準です）；
- ご自身で配線する前に、テスターで電圧レベルを確認し、機器の損傷を避けてください。
