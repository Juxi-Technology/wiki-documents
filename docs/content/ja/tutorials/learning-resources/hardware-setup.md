# ハードウェア接続

本章では製品のハードウェア接続方法を詳しく説明します。

## インターフェース説明

製品には以下のインターフェースがあります：

- USB-C：電源とデータ転送
- GPIO：汎用入出力インターフェース
- HDMI：映像出力

## 接続手順

1. **電源接続**：USB-C ケーブルで電源に接続
2. **周辺機器接続**：必要に応じて他の周辺機器を接続
3. **起動**：電源ボタンを押してデバイスを起動

## 注意事項

- 電源電圧が要件を満たしていることを確認
- 通電状態での GPIO デバイスの抜き差しを避ける
