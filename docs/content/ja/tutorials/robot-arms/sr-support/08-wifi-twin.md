# 08 WiFi とシミュレーションツイン

この手順は任意で、自己起立そのものには必要ありません。

## 8.1 ホットスポットとステータスページ

ホットスポット：SSID `SR-Support`、パスワード `srsupport`、アドレス `192.168.4.1`（`w` で切り替え。
起動時は既定でオン）。`w` はシリアル経由で送ります。シリアルモニタ/アシスタントの送信ボックスに `w` を
入力して Enter を押してください。シリアルツール / Windows 用 UartAssist のダウンロードは
[03 ページ 3.3 節](./03-build-flash.md)にあります。

ホットスポットに接続し、`http://192.168.4.1` を開きます（スマートフォンでは通常、ポータルが自動で
開きます）。ページは 300 ms ごとに更新され、状態、up ベクトルと直立度バー、関節指令、起き上がり姿勢/
フェーズ、家庭内 WiFi の状態、ツインストリームのスイッチが表示されます。ブラウザがプロキシを使用して
いる場合は、このアドレスの例外を追加してください。

## 8.2 プロビジョニング（家庭内 WiFi への接続）

ステータスページの Home WiFi カードで、`Scan` → ネットワークを選択 → パスワードを入力 → `Connect` の
順に操作します。成功すると ESP32 は AP+STA で動作します：

- ホットスポットは維持されます（ベンチ作業に影響しません）。
- ロボットは家庭内 LAN から到達可能になります（ページに `Robot IP` が表示されます）。
- 認証情報は NVS に保存され、起動時に自動で再接続されます。

2.4 GHz のみ対応です。起き上がりの実行中はスキャン/接続が拒否されます。

## 8.3 無線 MuJoCo ライブツイン

ステータスページで `Twin ON` を押し（シリアルの `d` と同じ）、次を実行します：

```bash
python tools/live_twin.py --tcp <Robot IP>:3333
```

（`SR-Support` フォルダで実行します。先に [02 ページ](./02-environment.md)のとおり `.venv` を作成・
有効化してください。ツール環境もそこでセットアップします。）

- ウィンドウは実際の姿勢をリアルタイムにミラーし、機体を床面に保ちます。
- アームはストールしたサーボと同様に床面との接触角で保持されます（床へのめり込みなし）。
- USB ケーブルが必要なのは書き込みとログのダンプ時のみです。
- `--replay <file>` で記録したログをオフラインで再生できます。

## 8.4 WiFi テレメトリのログ

```bash
python tools/tcp_log.py
```

ホットスポットのテレメトリストリームを `logs/wifi_<time>.txt` に保存します。オフラインでの再生と分析に使えます。

## 8.5 シミュレーションと学習のリファレンス

リポジトリには、再生と再学習のための MuJoCo モデルと学習コード（`training/b_line/`）が含まれています。モデルファイルの説明は [10 ページ](./10-reference.md)にあります。
