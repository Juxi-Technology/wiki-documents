# 11 リファレンス：モデル・パラメータ・ライセンス

## 11.1 リファレンスモデルファイル

シミュレーションは MuJoCo MJCF（`.xml` + `.stl` メッシュ）を使用し、ハードウェア自体の設計を共有しています：

| ファイル | 説明 |
|---|---|
| `hardware/v1/robot_v1.xml` | メインモデル（形状/質量をハードウェアに一致） |
| `hardware/v1/meshes/*.stl` | 4 つの印刷グループ（底板/シェル、肩マウント、上腕ブラケット/肘マウント、前腕）に組み上がる 6 つの STL メッシュ |
| `hardware/v1/meshes/print_mass_model.json` | パーツごとの印刷質量表（15% インフィル） |

URDF は同梱していません。ROS で使う場合は、上記の CAD/メッシュからエクスポートしてください。

## 11.2 ファームウェアパラメータ（`firmware/sr_support_b_ptk/include/config.h`）

| パラメータ | 値 | 意味 |
|---|---|---|
| `POLICY_DT` / `CTRL_PERIOD_US` | 0.02 s / 20000 µs | 50 Hz 制御周期 |

| `FALL_UP_Z` | 0.30 | フォールゲートの up_z しきい値 |

| `EXEC_SWITCH_W` | 0.8 rad/s | 切り替えを許可する最大角速度 |
| `EXEC_MIN_SWITCH_AGE` | 25 | 切り替えが可能になる最早 tick |
| `EXEC_MAX_SWITCHES` | 5 | 1 回の実行での最大切り替え回数 |
| `EXEC_NEUTRAL_MAX` | 120 | 中立収納の最大 tick 数 |
| `SERVO_SHOULDER_CENTER_US` | 1681 | 肩ゼロ点パルス（2026-11 に書き込んだ目視中心の値。再ゼロ点校正は [05 ページ](./05-zero-tool.md)） |

## 11.3 リファレンスシーケンス（肩、肘；rad；`training/b_line/getup_reference_b39.py` と値まで一致）

| 姿勢 | シーケンス |
|---|---|
| `roll_pos` | `[1.75,-0.90] → [-0.25,-0.90] → retract` |
| `roll_neg` | `[-1.80,0.70]` フルスピードの直接押し（ホールド ≤40 tick）→ ウェッジポンプ `[-1.80,0.35] → [-1.80,0.05]` ×2（各ホールド ≤30）→ フォールバック：`[0.35,0.70] → [0.35,1.10] → [-1.80,0.05]`（ホイップスラム、ホールド ≤40）→ 最終ホールド ≤90 → 収納 |
| `pitch_pos` | `[-1.32,1.45] → [-0.25,1.45] → retract` |
| `pitch_neg` | `[-1.32,-1.65] → [-0.25,-1.65] → retract` |

## 11.4 検証状況と工場検査（2026-11-06）

- **工場検査**：完成品は個体ごとに、サーボゼロ点の定義と書き込み（[05 ページ](./05-zero-tool.md)）、
  ジャイロ + 加速度ゼロ点のキャリブレーション（NVS）、出荷前の 4 方向起き上がりテストを受けます。
- 4 方向すべてが実機で検証済みで、いずれも**直接起き上がり**（転がりなし）、約 1〜6 秒。サーボエンベロープ
  違反はありません。
- `roll_neg` の最終レシピ：フルストロークの直接押し + 肘ウェッジポンプ ×2、フォールバックとして
  ホイップスラムのリトライ（以前の転がり + 再計画方式は廃止）。
- 姿勢パイプラインは加速度バイアスのキャリブレーションで修正され（[06 ページ 6.2 節](./06-debug-and-calibrate.md)参照）、
  横倒し姿勢が実機と一致するようになりました。
- `roll_neg` は 1× 質量のシミュレーションモデルでは依然として再現しません（アームの質量/摩擦が異なるため）。
  これは既知のモデルのギャップであり、実機ファームウェアは実機で検証されています。
