# 04 組立：プリント・組み立て・配線

> **完成品ユーザーはこのページをスキップできます**：工場でプリント、組立、配線、検査が完了しています
> （[index](./index.md) の出荷状態の節を参照）。このページは部品から組み立てる場合、または部品を交換
> する場合にのみ従ってください。

## 4.1 プリントと検査

1. 底板、肩サーボマウント、肘サーボマウント、トップストラットを印刷します（各 1 個）。
2. ベースの外形（約 88 × 82 mm）と全高（約 68 mm）をノギスで確認します。
3. 25T サーボホーンをスロットに仮合わせします。干渉がない場合にのみネジで固定します。
4. 印刷パーツをすべて計量し、`hardware/v1/meshes/print_mass_model.json` と照合して記録します。

## 4.2 サーボの準備（ファームウェアのゼロ点とホーンの取り付け）

1. **先に配線して書き込む**：4.4 の表に従って両サーボ、IMU、サーボ電源、コモングラウンドを配線し
   （機械パーツはまだ取り付けません。メインファームウェアは起動に IMU を必要とします）、
   [03 ページ 3.1 節](./03-build-flash.md)に従ってメインファームウェアを書き込みます。
2. **ファームウェアのゼロ点まで通電する**：115200 のシリアルポートを開き（シリアルツール /
   UartAssist のダウンロードは [03 ページ 3.3 節](./03-build-flash.md)）、電源を入れます。起動後、
   ファームウェアは両サーボを q=0（センターパルス 1681 / 1456 µs）まで駆動します。ログに
   `servo start q: 0.00 0.00 rad` と `ready; send g to run`（または `autorun on: ...`）が表示されたら、
   サーボはゼロ点にあります。
3. **電源を切る**：サーボ電源を切ります（USB は接続したままで構いません）。両サーボに負荷が
   かかっていないことを確認します。
4. **ホーンを取り付ける**：上腕が垂直になるように肩ホーンを取り付け、前腕がそれと一直線になるように
   肘ホーンを取り付けます。締め付けて、手で全可動範囲を確認します。
5. 方向の規約（シミュレータと一致）：`shoulder +q` は大アームを **−Y** 方向へ、`elbow +q` は前腕を
   **+X** 方向へ動かします。ファームウェアの既定値は `SERVO_SHOULDER_SIGN=-1`、
   `SERVO_ELBOW_SIGN=-1` です。

> ファームウェアのセンターパルス 1681 / 1456 µs には、工場でのキャリブレーションによるホーン歯位置の
> 再設定がすでに織り込まれています。**歯数を数えないでください**：アームを垂直にした状態で、
> ファームウェアのゼロ点でホーンを取り付けてください。別方法（同等、任意）として、シリアル送信ボックスで
> `e` を入力して Enter を押すと両サーボが 1520 µs の電気的中立位置に移動するので、そこで取り付けることも
> できます（[03 ページ](./03-build-flash.md)のコマンド表参照）。いずれの場合も、最終的な精密なゼロ点は
> [05 ページ](./05-zero-tool.md)の `z` コマンドで合わせます。

> ファームウェアのゼロ点での取り付けは**粗いセンタリング**にすぎません（ホーンのスプラインは離散的です）。
> 精密なゼロ点は、組立完了とメインファームウェアの書き込み（[03 ページ](./03-build-flash.md)）の後に
> [05 ページのゼロ点ツール](./05-zero-tool.md)で設定する必要があります。目視で垂直な姿勢を q=0 と宣言し
> （`z` は IMU を使わないためどの姿勢でも動作します）、表示されたパルス幅を `config.h` に書き込んで
> 再書き込みします。ホーンを完璧に取り付けられなくても、このゼロ点校正で補正できます。片側の可動範囲が
> 不足する場合（パルスが 500/2500 µs でクランプされる場合）にのみ、ホーンを抜いて歯位置を変更する必要が
> あります。ホーン歯位置は可動範囲が両側にどう配分されるかを決めます。ファームウェアの手動リミット
> （`Q_SHOULDER_MIN/MAX`）は実際の可動範囲と一致させる必要があり、**広げないでください**。ゼロ点校正後は、
> 05 ページの説明に従ってすべてのシーケンスのウェイポイントをシフトしてください。そうしないと実際の
> 起き上がり姿勢がずれます。

## 4.3 ベースとアームの組立

1. 底板と肩サーボマウントを M3 ネジで固定してベースを組み立てます（高さ約 68 mm）。
2. 肩サーボを肩マウントに取り付けます（ホーンを上向き）。
3. 肘サーボマウントを肩ホーンに取り付けて締めます（これが上腕になります）。肘サーボを肘マウントに
   取り付けます。
4. トップストラット（前腕）を肘ホーンに接続します。
5. アームを手で垂直（`q≈0`）に動かし、サーボのセンターと一致することを確認します。

## 4.4 配線

| デバイス | ESP32-S3 ピン | アダプタ | 備考 |
|---|---|---|---|
| アダプタ 3V3 | 3V3 | S1 信号ピン | もう一端は IMU VCC（3.3 V）へ |
| 肩信号 | GPIO4 | S4 | 50 Hz PWM |
| 肘信号 | GPIO5 | S5 | 50 Hz PWM |
| IMU SDA | GPIO6 | S6 信号ピン | もう一端は IMU SDA へ；I²C 0x23、100 kHz |
| IMU SCL | GPIO7 | S7 信号ピン | もう一端は IMU SCL へ；I²C 0x23、100 kHz |
| IMU GND | GND | —（直結） | コモングラウンド |
| LED（任意） | GPIO2 | — | ステータス LED |
| 5 V 電源入力 | 5V / GND | — | 1-to-2 ケーブル：一方を ESP32 へ、他方をアダプタの V+/GND（サーボ用）へ |
| サーボ電源 | — | V+/GND 端子 | 5 V / ≥5 A；**より高い電圧は必ずこの端子のみを使用し、ESP32 の 5V には絶対に接続しない** |
| S2 / S3 | — | — | 未接続 |

注記：

- アダプタはパッシブなパススルーです：S1/S6/S7 は信号ピンで 3V3 / SDA / SCL を伝え、S4/S5 はサーボ信号を
  伝えます。各ヘッダの V+/GND/信号の並び順を確認してください。極性を逆にするとサーボやボードが破損します。
- I²C 配線は短くし、サーボ配線から離してください。モジュールのプルアップは 3.3 V です。
- **5 V** 電源の場合、ESP32 の 5V/GND に給電し、同じ電源をアダプタの V+/GND（サーボ用）へ分岐しても
  構いません。より高い電圧（6 V / 7.4 V）はアダプタの V+/GND にのみ供給し、ESP32 は USB から給電して
  ください。
- **5 V バッテリーで ESP32 に給電している場合、Type-C を接続したままにできます**：公式 DevKitC-1 の
  回路図では各 USB VBUS がショットキーダイオードを経て 5V ネットに到達するため、逆流はなく、USB は
  データ（および補助電源）として機能します。ダイオードを省略した互換ボードの場合、または確認できない
  場合は、書き込み中は ESP32 への 5 V 分岐を外し、USB から給電してください（方法 2）。
- **デバッグ/書き込み中の給電（どちらも正常。1 つ選ぶ）**：
  1. 5 V 電源が分配ケーブル経由で ESP32 とサーボに給電し、USB はデータのみを伝送する。
  2. 考え方がより簡単：ESP32 への 5 V 分岐を外し、ESP32 は USB のみから給電し、5 V 電源はサーボにのみ
     給電する。
  書き込み、シリアルモニタリング、`c` キャリブレーションには方法 2 を使用し、単体動作には方法 1 を
  使用してください。
- 初回の電源投入時はサーボを未接続のままにし、テスターで V+ の極性と電圧を確認してから、1 個のサーボ、
  次に両方のサーボをテストしてください。
- 配線順序：グラウンドと信号 → 5 V 電源（ESP32 とサーボ同時）→ 必要に応じてシリアルポート用 USB。
  電源を切るときは逆順にします。

## 4.5 IMU の取り付け向き

IMU はネジでベースに固定されます（向きは調整できません）。そのためファームウェアは `IMU_YAW90` を有効にして、IMU 座標系の up ベクトルを機体座標に変換します。

```c
up_body = (up_imu.y, -up_imu.x, up_imu.z)
```

**機械的な向きの確認**（サーボ取り付け後、通電前に可能）：IMU モジュールに印刷または記載されている軸を基準に、

- 肩サーボの**出力軸**（ホーンを取り付ける軸。ホーン軸やギア軸とも呼ばれます）が IMU の **−Y** を向いている。
- 肘サーボの出力軸が IMU の **+X** を向いている。

下から上へ、2 つのサーボは**肩（下）→ 肘（上）**です。ホーンの取り付けや配線の際に入れ替えないでください。

この 2 方向が機体の肩軸と肘軸です。ハードウェアと一致しない場合は、IMU またはサーボマウントの取り付け向きが誤っています。通電前に修正してください。

通電後は [06 ページ](./06-debug-and-calibrate.md)で再確認してください：直立時は `up≈(0, 0, 1)` になり、4 つの横倒し姿勢は 6.5 の表に記載されています。
