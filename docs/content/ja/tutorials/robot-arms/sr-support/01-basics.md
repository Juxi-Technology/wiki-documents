# 01 基礎知識

## 1.1 動作原理

SR-Support は 2-DOF（肩 + 肘）のアクティブ自己起立デバイスです。

- **機構**：2 関節アームが方形ベースに搭載され、肩関節は機体の長軸まわりに揺動し、肘関節は
  前腕を折り畳みます。
- **センシング**：6 軸 IMU が姿勢クォータニオンを提供し、ファームウェアが機体座標系の up
  ベクトルから転倒を 4 つの姿勢（`pitch_pos/neg`、`roll_pos/neg`、[06 ページ](./06-debug-and-calibrate.md) 6.5 参照）
  のいずれかに分類します。
- **アクチュエーション**：リファレンスシーケンス実行器。各姿勢にはウェイポイント列
  （ウェイポイントごとに 20 tick、スルーレート 0.08 rad/tick）があり、アームを地面について
  押し、機体を転がして直立させます。`roll_neg` ではさらに肘による「ウェッジポンプ」と
  ホイップスラムのフォールバックを使用します。
- **フォールバック**：14 秒タイムアウト、姿勢の再計画、フォールゲート後の自動リトライ。
  `roll_neg` は段階ごとの適応ホールドを使用し、直立した時点で即座にアームを収納します。
- **検証済み**：4 方向とも約 1〜6 秒で直接起き上がります。同じモデルが MuJoCo シミュレーションと
  実機ライブツイン（[09 ページ](./09-mujoco.md)）を駆動します。

## 1.2 概要

| 項目 | 仕様 |
|---|---|
| ベース | 約 88 × 82 mm、高さ 68 mm（底板 + 肩サーボマウント、3D プリント） |
| アーム | 肩軸はベース上 56 mm、肘は肩の 40.1 mm 上。前腕ストラットは約 17 cm（12 mm 管） |
| 質量 | 約 133 g（モデル質量表：foot 92.1 / arm1 20.7 / arm2 20.1 g、サーボ 2 個を含む） |
| 肩 | PTK7452MG；手動リミット `[-1.85, +1.82]` rad（シミュレーションの関節範囲 `[-1.07, +2.07]`） |
| 肘 | PTK7452MG；手動リミット `[-0.90, +0.70]` rad（機械的には約 ±1.55 rad） |
| コントローラ | ESP32-S3-DevKitC-1（Arduino framework / PlatformIO） |
| 姿勢 | Juxi ICM42670P 6 軸 IMU（I²C アドレス 0x23、100 kHz） |
| サーボ駆動 | ESP32 LEDC、50 Hz、14 bit、パルス幅 500〜2500 µs |
