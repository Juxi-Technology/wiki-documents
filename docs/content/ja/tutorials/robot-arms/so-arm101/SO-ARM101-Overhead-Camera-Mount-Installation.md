# オーバーヘッドカメラマウント取付ガイド

> **[ストアで購入](https://www.juxitech.com/ja/products/overhead-camera-mount-for-so-arm100-so-arm101-realsense-compatible)**


- USB 自動フォーカスカメラの調整は [USB自動フォーカスカメラチュートリアル](https://juxitech.feishu.cn/docx/JXstdNbN6oiL1WxiqJrc2OJDnrf) を参照
- D405C 深度カメラキットをご購入の方は、注文番号をタオバオのカスタマーサービスに送信することで、[RealSense D405C チュートリアル](https://juxitech.feishu.cn/wiki/OSElwwOmYiVMNTkzo56c40g8nQe) のパスワードを問い合わせできます
- [公式モデルファイル](https://github.com/TheRobotStudio/SO-ARM100/tree/main/Optional/Overhead-Cam-Mount-Webcam) が必要です
