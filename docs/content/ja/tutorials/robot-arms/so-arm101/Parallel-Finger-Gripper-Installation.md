# 平行指グリッパー取り付けチュートリアル

**平行指グリッパー取り付け手順.mp4**（平行指夹爪安装步骤.mp4、サイトの単一ファイル上限を超えているため、support@juxitech.com までご請求ください）

![8.png](../../../../../public/images/tutorials/robot-arms/so-arm101/Parallel-Finger-Gripper-Installation/1.jpg)

## 1、4本の小ネジを緩めて、背面カバーを取り外す

## 2、5本のネジを使用して6番のサーボをカップリングに取り付ける

## 3、Feetech上位機を使用して中央位置キャリブレーションをクリックする（グリッパーを閉じたままにしてください！）

**Feetechサーボデバッグツールをダウンロード**

- Windowsパソコン

https://gitee.com/ftservo/fddebug

ダウンロード[`FD1.9.8.5(250729).7z`](https://gitee.com/ftservo/fddebug/blob/master/FD1.9.8.5(250729).7z)、解凍し、中のexeプログラムを実行します

- Ubuntuパソコン

https://github.com/Kotakku/FT_SCServo_Debug_Qt

1. Feetech上位機デバッグツールを開き、COMポート番号を選択し、ボーレートを100万に設定して、「開く」をクリックします

2. 「検索」をクリックし、「STS3215」が表示されたら、「停止」をクリックして、「STS3215」をクリックします

3. 上部の「プログラミング」を選択します

4. 「中央位置キャリブレーション」をクリックします

## 4、円柱を位置合わせし、背面カバーを取り付ける

## 5、4本の小ネジを締め戻す

## 6、4本の小ネジでサーボ固定ブラケットを取り付ける

## 7、6本の小ネジでカメラブラケットを取り付け可能なサーボ固定ブラケットを取り付ける

## 8、4本のワッシャー付きネジでカメラをブラケットに取り付ける

## 9、2本の小ネジでカメラブラケットをサーボ固定ブラケットに接続する

## 10、アダプターを5番サーボのホーンディスクに取り付ける

## 11、アダプターを平行指グリッパーに接続する
