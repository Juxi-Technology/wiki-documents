# Windowsコンピューター

`デバイスマネージャー`を開き、先に`フォロワーアーム（Follower）`を接続し、次に`リーダーアーム（Leader）`を接続して、対応するCOMポート番号を確認します

![image\.png](/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## 自分のポート番号を記録する

フォロワーアーム（Follower）：

COM6

リーダーアーム（Leader）：

COM7
