# ステップ2:シリアルポート番号の確認（Windows）

`デバイスマネージャー`を開き、先に`フォロワーアーム`を接続し、次に`リーダーアーム`を接続して、対応するCOMポート番号を確認します

![image.png](../../../../../../../public/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## 自分のポート番号を記録する

フォロワーアーム：

COM6

リーダーアーム：

COM7
