# 4 · テレオペレーション

> **前へ:** [03 接続とキャリブレーション](03-Calibration.md)
> **次へ:** [05 データセットの記録](05-Record-Dataset.md)

リーダーアームを手で動かすと、フォロワーがその動きをコピーします。これがデモンストレーションを記録する方法であり、キャリブレーションを確認する最短の方法です。

## 実行

1. **Teleoperation** タブを開きます。
2. ポートとキャリブレーションプロファイルを確認します——LeLab はキャリブレーション時のものを記憶しています。
3. テレオペレーションを開始します。
4. リーダーアームを動かします。

実行中、タブは関節位置を配信します。終わったら停止を押します。

**フォロワーを待機させるのは停止です。** タブを閉じたりプロセスを kill したりすると、アームはその場に留まります。

## 確認すること

| 確認項目 | 理由 |
|---|---|
| フォロワーが遅れやぶれなく滑らかに追従する | 粗い追従は使えない訓練データになります |
| フォロワーの可動範囲がリーダーと一致する | 途中で止まる、または限界に当たるなら、いずれかの関節が誤キャリブレーションです——[3 ページ](03-Calibration.md)に戻ってください |
| 両アームが同じ方向に動く | フォロワーが反転しているなら、関節が間違った方向でキャリブレーションされています |
| 可動限界で何も衝突しない | 使う予定の全範囲を通して動かしてください |

動きがおかしいが壊れてはいない場合——ずれ、1 つの関節の反転、範囲不足——補正するのではなく再キャリブレーションします。誤キャリブレーションのアームは、ポリシーに間違ったことをさせるデータセットを生みます。

## カメラ

カメラが設定されていれば、テレオペレーション表示にそのプレビューが出ます。

- リストカメラ：グリッパーと、これから掴むものを映していますか？
- 固定カメラ：作業空間全体を映していますか？
- どちらかの映像が横倒しや逆さまではありませんか？ 記録の前に[キャリブレーションタブ](03-Calibration.md)で **rotation** を直してください。

テレオペレーション中に記録されたフレームが、ポリシーが見る唯一のものです。
