# 3 · 接続とキャリブレーション

> **前へ:** [02 インストールと起動](02-Install.md)
> **次へ:** [04 テレオペレーション](04-Teleoperation.md)

キャリブレーションは各関節のゼロ点と可動範囲を記録します。アームごとに 1 回行い、分解した後やキャリブレーションファイルを失った場合はやり直します。

## 始める前に

- 両アームを組み立て済み、サーボに ID を設定済み。
- 両アームに通電済み。
- アームごとに USB ケーブル 1 本を、**2 つの別々の USB ポート**へ——共有ハブでは不安定に列挙されることがあります。

### Linux：シリアル権限

```bash
sudo usermod -aG dialout $USER
```

その後**ログアウトして再ログイン**します。これがないと、LeLab はアームを見つけてもすべての読み取りが権限エラーで失敗します。Windows と macOS では不要です。

## どちらのアームがどちらか

| アーム | LeRobot の名前 | LeLab での呼び方 |
|---|---|---|
| 手で動かす方 | `so101_leader` | **teleop** |
| 追従する方 | `so101_follower` | **robot** |

リーダーを先にキャリブレーションします。2 つを取り違えると、キャリブレーション直後のアームがおかしな動きをするよくある原因になります。

## 手順

**Calibration** タブを開き、一度に 1 本のアームを進めます：

1. **デバイスを選ぶ**——リーダー（teleop）かフォロワー（robot）。
2. **シリアルポートを選ぶ。** LeLab が見えている USB シリアルデバイスを一覧表示します。見分けるには、一方のアームを抜いてどの項目が消えるか確認します。選択は記憶されます。
3. **キャリブレーションプロファイルを選ぶ**——既存のものか新規。プロファイルは保存されたゼロ位置を保持します。このアームを以前にキャリブレーションしたなら、そのプロファイルを再利用します。
4. **ガイド付きの手順に従う。** LeLab が各関節を順に案内します。関節を求められた位置へ動かして確認します。キーボード入力はありません。
5. **もう一方のアームでも繰り返す**——それ自身のプロファイルとポートを使います。

> 各プロファイルは 1 本の物理アームに属します。2 本のアームを入れ替えると再キャリブレーションが必要です。

## カメラ

カメラは同じタブで設定します。各カメラの名前（`front`、`wrist`、…）はポリシーが見るキーなので、訓練ログで見分けられる名前を使ってください。

カメラはキャリブレーションの前後どちらでも取り付けられます。キャリブレーションはカメラに依存しません。ただし割り当ては固定してください——記録時と推論時で `wrist` と呼ばれる物理カメラを入れ替えると、訓練済みポリシーが意味不明な動きをします。

### 回転

カメラが逆さまか横倒しに取り付けられている場合は、**Rotation** を設定します：0°、90°、180°、270°（時計回り）。逆さまのリストカメラは 180° です。

回転はカメラごとに保存され、セットアッププレビュー、テレオペレーションプレビュー、記録したフレーム、推論に適用されます。回転設定のないプロファイルは 0° として扱われます。

- **90° と 270° は出力の寸法を入れ替えます。** 640 × 480 のキャプチャは 480 × 640 になります。
- **チェックポイントの画像寸法は向きを明かしません。** 0° と 180° は同じ寸法でも画像は逆になります。推論の前に、記録時に使った回転を設定してください——[6 ページ](06-Train-and-Inference.md)を参照。

## 保存されるもの

| ファイル | 内容 |
|---|---|
| `~/.cache/huggingface/lerobot/calibration/teleoperators/so101_leader/*.json` | リーダーのプロファイル |
| `~/.cache/huggingface/lerobot/calibration/robots/so101_follower/*.json` | フォロワーのプロファイル |
| `~/.cache/huggingface/lerobot/ports/leader_port.txt` | リーダーのシリアルポート |
| `~/.cache/huggingface/lerobot/ports/follower_port.txt` | フォロワーのシリアルポート |

これらは `~/.cache/` の下にあるため、キャッシュを消去するツールが削除することがあります。キャリブレーション済みのアームがまたキャリブレーションを求められたら、ここを確認してください——[トラブルシューティング](07-Troubleshooting.md)を参照。
