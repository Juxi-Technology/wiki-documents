# LeRobotを知る

## 身体性知能とは？

身体を備えた知能です。AIをさまざまなハードウェア実体に接続します。例えば：

四足ロボット犬、二足歩行ヒューマノイドロボット、車輪脚ロボット、ドローン、自動運転車

## LeRobotとは？

LeRobotはHuggingFaceのオープンソース`身体性知能ロボットソフトウェアフレームワーク`です

Githubアドレス：https://github.com/huggingface/lerobot

低いハードルでの実現：強化学習と**模倣学習（VLA）**の**データ収集、アルゴリズムトレーニング、推論デプロイ**、その中で最も主要なのは**模倣学習（VLA）**です

- どのようなロボットをLeRobotで開発できますか？

1000元クラスのSO-ARM 101ロボットアーム、LeKiwi小型車から、数万元の松灵piperロボットアーム、华馨京StarAIロボットアーム、Hope-JR器用なハンド、十数万元の宇树G1ヒューマノイドロボットまで。LeRobotはすでに身体性知能業界における、データ収集とアルゴリズムトレーニングの規範となっています。

自分のロボットをLeRobotフレームワークに適合させることもできます。

- LeRobotデータセットとモデル

LeRobotは独自の模倣学習データセット形式を定義しており、HuggingFace上のすべての公開データセットとモデルを閲覧、使用、ダウンロード、トレーニングでき、自分のデータセットをHuggingFaceにアップロードすることもできます

## SO-ARM 101ロボットアームとは？

本教程ではSO-ARM 101ロボットアームを例に、3Dプリントの構造部品とFeetechサーボを採用しており、コストは非常に低いです。

これは貧しい学生でも買える身体性知能の本体であり、LeRobot公式が推奨する本体の一つでもあります。

ロボットアームはリーダーアーム（Leader）とフォロワーアーム（Follower）の2つのロボットアームを含みます。各ロボットアームは6つの自由度（5つの関節自由度 + 1つのグリッパー自由度）を備えています。

## 必要なパソコンのスペックは？

普通のWindowsノートパソコン1台で、トレーニング前のすべての操作を完了できます

普通のMac1台で、すべての操作を完了できます

NVIDIAグラフィックスカードを搭載したUbuntuパソコン1台で、すべての操作を完了できます

本教程では、[クラウドGPUプラットフォーム](https://featurize.cn?s=d7ce99f842414bfcaea5662a97581bd1)を使ってモデルをトレーニングするため、自分のパソコンに高いスペックは必要ありません

## **模倣学習とVLA**とは？

人間がロボットを引っ張って教示しデータセットを収集し、データセットを形成します。次にこのデータセットで模倣学習アルゴリズムをトレーニングし、最終的にロボットにデプロイすることで、ロボットが人間の動作を自律的に模倣し、実環境に汎化できるようにします。テレオペレーションやリモコン操作は不要です。

例えば上の動画では、人間がSO-ARMロボットアームを引っ張ってザリガニをつかみ、調味料に浸し、油の鍋に入れ、最終的にロボットアームがこの動作を自律的に完了できるようにしています。新しいザリガニが来ても、いつでも反応して動作を完了できます。

模倣学習にはまた、先端的で流行の名前があります：VLA（視覚言語行動大規模モデル）。これも現在、発展が最も迅速で、投資が最も活発で、米中競争が最も激しく、オープンソースエコシステムが最も繁栄し、メディアが高度に注目し、無数の修士・博士がこぞって参入する身体性知能の研究領域です。

LeRobotが最も主要に適合させているアルゴリズムが模倣学習です。例えばACT、Diffusion Policy、SmolVLA、Pi0、Pi0.5、Wall-OSSなど。

本教程の模倣学習はVLAのみです。
