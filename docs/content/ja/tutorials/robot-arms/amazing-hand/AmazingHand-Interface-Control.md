## 公式リポジトリの例

Juxi Technology は AmazingHand 用のオープンソース制御コードを提供しています: [GitHub](https://github.com/Juxi-Technology/AmazingHand)

### 基本制御

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
