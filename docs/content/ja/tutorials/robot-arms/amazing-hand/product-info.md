# AmazingHand 器用なハンド製品資料

## 製品概要

AmazingHand は**高精度・軽量・ジェスチャートラッキング対応の器用なハンド**で、身体知能研究、ロボット教育、ヒューマンマシンインタラクション応用のために設計されています。本製品は 8 個の高精度 SCS0009 TTL シリアルサーボで制御され、右手、左手および両手機器人の操作に対応し、複雑なジェスチャー動作とリアルタイムトラッキング機能を実現します。

### 一、ハードウェア設計：高精度・軽量、デバッグしやすく拡張可能

- **サーボ構成**：単体の器用なハンドは**8 個の SCS0009 TTL シリアルサーボ**を採用し、2 個のサーボが協調して同じ 1 本の指を制御し、精密な運動制御と安定した把持能力を提供します。

- **軽量構造**：器用なハンドの総重量はわずか 0.416kg で、構造がコンパクトで、各種ロボットプラットフォームへの取り付けが容易です。

- **簡単な接続**：Type-C インターフェースで通信し、サーボドライバ基板と MEGA328P 開発ボードを組み合わせることで、プラグアンドプレイで、ハードウェア接続の手順を簡素化します。

- **モジュール設計**：右手、左手の単独構成に対応し、両手機器人の協調動作も可能で、さまざまな応用シーンに柔軟に対応します。

### 二、ソフトウェアエコシステム：ジェスチャートラッキングを統合し、AI 開発も容易

- **リアルタイムジェスチャートラッキング**：MediaPipe ベースのリアルタイム手部トラッキング技術により、Web カメラでジェスチャーを捉え、器用なハンドの模倣学習と追従制御を実現します。

- **分散データフロー**：**DORA 分散データフローエンジン**を採用し、ハードウェアとアルゴリズムの低遅延な連携を実現し、ジェスチャーデータからサーボ制御までの全リンクの疎通をサポートします。

- **シミュレーションとハードウェアの統一**：仮想シミュレーション環境を提供し、シミュレーションで制御アルゴリズムを検証した後、シームレスに実機へ移行できます。

- **オープンソースエコシステム**：制御コード、学習スクリプトおよびチュートリアルをオープンソース化し、二次開発と機能拡張をサポートします。

### 三、コア応用シーン：教育から研究まで、全シーンをカバー

1. **ロボット教育入門**：器用なハンドの組立、サーボデバッグ、基礎制御からジェスチャートラッキングまでの全工程チュートリアルを提供し、デモプログラムとサンプルコードを用意しており、未経験のユーザーでも素早く使いこなせます。

2. **身体知能研究**：**ジェスチャー模倣学習、ヒューマンマシンインタラクション**の研究に注力し、カメラで人間の手の動作を捉えて器用なハンドを訓練することをサポートします。典型的な応用：ジェスチャー制御、物体把持、人機協調などのタスク。

3. **ヒューマンマシンインタラクションプロトタイプ**：低コストでヒューマンマシンインタラクションの方案を検証し、**ジェスチャー制御、遠隔操作、VR/AR インタラクション**などのシーンに対応し、プロトタイプ検証を迅速に実現します。

### 四、製品の優位性

- **高コストパフォーマンス**：成熟したシリアルサーボ方案を採用し、コストを抑えられ、個人、研究室および教育機関の一括導入に適しています。

- **ジェスチャートラッキング**：ジェスチャートラッキング機能を内蔵し、追加の複雑な設備は不要で、通常のカメラで器用なハンドのリアルタイム追従制御を実現できます。

- **開発にやさしい**：完全なデバッグチュートリアル、デモプログラムおよび開発インターフェースを提供し、ハードウェアデバッグからソフトウェア制御まで素早く使いこなせます。

- **両手協調**：単手機器人の独立操作に対応し、両手機器人の協調動作にも対応し、異なる実験と応用のニーズに柔軟に対応します。
