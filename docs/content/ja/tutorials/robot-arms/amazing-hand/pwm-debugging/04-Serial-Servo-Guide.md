# 04-シリアルサーボバージョン-使用説明

SCS0009 公式バスサーボ版 — 使用説明

> **PWM サーボ版(ESP32-S3 + 8 チャンネル PWM)をご購入の場合は、本ディレクトリを無視してください**,
使用 `..\01_gui_control` または `..\02_hand_tracking` で構いません。

本ディレクトリで説明するのは AmazingHand **公式オリジナル SCS0009 バスサーボ**のサポート状況です。

## 現在の状態

本 delivery_package の `..\02_hand_tracking\Demo` は 2 種類のサーボバックエンドを同時にサポートし、設定によりシームレスに切り替えられます：

|バージョン|サーボ種類|ボーレート|設定ファイル|
|---|---|---|---|
|**PWM**(本パッケージの主要な成果物)|ESP32-S3 直接駆動 PWM|115200|`{l,r}_hand_pwm.toml`|
|**SCS0009**(公式オリジナル版)|公式バスサーボ|1,000,000|`{l,r}_hand.toml`|

- **PWM 版**：メニューで `3 - PWM 舵机(ESP32 直驱)` を選択し、本パッケージのチュートリアルを使用します。

- **SCS0009 版**：メニューで `2 - 真实硬件(SCS0009 总线舵机)` を選択します。

## SCS0009 版の使用方法

1. ハードウェア：公式バスサーボ + シリアルアダプタ(ボーレート 1M)。

2. デプロイ：`Demo\Windows_Scripts_CN\3-部署代码.bat`(または Linux の対応スクリプト)。

3. 実行：4-运行代码.bat → `2 - 真实硬件(SCS0009 总线舵机)` を選択 → ハンドの種類を選択。

4. 詳細な説明は `..\02_hand_tracking\Demo\双版本舵机并存说明.md`
および `Demo\Windows_Scripts_CN\Windows使用教程.md`(公式チュートリアル)を参照してください。

## 注意事項

- SCS0009 は公式サーボ id 設定が必要です(`{l,r}_hand.toml` に内蔵済み)、PWM 版には関係ありません。

- 2 種類のサーボは**同一時刻に 1 セットのみ接続します**、ハードウェア + メニューオプションを切り替えるだけです。

- 本パッケージは PWM 版を主要な成果物とします；SCS0009 の公式チュートリアルは公式 Demo を基準とします。
