## Como Contribuir

### 1. Escreva Tutoriais

Compartilhe sua experiência com o SO-ARM101 escrevendo tutoriais para ajudar outras pessoas.

**Para começar:**
- Escolha um tópico (cenários de aplicação, aprofundamentos técnicos, etc.)
- Siga a estrutura de tutorial existente
- Envie um Pull Request

### 2. Traduza a Documentação

Ajude-nos a traduzir a documentação para mais idiomas, para que mais utilizadors se beneficiem.

**Idiomas atuais:** chinês simplificado / inglês / chinês tradicional

### 3. Envie Casos

Compartilhe seus casos de uso e mostre os resultados dos seus projetos. Veja a [página de Histórias de Sucesso](/pt-pt/cases/).

### 4. Reporte Problemas

Encontrou um bug ou tem uma sugestão? Envie um Issue para nos ajudar a melhorar.

### 5. Contribuições de Código

Contribua com código para projetos open source relacionados, incluindo o LeRobot.
