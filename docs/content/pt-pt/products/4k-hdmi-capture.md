# Capturadora HDMI 4K

> **[Comprar na loja](https://www.juxitech.com/products/4k-hd-hdmi-capture-card)**

## Visão Geral

A capturadora HDMI 4K suporta interfaces de placa HDMI / Micro HDMI / DP por meio de adaptadores, conectando-se diretamente via USB/Type-C a notebooks, PCs e monitores — para streaming, gravação e demonstrações de ensino.

**Principais recursos**:

- Captura HD 4K
- Compatível com HDMI / Micro HDMI / DP
- Plug-and-play via USB / Type-C
- Suporte a OBS / PotPlayer

## Especificações

| Categoria | Especificação |
|----------|------|
| Entrada | HDMI / Micro HDMI / DP (adaptador) |
| Saída | USB / Type-C |
| Qualidade | HD 4K |
| Software | OBS / PotPlayer |

## Início Rápido

1. Escolha a conexão conforme a interface da placa (HDMI / Micro HDMI / DP)
2. Conecte a USB da capturadora ao dispositivo de exibição
3. Selecione o dispositivo de captura no OBS / PotPlayer
