# Suporte de Câmara Superior SO-ARM101

> **[Comprar na loja](https://www.juxitech.com/products/overhead-camera-mount-for-so-arm100-so-arm101-realsense-compatible)**

## Visão Geral

O suporte de câmara superior SO-ARM101 proporciona uma visão de cima para baixo, compatível com câmaras de profundidade RealSense e câmaras USB padrão. Ideal para recolha de dados de visão robótica (a visão superior beneficia os dados de treino LeRobot).

**Principais recursos**:

- Montagem superior
- Compatível com RealSense / câmaras USB
- Projetado para SO-ARM100/101
- Instalação fácil

## Especificações

| Categoria | Especificação |
|----------|------|
| Visão | De cima para baixo |
| Compatível | RealSense / câmaras USB |
| Plataforma | SO-ARM100/101 |

## Início Rápido

1. Monte o suporte nos pontos de fixação do SO-ARM
2. Instale a câmara (RealSense ou USB)
3. Conecte ao host, confirme com `python -m lerobot.find_cameras`
