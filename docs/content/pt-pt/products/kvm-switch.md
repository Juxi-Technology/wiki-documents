# Chaveador KVM 4-em-1

> **[Comprar na loja](https://www.juxitech.com/products/4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**

## Visão Geral

O chaveador KVM 4-em-1 combina comutação HDMI, serial TTL, Bluetooth e expansão USB para desenvolvimento e depuração de robótica. Troca com um clique entre hosts/monitores/periféricos do braço robótico.

**Principais recursos**:

- Comutação HDMI entre vários dispositivos
- Depuração por serial TTL (UART)
- Bluetooth sem fio
- Expansão via hub USB

## Especificações

| Categoria | Especificação |
|----------|------|
| Funções | Comutador HDMI + serial TTL + BT + HUB USB |
| Interfaces | HDMI / TTL / USB |
| Hosts | PC (Win/Linux), Jetson |

## Início Rápido

1. Conecte os dispositivos às respectivas portas
2. Alterne display/entrada via botão ou software
3. Serial TTL para depuração de Pi/Jetson
