## Introdução

O**Módulo Sensor de Frequência Cardíaca e SpO2**integra o**chip de frequência cardíaca e oxigênio no sangue MAX30102 da Maxim**a um microcontrolador de algoritmo integrado, permitindo a saída direta dos valores de frequência cardíaca e SpO2 sem exigir desenvolvimento adicional de algoritmos. Isso reduz significativamente a complexidade de integração do sensor e conserva os recursos do MCU host.

Usando medição óptica**PPG (FotoPletismografia)**o microcontrolador integrado processa os dados brutos do sensor para fornecer leituras precisas de frequência cardíaca e SpO2, com saída via interface I2C ou UART. O módulo inclui software host acompanhante para monitoramento e registro de dados em tempo real via PC, tornando-o ideal para wearables, monitoramento de saúde doméstico, rastreamento fisiológico de longo prazo e projetos de saúde embarcados — uma excelente escolha para desenvolvimento embarcado voltado à saúde.

- Chip MAX30102 Genuíno
- Microcontrolador de Algoritmo Integrado
- Detecção Óptica PPG
- Interface Dupla I2C/UART
- Monitoramento de Dados pelo Software Host
- Compatível com Múltiplas Plataformas

## Vantagens do Produto

### 01 Detecção de Alta Precisão, Estável e Confiável

Equipado com um**chip genuíno MAX30102 de alta precisão para frequência cardíaca e SpO2**e algoritmos profissionais de detecção de parâmetros fisiológicos, o módulo entrega leituras estáveis e confiáveis, adequadas para vários cenários de monitoramento de saúde de nível consumidor.

### 02 Microcontrolador de Algoritmo Integrado

O microcontrolador integrado processa os dados brutos do sensor para calcular os valores de frequência cardíaca e SpO2, e então envia os resultados via interface I2C ou UART. Não é necessário processamento complexo de sinal ou desenvolvimento de algoritmos, reduzindo drasticamente a dificuldade de desenvolvimento e o tempo de lançamento no mercado.

### 03 Detecção Óptica PPG, Medição Não Invasiva

Utiliza**FotoPletismografia (PPG)**para detecção não invasiva — sem coleta de sangue ou procedimentos invasivos. Basta posicionar a ponta do dedo contra a área de detecção do sensor e fixá-la com a alça incluída, tornando-o ideal para aplicações de monitoramento contínuo de longo prazo.

### 04 Software Host Acompanhante para Depuração Fácil

Um software host dedicado é fornecido — conecte o módulo ao seu PC via adaptador USB-serial para visualizar os dados de detecção em tempo real, permitindo depuração e registro de dados convenientes.

### 05 Interface de Comunicação Dupla, Adaptação Flexível

Suporta simultaneamente as interfaces de comunicação I2C e UART. O endereço I2C é fixo em 0x57, e a taxa de transmissão serial padrão é 9600. Selecione o método de comunicação que melhor se adequa aos requisitos do seu projeto e aos recursos de hardware.
