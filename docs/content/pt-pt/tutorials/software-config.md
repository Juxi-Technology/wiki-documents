# Configuração de Software

Este capítulo apresenta o método de configuração de software do produto.

## Requisitos de Sistema

- Node.js 18+
- Python 3.10+
- Git

## Etapas de Instalação

```bash
# Clone repository
git clone https://github.com/Juxi-Technology/your-repo.git

# Navigate to directory
cd your-repo

# Install dependencies
npm install
```

## Ficheiro de Configuração

Edite o `config.json` para configurar conforme necessário:

```json
{
  "port": 3000,
  "language": "zh-CN"
}
```
