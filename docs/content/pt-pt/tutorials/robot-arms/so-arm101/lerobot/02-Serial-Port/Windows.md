# Etapa 2: Ver a porta do dispositivo série (Windows)

Abra o `Gestor de Dispositivos`, ligue primeiro o `braço seguidor` e depois o `braço líder`, e verifique o número da porta COM correspondente

![image.png](../../../../../../../public/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## Registar os números das minhas portas

Braço seguidor：

COM6

Braço líder：

COM7
