## Exemplo do repositório oficial

A Juxi Technology fornece código de controle open source para a mão hábil de 4 dedos AmazingHand: [GitHub](https://github.com/Juxi-Technology/AmazingHand)

### Controle básico

O repositório contém um exemplo completo de controle em Python, com suporte ao protocolo de comunicação TTL. Após clonar o repositório, execute:

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```

### Protocolo de comunicação TTL

A mão hábil se comunica com o controlador host por meio de um barramento serial TTL. Consulte o README e o código-fonte do repositório para obter detalhes do protocolo.
