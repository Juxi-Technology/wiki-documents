# 02 · Função HUB (um para três)

> [← Voltar à visão geral](/pt-pt/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Produto aplicável: JUXI Technology KVM&HUB&TTL

## Como utilizar

**Uma entrada Type-C, três saídas USB-A** — com apenas um computador ligado, este produto é um HUB USB comum:

1. Ligue o computador à porta **PC1** (ou PC2) com um cabo Type-C;
2. Ligue teclado, rato, pen drive, etc. a qualquer porta **USB-A**.

Com dois computadores ligados, as 3 portas USB-A comutam entre eles como um conjunto (ver [01](/pt-pt/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

## Dispositivos suportados

| Compatíveis | Melhor ligar diretamente ao computador |
|---|---|
| Teclados, ratos (incluindo recetores sem fios) | Discos externos, SSDs |
| Pen drives | Placas de captura de vídeo e outros dispositivos de elevada largura de banda |
| Impressoras, dongles USB | Periféricos gaming com elevada taxa de polling (com cautela) |
| Módulos série, sensores (a porta TTL é melhor — ver 04) | |

- **Sem controladores**: plug-and-play em Windows / macOS / Linux / sistemas operativos nacionais chineses;
- A especificação é **USB 2.0** — escolha os dispositivos conforme a tabela acima.
