# Comunicação PC

## Ligação do dispositivo

Mova o interruptor de corrediça para o modo de porta série STC8

![Imagem 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## Abrir o assistente de depuração de porta série

- Abra o Uart Assistant, selecione o número da porta série correspondente e defina o débito em bauds para 115200,

![Imagem 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- Consulte o ficheiro lista de protocolos de palavras de comando / palavras de reprodução V1_中文 no pacote comprimido

![Imagem 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- Quando dizemos “小车前进”, o assistente de depuração de porta série imprime o protocolo correspondente

![Imagem 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- Introduza o comando correspondente de acordo com o ficheiro lista de protocolos de palavras de comando / palavras de reprodução V1_中文, e o módulo de voz reproduz o texto correspondente ao protocolo

![Imagem 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

É possível ouvir o módulo de voz a reproduzir normalmente.
