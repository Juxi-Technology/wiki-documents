# Hardware-Verbindung

Detaillierte Anleitung zur Hardware-Verbindung des Produkts.

## Schnittstellen

- USB-C: Strom & Daten
- GPIO: universelle Ein-/Ausgänge
- HDMI: Videoausgang

## Verbindungsschritte

1. **Strom anschließen**: USB-C-Kabel für Strom
2. **Peripherie anschließen**: nach Bedarf
3. **Einschalten**: Netzschalter drücken

## Hinweise

- Spannung im zulässigen Bereich prüfen
- Keine GPIO-Geräte im eingeschalteten Zustand an-/abstecken
