# 2-DOF-Gimbal

> **[Im Shop kaufen](https://www.juxitech.com/de/products/2-dof-servo-pan-tilt-unit)**

2-DOF-Kamera-Gimbal: unterstützt manuelle Tastatursteuerung sowie automatisches Farb-, Gesichts- und QR-Code-Tracking.
Hardware: 2 SCS009-Servos (Links-/Rechts-Drehung + Auf-/Ab-Neigung) + CH343-Treiberplatine für den seriellen Bus (Standard-Baudrate 1Mbps).
