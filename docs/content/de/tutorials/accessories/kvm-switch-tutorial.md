# KVM-Switch Anleitung

> **[Im Shop kaufen](https://www.juxitech.com/de/products/4-in-1-kvm-switch-hub-ttl-serial-bluetooth-docking-station)**


Der KVM-Switch bietet HUB-Funktion, TTL-Serial und Bluetooth-Modul.

## Modul-Funktionen

### 1. HUB

1× USB (Type-C) → 3× USB.

### 2. TTL-Serial

Pins (links nach rechts): GND RXD TXD TNOW 3V3 5V

### 3. Bluetooth

AT-Befehle oder Slave-Modus (Handy: 4.2-Protokoll).

## Dual-Switch

### 1. Gerät A + Gerät B (beide mit Display)

Tastenschalter & IR-Fernbedienung.

### 2. Mainboard (ohne Display) + Host (mit Display)

Umschalten per Taste.
