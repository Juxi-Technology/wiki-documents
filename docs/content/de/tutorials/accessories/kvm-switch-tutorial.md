## Modul-Funktionen

### 1. HUB

1× USB (Type-C) → 3× USB.

![1. HUB Function – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/2.png)

### 2. TTL-Serial

Pins (links nach rechts): GND RXD TXD TNOW 3V3 5V

![2. TTL Serial Port – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/3.png)

### 3. Bluetooth

![3. Bluetooth Module – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/4.png)

AT-Befehle oder Slave-Modus (Handy: 4.2-Protokoll).



## Dual-Switch

### 1. Gerät A + Gerät B (beide mit Display)

Tastenschalter & IR-Fernbedienung.

![1. Device A + Device B both ends have monitors – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/5.png)

### 2. Mainboard (ohne Display) + Host (mit Display)

Es genügt, zusätzlich ein 4K-HD-HDMI-Capture-Gerät an den Host anzuschließen und am Host mit Software wie OBS oder Potplayer den Bildschirm aufzunehmen.

![2. Motherboard without monitor + Host with monitor – 1](../../../../public/images/tutorials/accessories/kvm-switch-tutorial/6.png)

**Verkabelung des 4K-HD-HDMI-Capture-Geräts**

Je nach Mainboard-Schnittstelle gibt es die folgenden drei Verkabelungsvarianten:

**HDMI-Schnittstelle** → HDMI-Kabel → HDMI-Eingang des Capture-Geräts → USB/Type-C → Anzeige (z. B. Laptop, Computer, All-in-One, Handy/Tablet)

**Micro-HDMI-Schnittstelle** → Micro-auf-HDMI-Adapter → HDMI-Kabel → HDMI-Eingang des Capture-Geräts → USB/Type-C → Anzeige (z. B. Laptop, Computer, All-in-One, Handy/Tablet)

**DP-Schnittstelle** → DP-auf-HDMI-Adapter → HDMI-Kabel → HDMI-Eingang des Capture-Geräts → USB/Type-C → Anzeige (z. B. Laptop, Computer, All-in-One, Handy/Tablet)
