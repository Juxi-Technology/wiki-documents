# 02 · HUB-Funktion (eins zu drei)

> [← Zurück zur Übersicht](/de/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Gilt für: JUXI Technology KVM&HUB&TTL

## Verwendung

**Ein Type-C-Eingang, drei USB-A-Ausgänge** — mit nur einem angeschlossenen Computer ist das Produkt ein normaler USB-HUB:

1. Computer über Type-C-Kabel an **PC1** (oder PC2) anschließen;
2. Tastatur, Maus, USB-Stick usw. an einen beliebigen **USB-A**-Anschluss stecken — fertig.

Mit zwei angeschlossenen Computern werden die drei USB-A-Anschlüsse als Gruppe zwischen beiden Computern umgeschaltet (siehe [01](/de/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

(Abbildung: Tutorial-Material 02 – HUB eins zu drei)

## Welche Geräte unterstützt werden

| Unterstützt | Besser direkt am Computer anschließen |
|---|---|
| Tastaturen, Mäuse (inkl. Funkempfänger) | Externe Festplatten, SSDs |
| USB-Sticks | Video-Capture-Cards und andere Bandbreiten-intensive Geräte |
| Drucker, USB-Dongles | Gaming-Peripherie mit hoher Abtastrate (mit Vorsicht) |
| Serielle Module, Sensoren (TTL-Anschluss besser — siehe 04) | |

- **Treiberfrei**: Plug-and-Play unter Windows / macOS / Linux / chinesischen Inlands-Betriebssystemen;
- Spezifikation ist **USB 2.0** — wählen Sie Geräte gemäß obiger Tabelle.
