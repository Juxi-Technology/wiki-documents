# Weckwort und Befehlswörter ändern

## 1.Hinweise

Bitte ändern Sie das Weckwort in einer ruhigen Umgebung; eine laute Umgebung beeinträchtigt die Erkennungsgenauigkeit des Sprachinteraktionsmoduls.

Beim Sprechen eines Eintrags sollte die Stimme laut sein und das Sprechtempo nicht zu hoch; es wird empfohlen, einen Abstand von höchstens 5 Metern zum Modul einzuhalten.

## 3.Weckwort ändern

Sprechen Sie „你好，小犀“ zum Sprachinteraktionsmodul, um es aufzuwecken; wenn das Modul mit „我在“ antwortet, befindet es sich im erkennungsbereiten Zustand. Sprechen Sie dann den Eintrag „学习唤醒词“ zum Sprachinteraktionsmodul; das Modul antwortet mit „说出唤醒词“, und Sie gelangen in den Lernmodus für das Weckwort. Sprechen Sie anschließend das gewünschte Weckwort zum Sprachinteraktionsmodul; das Weckwort sollte möglichst kurz sein – hier wird als Beispiel „你好，小犀“ eingestellt. Wenn das Sprachinteraktionsmodul erfolgreich erkannt hat, wird „学习成功“ angesagt, was bedeutet, dass das Weckwort erfolgreich geändert wurde; von nun an können Sie das Modul mit dem Eintrag „你好小犀“ aufwecken.

Hinweis: Das Weckwort „你好，小犀“ in der Werks-Firmware ist das grundlegende Weckwort und kann nicht per Sprache geändert oder gelöscht werden. Von Benutzern per Sprache geänderte Weckwörter können nur jeweils einzeln existieren und bestehen gemeinsam mit dem grundlegenden Weckwort.

Sprechen Sie „你好，小犀“ zum Sprachinteraktionsmodul, um es aufzuwecken; wenn das Modul mit „我在“ antwortet, befindet es sich im erkennungsbereiten Zustand. Sprechen Sie dann den Eintrag „学习停车指令“ zum Sprachinteraktionsmodul; das Modul antwortet mit „请说指令“, und Sie gelangen in den Lernmodus für Befehlswörter. Sprechen Sie anschließend das gewünschte Befehlswort zum Sprachinteraktionsmodul; das Befehlswort sollte möglichst kurz sein – hier wird als Beispiel „前方停车“ festgelegt. Wenn das Sprachinteraktionsmodul erfolgreich erkannt hat, wird „学习成功“ angesagt, was bedeutet, dass das Befehlswort erfolgreich geändert wurde; von nun an können wir mit dem Eintrag „前方停车“ dieselbe Wirkung erzielen wie mit dem Befehlswort „停车“. Wenn der Eintrag „前方停车“ gelöscht werden soll, sagen Sie einfach „删除停车指令“; wenn mit „删除成功“ geantwortet wird, ist das Löschen des Eintrags abgeschlossen (hier wird nur „前方停车“ gelöscht, nicht „停车“).

Hinweis: Die Befehlswörter in der Werks-Firmware sind grundlegende Befehlswörter und können nicht per Sprache geändert oder gelöscht werden. Von Benutzern per Sprache geänderte Befehlswörter können nur jeweils einzeln existieren und bestehen gemeinsam mit den grundlegenden Befehlswörtern.
