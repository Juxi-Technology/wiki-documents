# Flashen der Modul-Firmware

## Methode zum Flashen der Modul-Firmware

## 1. Schritte zum Flashen des Sprachchips

## 1.1 Geräteanschluss

![Abb. 1](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/1.png)

## 1.2. Brennsoftware öffnen

Öffnen Sie im Anhang den Ordner des Brenntools für die Sprachchip-Firmware und klicken Sie auf „PACK_UPDATE_TOOL.exe“

![Abb. 2](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/2.png)

Wählen Sie den Chip CI1302 und klicken Sie dann auf „固件升级“

![Abb. 3](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/3.png)

Nach dem Aufrufen der Oberfläche für die Firmware-Aktualisierung können Sie mit "F1" die Hilfe aufrufen

Klicken Sie auf „Auswählen“ und wählen Sie die soeben erstellte Firmware aus; suchen Sie im Anhang die Werk-Firmware „CI1302中文单麦_V00681_UART1_115200_2M“.

![Abb. 4](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/4.png)

Wählen Sie die Firmware, suchen Sie den entsprechenden Port und setzen Sie ein Häkchen im Kästchen

![Abb. 5](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/5.png)

Schieben Sie den Schiebeschalter auf die Position Download; Download steht für das Flashen der Firmware des Sprachchips (also die rechte Seite)

![Abb. 6](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/6.png)

Nachdem Sie den Schalter auf die entsprechende Position gebracht haben, drücken Sie die RST-Taste am Sprachinteraktionsmodul, um den Flashvorgang zu starten. Warten Sie, bis das Flashen erfolgreich abgeschlossen ist, und klicken Sie dann auf „退出“.

![Abb. 7](../../../../../public/images/tutorials/accessories/ai-voice-module/Firmware-Flashing/7.png)
