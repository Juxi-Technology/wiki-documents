# PC-Kommunikation

## Geräteanschluss

Schieben Sie den Schiebeschalter in den STC8-Serielle-Schnittstelle-Modus

![Abb. 1](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## Seriellen Debug-Assistenten öffnen

- Öffnen Sie Uart Assistant, wählen Sie den entsprechenden Port und die Baudrate 115200,

![Abb. 2](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- Beachten Sie die Datei 命令词播报词协议列表V1_中文 im Komprimierungspaket

![Abb. 3](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- Wenn wir „小车前进“ sagen, gibt der serielle Debug-Assistent das entsprechende Protokoll aus

![Abb. 4](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- Geben Sie gemäß der Datei 命令词播报词协议列表V1_中文 die entsprechenden Anweisungen ein; das Sprachmodul sagt dann den Text des entsprechenden Protokolls an

![Abb. 5](../../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

Sie können hören, dass das Sprachmodul normal ansagt.
