# 4K-HDMI-Capture-Karte – Tutorial

## Verkabelung

Je nach Anschluss der Hauptplatine gibt es drei Verkabelungsmöglichkeiten

**HDMI-Anschluss**——&gt;HDMI-Kabel——&gt;HDMI-Anschluss der Capture-Karte——&gt; USB/Type-C ——&gt;Notebook, PC, All-in-One, Smartphone/Tablet usw.

**Micro-HDMI-Anschluss**——&gt;Micro-HDMI-Adapter——&gt;HDMI-Kabel——&gt;HDMI-Anschluss der Capture-Karte——&gt; USB/Type-C ——&gt;Notebook, PC, All-in-One, Smartphone/Tablet usw.

**DP-Anschluss**——&gt;DP-auf-HDMI-Adapter——&gt;HDMI-Kabel——&gt;HDMI-Anschluss der Capture-Karte——&gt; USB/Type-C ——&gt;Notebook, PC, All-in-One, Smartphone/Tablet usw.
