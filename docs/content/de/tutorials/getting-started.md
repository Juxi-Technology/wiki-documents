# Schnellstart

Willkommen bei Juxi Technology! Dieses Tutorial hilft dir, unsere Produkte schnell zu nutzen.

## Vorbereitung

Bereite Folgendes vor:

- Produkthardware
- USB-Kabel
- PC (Windows/macOS/Linux)

## Schritt 1: Hardware verbinden

1. Produkt per USB-Kabel mit dem PC verbinden
2. Automatische Treiberinstallation abwarten
3. Gerät wird korrekt erkannt

## Schritt 2: Software installieren

```bash
# Abhängigkeiten installieren
npm install

# App starten
npm start
```

## Schritt 3: Loslegen

Jetzt kannst du das Produkt nutzen! Weitere Details in anderen Tutorials.
