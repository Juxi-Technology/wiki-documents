# Schnellstart

Willkommen bei JUXI! Dieses Tutorial hilft Ihnen, schnell mit unseren Produkten zu starten.

## Vorbereitung

Stellen Sie vor dem Start Folgendes bereit:

- Produkthardware
- USB-Datenkabel
- Computer (Windows/macOS/Linux)

## Schritt 1: Hardware anschließen

1. Produkt per USB-Datenkabel mit dem Computer verbinden
2. Warten, bis der Gerätetreiber automatisch installiert ist
3. Prüfen, ob das Gerät korrekt erkannt wurde

## Schritt 2: Software installieren

```bash
# Abhängigkeiten installieren
npm install
# Anwendung starten
npm start
```

## Schritt 3: Loslegen

Jetzt können Sie das Produkt nutzen! Weitere Tutorials zeigen die Details.
