# Schritt 2: Ports der seriellen Geräte anzeigen (Windows)

Öffnen Sie den `Geräte-Manager`, schließen Sie zuerst den `Folgearm` an, dann den `Führungsarm`, und sehen Sie sich die entsprechende COM-Port-Nummer an

![image.png](../../../../../../../public/images/tutorials/robot-arms/so-arm101/lerobot-02-Serial-Port-Windows/1.png)

## Meine Portnummer notieren

Folgearm：

COM6

Führungsarm：

COM7
