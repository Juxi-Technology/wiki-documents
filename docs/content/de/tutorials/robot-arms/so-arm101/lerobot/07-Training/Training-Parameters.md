# Schritt 7: Empfehlungen für Trainingsparameter

https://github.com/huggingface/lerobot/blob/main/src/lerobot/configs/train.py

Sie können den Parameter `save_freq` etwas verringern, damit das Modell nach dem Training früher erscheint

Für einfache Aufgaben (Greifen, Händeschütteln, Ablegen) sind 20K Trainingsschritte völlig ausreichend
