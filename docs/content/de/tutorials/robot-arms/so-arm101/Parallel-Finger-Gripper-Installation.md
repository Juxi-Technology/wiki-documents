**Feetech-Servo-Debug-Tool herunterladen**

- Windows-Computer

https://gitee.com/ftservo/fddebug

Laden Sie [`FD1.9.8.5(250729).7z`](https://gitee.com/ftservo/fddebug/blob/master/FD1.9.8.5(250729).7z) herunter, entpacken Sie es und führen Sie die darin enthaltene exe-Datei aus

- Ubuntu-Computer

https://github.com/Kotakku/FT_SCServo_Debug_Qt

1. Öffnen Sie das Feetech-PC-Debug-Tool, wählen Sie die COM-Portnummer, die Baudrate beträgt eine Million, und klicken Sie auf „Öffnen“

2. Klicken Sie auf „Suchen“; nachdem „STS3215“ erscheint, klicken Sie auf „Stopp“ und dann auf „STS3215“

3. Wählen Sie oben „Programmierung“

4. Klicken Sie auf „Mittelstellungskalibrierung“
