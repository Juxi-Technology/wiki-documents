# Feetech-Bus-Servos (SCS0009 / STS3215)

> **[Im Shop kaufen](https://www.juxitech.com/de/products/feetech-scs0009-serial-bus-servo)**

## Produktübersicht

Die Feetech-Serienbus-Servos sind das Antriebszentrum von Roboterarmen wie dem SO-ARM101. Sie unterstützen das **SCS-Kommunikationsprotokoll** und verbinden mehrere Servos an einem Bus. Zwei Versionen (Magnetencoder STS / Potentiometer SCSCL) mit FD-Host-Debugging unter Windows.

**Kernfunktionen**:

- Serienbus-Kommunikation, mehrere Servos an einem Bus
- Magnetencoder (STS) / Potentiometer (SCSCL) Versionen
- Echtzeit-Feedback für Position/Geschwindigkeit/Drehmoment
- Vollständige Speichertabellen-Dokumentation
- Duale Kommunikation: TTL (schnell) / RS485 (störfest)
- Bis zu 254 Servos pro Bus (ID 0-253, Broadcast ID 254)
- Standard 1M Baud, 8 Datenbits, 1 Stoppbit
- Überhitzungs-/Überspannungs-/Überstrom-/Überlastschutz
- FD-Host-Debugging (Windows)
