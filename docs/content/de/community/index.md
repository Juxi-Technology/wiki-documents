## So können Sie beitragen

### 1. Tutorials schreiben

Teilen Sie Ihre Erfahrungen mit dem SO-ARM101, indem Sie Tutorials schreiben, die anderen helfen.

**Einstieg:**
- Ein Thema wählen (Anwendungsszenarien, technische Vertiefungen usw.)
- Der bestehenden Tutorial-Struktur folgen
- Einen Pull Request einreichen

### 2. Dokumentation übersetzen

Helfen Sie uns, die Dokumentation in weitere Sprachen zu übersetzen, damit mehr Nutzer davon profitieren.

**Aktuelle Sprachen:** Vereinfachtes Chinesisch / Englisch / Traditionelles Chinesisch

### 3. Anwendungsfälle einreichen

Teilen Sie Ihre Anwendungsfälle und präsentieren Sie Ihre Projektergebnisse. Siehe [Erfolgsgeschichten](/de/cases/).

### 4. Probleme melden

Einen Fehler entdeckt oder einen Verbesserungsvorschlag? Reichen Sie ein Issue ein, damit wir uns verbessern können.

### 5. Code beitragen

Tragen Sie Code zu verwandten Open-Source-Projekten bei, einschließlich LeRobot.
