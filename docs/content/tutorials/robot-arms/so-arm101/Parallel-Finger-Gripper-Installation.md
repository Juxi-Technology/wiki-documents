# Parallel Finger Gripper Installation

[Onshape](https://cad.onshape.com/documents/96518c699fd03eea508b06d3/w/d5f95a6266b027d84ae48634/e/317bed52afdde5ea3dcfc236) to view the model files

**Parallel Finger Gripper Installation Steps.mp4**（平行指夹爪安装步骤.mp4，体积超过站点单文件上限，可向 support@juxitech.com 索取）

![8.png](../../../../public/images/tutorials/robot-arms/so-arm101/Parallel-Finger-Gripper-Installation/1.jpg)

## 1. Unscrew the four small screws and remove the back cover

## 2. Use five screws to mount servo #6 on the coupling

## 3. Use the Feetech host software and click center calibration (keep the gripper closed!)

**Download the Feetech servo debugging tool**

- Windows

https://gitee.com/ftservo/fddebug

Download [`FD1.9.8.5(250729).7z`](https://gitee.com/ftservo/fddebug/blob/master/FD1.9.8.5(250729).7z), extract it, and run the exe program inside

- Ubuntu

https://github.com/Kotakku/FT_SCServo_Debug_Qt

1. Open the Feetech host debugging tool, select the COM port, set the baud rate to one million, and click "Open"

2. Click "Search"; once "STS3215" appears, click "Stop" and then click "STS3215"

3. Select "Programming" at the top

4. Click "Center Calibration"

## 4. Align the cylinder and install the back cover

## 5. Screw back the four small screws

## 6. Use four small screws to install the servo mount

## 7. Use 6 small screws to install the servo mount that can hold the camera bracket

## 8. Use 4 washer screws to mount the camera on the bracket

## 9. Use 2 small screws to connect the camera bracket to the servo mount

## 10. Install the adapter on the horn of servo #5

## 11. Connect the adapter to the parallel finger gripper
