# Remote File Transfer

## 1. MobaXterm

MobaXterm is a powerful remote tool that integrates remote tools such as SHH, VNC, and FTP.

## 2. MobaXterm Installation

Official website: [https://mobaxterm.mobatek.net/](https://mobaxterm.mobatek.net/)

![Image 1](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/1.png)

### 2.1. Download MobaXterm

Choose the free version to download:

![Image 2](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/2.png)

Choose the installable version to download:

![Image 3](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/3.png)

### 2.2. Install MobaXterm

Extract the compressed package downloaded from the official website, and open the `MobaXterm_installer_24.4.msi` file to install:

![Image 4](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/4.png)

Agree to the agreement:

![Image 5](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/5.png)

Select the software installation location: the default location is recommended

![Image 6](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/6.png)

Formal installation:

![Image 7](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/7.png)

![Image 8](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/8.png)

Complete the installation:

![Image 9](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/9.png)

## 3. Using MobaXterm

Find the `MobaXterm` icon on the desktop and open it:

![Image 10](../../../../public/images/tutorials/sensors/imu/remote-file-transfer/10.png)

## 4. MobaXterm: SSH Remote

Select `Session` → `SSH` : fill in the remote device IP and username

For example:

Default information of the Jetson board:

Username: juxi

Password: juxi

Note: When MobaXterm uses SSH remote, it will automatically use SFTP remote login in the sidebar
