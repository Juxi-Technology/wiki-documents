# 02 · HUB Function (One to Three)

> [← Back to overview](/tutorials/accessories/kvm-switch/00-Overview-and-Quick-Start) | Applies to: JUXI Technology KVM&HUB&TTL

## How to Use

**One Type-C in, three USB-A out** — with only one computer connected, the product is a standard USB HUB:

1. Connect the computer to the **PC1** (or PC2) port with a Type-C cable.
2. Plug the keyboard, mouse, USB drive, etc. into any **USB-A** port.

With two computers connected, the three USB-A ports switch between them as a group (see [01](/tutorials/accessories/kvm-switch/01-Switching-Between-Two-Computers)).

(Illustration: tutorial asset 02 – One-to-three HUB)

## What You Can Connect

| Supported | Connect directly to the computer instead |
|---|---|
| Keyboards, mice (including wireless receivers) | Portable hard drives, SSDs |
| USB flash drives | Video capture cards and other high-bandwidth devices |
| Printers, USB dongles | High-report-rate gaming peripherals (use with caution) |
| Serial modules, sensors (the TTL port is better — see 04) | |

- **Driver-free**: plug and play on Windows / macOS / Linux / Chinese domestic operating systems.
- Specification is **USB 2.0** — choose devices according to the table above.
