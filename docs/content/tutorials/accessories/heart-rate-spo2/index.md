# MAX30102 Heart Rate & SpO2 Sensor Module Usage Tutorial

This tutorial covers how to use the Juxi Technology MAX30102 heart rate & SpO2 sensor module. The module features the Maxim MAX30102 dedicated heart rate & SpO2 sensor chip, has a built-in in-house heart rate & SpO2 algorithm, can directly output heart rate, blood oxygen saturation and onboard temperature, and supports both I2C and UART communication.

## Quick Start

1. Read [Product Info](./product-info.md) first and confirm the power supply (3.3–5V) and pin definitions;
2. Just want to see data quickly: use the [Web Console Usage Tutorial](./web-console.md); just open the page in Chrome / Edge;
3. Connecting to a microcontroller: see the [Arduino Usage Tutorial](./arduino.md);
4. Connecting to a Raspberry Pi: see the [Raspberry Pi Usage Tutorial](./raspberry-pi.md);
5. Connecting to a PC: see [PC · Running Python](./pc/python.md) or the [PC GUI App](./pc/upper-computer.md).

> This product is a consumer-grade electronic sensing module and is not a professional medical device; its readings are for daily health reference only.
