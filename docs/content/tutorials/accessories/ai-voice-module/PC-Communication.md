# PC Communication

## Device Connection

Move the slide switch to STC8 serial port mode

![Image 1](../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/1.png)

## Open the Serial Debug Assistant

- Open Uart Assistant, select the corresponding serial port number, and set the baud rate to 115200,

![Image 2](../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/2.png)

- Refer to the command word / playback word protocol list V1_中文 file in the archive

![Image 3](../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/3.png)

- When we say “小车前进”, the serial debug assistant prints the corresponding protocol

![Image 4](../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/4.png)

- Enter the corresponding command according to the command word / playback word protocol list V1_中文 file, and the voice module plays back the text corresponding to the protocol

![Image 5](../../../../public/images/tutorials/accessories/ai-voice-module/PC-Communication/5.png)

You can hear the voice module playing back normally.
