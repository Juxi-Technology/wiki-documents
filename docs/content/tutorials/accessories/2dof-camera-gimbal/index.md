# 2-DOF Camera Gimbal

> **[Buy in Store](https://www.juxitech.com/products/2-dof-servo-pan-tilt-unit)**

The 2-DOF camera gimbal supports manual keyboard control as well as automatic color, face, and QR code tracking.
Hardware: 2 × SCS009 servos (pan + tilt) + CH343 serial bus driver board (default baud rate 1Mbps).
