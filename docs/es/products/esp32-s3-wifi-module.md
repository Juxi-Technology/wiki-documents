# Módulo de video WiFi ESP32-S3

> **[Comprar en la tienda](https://www.juxitech.com/es/products/esp32-s3-wifi-video-module)**

## Descripción del producto

**Características principales**:

- Cámara HD de 2 MP (1600×1200@30FPS)
- Transmisión de video WiFi en tiempo real en **doble modo AP + STA**
- Visión IA: segmentación por umbral de color + CNN ligero (color/rostro/QR)
- Actualización de firmware Type-C con un toque
- Interfaces de comunicación I2C / UART estándar PH2.0

## Especificaciones del producto

| Categoría | Especificación |
|------|------|
| Controlador principal | ESP32-S3 (oficial de Espressif, doble núcleo) |
| Cámara | CMOS de 2 MP (1600×1200@30FPS) |
| Ángulo de visión | diagonal 68°, horizontal 49,5° |
| Inalámbrico | WiFi (doble modo BT) AP/STA + antena de alta ganancia |
| Interfaces | Type-C / I2C / UART (PH2.0) |
| Tecla de función | Tecla de reinicio + tecla programable |
| Capacidad de reconocimiento | Color, rostro, QR |

## Inicio rápido

1. Buscar y conectar el punto de acceso del módulo desde el móvil/PC
2. Abrir la dirección indicada en el navegador para ver el video en vivo
