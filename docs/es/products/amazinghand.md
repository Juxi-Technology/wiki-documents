# Mano robótica AmazingHand

> **[Comprar en tienda](https://www.juxitech.com/es/products/amazinghand)**

## Resumen

Mano biónica de 5 dedos multiarticulados. Control por bus serie TTL, CAD abierto para diseños de dedos personalizados.

## Especificaciones

| カテゴリ | 仕様 |
|------|------|
| Tipo | Mano 5 dedos multiarticulados |
| Control | Bus serie TTL |
| Ecosistema | Python SDK, ROS |
| Open source | CAD/código abiertos |

## Inicio rápido

```bash
git clone https://github.com/Juxi-Technology/AmazingHand.git
cd AmazingHand
pip install -r requirements.txt
python examples/basic_control.py
```
