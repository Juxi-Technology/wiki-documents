# Conexión de hardware

Este capítulo describe en detalle la conexión de hardware de los productos.

## Interfaces

El producto incluye las siguientes interfaces:

- USB-C: alimentación y transferencia de datos
- GPIO: entradas/salidas de uso general
- HDMI: salida de video

## Pasos de conexión

1. **Conectar la alimentación**: usar un cable USB-C para conectar la corriente
2. **Conectar periféricos**: conectar otros periféricos según sea necesario
3. **Encender**: pulsar el botón de encendido para iniciar el dispositivo

## Notas

- Asegurarse de que la tensión de alimentación cumpla los requisitos
- Evitar conectar/desconectar dispositivos GPIO con el equipo encendido
