# Conexión de hardware

Guía detallada de conexión de hardware del producto.

## Interfaces

- USB-C: alimentación y datos
- GPIO: entradas/salidas generales
- HDMI: salida de vídeo

## Pasos de conexión

1. **Alimentación**: conectar cable USB-C
2. **Periféricos**: conectar según necesidad
3. **Encender**: pulsar el botón de encendido

## Precauciones

- Verificar la tensión de alimentación
- No conectar/desconectar dispositivos GPIO con corriente
