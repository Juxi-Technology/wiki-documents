鉅犀科技機器人與 AI 硬體產品的開放文檔平台。涵蓋機器人機械臂、傳感器、配件及開發者指南。

🌐 **[wiki.juxitech.com](https://wiki.juxitech.com/)**

## 本地開發

```bash
npm ci
npm run docs:dev   # http://localhost:5173
```

## 構建

```bash
npm run docs:build      # 生產構建到 docs/.vitepress/dist
npm run docs:preview    # 預覽生產構建
```
